## 1. この型とは何か

### 概要

「ランキング形式動画」は、以下の構造を持つSNS動画です：

```
女性の声：キーワードを読み上げる（「ChatGPT」「NISA」など）
男性の声：評価を下す（「論外」「3位」など）+ 理由説明
最後にCTA：「好きな〇〇をコメントで教えてね」→ 特典DM配布
```

### 特徴

| 要素 | 内容 |
|------|------|
| 尺 | 60〜90秒 |
| 形式 | 男女掛け合い |
| 構造 | 論外 → ランキング → 1位 → CTA |
| 目的 | コメント獲得 → 特典DM配布 → リスト構築 |

### この型の強み

- **視聴完了率が高い**: 1位を見るまで離脱できない構造
- **コメント率が高い**: 思考コスト0のCTA設計
- **再現性が高い**: 型に沿えば誰でも作れる

## 2. ターゲット分析

この型の投稿は、特定のターゲットに最適化されています。
ターゲットを理解することで、ツール選定・説明の解像度・金額設定が決まります。

### 2.1 ペルソナ

#### 基本属性

| 項目 | 内容 |
|------|------|
| **年齢** | 25〜45歳 |
| **職業** | 会社員、主婦、パート、フリーター |
| **居住** | 都市部〜地方（在宅で完結する副業に興味） |
| **SNS利用** | Instagram、TikTokをよく見る |

#### ITリテラシー

| レベル | 説明 |
|--------|------|
| **AIリテラシー** | ChatGPTは知っているが「使いこなせていない」 |
| **技術リテラシー** | プログラミング不可。「〜するだけ」が限界 |
| **情報収集** | SNS中心。公式ドキュメントは読まない |
| **学習意欲** | 低い。「教えてもらいたい」「正解を知りたい」 |

#### 収入・目標

| 項目 | 内容 |
|------|------|
| **現在の収入** | 本業で生活はできている |
| **副業経験** | なし or 失敗経験あり |
| **目標収入** | 月10万〜100万（副業レベル） |
| **動機** | 「今の生活を少し良くしたい」「贅沢したい」 |

#### 心理特性

| 特性 | 説明 |
|------|------|
| **決断力** | 低い。「正解を教えてほしい」 |
| **行動力** | 低い。「簡単なら始める」 |
| **継続力** | 低い。「すぐ結果が出るもの」を好む |
| **信頼対象** | SNSのインフルエンサー |

### 2.2 ターゲットの悩み

サンプル投稿内で言及されている悩み：

```
「何から始めたらいいかわからない」
「映え写真がないから投稿できない」
「寝起きすっぴんでも理想の自分になりたい」
「今から生活を変えたい」
「難しいのは無理」
```

### 2.3 ターゲットの行動パターン

```
1. SNS（Instagram/TikTok）で情報収集
2. 「稼げる」「簡単」というワードに反応
3. コメントで特典をもらう文化に慣れている
4. 複数のインフルエンサーの投稿を見比べている
5. 「これだ」と思ったら行動するが、続かない
```

### 2.4 ターゲットの「信念」（否定されるもの）

ターゲットは以下のような「信念」を持っている。これを「論外」で否定する。

| 信念 | 情報源 |
|------|--------|
| 「ChatGPTが最強」 | 一般的なAI認知 |
| 「NISAが正解」 | テレビ・メディア |
| 「LINEスタンプで稼げる」 | 他のインフルエンサー |
| 「ASMR動画が稼げる」 | 過去のトレンド情報 |

**ポイント**: 他のインフルエンサーやメディアの情報を鵜呑みにしている。

### 2.5 ターゲットが求めているもの

#### 求めているもの

| 項目 | 具体例 |
|------|--------|
| **正解** | 「これをやればいい」という明確な答え |
| **簡単さ** | 「〜するだけ」「1分で」「誰でも」 |
| **即効性** | 「初月で収益化」「すぐに結果が出る」 |
| **安心感** | 「〇万人が使っている」「公式」 |
| **手取り足取り** | プロンプト集、使い方ガイド、作り方マニュアル |

#### 求めていないもの

| 項目 | 理由 |
|------|------|
| 技術的な深い知識 | 理解できない、面倒 |
| 長期的な投資 | 今すぐ結果が欲しい |
| 自分で考えること | 正解を教えてほしい |
| 難しいツール | 「〜するだけ」で済むもの以外は無理 |

### 2.6 投稿設計への示唆

#### ツール選定の基準

| 基準 | 説明 |
|------|------|
| **操作難易度** | 「〜するだけ」で説明できるもの |
| **初期コスト** | 無料 or 安価（月1,000円以下） |
| **日本語対応** | 英語UIは避ける（または「日本語で使える」と補足） |
| **即効性** | 「1分で」「30秒で」結果が出る |

#### 説明の解像度

| NG | OK |
|----|-----|
| 「APIキーを取得して設定」 | 「登録するだけ」 |
| 「プロンプトエンジニアリング」 | 「このプロンプトをコピペ」 |
| 「ワークフローを構築」 | 「10分で設定完了」 |
| 「OAuth認証を通す」 | 「ログインするだけ」 |

#### 金額の設定

| 金額 | 使い方 |
|------|--------|
| 月10万〜20万 | 下位ランク（手堅い） |
| 月30万〜50万 | 中位ランク（夢がある） |
| 月100万 | 1位（目標・憧れ） |

#### 特典の設計

**ターゲットが欲しいもの**:
- 「そのまま使える」プロンプト集
- 「コピペでOK」のテンプレート
- 「見ながらやれば完成」のマニュアル

**ターゲットが欲しくないもの**:
- 概念の説明
- 原理の解説
- 応用のヒント

## 3. なぜこの型がバズるのか

### 3.1 認知的不協和（冒頭3秒）

**原理**: 人は「自分の信念」と「新しい情報」が矛盾すると不快感を感じ、その不快感を解消するまで離脱できない。

```
視聴者の信念：「ChatGPTが最強」
        ↓
動画の冒頭：「ChatGPT？論外」
        ↓
認知的不協和（不快感）が発生
        ↓
「なぜ論外なの？」を知りたくて続きを見る
```

**ポイント**: 視聴者が「当たり前」と思っているものを否定する。

### 3.2 ツァイガルニク効果（ランキング構造）

**原理**: 人は「未完了のタスク」を完了させたい本能がある。

ランキング形式 = 「1位を見るまで未完了」
→ 1位を見るまで離脱できない。

### 3.3 順番シャッフル（予測の裏切り）

**原理**: 予測できると脳が省エネモードになり、離脱しやすくなる。

```
❌ 単純な昇順：4位→3位→2位→1位（予測可能）
✅ シャッフル：論外→3位→4位→2位→1位（予測不可能）
```

**ルール**:
- 1位は必ず最後（これだけは絶対）
- 論外の直後は、論外と関連するツールを紹介
- 残りの順番はシャッフル

### 3.4 数字の3つの心理効果

| 役割 | 訴える心理 | 例 |
|------|------------|-----|
| **目標提示** | 欲望（欲しい） | 「月100万」「日給3万」 |
| **証拠提示** | 信頼（本当だ） | 「2.1億再生」「52%が初月収益化」 |
| **障壁除去** | 安心（できそう） | 「30秒で」「1分で」 |

3つ揃うと「欲しい」→「本当だ」→「できそう」の流れが完成。

### 3.5 断定の心理効果

**原理**: 情報過多の時代、人は自分で判断することに疲れている。「これが正解」と断定してくれる人を信頼する。

```
❌ 「ChatGPTはあまりおすすめしません」（弱い）
✅ 「ChatGPT？論外」（断定）
```

### 3.6 CTA設計（思考コスト0）

**原理**: コメントの障壁を極限まで下げる。

```
「好きな〇〇を教えてね」
```

- 正解がない → 何を書いても間違いじゃない
- 1-2語で済む → 「冬」「犬」で完了
- 考える必要がない → 衝動的にコメントできる

## 4. 台本作成フロー

### 4.0 この型の本質

#### 再現性が極めて高い理由

| 要素 | クリエイティブ性 |
|------|------------------|
| 再生数 | ❌ 他人の動画から取ってくる（調べるだけ） |
| 収益 | ❌ 「推定」として表示（計算すればいい） |
| ランキング構成 | ❌ 型に沿って並べるだけ |
| 台本 | ❌ テンプレートに当てはめるだけ |
| CTA | ❌ エルグラムで反応しやすいものを都度考える |

**クリエイティブな箇所がほとんどない。完全に「型」。誰でも作れる。**

#### 数字の扱い方

| 項目 | 出典 | 表現 |
|------|------|------|
| 再生数 | **他人の動画**から取得 | 「〇万再生」（事実） |
| 収益 | **推定**として表示 | 「推定収益はこのくらい」（画面表示） |

**投稿者自身の実績は不要。他人の成功事例を引用するだけ。**

#### マーケティングの本質

```
投稿で見せるもの    : 「〇〇で稼げる」「〇〇が便利」
ターゲットが期待    : 「稼ぎ方を教えてもらえる」
実際に提供するもの  : 「ツールの使い方」（プロンプト + 基本手順）
```

- ターゲットは「稼げる」「便利」と思って食いつく
- 特典で「ツールの使い方」を受け取る
- **「稼ぎ方」は一切教えていない**
- 講座 = ツールの使い方 → 特典と完全に一致

### 4.1 パターンを選ぶ

| パターン | フック | 例 |
|----------|--------|-----|
| **副業系** | 「稼げる」 | 月〇万、日給〇万 |
| **ツール系** | 「便利」「効率化」 | 30秒で完成、一瞬で |

### 4.2 リサーチフローと参照先

#### 【重要】参照すべき成果物

**`C:\Instagram_AI\YYYYMMDD_XX\step1_influencer_data.json`（最新のディレクトリ）を参照する。**

#### 抽出ロジック

**目標：12本の投稿を作成する**

```
Step 1: step1_influencer_data.json のタイトルを分析
        ↓
Step 2: ユースケース（ニーズ）を抽出
        例：資料作成、画像生成、業務自動化、SNS運用、音楽生成...
        ↓
Step 3: 出現頻度をカウント
        ⚠️ 重要：出現頻度が高い ≠ 視聴者が食いつく
        ↓
Step 4: ニーズの中から「食いつく」要素を見つける
        - 「稼げる」に繋がるか
        - 「簡単」「時短」で訴求できるか
        - ターゲットの悩みを解決するか
        ↓
Step 5: 12本分のテーマを決定
        テーマはニーズそのままでOK
        中で「食いつく」要素を入れる
```

#### 【重要】出現頻度 ≠ 食いつく

| 出現頻度 | 視聴者の反応 | 例 |
|----------|-------------|-----|
| 高い | 必ずしも食いつくわけではない | 資料作成（ビジネスマン向け） |
| 低い | 食いつく可能性がある | 音楽生成×収益化（Suno × Spotify） |

**インフルエンサーが多く発信している ≠ 視聴者が食いつく**

#### テーマはニーズそのままでOK

サンプル5本は別々のインフルエンサーが投稿しているが、**「型」は全く同じ**。

| サンプル | テーマ（ニーズ） | 中で入れた「食いつく」要素 |
|----------|------------------|---------------------------|
| 1 | AIツール | 「寝起きすっぴんでも30秒で理想の自分」 |
| 2 | AI副業 | 「月100万」「日給3万」「52%が初月収益化」 |
| 3 | AI副業収益 | 「月100万」「9000万再生」 |
| 4 | SNS運用 | 「映え写真がないから投稿できひん」を解決 |
| 5 | AI動画ジャンル | 「月100万」「2.1億再生」 |

**テーマを「稼げる系」に変える必要はない。テーマはそのままで、中で「食いつく」要素を入れる。**

#### 特典ネタの3つのソース

| ソース | 内容 | メリット |
|--------|------|----------|
| **リサーチ結果（ニーズ）** | 今求められているユースケース | 需要が高い |
| **講座コンテンツからの切り出し** | 既存講座を再利用 | 新規作成不要、検証済み |
| **独自調査** | 自分で発見したノウハウ | 競合と差別化できる |

### 4.3 パターンに応じてリサーチ

#### 副業系の場合

```
Step 1: step1のタイトルからユースケースを抽出
        → 「稼げる」に繋がるものを探す

Step 2: そのユースケースで稼げそうな副業をリサーチ
        → トレンドを確認
        → ターゲットが食いつくものを選ぶ

Step 3: 他人の成功事例を収集
        → 再生数を取ってくる（事実）
        → 収益は「推定」として表示
```

#### ツール系の場合

```
Step 1: step1のタイトルからユースケースを抽出
        → ターゲットの悩みに繋がるものを探す

Step 2: そのユースケースを解決できるツールをリサーチ
        → 「映え写真がない」「時短したい」など

Step 3: 悩みを解決できるツールをピックアップ
        → 「食いつく」要素が入れやすいものを1位に
```

### 4.5 台本の準備項目

台本を書く前に、以下の項目を決めます。

#### ターゲットの「今の信念」を特定する

**質問**: ターゲットが「当たり前」「正解」と思っていることは何か？

**見つけ方**:
1. ターゲットが日常的に使っているツール/サービス
2. メディアで「おすすめ」と紹介されているもの
3. 多くの人が「これでいい」と思っているもの

**例**:
| ジャンル | ターゲットの信念 |
|----------|------------------|
| AIツール | 「ChatGPTが最強」 |
| 投資 | 「NISAが正解」 |
| 副業 | 「LINEスタンプで稼げる」 |
| Instagram自動化 | 「ManyChatが最強」 |

#### 「論外」にするものを決める

ターゲットの信念を「論外」として否定します。

**否定の理由を1つ決める**（端的に言えるもの）:
- 「時代遅れ」
- 「無料版だと制限が厳しい」
- 「実際は稼げない」
- 「設定が複雑」

#### ランキング項目を決める（4〜5個）

1位に推したいものを決め、そこから逆算して他のランクを決めます。

**設計の流れ**:
```
Step 1: 1位を決める（最も推したいもの）
Step 2: 論外を決める（ターゲットの信念）
Step 3: 論外の弱点を補うものを決める（論外直後に紹介）
Step 4: 残りを埋める（2〜3個）
```

#### 順番を決める

**ルール**:
1. **1位は必ず最後**
2. **論外の直後は関連ツール**（論外の弱点を補うもの）
3. **残りはシャッフル**

**例**:
```
論外: ChatGPT（画像生成が弱い）
  ↓
3位: Nano Banana（画像生成に強い）← 論外の弱点を補う
4位: Claude
2位: Google AI Studio
1位: Genspark
```

#### CTAキーワードを決める

エルグラムで反応しやすいキーワードを都度考える。

| 種類 | 例 | 特徴 |
|------|-----|------|
| 季節系 | 好きな季節 | 4択で答えやすい |
| 食べ物系 | 今日何食べた | 誰でも答えられる |
| 動物系 | 好きな動物 | ポジティブ |
| アニメ系 | 好きなアニメ | ターゲット層に刺さる |

**ポイント**: 投稿内容と無関係でOK。コメントしやすさ優先。

## 5. 台本作成手順

### Step 1: 冒頭フック（3秒）

```
女性：[ターゲットの信念キーワード]
男性：論外。[1文で否定理由]。
```

**例**:
```
女性：ChatGPT。
男性：うーん、論外。時代遅れです。
```

**チェック**:
- [ ] ターゲットの信念を否定しているか
- [ ] 「論外」など強い否定ワードを使っているか
- [ ] 理由は1文で端的か

### Step 2: 論外の補足 + 関連ツール紹介（10秒）

論外の理由をもう少し詳しく説明し、その弱点を補うツールを紹介します。

```
男性：[論外の詳しい理由。2-3文]
      [弱点を補うツール]なら[できること]。
      [特典チラ見せ：このプロンプトを使えば〜]
      ってことで、[ツール名]は3位。
```

**例**:
```
男性：確かに最近までは「ChatGPTだけ使っとけばOK」という風潮がありました。
      でも今はリサーチ、文章作成、画像生成、全部ChatGPTより優秀なAIが出ています。
      例えば画像生成なら、NanoBanana一択です。
      こんな感じで自分の髪型や服装を自由に変えられます。
      このプロンプトを使えば、寝起きすっぴんでも30秒で理想の自分になれます。
      ということで、NanoBananaは3位。
```

**チェック**:
- [ ] 論外の理由を補足しているか
- [ ] 論外の弱点を補うツールを紹介しているか
- [ ] 特典のチラ見せ（効果の先出し）があるか
- [ ] 順位は昇順ではなくシャッフルされているか

### Step 3: 残りのランキング紹介（各10秒）

**構造**:
```
女性：[ツール名]
男性：[順位]。[何ができるか1-2文]。[証拠の数字]。[簡単さ1文]。
```

**例**:
```
女性：Claude。
男性：4位です。
      ChatGPTより長文や論理的な文章に強いので、台本作成で愛用しています。
      このプロンプトを送れば、バズるリールを量産してくれます。
```

**チェック**:
- [ ] [機能] → [証拠] → [簡単さ] の流れになっているか
- [ ] 順番はシャッフルされているか（昇順ではない）
- [ ] 特典のチラ見せを入れているか（任意）

### Step 4: 中盤の論外（任意・5秒）

中だるみ防止のため、中盤に別の「論外」を挿入します。

```
女性：[別の有名キーワード]
男性：論外。[1文で理由]。
```

**例**:
```
女性：Lofi音楽。
男性：論外！
      作業用BGMを流すこんな動画は、1億再生超えもあるんだけど、
      今はもうこのコンテンツ自体制限がかかってしまい、収益化できなくなりました。
```

### Step 5: 1位の紹介（15秒）

**必ず最後に配置**。最も詳しく説明します。

```
女性：[ツール名]
男性：これ、圧倒的1位。[何ができるか2-3文]。
      [証拠の数字]。[簡単さ1-2文]。
```

**例**:
```
女性：Genspark。
男性：1位です。

      リサーチも出典を明記してくれるので、ChatGPTより精度が高いです。

      困ったらとりあえずお願いすれば何でもやってくれるので、現時点で最強AIです。
```

**チェック**:
- [ ] 他のランクより詳しく説明しているか
- [ ] 「圧倒的」「最強」「一択」など断定ワードがあるか
- [ ] 証拠の数字と簡単さの両方があるか

### Step 6: CTA（5秒）

```
男性：今日紹介した[具体的な内容]の[特典形式]をまとめました。
      欲しい人は[好きな〇〇]をコメントで教えてください。
```

**例**:
```
男性：今日紹介したプロンプトと、Gensparkを初心者でも使えるように資料にまとめました。
      受け取りたい人は「好きな季節」をコメントで教えてください。
```

**チェック**:
- [ ] 特典の内容が具体的か
- [ ] コメントキーワードは1-2語で答えられるか
- [ ] 「教えてください」など柔らかい言い方か

## 6. 言葉選びのルール

### 6.1 口調ルール

| ルール | 説明 |
|--------|------|
| ですます調 | 全体を通して丁寧語で統一 |
| 「ですよ」「ますよ」禁止 | 上から目線になるため |
| バージョン番号はサラッと | 「最新のGemini 3は〜」程度。メインは「Gemini」でOK |

### 6.2 使うべき断定ワード

| カテゴリ | ワード |
|----------|--------|
| 否定 | 論外、オワコン、時代遅れ、微妙 |
| 肯定 | 一択、最強、確実に、圧倒的 |
| 限定 | これだけ、唯一、〜しかない |

### 6.3 避けるべき言葉

| NG | なぜダメか | 代替 |
|----|------------|------|
| 「〜かもしれない」 | 不確実 | 「〜です」 |
| 「〜と思います」 | 自信がない | 「〜です」 |
| 「個人的には」 | 責任回避 | 削除 |
| 「おすすめかも」 | 曖昧 | 「おすすめです」 |
| 「〜ですよ」「〜ますよ」 | 上から目線 | 「〜です」「〜ます」 |

## 7. 完成前チェックリスト

### 構造チェック

- [ ] 冒頭3秒で「論外」など強い否定があるか
- [ ] 論外の直後に関連ツールを紹介しているか
- [ ] 順番はシャッフルされているか（昇順ではない）
- [ ] 1位は必ず最後に配置されているか
- [ ] CTAは最後にあるか

### 数字チェック

- [ ] 目標の数字（月〇万、日給〇万）があるか
- [ ] 証拠の数字（〇万再生、〇%）があるか
- [ ] 障壁除去の数字（〇秒で、〇分で）があるか

### 特典チェック

- [ ] 動画内で特典の「効果」をチラ見せしているか
- [ ] 「このプロンプトを使えば〜」など効果を先出ししているか
- [ ] CTAで特典の存在を伝えているか

### 言葉チェック

- [ ] 「〜かもしれない」を使っていないか
- [ ] 「〜と思います」を使っていないか
- [ ] 断定ワード（論外、一択、最強）を使っているか

### CTAチェック

- [ ] コメントキーワードは1-2語で答えられるか
- [ ] 正解がない質問か（何を書いても間違いじゃない）
- [ ] 「教えてね」など柔らかい言い方か

## 8. よくある失敗と対策

### 失敗1: 冒頭が弱い

```
❌ 「ChatGPTはあまりおすすめしません」
✅ 「ChatGPT？論外。時代遅れです」
```

**対策**: 「論外」「オワコン」など強い否定ワードを使う。

### 失敗2: 順番が単純な昇順

```
❌ 論外→4位→3位→2位→1位（予測可能）
✅ 論外→3位→4位→2位→1位（予測不可能）
```

**対策**: 1位以外はシャッフルする。

### 失敗3: 数字がない

```
❌ 「すごく再生されています」
✅ 「2.1億回再生されています」
```

**対策**: 目標・証拠・障壁除去の3種類の数字を入れる。

### 失敗4: 特典のチラ見せがない

```
❌ CTA「プロンプト集をまとめました」（いきなり）
✅ 動画内「このプロンプトを使えば30秒で〜」→ CTA「プロンプト集をまとめました」
```

**対策**: 動画内で特典の効果を先に見せ、欲求を作ってからCTAで刈り取る。

### 失敗5: CTAが難しい

```
❌ 「このツールについてどう思いますか？」（考える必要がある）
✅ 「好きな季節をコメントで教えてね」（考える必要がない）
```

**対策**: 1-2語で答えられる、正解がない質問にする。

### 失敗6: 曖昧な言葉を使う

```
❌ 「個人的にはこれがおすすめかもしれません」
✅ 「これ、圧倒的1位です」
```

**対策**: 断定する。迷いを見せない。

### Suno講座の場合
