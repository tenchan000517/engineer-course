---

## 1. このRAGの使い方

### 台本を書くときの視点

このRAGは「何ができるか」ではなく、**「何に困っていたか」→「だから作った」→「結果こうなった」**というストーリーで書いている。

視聴者は「機能」に興味がない。**「自分の困りごとが解決するか」**に興味がある。

### フックの作り方

| NG | OK |
|----|-----|
| 「〇〇ができます」 | 「〇〇で困ってませんか？」 |
| 「〇〇を自動化しました」 | 「〇〇を毎回手動でやってませんか？」 |
| 「コピペだけでできます」 | 「僕も昔これで地獄だったんですが」 |

**「コピペだけ」は結果であって、フックじゃない。フックは困りごと。**

---

## 2. アイデンティティ: 仕組み化のプロ

### 定義

**ツール紹介者ではない。AIエンジニアでもない。**

```
自分が困っていたことを仕組み化し、
誰でも再現できる形にして、
「できない→できる」の変化を提供する
```

「このツールすごいでしょ」ではなく、
「僕もこれで困ってたけど、この仕組みで解決した。あなたも使っていい」を見せる。

### 証拠: 2つのプロジェクト

| プロジェクト | 困っていたこと | 作った仕組み |
|-------------|--------------|-------------|
| **Engineer Course** | 動画編集で毎回同じ作業に何時間もかかってた | 台本書くだけで自動で完成動画 |
| **Work Manual** | HP制作の情報整理が地獄だった | フォーム入力だけでHP納品まで自動 |

## 3. 虫・鳥・魚の視点

| 視点 | 定義 | 使い方 |
|------|------|--------|
| **虫の目** | 細部に入り込む。1つの「これすごい！」を深掘り | 小ネタ系動画に最適 |
| **鳥の目** | 全体を上から見る。パイプライン全体 | 「〇〇から△△まで自動」系動画 |
| **魚の目** | 流れを泳ぎ切る。入力から出力まで本当に辿り着けるか | 「この仕組みで完成する」証明系動画 |

**注意:** 魚の目はトレンドやニュースではない。**システム全体の流れを見て、ゴールに辿り着けるかどうかの視点。**

## 5. テーマ選定の考え方

### どの視点を選ぶか

| 動画の目的 | 選ぶ視点 | 例 |
|-----------|---------|-----|
| 「え、これできるの？」と驚かせたい | 虫の目 | メニューからワンクリックで実行 |
| 「この流れで自動化」を見せたい | 鳥の目 | 台本書くだけで自動で完成動画 |
| 「本当に完成する」を証明したい | 魚の目 | フォーム入力だけでHP納品まで |

### フックが自然に出てくるか確認

テーマを選んだら、フックを考える:

| パターン | 例 |
|---------|-----|
| 困りごと型 | 「〇〇で困ってませんか？」 |
| 共感型 | 「僕も昔これで地獄だったんですが」 |
| 疑問型 | 「〇〇、毎回手動でやってませんか？」 |

**フックが自然に出てこないテーマ = 自分が本当に困っていなかった証拠。**

### 3ステップに凝縮できるか確認

どんな仕組みも3ステップで説明できる。説明できないなら、テーマとして不適切。

```
1. 何に困っていたか（ビフォー）
2. 何を作ったか（仕組み）
3. どうなったか（アフター）
```

### ステップは最低3つ

**2ステップしかないテーマはステップバイステップにする意味がない。**

| NG | なぜNG |
|----|-------|
| 「コピペして実行」 | 2ステップしかない。動画にする価値がない |
| 「開いて入力」 | 2ステップしかない。当たり前すぎる |

3ステップに分解できないテーマは:
- そもそもシンプルすぎる（動画にする価値がない）
- または説明の仕方が間違っている（もっと分解できるはず）

## 6. NG例（今日の失敗から学ぶ）

### 内輪ネタを使ってしまった

| NG | なぜNG | OK |
|----|-------|-----|
| 「F5で完成」 | 視聴者は「F5って何？」 | 「ボタン1つで完成」「自動で完成」 |
| 「narration.txt」 | ファイル名は内輪ネタ | 「台本」 |
| 「placement.json」 | 技術用語 | 「配置データ」 |
| 「GASを開く」 | 「GASって何？」となる | 「スクリプトを開く」 |

### 結果だけ言ってしまった

| NG | なぜNG | OK |
|----|-------|-----|
| 「コピペだけでできます」 | コピペできるのは作ったから | 「僕が作ったコードをコピペするだけ」 |
| 「1クリックで完成」 | なぜ1クリックなのか不明 | 「毎回手動でやってたのが1クリックになった」 |
| 「自動化しました」 | 何が自動化されたか不明 | 「〇〇を毎回やってたのが自動になった」 |

### 曖昧なステップを言ってしまった

| NG | なぜNG | OK |
|----|-------|-----|
| 「台本を書きます」 | どうやって書くの？ | 「キャプションにあるプロンプトを使って台本を生成します」 |
| 「画像を作ります」 | どうやって作るの？ | 「〇〇で、キャプションにあるプロンプトを使って画像を生成します」 |
| 「設定します」 | 何をどう設定するの？ | 「〇〇をオンにします」「〇〇に✓を入れます」 |

**ステップは視聴者が再現できる具体的な動作で書く。**

「〇〇を作ります」「〇〇を書きます」は曖昧。
→ 「キャプションにあるプロンプトを使って〇〇を生成します」なら再現できる。

**基準:** 「これを聞いて、視聴者は自分の困りごとを思い出すか？」
