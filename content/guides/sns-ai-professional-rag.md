## 2. リールの型・構成パターン

### 2.1 6つの基本型

| 型 | 特徴 | 保存率 | 適したネタ | 制作難易度 |
|----|------|--------|-----------|-----------|
| **ランキング型** | 順位づけで権威性、最後まで見させる | ★★★★★ | AIツール比較、副業ランキング | 中 |
| **比較型** | Before/After、2つを対比 | ★★★★☆ | ツール比較、ビフォーアフター | 低 |
| **アフレコ型** | 顔出し不要、AI音声活用 | ★★★★☆ | チュートリアル、解説系 | 中 |
| **図解型** | 情報密度高、保存向き | ★★★★★ | ノウハウ、仕組み解説 | 高 |
| **トーク型** | 親近感、ファン化向き | ★★★☆☆ | 体験談、共感系 | 低 |
| **Vlog型** | 日常感、ブランディング | ★★☆☆☆ | 日常、BTS | 低 |

### 2.2 ランキングリール構成

**標準構成（60秒）**:
```
[0-2秒] 女性声でツール名「ChatGPT」
[2-8秒] 男性「うーん、論外。〜なので正直微妙です」
[8-15秒] 2位ツール紹介 + 特典言及
[15-25秒] 4位ツール紹介
[25-35秒] 3位ツール紹介
[35-50秒] 1位ツール詳細 + 特典言及
[50-60秒] CTA「今日紹介した〜をまとめました」
```

**順位構成のコツ**:
- 論外: 知名度高いけど実は微妙（ChatGPT, CapCut, Canva）
- 1位: ニッチで価値あるツール（Genspark, n8n, Vrew）
- 2位: 「プロンプトを投げれば〇〇」で特典化しやすい

### 2.3 解説系リール構成（チュートリアル）

**標準構成（30-45秒）**:
```
[0-5秒] フック動画（衝撃映像）
[5-10秒] 導入「これ見たことありますか〜30秒で解説します」
[10-20秒] ステップ1「ナノバナナでプロンプトを使って〜」
[20-30秒] ステップ2「クリングで〜すれば完成です」
[30-35秒] 完成「これだけで〜ができます」
[35-45秒] CTA「今日紹介した〜ほしい人は〇〇とコメント」
```

**フックの型5選**:
1. 物体衝突型（鉄球、車）- 最もバズりやすい
2. 壁崩壊型 - インパクト大
3. 煙で瞬間移動型 - ミステリアス
4. 衣装変身型 - 親しみやすい
5. 地球ズームアウト型 - スケール感

## 4. フック・台本テクニック

### 4.1 効果実証済みフック7パターン

| # | パターン | 例 | 効果 |
|---|---------|-----|------|
| 1 | **衝撃数字** | 「月収100万達成した方法」 | 好奇心喚起 |
| 2 | **否定から入る** | 「これ、絶対やっちゃダメです」 | 緊張感 |
| 3 | **質問型** | 「これ、知ってますか？」 | 参加意識 |
| 4 | **秘密暴露** | 「誰も教えてくれない〇〇」 | 希少性 |
| 5 | **Before/After** | 「3ヶ月前の自分に教えたい」 | 変化への期待 |
| 6 | **緊急性** | 「今やらないと損します」 | FOMO |
| 7 | **権威否定** | 「〇〇は嘘。本当は〜」 | 信頼獲得 |

### 4.2 冒頭3秒フック集

**数字系**:
- 「月収50万超えました」
- 「3日で10万再生」
- 「たった5分でできる」

**衝撃系**:
- 「これ、AIで作りました」
- 「無料でここまでできる」
- 「日本ではまだ誰もやってない」

**共感系**:
- 「〇〇で悩んでませんか？」
- 「正直、キツくないですか？」
- 「あの頃の自分に伝えたい」

### 4.3 構成テンプレート

**標準型（60秒）**:
```
[0-3秒] フック（数字 or 衝撃）
[3-8秒] 問題提起（共感）
[8-45秒] 本編（3-5ポイント）
[45-55秒] まとめ
[55-60秒] CTA
```

**ランキング型（60秒）**:
```
[0-2秒] ツール名（女性声）
[2-10秒] 論外の理由
[10-20秒] 2位（特典言及）
[20-30秒] 4位
[30-40秒] 3位
[40-55秒] 1位（特典言及、詳細）
[55-60秒] CTA
```

**チュートリアル型（30秒）**:
```
[0-5秒] 衝撃映像フック
[5-10秒] 導入「30秒で解説」
[10-25秒] ステップ1-3
[25-30秒] CTA
```

### 4.4 台本作成のルール

1. **1行最大8文字**（テロップ用）
2. **セマンティック・チャンクで区切る**（助詞で終わる）
3. **句読点排除**（テンポ維持）
4. **具体的数字を入れる**（「10秒で」「1日3枚」）
5. **ですます調統一**
6. **ツール名は正確に**（ai-tool-name-list.md参照）

### 4.5 テロップ分割7つの鉄則

| # | 鉄則 | 説明 |
|---|------|------|
| 1 | 1行最大8文字厳守 | 10文字超えは絶対NG |
| 2 | 1行1テロップ | 改行=テロップ切り替え |
| 3 | 音読完全一致 | 一字一句ナレーションと一致 |
| 4 | セマンティック・チャンク | 助詞（が・を・に）で終わる |
| 5 | 高速スタッカート | 重要単語は1単語1行 |
| 6 | 3行禁止・原則1行 | 2行は例外的に許容 |
| 7 | 句読点排除 | 間は改行で表現 |

### 4.6 トレンドリサーチプロンプト

```markdown
# AIツールランキングリール台本の調査依頼

## 要件
- テーマ粒度: 「2026年〇〇に使えるAIツールランキング」
- 論外枠: 知名度高いけど実は微妙（ChatGPT、CapCut等）
- 1位・2位枠: ニッチで価値あるツール
- 異なる用途のツールを横断的に選ぶ

## 調査内容
1. ランキングテーマを5〜10個提案
2. 各テーマの論外・1位・2位候補
3. 「このプロンプトを投げれば〇〇」の〇〇部分
```

### 5.2 トリガーワード活用法

## 8. よくある質問

### Q: どのリールの型から始めるべき？

**A**: ランキング型がおすすめ。理由:
1. 構成が決まっているので作りやすい
2. 最後まで見てもらいやすい（順位知りたい）
3. 特典誘導が自然にできる

### Q: 顔出しなしで伸ばせる？

**A**: 可能。方法:
1. アフレコ型（Fish Audio + AI動画）
2. 図解型（画像のみ）
3. アバター型（Hedra / KLING）

### Q: 毎日投稿は必要？

**A**: 初期は週3-5投稿推奨。毎日投稿より:
- 質の高い投稿を定期的に
- 同じ時間帯に投稿
- フォロワーとのコミュニケーション

### Q: バズった投稿の特徴は？

**A**: 共通点:
1. 冒頭3秒で「何これ？」
2. 最後まで見たくなる構成
3. 保存したくなる実用性
4. コメントしやすいCTA

### Q: 特典は何がいい？

**A**: 「プロンプト提供」が最強。理由:
1. 制作コスト低い
2. 即使える価値
3. 再現性が高い
