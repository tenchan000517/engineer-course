### Phase 1: 準備

1. ユーザーが「ランキング形式の台本を作ってください」と依頼

   3. 2026年アプリ開発に使えるAIツールランキング
   4. 2026年「作業効率が爆上がりする」AIツールランキング
   5. 2026年「売れるクリエイティブ」を作るAIツールランキング
   6. 2026年「顔出し無しで伸ばす」AIツールランキング
   7. 2026年「情報発信×調査」で勝つAIツールランキング
3. ユーザーがテーマを選択
4. **プロジェクトフォルダを作成**
   - 場所: `C:\Instagramショート\Instagram_Reels_Production\ランキング_{テーマ}_{日付}\`
   - 例: `C:\Instagramショート\Instagram_Reels_Production\ランキング_SNS_AIツール_2026-01-23\`

### Phase 2: 台本作成

5. Claude Codeが台本作成プロンプトの「ランキングテーマ: {ここにテーマを入力}」をユーザーが選択したテーマに置き換えて出力

7. Claude Codeが台本を保存
   - **保存先**: `C:\Instagramショート\Instagram_Reels_Production\ランキング_{テーマ}_{日付}\script.txt`
   - **内容**: 貼り付けられた台本部分のみ（リサーチ結果やランキング決定理由は除く）
8. Claude Codeが台本から以下を抽出し、特典用プロンプト生成プロンプトのプレースホルダーを埋めて出力
   - {2位ツール名}
   - {1位ツール名}
   - {種類}：プロンプト系 or 非プロンプト系
   - {できること}：「このプロンプトを投げれば〇〇ができます」または「〇〇ができます」の〇〇

### Phase 3: 特典作成・検証

9. ユーザーがプロンプト生成プロンプトを実行

    - プロンプト系：出力されたプロンプトをツールに投げて、期待通りの結果が出るか確認

13. 特典ページ作成
    - **保存先**: `C:\engineer-course\content\gifts\{テーマ}.md`（Webデプロイ用）

### Fish Audio用フォーマット（音声生成）

Fish Audio APIで音声を生成する場合は、以下のルールで整形する。

**ルール**:
- 句読点（。、）を入れない
- 改行しない（1つのセグメントは1行）
- 息継ぎや間隔は不要（AIが自然に処理する）
- **例外**: 順位（「論外」「2位」「3位」「4位」「1位」等）の後は間が欲しいので句読点と改行を入れる

**例（NG）**:
```
2位。
Instagram投稿のビジュアル制作はこれ一択です。
Googleの最新画像AIで、完全無料で枚数制限もないので、心配なく使えます。
```

```
2位。
```

#### テロップ分割7つの鉄則

ショート動画のテロップは「読むもの」ではなく、脳に「飛び込んでくる画像」として捉える。

| # | 鉄則 | 説明 |
|---|------|------|
| 1 | **1行最大8文字厳守** | 全角・半角問わず1行は最大8文字以内 |
| 2 | **1行1テロップ** | 改行＝テロップの切り替えとして処理 |
| 3 | **音読完全一致** | ナレーションの語尾や接続詞を一切削らず、一字一句一致させる |
| 4 | **セマンティック・チャンク** | 助詞（が・を・に・ので）で終わるように区切ると次への期待感が出る。単語の途中で切らない |
| 5 | **高速スタッカート演出** | 重要な単語（企画、構成、1位、無料など）は1単語で1行独立させ、視覚的リズムを作る |
| 6 | **3行禁止・原則1行** | 2行は、8文字で収まらず意味が崩れる場合のみ許容。3行は絶対禁止 |
| 7 | **句読点排除** | 句読点（、。）は排除し、間を置く場合は改行（テロップ切り替え）で表現 |

**心理学的根拠**: 耳から入る情報と目から入る情報にズレがあると「認知的不協和」が発生し、視聴者の離脱に直結する。

#### テロップ分割プロンプト（Claude Code用）

```markdown

あなたはプロのSNSショート動画クリエイター、バズり投稿専門家、天才マーケター、そして心理学者です。
Premiere Proで効率よく「視聴者の脳をジャックする」テロップ作成を行うためのテキスト整形を行います。

# Task
ナレーション原稿を、ショート動画に最適な「テロップ分割リスト」に変換してください。

# Input
- ナレーション原稿: `{PROJECT_FOLDER}/narration.txt`
- ツール名変換リスト: `docs/archive/ai-tool-name-list.md`

# Output
- テロップテキスト: `{PROJECT_FOLDER}/telop.txt`

# Constraints (鉄則)
1. **1行最大8文字厳守**: 全角・半角問わず1行は最大8文字以内。
2. **1行1テロップ**: 改行＝テロップの切り替えとして処理。

6. **3行禁止・原則1行**:
   - 2行は、どうしても8文字で収まらず、かつ1行で出すと意味が崩れる場合のみ許容。3行は絶対禁止。
7. **記号の処理**: 句読点（、。）は排除し、間を置く場合は改行（テロップ切り替え）で表現する。
8. **ツール名変換**: `ai-tool-name-list.md`を参照し、カタカナ→SRT表記（英語）に変換する。

- テロップの内容のみを改行区切りで出力
- ツール名（見出し）の後は空行を入れる
```


**アルゴリズム**:

1. **アンカーポイント特定**: JSONセグメントとtelop行の先頭3文字が一致する箇所を特定
2. **アンカー間を文字数で按分**: アンカー間のtelop行は文字数比率で時間を配分

```
アンカーA (5.0秒) ─────────────── アンカーB (8.0秒)
    │                                  │
    ├─ telop1 (5文字) → 5.0-5.9秒      │
    ├─ telop2 (8文字) → 5.9-7.3秒      │
    └─ telop3 (4文字) → 7.3-8.0秒      │
```

**特徴**:
- アンカーポイントでタイミングが正確に固定される
- アンカー間は文字数で按分（累積ずれが発生しない）
- ツール名（英語↔カタカナ）は一致しないが、前後のアンカーから按分で補間される
- 一致率は約67%（29/43セグメント）、ずれは0.1〜0.4秒程度

```
Canva

2
00:00:00,660 --> 00:00:01,050
うーん

3
00:00:01,050 --> 00:00:01,320
論外
```

## SRTファイル作成ルール

ナレーション台本をPremiere Pro用のSRTファイル（字幕ファイル）に変換するルール。

### 基本ルール

- 1行8文字前後
- 最大2行
- 不自然な改行をするくらいなら少ない文字でOK
- 2行で収まらない場合は次の字幕に分割

### 話スピード（表示時間）

- 短いフレーズ（1行）: 0.5〜1秒
- 通常フレーズ（2行）: 1〜2秒
- 強調・間を取る箇所: 2〜4秒

### 表記ルール

- ツール名はアルファベット: `Nanobanana`、`KLING AI`、`Google AI`
- 数字は半角: `5,000万回`、`2つ`、`5分`

### 改行位置

意味の区切りで改行または分割する:

**2行でまとめる例**:
```
これあるAIを
使えば

たった5分で
できちゃいます
```

**別の字幕に分割する例**:
```
12
00:00:28,416 --> 00:00:29,083
このプロンプト

13
00:00:29,083 --> 00:00:29,958
を使って

14
00:00:29,958 --> 00:00:30,625
開始フレームの

15
00:00:30,625 --> 00:00:31,500
画像を作ります
```

### 間隔

- 通常: 字幕が連続
- セクション切り替え: 数秒の空白あり

### SRTファイルの形式

```
1
00:00:00,000 --> 00:00:01,000
実はこれ

2
00:00:01,000 --> 00:00:02,000
AIで作った

3
00:00:02,000 --> 00:00:04,000
ASMRベッド
動画なんです
```

### Premiere Proで読み込む

1. ファイル → 読み込み
2. SRTファイルを選択
3. タイムラインにドラッグ
4. 音声に合わせてタイミングを調整
