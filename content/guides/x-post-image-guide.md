# X投稿画像生成ガイド（要約投稿）

## トリガー

「X投稿画像を作成して」「画像付き投稿を生成して」

---

## 概要

| 項目 | 内容 |
|------|------|
| 件数 | 60件/月（2件/日） |
| ソース | ニュース（アナウンスと同じソース） |
| 形式 | **要約** + バナー画像 |
| URL | なし |
| ツール | Nano Banana Pro |
| 出力 | `{{PROJECT_DIR}}/step4_image_posts.json` |

---

## Step 0: 初期化

### 0.1 システム日時確認（必須）

1. 現在のシステム日時を取得して**必ず出力**すること

```
出力例:
今日: 2026-01-27
```

### 0.2 ディレクトリ確認・作成

1. `C:\Instagram_AI\X_Research\` 配下の当日ディレクトリを確認
2. 当日ディレクトリ内に `step4_image_posts.json` が**既にあれば**次の連番へ
3. パス: `C:\Instagram_AI\X_Research\YYYYMMDD_XX\`
4. 以降、このディレクトリを `{{PROJECT_DIR}}` とする

```
例:
- 20260127_01/step4_image_posts.json が既にある → 20260127_02 を使用
- 20260127_01 に画像付きファイルが無い → 20260127_01 を使用
- 当日ディレクトリ無し → 20260127_01 を作成
```

**各タイプのチェックファイル:**

| タイプ | チェックするファイル |
|--------|---------------------|
| アナウンス | `step3_news_posts.json` |
| 画像付き | `step4_image_posts.json` |
| スレッド | `step5_thread_posts.json` |

### 0.3 ソース参照（必須）

**同じディレクトリ内の `step3_news_posts.json` を参照する**

```
参照元: {{PROJECT_DIR}}/step3_news_posts.json
```

各投稿の `source_url` から記事を取得し、要約を作成する。

**注意**: アナウンス投稿が先に生成されている必要がある。

---

## アナウンス投稿との違い

| | アナウンス投稿 | 画像付き投稿 |
|--|----------------|--------------|
| 役割 | **アナウンス**（お知らせ） | **要約**（内容がわかる） |
| テキスト | 箇条書きでポイント | 記事の要約※プロンプトなどが記載されてたらプロンプトは全文記載する |
| 添付 | URL（詳細はこちら） | バナー画像 |
| 読後感 | 「詳細はURL見てね」 | 「この投稿で内容がわかった」 |

**それぞれ独立した投稿。同じニュースをソースにしているだけ。**

---

## 要約とは

この投稿を読めばニュースの内容がわかる状態。

**箇条書きは要約ではない。**

---

## 例

### ソース（Boltのニュース）

```
4 ways to use video as a design element
Learn how to integrate video into the backdrop or hero of your site...
```

### 投稿テキスト（要約）

```
【Bolt】ウェブサイトに動画を組み込む4つのデザイン手法

Boltのパワーユーザー Jakub Skrzypczak氏が、サイトのヒーローセクションに動画を活用する4つのエフェクトを公開。コピペで使えるプロンプト付き。

1. 反転ヘッドライン
テキストが背後の動画に応じて明暗反転
→ Add a big headline over the video that changes color based on what's behind it.

2. マスク付きカード
カードを傾けると窓から覗くように動画が見える
→ Make the video peek through a masked opening that shifts with the card's tilt.

3. ノックアウトテキスト
白いオーバーレイに文字型の穴を開けて動画を見せる
→ Create a white overlay slab with text cut out revealing video behind the letters.

4. シェーダーオーバーレイ
メッシュやドットグリッドを動画に重ねて雰囲気を変える
→ Add subtle shader overlays with opacity control, layered over video.

#AI #Bolt
```

### バナー画像（Nano Banana Pro）

**プロンプトテンプレート**:

```
【タイトル】★ここを書き換えてください（例：【Bolt】ウェブサイトに動画を組み込む4つのデザイン手法）
【要約の核心】★ここを書き換えてください（例：動画をデザイン要素として活用する4つのエフェクト手法）

上記の情報をもとに、要約の内容を視覚化したバナーを作成してください。

【デザイン要件】
- メインコピー：タイトルそのまま使用（クリエイティブにしない、揺らぎを残さない）
- サブコピー：ニュースの核心を一文で（例：「コピペで使える4つのプロンプト付き」）
- ビジュアル：★ここを書き換えてください（例：ウェブサイトのヒーローセクションに動画が埋め込まれ、4分割で異なるエフェクトが適用されているイメージ）
- 配色：★ここを書き換えてください（例：ダークテーマ、#1a1a2e をベースに、アクセントでブルー #4361ee）
- レイアウト：上部にメインコピー、中央にビジュアル、下部にサブコピー
- サイズ：1920x1080px（X長方形投稿）
- フォント：メインコピーは太めのゴシック体、サブコピーは読みやすいゴシック体
- 雰囲気：★ここを書き換えてください（例：モダン、プロフェッショナル、テック系）
```

**例（Boltのニュース）**:

```
【タイトル】【Bolt】ウェブサイトに動画を組み込む4つのデザイン手法
【ニュースの核心】動画をデザイン要素として活用する4つのエフェクト手法、コピペで使えるプロンプト付き

上記の情報をもとに、ニュース内容を視覚化したバナーを作成してください。

【デザイン要件】
- メインコピー：【Bolt】ウェブサイトに動画を組み込む4つのデザイン手法
- サブコピー：コピペで使える4つのプロンプト付き
- ビジュアル：ウェブサイトのヒーローセクションに動画が埋め込まれているイメージ。画面が4分割され、それぞれ異なるエフェクト（反転テキスト、チルトカード、ノックアウト、シェーダー）が適用されている
- 配色：ダークテーマ、#1a1a2e をベースに、アクセントでパープル #7209b7
- レイアウト：上部にメインコピー、中央に4分割のビジュアル、下部にサブコピー
- サイズ：1080x1080px
- フォント：メインコピーは太めのゴシック体、サブコピーは読みやすいゴシック体
- 雰囲気：モダン、プロフェッショナル、テック系、開発者向け
```

## 要約のポイント

| ポイント | 内容 |
|----------|------|
| 読めば内容がわかる | 箇条書きだけでは不十分 |
| コピペで使えるものは見逃さない | プロンプト、コード等 |
| 核心を捉える | 何が新しいのか、何が有益なのか |

---

## バナーのポイント

| ポイント | 内容 |
|----------|------|
| テキスト | タイトルそのまま（揺らぎを残さない） |
| ビジュアル | ニュースの内容を視覚化、具体的に指示 |
| サイズ | 1080x1080px |

## 出力形式

**ファイル名**: `step4_image_posts.json`

```json
{
  "generated_at": "2026-01-27",
  "total": 60,
  "posts": [
    {
      "post_id": "20260127-I001",
      "pattern": "image",
      "tool_name": "Bolt",
      "content": "【Bolt】ウェブサイトに動画を組み込む4つのデザイン手法\n\n（要約全文）",
      "image_prompt": "（画像生成プロンプト）"
    }
  ]
}
```

**post_id形式**: `YYYYMMDD-IXXX`（例: 20260127-I001）
- `I` = Image の識別子
- アナウンス（`YYYYMMDD-XXX`）と区別

**必須フィールド（GAS/n8n対応）**:

| フィールド | 内容 | n8n参照 |
|-----------|------|---------|
| post_id | 一意のID | `$json.post_id` |
| pattern | `image` 固定 | フィルタ条件 |
| tool_name | ツール名 | - |
| content | 要約テキスト（投稿本文） | `$json.content` |
| image_prompt | 画像生成プロンプト | `$json.image_prompt` |

**省略可能フィールド（GASがデフォルト値を設定）**:

| フィールド | GASデフォルト | 備考 |
|-----------|--------------|------|
| status | `READY` | n8nが`READY`を取得 |
| tweet_count | `1` | image/announcementは1 |
| angle | 空文字 | 未使用 |
| scheduled_date | 空文字 | 未使用 |
| reply_content | 空文字 | 画像投稿では不要 |

## シャッフル処理（必須）

生成後、同じツールが連続しないようにシャッフルする。

### アルゴリズム

1. 残り投稿数が多いツールを優先的に選択
2. ただし前回と同じツールは避ける
3. post_idを `YYYYMMDD-I001` から再採番

### 確認事項

- [ ] 同じツールが連続していない
- [ ] post_idが `YYYYMMDD-I001` 形式で連番

---

## 品質チェック

- [ ] 要約を読めばニュースの内容がわかる
- [ ] コピペで使えるもの（プロンプト等）を見逃していない
- [ ] バナーのテキストがタイトルそのまま
- [ ] ビジュアル指示が具体的
