# Instagram特典サンプル保存ガイド

## 概要

他アカウントのリール動画の台本と特典をサンプルとして収集・保存するフロー。

---

## 保存先

```
docs/reference/instagram-tokuten/
├── {アカウント名}/
│   ├── images/
│   │   └── (画像ファイル)
│   └── tokuten-01-{内容}.md
```

**注意**: このディレクトリは `.gitignore` に登録されている（非公開）

---

## 必要な情報

ユーザーから以下を受け取る：

| 項目 | 必須 | 備考 |
|------|------|------|
| 動画台本 | 必須 | 文字起こし済みのもの |
| 特典内容 | 任意 | テキスト形式 |
| 特典画像 | 任意 | スクリーンショット |
| アカウント名 | 必須 | ディレクトリ名に使用 |

---

## フロー

### 1. ディレクトリ作成

```bash
mkdir -p docs/reference/instagram-tokuten/{アカウント名}/images
```

### 2. Markdownファイル作成

ファイル名: `tokuten-01-{内容の要約}.md`

### 3. ファイル構成

```markdown
# 特典例 01: {タイトル}

## 基本情報

| 項目 | 内容 |
|------|------|
| 収集日 | YYYY-MM-DD |
| アカウント | {アカウント名} |
| ジャンル | {AI動画生成・副業など} |
| 特典形式 | テキスト記事 + 画像 + プロンプト など |
| 言語 | 日本語 / 中国語→日本語訳 / 韓国語→日本語訳 |

---

## 動画台本

### 動画タイトル
**{タイトル}**

### 構成

{台本内容}

---

## 特典内容

{特典の内容}

---

## 台本のポイント

| 項目 | 内容 |
|------|------|
| 動画の型 | ランキング/アフレコ/解説系など |
| フック | 冒頭の引き |
| CTA | コメント誘導のトリガー |

---

## 特典の特徴

- {箇条書きで特徴を列挙}
```

### 4. 画像をコピー

```bash
cp /mnt/c/Users/tench/Downloads/{画像ファイル} docs/reference/instagram-tokuten/{アカウント名}/images/
```

### 5. Markdownに画像参照を追加

```markdown
![説明文](./images/{ファイル名})
```

**注意**: ファイル名にスペースがある場合は `%20` でエンコード

```markdown
![説明](./images/unnamed%20(1).png)
```

---

## 外国語の場合

| 言語 | 対応 |
|------|------|
| 中国語（繁体字/簡体字） | 日本語訳して保存 |
| 韓国語 | 日本語訳して保存 |
| 英語 | 原文のままでも可 |

基本情報の「言語」欄に元の言語を記載する。

---

## 分析観点

保存時に以下を分析して記載：

### 動画の型
- ランキングリール
- 比較リール
- アフレコリール
- トークリール
- 解説系リール

### 特典の型
- プロンプト系（プロンプト提供）
- 非プロンプト系（ツール使い方SOP）
- コンサル誘導あり
- 有料サービス誘導あり

### CTAパターン
- トリガーワード（「AI」「ガイド」など）
- 果物名などの自由入力
- 特定のキーワード
