# 解説系リール（チュートリアル）台本作成ガイド

## 概要

AIツールの使い方を「衝撃映像フック + ステップ解説」で紹介する解説系リールの完全フロー。

---

## 台本作成フロー

### Phase 1: 準備

1. ユーザーが「解説系リール（チュートリアル）の台本を作ってください」と依頼
2. Claude Codeが以下のテーマ選択肢を提示：
   1. 衝撃映像フックの作り方（鉄球衝突、壁崩壊など）
   2. AIアバター動画の作り方（KLING、Hedra、Higgsfield）
   3. AI画像生成テクニック（Gemini、Nano Banana Pro）
   4. 顔出しなしリールの作り方
   5. 自分が持っているテーマを入力
3. ユーザーがテーマを選択
4. Claude Codeが以下を確認：
   - 使用するAIツール（例: Gemini + Higgsfield）
   - ステップ数（推奨: 3ステップ）
   - CTA方式（トリガーワード or 自由入力）
5. **プロジェクトフォルダを作成**
   - 場所: `C:\Instagramショート\Instagram_Reels_Production\チュートリアル_{テーマ}_{日付}\`
   - 例: `C:\Instagramショート\Instagram_Reels_Production\チュートリアル_鉄球AI動画_2026-01-27\`

### Phase 2: AIフック映像プロンプト生成

6. Claude Codeがフックの型を選択肢から確認：
   - 物体衝突型（鉄球、車、巨大物体）
   - 壁崩壊型
   - 煙で瞬間移動型
   - 衣装変身型
   - 地球ズームアウト型
7. Claude Codeが「AIフック映像プロンプト生成プロンプト」を出力
8. ユーザーがAIで画像・動画プロンプトを生成
9. 結果をClaude Codeに貼る
10. Claude Codeがプロンプトを保存
    - **保存先**: `{PROJECT_FOLDER}\hook_prompts.txt`

### Phase 3: 台本作成

11. Claude Codeが台本作成プロンプトの以下を置き換えて出力：
    - テーマ
    - 使用ツール
    - ステップ数
    - フック映像の説明
12. ユーザーがAIで台本を生成
13. 結果をClaude Codeに貼る
14. Claude Codeが台本を保存
    - **保存先**: `{PROJECT_FOLDER}\script.txt`
    - **内容**: 貼り付けられた台本部分のみ
15. Claude Codeが台本から以下を抽出し、特典用プロンプト生成プロンプトのプレースホルダーを埋めて出力：
    - {ツール名1}: 例）Gemini
    - {ツール名2}: 例）Higgsfield
    - {種類}: プロンプト系 or 非プロンプト系
    - {できること}: 例）鉄球衝突AI動画が作れる

### Phase 4: 特典作成・検証

16. ユーザーがプロンプト生成プロンプトを実行
17. 結果をClaude Codeに貼る
18. Claude Codeがテスト用プロンプトを作成
    - プロンプト系：プレースホルダーを実際の値で埋めた状態で出力
    - 非プロンプト系：手順はそのまま出力
19. ユーザーが検証（実際に動くか確認）
    - NGならClaude Codeに報告 → 修正 → 再検証
20. 特典ページ作成
    - **保存先**: `C:\engineer-course\content\gifts\{テーマ}.md`（Webデプロイ用）
    - 参照: `C:\engineer-course\content\guides\gift-page-creation-guide.md`

### Phase 5: キャプション・ナレーション

21. キャプション作成
    - **保存先**: `{PROJECT_FOLDER}\caption.txt`
    - **ツール名**: `ai-tool-name-list.md` のSRT表記（英語）を使用（備考欄も確認）
    - ルール: 本ファイルの「キャプション作成ルール」参照
22. ナレーション整形（Fish Audio用フォーマット）
    - **保存先**: `{PROJECT_FOLDER}\narration.txt`
    - **元データ**: `script.txt`（Step 14で保存した台本）
    - **ツール名**: `ai-tool-name-list.md` のナレーション表記（カタカナ）を使用（備考欄も確認）
    - ルール: 本ファイルの「ナレーション用フォーマット」参照

### Phase 6: 音声生成・SRT作成

23. ナレーション手動修正（必要に応じて）
    - `narration.txt` を確認し、読み間違えやすい単語などを調整
24. Fish Audio音声生成
    ```bash
    python C:\engineer-course\scripts\generate_tutorial_narration.py "{PROJECT_FOLDER}"
    ```
    - 各行が1つの音声ファイルとして生成される
    - 出力: `{PROJECT_FOLDER}\audio\01.mp3, 02.mp3, ...`
25. 音声の部分修正（必要に応じて）
    - 問題のあるファイルのみFish AudioブラウザUIで再生成
    - `audio/` フォルダ内のファイルを上書き
26. 音声トルツメ
    ```bash
    python C:\engineer-course\scripts\trim_audio.py "{PROJECT_FOLDER}"
    ```
    - 各音声ファイルの前後の無音を削除
    - 出力: `{PROJECT_FOLDER}\audio_trimmed\01.mp3, 02.mp3, ...`
27. Whisperでタイムスタンプ取得
    ```bash
    C:\Users\tench\whisper-env\Scripts\python.exe C:\engineer-course\scripts\whisper_tutorial_timestamps.py "{PROJECT_FOLDER}"
    ```
    - 各音声ファイルを個別にWhisperで処理
    - 出力: `{PROJECT_FOLDER}\audio_trimmed\01.json, 02.json, ...`
28. テロップテキスト作成（Claude Code）
    - `narration.txt` をテロップ用に分割
    - 出力: `{PROJECT_FOLDER}\telop.txt`
29. テロップ修正（必要に応じて）
30. タイムスタンプ付与・SRT作成
    ```bash
    python C:\engineer-course\scripts\create_tutorial_srt.py "{PROJECT_FOLDER}"
    ```
    - 各セグメントのタイムスタンプをオフセット計算して結合
    - 出力: `{PROJECT_FOLDER}\subtitle.srt`

## ナレーション用フォーマット

解説リールのナレーションは **編集点（画像切り替えタイミング）** に対応する。
各行が1つのセグメントとなり、音声生成・タイムスタンプ取得・Premiere Pro自動配置の基準となる。

### 基本ルール

- **1行 = 1セグメント = 1編集点**
- 男性の単一話者（話者指定行は不要）
- セクションごとに1行にまとめる
- 句読点は自然さを保つために適度に残す（完全削除しない）
- ツール名は `ai-tool-name-list.md` のナレーション表記（カタカナ）を使用

### セクション構造

| 行 | セクション | 映像 | ナレーション例 |
|----|------------|------|----------------|
| - | フック | AI生成動画再生（5秒） | なし |
| 1 | 導入 | 動画ウィンドウ | これ～今から30秒で解説します。 |
| 2 | ステップ1 | 制作物静止画 | まず【ツール名】で～作ります。 |
| 3 | ステップ2 | UI静止画 | 次に【ツール名】で～ます。 |
| 4 | ステップ2続き | （同上） | 〇〇モードをオンにして～完成です。 |
| 5 | 完成 | 完成動画ウィンドウ | これだけで～動画ができます。 |
| 6 | CTA前半 | なし | 今日紹介した～ほしい人は |
| 7 | CTA後半 | トリガーワード静止画 | 【トリガーワード】とコメントしてください。 |

### 例: モンスターASMR

```
これ、見たことありますか?海外でバズってるモンスターASMRなんですが、日本ではまだ誰もやってないんです。今やれば100万再生も狙えます。しかも作り方は超簡単です。今から30秒で解説します。
まずナノバナナで、手のひらサイズの果物に赤ちゃん顔がついた生き物の画像を作ります。
次にクリングで、この画像を動画にします。
ASMRモードをオンにして、クッキーを食べる動作を指定するだけです。音声プロンプトでサクサク音を指定すれば完成です。
これだけで本格的なASMR動画ができます。
今日紹介したモンスターASMRの作り方をまとめました。ほしい人は
モンスターとコメントしてください。
```

### ポイント

1. **フックにナレーションは入れない**: AI生成動画を5秒再生して注目を集める
2. **導入は1行に凝縮**: 「これ～30秒で解説します」までを1行に
3. **ステップは映像切り替えで分割**: 静止画・UIが変わるタイミングで行を分ける
4. **CTAは2行に分割**: 「ほしい人は」の後で改行し、トリガーワード表示タイミングを作る

### なぜこの形式が重要か

この形式により以下が自動化される：
1. **Fish Audio**: 各行を1つの音声ファイルとして生成
2. **Whisper**: 各音声ファイルから個別にタイムスタンプを取得
3. **Premiere Pro**: タイムスタンプに基づいて画像を自動配置

## テロップ分割ルール

### テロップ分割7つの鉄則

ショート動画のテロップは「読むもの」ではなく、脳に「飛び込んでくる画像」として捉える。

| # | 鉄則 | 説明 |
|---|------|------|
| 1 | **1行最大8文字厳守** | 全角・半角問わず1行は最大8文字以内 |
| 2 | **1行1テロップ** | 改行＝テロップの切り替えとして処理 |
| 3 | **音読完全一致** | ナレーションの語尾や接続詞を一切削らず、一字一句一致させる |

### 解説リール固有のポイント

- **セグメント区切り**: narration.txtの各行（セグメント）の間に空行を入れて区切る
- **ツール名変換**: `ai-tool-name-list.md` のSRT表記（英語）に変換する（備考欄も確認）
- **フックはテロップなし**: フックはナレーションがないためテロップも不要

### テロップ分割プロンプト（Claude Code用）

```markdown
# Role
あなたはプロのSNSショート動画クリエイター、バズり投稿専門家です。
Premiere Proで効率よく「視聴者の脳をジャックする」テロップ作成を行うためのテキスト整形を行います。

# Task
ナレーション原稿を、ショート動画に最適な「テロップ分割リスト」に変換してください。

# Input
- ナレーション原稿: `{PROJECT_FOLDER}/narration.txt`
- ツール名変換リスト: `docs/archive/ai-tool-name-list.md`

# Output
- テロップテキスト: `{PROJECT_FOLDER}/telop.txt`

# Constraints (鉄則)
1. **1行最大8文字厳守**: 全角・半角問わず1行は最大8文字以内。
2. **1行1テロップ**: 改行＝テロップの切り替えとして処理。
3. **音読完全一致**: ナレーションの語尾や接続詞を一切削らず、一字一句一致させること。
4. **セマンティック・チャンク（意味の塊）**:
   - 助詞（が・を・に・ので）で終わるように区切ると次への期待感が出る。
   - 意味が通じない不自然な場所（単語の途中など）で切らない。
5. **高速スタッカート演出**:
   - 重要な単語（例：100万再生、完成、無料など）は、1単語で1行独立させ、視覚的リズムを作ること。
6. **3行禁止・原則1行**:
   - 2行は、どうしても8文字で収まらず、かつ1行で出すと意味が崩れる場合のみ許容。3行は絶対禁止。
7. **記号の処理**: 句読点（、。）は排除し、間を置く場合は改行（テロップ切り替え）で表現する。
8. **ツール名変換**: `ai-tool-name-list.md`を参照し、カタカナ→SRT表記（英語）に変換する（備考欄も確認）。
9. **セグメント区切り**: narration.txtの各行（セグメント）の間に空行を入れて区切る。

# Output Format
- テロップの内容のみを改行区切りで出力
- セグメント間は空行で区切る
```
