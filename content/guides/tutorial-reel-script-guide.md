# 解説系リール（チュートリアル）台本作成ガイド

## 概要

AIツールの使い方を「衝撃映像フック + ステップ解説」で紹介する解説系リールの完全フロー。

---

## 台本作成フロー

### Phase 1: 準備

1. ユーザーが「解説系リール（チュートリアル）の台本を作ってください」と依頼
2. Claude Codeが以下のテーマ選択肢を提示：
   1. 衝撃映像フックの作り方（鉄球衝突、壁崩壊など）
   2. AIアバター動画の作り方（KLING、Hedra、Higgsfield）
   3. AI画像生成テクニック（Gemini、Nano Banana Pro）
   4. 顔出しなしリールの作り方
   5. 自分が持っているテーマを入力
3. ユーザーがテーマを選択
4. Claude Codeが以下を確認：
   - 使用するAIツール（例: Gemini + Higgsfield）
   - ステップ数（推奨: 3ステップ）
   - CTA方式（トリガーワード or 自由入力）
5. **プロジェクトフォルダを作成**
   - 場所: `C:\Instagramショート\Instagram_Reels_Production\チュートリアル_{テーマ}_{日付}\`
   - 例: `C:\Instagramショート\Instagram_Reels_Production\チュートリアル_鉄球AI動画_2026-01-27\`

### Phase 2: AIフック映像プロンプト生成

6. Claude Codeがフックの型を選択肢から確認：
   - 物体衝突型（鉄球、車、巨大物体）
   - 壁崩壊型
   - 煙で瞬間移動型
   - 衣装変身型
   - 地球ズームアウト型
7. Claude Codeが「AIフック映像プロンプト生成プロンプト」を出力
8. ユーザーがAIで画像・動画プロンプトを生成
9. 結果をClaude Codeに貼る
10. Claude Codeがプロンプトを保存
    - **保存先**: `{PROJECT_FOLDER}\hook_prompts.txt`

### Phase 3: 台本作成

11. Claude Codeが台本作成プロンプトの以下を置き換えて出力：
    - テーマ
    - 使用ツール
    - ステップ数
    - フック映像の説明
12. ユーザーがAIで台本を生成
13. 結果をClaude Codeに貼る
14. Claude Codeが台本を保存
    - **保存先**: `{PROJECT_FOLDER}\script.txt`
    - **内容**: 貼り付けられた台本部分のみ
15. Claude Codeが台本から以下を抽出し、特典用プロンプト生成プロンプトのプレースホルダーを埋めて出力：
    - {ツール名1}: 例）Gemini
    - {ツール名2}: 例）Higgsfield
    - {種類}: プロンプト系 or 非プロンプト系
    - {できること}: 例）鉄球衝突AI動画が作れる

### Phase 4: 特典作成・検証

16. ユーザーがプロンプト生成プロンプトを実行
17. 結果をClaude Codeに貼る
18. Claude Codeがテスト用プロンプトを作成
    - プロンプト系：プレースホルダーを実際の値で埋めた状態で出力
    - 非プロンプト系：手順はそのまま出力
19. ユーザーが検証（実際に動くか確認）
    - NGならClaude Codeに報告 → 修正 → 再検証
20. 特典ページ作成
    - **保存先**: `C:\engineer-course\content\gifts\{テーマ}.md`（Webデプロイ用）
    - 参照: `C:\engineer-course\content\guides\gift-page-creation-guide.md`

### Phase 5: キャプション・ナレーション

21. キャプション作成
    - **保存先**: `{PROJECT_FOLDER}\caption.txt`
    - **ツール名**: `ai-tool-name-list.md` のSRT表記（英語）を使用（備考欄も確認）
    - ルール: 本ファイルの「キャプション作成ルール」参照
22. ナレーション整形（Fish Audio用フォーマット）
    - **保存先**: `{PROJECT_FOLDER}\narration.txt`
    - **元データ**: `script.txt`（Step 14で保存した台本）
    - **ツール名**: `ai-tool-name-list.md` のナレーション表記（カタカナ）を使用（備考欄も確認）
    - ルール: 本ファイルの「ナレーション用フォーマット」参照

### Phase 6: 音声生成・SRT作成

※ランキングリールと同じフロー（Step 16-23）を適用

23. ナレーション手動修正（必要に応じて）
24. Fish Audio音声生成
25. 音声の部分修正（必要に応じて）
26. 音声トルツメ
27. Whisperでタイムスタンプ取得
28. テロップテキスト作成（Claude Code）
29. テロップ修正（必要に応じて）
30. タイムスタンプ付与・SRT作成

```markdown
# 解説系リール台本作成プロンプト

## 指示

あなたはInstagramリールの台本ライターです。
以下の情報に基づいて、100万再生を狙える解説系リールの台本を作成してください。

## 入力情報

### テーマ
{例: 鉄球衝突AI動画の作り方}

### 使用ツール
{例: Gemini（画像生成）、Higgsfield（動画生成）}

### ステップ数
{例: 3ステップ}

### 尺
{例: 45秒}

### フック映像
{例: 建設現場で鉄球が頭上に落ちる衝撃映像}

### フックの型
{以下から1つ選択}
1. 否定型（「〜しない限り〇〇できない」）
2. 数字型（「100万再生」「月〇〇万」）
3. 驚き型（「これ、マジでクレイジー」）
4. 比較型（「現実の私は〜、でもAIの私は〜」）

### CTAの型
{以下から1つ選択}
1. 自由入力型（「今行きたい場所」「好きな果物」など）
2. トリガーワード型（「AI」「ガイド」など特定ワードをコメント）

---

## テンプレート

### 冒頭フック（0-3秒）

（{映像: フック映像の説明}）

（ナレーション）{数字型フック or 驚き型フック}

---

### 導入（3-10秒）

（{映像: 海外事例やPC作業風景}）

（ナレーション）
これは{海外でバズっている/話題になっている}{コンテンツ種類}なんですが、
日本ではまだやっている人がいないので、
今やれば{ベネフィット: 100万再生も狙えます/先行者利益が取れます}。

---

### ステップ紹介（10-35秒）

（ナレーション）しかも作り方は超簡単なので、今から{尺}秒で解説します。

**ステップ1**:
（{映像: ツール1の操作画面}）
まずは{前提条件: 自撮りの写真を用意}。
次に{ツール1}を開いて、{操作1}。
{操作2}。

**ステップ2**:
（{映像: ツール1の続き or ツール2}）
{操作3}。
{操作4}。

**ステップ3**:
（{映像: ツール2の操作画面}）
次に{ツール2}というサイトを開いて、
{操作5}。
{操作6}すれば、完成。

---

### CTA（35-45秒）

（{映像: 完成動画 + 特典訴求}）

（ナレーション）
今回使ったプロンプトと作り方の詳細をまとめた記事は、
フォローしてから、
「{CTAワード: 今行きたい場所/好きな果物/AI}」を{コメント欄に書いて/教えて}くれた方の
リクエスト欄に送ります。

---

## プレースホルダー定義

| プレースホルダー | 定義 |
|---|---|
| フック映像の説明 | 冒頭の衝撃映像の説明（例: 建設現場で鉄球が頭上に落ちる） |
| 数字型フック | 具体的数字を使ったフック（例: 今やれば100万再生も狙えます） |
| コンテンツ種類 | 紹介するコンテンツの種類（例: AI動画、AIアバター） |
| ベネフィット | 視聴者が得られるメリット（例: 100万再生狙える、先行者利益） |
| ツール1 | 最初に使うツール（例: Gemini） |
| ツール2 | 次に使うツール（例: Higgsfield） |
| CTAワード | コメントで答える内容（例: 今行きたい場所、好きな果物） |

---

## ルール

1. **尺は30-45秒で完結** - 長すぎると離脱率UP
2. **ステップは3つ以内** - 多すぎると「難しそう」と感じる
3. **「超簡単」「30秒で」を強調** - 参入障壁を下げる
4. **操作画面を見せる** - 再現性を証明
5. **フック映像は冒頭0-3秒** - スクロール停止が最優先
6. **CTAは自然な流れで** - 「フォローしてから」を必ず入れる
7. **プロンプトは動画内で見せない** - 特典価値を維持

---

## 出力形式

1. フック（セリフ + 映像指示）
2. 本編構成（時間 × 映像 × テロップ × セリフ）
3. CTA（セリフ + 特典内容）
4. 映像演出メモ
```

## ランキングリールとの違い

| 項目 | ランキングリール | 解説系リール |
|------|-----------------|--------------|
| 構成 | 論外→2位→4位→3位→1位 | ステップ1→2→3 |
| フック | ツール名提示→「論外」 | 衝撃映像 + 数字型フック |
| 本編 | 5つのツールを順位づけ | 1-2ツールの操作手順 |
| 特典 | 1位・2位のプロンプト | 使用したプロンプト全部 |
| CTA | トリガーワード型が多い | 自由入力型が多い |
| 尺 | 60秒 | 30-45秒 |
| 話者 | 2声（女性＋男性） | 1声（単独） |

## 成功事例：鉄球衝突AI動画の作り方

**構成**:
- フック: 建設現場で鉄球が頭上に落ちる映像 + 「リールが爆発的に伸びます」
- 導入: 「海外でバズっている」「日本ではまだ少ない」「100万再生狙える」
- ステップ1: Geminiで画像1生成
- ステップ2: Geminiで画像2生成
- ステップ3: Higgsfieldで動画生成
- CTA: 「今行きたい場所」を自由入力

**特典**:
- 画像1プロンプト（スタートフレーム）
- 画像2プロンプト（エンドフレーム）
- 動画生成プロンプト
- バズる理由4つの解説

**バズ要因**:
1. 衝撃映像でスクロール停止
2. 「日本ではまだ」で先行者利益
3. 30秒で完結するテンポ
4. プロンプト提供で再現性保証
