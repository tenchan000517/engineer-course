# 解説系リール（チュートリアル）台本作成ガイド

## 概要

AIツールの使い方を「衝撃映像フック + ステップ解説」で紹介する解説系リールの完全フロー。

---

## 台本作成フロー

### Phase 1: 準備

1. ユーザーが「解説系リール（チュートリアル）の台本を作ってください」と依頼
2. Claude Codeが以下のテーマ選択肢を提示：
   1. 衝撃映像フックの作り方（鉄球衝突、壁崩壊など）
   2. AIアバター動画の作り方（KLING、Hedra、Higgsfield）
   3. AI画像生成テクニック（Gemini、Nano Banana Pro）
   4. 顔出しなしリールの作り方
   5. 自分が持っているテーマを入力
3. ユーザーがテーマを選択
4. Claude Codeが以下を確認：
   - 使用するAIツール（ツール名・種類・用途）
   - フック映像の説明
   - トリガーワード
5. **プロジェクトフォルダを作成**
   - 場所: `C:\Instagramショート\Instagram_Reels_Production_V26.0.0\チュートリアル_{テーマ}_{日付}\`
   - 例: `C:\Instagramショート\Instagram_Reels_Production_V26.0.0\チュートリアル_鉄球AI動画_2026-01-27\`

### Phase 2: AIフック映像プロンプト生成

6. Claude Codeがフックの型を選択肢から確認：
   - 物体衝突型（鉄球、車、巨大物体）
   - 壁崩壊型
   - 煙で瞬間移動型
   - 衣装変身型
   - 地球ズームアウト型
7. Claude Codeが「AIフック映像プロンプト生成プロンプト」を出力
8. ユーザーがAIで画像・動画プロンプトを生成
9. 結果をClaude Codeに貼る
10. Claude Codeがプロンプトを保存
    - **保存先**: `{PROJECT_FOLDER}\hook_prompts.txt`

### Phase 3: 台本作成

11. Claude Codeが台本作成プロンプトの以下を置き換えて出力：
    - テーマ
    - 使用ツール（ツール名・種類・用途の表形式）
    - フック映像
    - トリガーワード
12. ユーザーがAIで台本を生成
13. 結果をClaude Codeに貼る
14. Claude Codeが台本を保存
    - **保存先**: `{PROJECT_FOLDER}\script.txt`
    - **内容**: 貼り付けられた台本部分のみ
15. Claude Codeが台本から以下を抽出し、特典用プロンプト生成プロンプトのプレースホルダーを埋めて出力：
    - {ツール名1}: 例）Gemini
    - {ツール名2}: 例）Higgsfield
    - {種類}: プロンプト系 or 非プロンプト系
    - {できること}: 例）鉄球衝突AI動画が作れる

### Phase 4: 特典作成・検証

16. ユーザーがプロンプト生成プロンプトを実行
17. 結果をClaude Codeに貼る
18. Claude Codeがテスト用プロンプトを作成
    - プロンプト系：プレースホルダーを実際の値で埋めた状態で出力
    - 非プロンプト系：手順はそのまま出力
19. ユーザーが検証（実際に動くか確認）
    - NGならClaude Codeに報告 → 修正 → 再検証
20. 特典ページ作成
    - **保存先**: `C:\engineer-course\content\gifts\{テーマ}.md`（Webデプロイ用）
    - 参照: `C:\engineer-course\content\guides\gift-page-creation-guide.md`

### Phase 5: キャプション・ナレーション

21. キャプション作成
    - **保存先**: `{PROJECT_FOLDER}\caption.txt`
    - **ツール名**: `ai-tool-name-list.md` のSRT表記（英語）を使用（備考欄も確認）
    - ルール: 本ファイルの「キャプション作成ルール」参照
22. ナレーション整形（Fish Audio用フォーマット）
    - **保存先**: `{PROJECT_FOLDER}\narration.txt`
    - **元データ**: `script.txt`（Step 14で保存した台本）
    - **ツール名**: `ai-tool-name-list.md` のナレーション表記（カタカナ）を使用（備考欄も確認）
    - ルール: 本ファイルの「ナレーション用フォーマット」参照

### Phase 6: 音声生成・SRT作成

**重要: Claude Codeが実行する場合は `powershell.exe -Command` を使用すること（WSLにffmpeg/Whisperがないため）**

23. ナレーション手動修正（必要に応じて）
    - `narration.txt` を確認し、読み間違えやすい単語などを調整
24. Fish Audio音声生成（Claude Codeが実行）
    ```bash
    # WSLから実行可能（python3を使用）
    python3 /mnt/c/engineer-course/scripts/generate_tutorial_narration.py "{PROJECT_FOLDER_WSL}"
    ```
    - 各行が1つの音声ファイルとして生成される
    - 出力: `{PROJECT_FOLDER}\audio\01.mp3, 02.mp3, ...`
25. 音声の部分修正（必要に応じて）
    - 問題のあるファイルのみFish AudioブラウザUIで再生成
    - `audio/` フォルダ内のファイルを上書き
26. 音声トルツメ（Claude Codeが実行）
    ```bash
    # powershell.exe経由で実行（ffmpegが必要）
    powershell.exe -Command "python C:\engineer-course\scripts\trim_audio.py '{PROJECT_FOLDER}'"
    ```
    - 各音声ファイルの前後の無音を削除
    - 出力: `{PROJECT_FOLDER}\audio_trimmed\01.mp3, 02.mp3, ...`
27. Whisperでタイムスタンプ取得（Claude Codeが実行）
    ```bash
    # powershell.exe経由で実行（whisper-envが必要）
    powershell.exe -Command "C:\Users\tench\whisper-env\Scripts\python.exe C:\engineer-course\scripts\whisper_tutorial_timestamps.py '{PROJECT_FOLDER}'"
    ```
    - 各音声ファイルを個別にWhisperで処理
    - 出力: `{PROJECT_FOLDER}\audio_trimmed\01.json, 02.json, ...`
28. ~~テロップテキスト作成~~ **廃止** - `create_tutorial_srt.py`がnarration.txtから自動生成
29. ~~テロップ修正~~ **廃止** - narration.txtを修正すれば自動反映
30. タイムスタンプ付与・SRT + placement.json作成（Claude Codeが実行）
    ```bash
    # powershell.exe経由で実行
    powershell.exe -Command "python C:\engineer-course\scripts\create_tutorial_srt.py '{PROJECT_FOLDER}'"
    ```
    - 各セグメントのタイムスタンプをオフセット計算して結合
    - 出力:
      - `{PROJECT_FOLDER}\subtitle.srt`（字幕ファイル）
      - `{PROJECT_FOLDER}\placement.json`（素材配置データ）

## 台本作成プロンプト

```markdown
# 解説系リール台本作成プロンプト

## 指示

あなたはInstagramリールの台本ライターです。
以下のテンプレートとルールに従って、解説系リールの台本を作成してください。

## 作成手順

1. 入力されたテーマとツールを確認
2. 各ツールがプロンプト系か手順系かを判断（用途から自動判定）
3. テンプレートに沿って台本を作成
4. narration.txt形式で出力

## テンプレート

### 導入（1行目）- 訴求タイプ別テンプレート

**バズ系:**
これ、見たことありますか?海外でバズってる{コンテンツ種類}なんですが、日本ではまだ誰もやってないんです。今やれば100万再生も狙えます。しかも作り方は超簡単です。今から30秒で解説します。

**収益系:**
これ、知ってますか?{コンテンツ種類}で月{収益額}稼いでる人が続出してるんです。しかもやり方は超簡単です。今から30秒で解説します。

**効率化系:**
これ、やってますか?{コンテンツ種類}を使えば、{削減効果}になるんです。しかもやり方は超簡単です。今から30秒で解説します。

**スキル系:**
これ、できますか?{コンテンツ種類}を使えば、誰でもプロ級の{成果物}が作れるんです。しかもやり方は超簡単です。今から30秒で解説します。

### ステップ紹介（2行目〜N行目）
**プロンプト系ツールの場合:**
ステップ{N}、{ツール名}で、キャプションにあるプロンプトを使って、{生成物}を作ります。

**手順系ツールの場合:**
ステップ{N}、{ツール名}で、{操作内容}。

**最終ステップの場合:**
ステップ{N}、{ツール名}で、{操作内容}すれば完成です。

### 完成（N+1行目）
これだけで{完成物の説明}ができます。

### CTA（最後2行）
今日紹介した{コンテンツ種類}の作り方をまとめました。ほしい人は
{トリガーワード}とコメントしてください。

## プレースホルダー定義

| プレースホルダー | 定義 |
|-----------------|------|
| コンテンツ種類 | 紹介するコンテンツの種類（例: モンスターASMR、鉄球AI動画） |
| ツール名 | ステップで使用するツール（ナレーション表記、例: ナノバナナ、クリング） |
| 生成物 | プロンプト系ツールで生成するもの（例: モンスターの画像、スタートフレーム） |
| 操作内容 | 手順系ツールでの操作（例: ASMRモードをオンにして、動画にします） |
| 完成物の説明 | 最終的にできるもの（例: 本格的なASMR動画、衝撃的なAI動画） |
| トリガーワード | コメント誘導用のワード（例: モンスター、鉄球） |
| 収益額 | 収益系で使用する金額（例: 5万円、10万円）【収益系のみ】 |
| 削減効果 | 効率化系で得られる効果（例: 作業時間が90%削減、手作業が不要）【効率化系のみ】 |
| 成果物 | スキル系で作成できるもの（例: デザイン、動画、イラスト）【スキル系のみ】 |

## ツール種類の判断基準

| 種類 | 判断基準 | 例 |
|------|---------|-----|
| プロンプト系 | テキストプロンプトを入力してAIが生成 | Nano Banana, Gemini, ChatGPT, ImageFX |
| 手順系 | 設定変更やモード切替などの操作 | KLING（ASMRモード）, Vrew（字幕編集） |
| 混合 | 同じツールでも操作によって異なる | KLING（プロンプト入力 + モード設定） |

## ルール

1. **ステップは2〜3つ** - 多すぎると「難しそう」と感じる
2. **「ステップN、ツール名で」形式を厳守** - 自動検出に必要
3. **プロンプト系は「キャプションにあるプロンプトを使って」を必ず入れる**
4. **手順系はそのまま操作内容を説明**
5. **最終ステップは「〜すれば完成です」で終わる**
6. **CTAは「今日紹介した」で始める** - 自動検出トリガー
7. **ですます調で統一**
8. **1行1セグメント** - narration.txt形式に直接対応

## 入力

### テーマ
{ここにテーマを入力}

### 訴求タイプ
{以下から選択}
1. バズ系 - 「海外でバズってる」「100万再生狙える」
2. 収益系 - 「月○万円稼げる」「副業で稼ぐ」
3. 効率化系 - 「作業時間90%削減」「自動化」
4. スキル系 - 「プロ級の〇〇が作れる」「誰でもできる」

### 使用ツール
| ツール名 | 種類 | 用途 |
|---------|------|------|
| {ツール1} | {プロンプト系 or 手順系} | {用途1} |
| {ツール2} | {プロンプト系 or 手順系} | {用途2} |

### フック映像
{フック映像の説明}

### トリガーワード

## ナレーション用フォーマット

解説リールのナレーションは **編集点（画像切り替えタイミング）** に対応する。
各行が1つのセグメントとなり、音声生成・タイムスタンプ取得・Premiere Pro自動配置の基準となる。

### 基本ルール

- **1行 = 1セグメント = 1編集点**
- 男性の単一話者（話者指定行は不要）
- セクションごとに1行にまとめる
- **句読点・スペースは排除**（Fish Audio TTSで不自然な長い間が発生するため）
- **ステップ番号はひらがな**で書く（いち、に、さん）- TTSが数字を安定して読むため
- **漢字/ひらがな→アルファベット直接接続時はスペースを入れる**（例: ステップさん ASMR）
- ツール名は `ai-tool-name-list.md` のナレーション表記（カタカナ）を使用

### セグメント構造（動的ステップ対応）

| セグメント | セクション | 映像要素 | トリガーセリフ（固定） |
|------------|------------|----------|----------------------|
| 0 | フック | hook.mp4 | （ナレーションなし） |
| 1 | 導入 | completion（プレビュー） | 「これ見たこと〜」「〜100万再生も狙えます」 |
| 2〜N | ステップ1〜N | ツール名 + ui_{N}.png | 「ステップ1」「ステップ2」...（動的検出） |
| N+1 | 完成 | completion.mp4 | 「これだけで〜」 |
| N+2 | CTA前半 | （テロップ背景のみ） | 「今日紹介した〜ほしい人は」 |
| N+3 | CTA後半 | trigger.png | 「〇〇とコメントしてください」 |

**ステップ数は動的に検出**: ナレーション内の「ステップN」パターンを自動検出し、対応するUI画像を配置。

### 固定セリフとトリガーワード

台本は以下の固定セリフをトリガーにして、対応する映像要素が自動配置される：

| トリガーセリフ | 映像要素 | 備考 |
|---------------|----------|------|
| 「これ見たこと〜」「〜100万再生も狙えます」 | 完成動画プレビュー | 導入（完成物を先に見せる） |
| 「ステップN、ツール名で」 | ツール名 + ui_0N.png | ステップN（動的検出） |
| 「キャプションにあるプロンプトを使って」 | - | プロンプト系のみ使用 |
| 「これだけで〜」 | 完成動画（CTA直前まで） | 完成 |
| 「今日紹介した〜ほしい人は」 | テロップ背景 | CTA（固定セリフ） |
| 「〇〇とコメントしてください」 | trigger.png | CTA |

### ステップの種類

| 種類 | 説明 | 判定方法 |
|------|------|----------|
| **プロンプト系** | AIにプロンプトを入力して生成 | 「キャプションにあるプロンプトを使って」が含まれる |
| **手順系** | 設定変更やモード切替など | 上記フレーズが含まれない |

### 例: モンスターASMR（プロンプト系 + 手順系の混合）

```

モンスターとコメントしてください
```

↑ステップいちはプロンプト系、ステップにはは手順系
※「クリングで ASMR」「な ASMR」のようにアルファベット前はスペース

### 例: 鉄球AI動画（全てプロンプト系）

```
これ見たことありますか海外でバズってる鉄球衝突 AI動画なんですが日本ではまだ誰もやってないんです今やれば100万再生も狙えますしかも作り方は超簡単です今から30秒で解説します

### 例: 設定変更のみ（全て手順系）

```

ステップにクリングで ASMRモードをオンにします
ステップさんクリングで書き出しボタンを押せば完成です
これだけで...
```

### ポイント

1. **フックにナレーションは入れない**: AI生成動画を5秒再生して注目を集める
2. **導入は1行に凝縮**: 「これ～30秒で解説します」までを1行に
3. **各ステップは1行**: 「ステップN、ツール名で、キャプションにあるプロンプトを使って...」
4. **完成は1行**: 「これだけで〜ができます」
5. **CTAは2行に分割**: 「ほしい人は」の後で改行し、トリガーワード表示タイミングを作る

この形式により以下が自動化される：
1. **Fish Audio**: 各行を1つの音声ファイルとして生成
2. **Whisper**: 各音声ファイルから個別にタイムスタンプを取得
3. **Premiere Pro**: タイムスタンプに基づいて画像を自動配置

## テロップ分割ルール（スラッシュ方式）

### 概要

narration.txtに**スラッシュ（/）**でテロップ分割位置を指定する。
これにより、narration.txtが唯一の情報源となり、音声とテロップのズレを防ぐ。

```
narration.txt（スラッシュ付き）
    ↓ Fish Audio（スラッシュ除去して音声生成）
    ↓ create_tutorial_srt.py（スラッシュで分割してSRT生成）
```

### 文字数ルール

| ルール | 説明 |
|-------|------|
| **10文字超えは絶対NG** | どんな場合も10文字を超えてはいけない |
| **9〜10文字は許容** | きれいに見えるなら許容範囲 |
| **目標は8文字前後** | 基本的な目安 |

### 分割の鉄則

| # | 鉄則 | 説明 |
|---|------|------|
| 1 | **意味の塊で区切る** | 文法的・意味的に自然な単位で分割 |
| 2 | **接続詞は独立** | 「しかも」「でも」「だから」等は単独で1行 |
| 3 | **刻みすぎはダメ** | 「海外で/バズってる」ではなく「海外でバズってる」 |
| 4 | **単語の途中で切らない** | 「ありますか」を「あります/か」にしない |
| 5 | **音読完全一致** | ナレーションと一字一句一致させる |
| 6 | **ツール名変換** | カタカナ→SRT表記（英語）に変換 |

### 良い例・悪い例

#### 例1: 疑問文

| 悪い例 | 良い例 |
|-------|-------|
| `これ見たことあります/か海外で` | `これ見たこと/ありますか` |
| 「か」が次の行にくっついている | 疑問文として意味の塊で区切る |

#### 例2: 接続詞

| 悪い例 | 良い例 |
|-------|-------|
| `しかも作り方は/超簡単です` | `しかも/作り方は超簡単です` |
| 「しかも作り方は」は意味が不完全 | 接続詞「しかも」を独立させる |

#### 例3: 刻みすぎ

| 悪い例 | 良い例 |
|-------|-------|
| `海外で/バズってる` | `海外でバズってる` |
| 細かすぎて読みにくい | 8文字なのでそのまま |

#### 例4: 長すぎ

| 悪い例 | 良い例 |
|-------|-------|
| `モンスターASMRなんですが`（14文字） | `モンスターASMR/なんですが` |
| 10文字超えはNG | 10文字+5文字に分割 |

#### 例5: ツール名

| 悪い例 | 良い例 |
|-------|-------|
| `ステップ1ナノバナナで` | `ステップ1/Nano Bananaで` |
| カタカナのまま、長すぎ | SRT表記に変換、分割 |

## 成功事例：鉄球衝突AI動画の作り方

**構成**:
- フック: 建設現場で鉄球が頭上に落ちる映像 + 「リールが爆発的に伸びます」
- 導入: 「海外でバズっている」「日本ではまだ少ない」「100万再生狙える」
- ステップ1: Geminiで画像1生成
- ステップ2: Geminiで画像2生成
- ステップ3: Higgsfieldで動画生成
- CTA: 「今行きたい場所」を自由入力

**特典**:
- 画像1プロンプト（スタートフレーム）
- 画像2プロンプト（エンドフレーム）
- 動画生成プロンプト
- バズる理由4つの解説

**バズ要因**:
1. 衝撃映像でスクロール停止
2. 「日本ではまだ」で先行者利益
3. 30秒で完結するテンポ
4. プロンプト提供で再現性保証
