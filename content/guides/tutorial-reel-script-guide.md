# 解説系リール（チュートリアル）台本作成ガイド

## 概要

AIツールの使い方を「衝撃映像フック + ステップ解説」で紹介する解説系リールの完全フロー。

---

## 台本作成フロー

### Phase 1: 準備

1. ユーザーが「解説系リール（チュートリアル）の台本を作ってください」と依頼
2. Claude Codeが以下のテーマ選択肢を提示：
   1. 衝撃映像フックの作り方（鉄球衝突、壁崩壊など）
   2. AIアバター動画の作り方（KLING、Hedra、Higgsfield）
   3. AI画像生成テクニック（Gemini、Nano Banana Pro）
   4. 顔出しなしリールの作り方
   5. 自分が持っているテーマを入力
3. ユーザーがテーマを選択
4. Claude Codeが以下を確認：
   - 使用するAIツール（ツール名・種類・用途）
   - フック映像の説明
   - トリガーワード
5. **プロジェクトフォルダを作成**
   - 場所: `C:\Instagramショート\Instagram_Reels_Production\チュートリアル_{テーマ}_{日付}\`
   - 例: `C:\Instagramショート\Instagram_Reels_Production\チュートリアル_鉄球AI動画_2026-01-27\`

### Phase 2: AIフック映像プロンプト生成

6. Claude Codeがフックの型を選択肢から確認：
   - 物体衝突型（鉄球、車、巨大物体）
   - 壁崩壊型
   - 煙で瞬間移動型
   - 衣装変身型
   - 地球ズームアウト型
7. Claude Codeが「AIフック映像プロンプト生成プロンプト」を出力
8. ユーザーがAIで画像・動画プロンプトを生成
9. 結果をClaude Codeに貼る
10. Claude Codeがプロンプトを保存
    - **保存先**: `{PROJECT_FOLDER}\hook_prompts.txt`

### Phase 3: 台本作成

11. Claude Codeが台本作成プロンプトの以下を置き換えて出力：
    - テーマ
    - 使用ツール（ツール名・種類・用途の表形式）
    - フック映像
    - トリガーワード
12. ユーザーがAIで台本を生成
13. 結果をClaude Codeに貼る
14. Claude Codeが台本を保存
    - **保存先**: `{PROJECT_FOLDER}\script.txt`
    - **内容**: 貼り付けられた台本部分のみ
15. Claude Codeが台本から以下を抽出し、特典用プロンプト生成プロンプトのプレースホルダーを埋めて出力：
    - {ツール名1}: 例）Gemini
    - {ツール名2}: 例）Higgsfield
    - {種類}: プロンプト系 or 非プロンプト系
    - {できること}: 例）鉄球衝突AI動画が作れる

### Phase 4: 特典作成・検証

16. ユーザーがプロンプト生成プロンプトを実行
17. 結果をClaude Codeに貼る
18. Claude Codeがテスト用プロンプトを作成
    - プロンプト系：プレースホルダーを実際の値で埋めた状態で出力
    - 非プロンプト系：手順はそのまま出力
19. ユーザーが検証（実際に動くか確認）
    - NGならClaude Codeに報告 → 修正 → 再検証
20. 特典ページ作成
    - **保存先**: `C:\engineer-course\content\gifts\{テーマ}.md`（Webデプロイ用）
    - 参照: `C:\engineer-course\content\guides\gift-page-creation-guide.md`

### Phase 5: キャプション・ナレーション

21. キャプション作成
    - **保存先**: `{PROJECT_FOLDER}\caption.txt`
    - **ツール名**: `ai-tool-name-list.md` のSRT表記（英語）を使用（備考欄も確認）
    - ルール: 本ファイルの「キャプション作成ルール」参照
22. ナレーション整形（Fish Audio用フォーマット）
    - **保存先**: `{PROJECT_FOLDER}\narration.txt`
    - **元データ**: `script.txt`（Step 14で保存した台本）
    - **ツール名**: `ai-tool-name-list.md` のナレーション表記（カタカナ）を使用（備考欄も確認）
    - ルール: 本ファイルの「ナレーション用フォーマット」参照

### Phase 6: 音声生成・SRT作成

23. ナレーション手動修正（必要に応じて）
    - `narration.txt` を確認し、読み間違えやすい単語などを調整
24. Fish Audio音声生成
    ```bash
    python C:\engineer-course\scripts\generate_tutorial_narration.py "{PROJECT_FOLDER}"
    ```
    - 各行が1つの音声ファイルとして生成される
    - 出力: `{PROJECT_FOLDER}\audio\01.mp3, 02.mp3, ...`
25. 音声の部分修正（必要に応じて）
    - 問題のあるファイルのみFish AudioブラウザUIで再生成
    - `audio/` フォルダ内のファイルを上書き
26. 音声トルツメ
    ```bash
    python C:\engineer-course\scripts\trim_audio.py "{PROJECT_FOLDER}"
    ```
    - 各音声ファイルの前後の無音を削除
    - 出力: `{PROJECT_FOLDER}\audio_trimmed\01.mp3, 02.mp3, ...`
27. Whisperでタイムスタンプ取得
    ```bash
    C:\Users\tench\whisper-env\Scripts\python.exe C:\engineer-course\scripts\whisper_tutorial_timestamps.py "{PROJECT_FOLDER}"
    ```
    - 各音声ファイルを個別にWhisperで処理
    - 出力: `{PROJECT_FOLDER}\audio_trimmed\01.json, 02.json, ...`
28. テロップテキスト作成（Claude Code）
    - `narration.txt` をテロップ用に分割
    - 出力: `{PROJECT_FOLDER}\telop.txt`
29. テロップ修正（必要に応じて）
30. タイムスタンプ付与・SRT + placement.json作成
    ```bash
    python C:\engineer-course\scripts\create_tutorial_srt.py "{PROJECT_FOLDER}"
    ```
    - 各セグメントのタイムスタンプをオフセット計算して結合
    - 出力:
      - `{PROJECT_FOLDER}\subtitle.srt`（字幕ファイル）
      - `{PROJECT_FOLDER}\placement.json`（素材配置データ）

```

  ├─ ツール名 ─┤├─ プロンプトスクショ ─┤├─ UI/成果物 ─────────┤
    「〜で」    「キャプション〜」       残り
```

#### ポイント

- **すべて正方形**: Premiere Pro配置時のスケール・位置が統一される
- **番号順にダウンロード**: Claude Codeが自動でリネーム
- **ステップの種類に応じて素材を用意**: プロンプト系は `prompt_XX.png` が必要

### Phase 7: Premiere Pro自動配置

31. 素材の確認
    - 以下のファイルがプロジェクトフォルダに存在することを確認:
      - `hook.mp4`（フック動画）
      - `prompt_01.png`（ステップ1プロンプトスクショ）※プロンプト系のみ
      - `ui_01.png`（ステップ1 UI/成果物）
      - `prompt_02.png`（ステップ2プロンプトスクショ）※プロンプト系のみ
      - `ui_02.png`（ステップ2 UI/成果物）
      - `completion.mp4`（完成動画）
      - `trigger.png`（トリガーワード静止画）
      - `placement.json`（Step 30で生成）
32. Premiere Proでシーケンス準備
    - プロジェクトを開く
    - シーケンスをアクティブにする
33. JSX実行
    - VS CodeでF5を押す
    - ファイル選択ダイアログが表示される
    - **プロジェクトフォルダの `placement.json` を選択**
    - 自動配置が実行される
34. 配置結果の確認・微調整
    - 各トラックに素材が正しく配置されているか確認
    - 必要に応じて手動で微調整

## 台本作成プロンプト

```markdown
# 解説系リール台本作成プロンプト

## 指示

あなたはInstagramリールの台本ライターです。
以下のテンプレートとルールに従って、解説系リールの台本を作成してください。

## 作成手順

1. 入力されたテーマとツールを確認
2. 各ツールがプロンプト系か手順系かを判断（用途から自動判定）
3. テンプレートに沿って台本を作成
4. narration.txt形式で出力

## テンプレート

### 導入（1行目）- 訴求タイプ別テンプレート

**バズ系:**
これ、見たことありますか?海外でバズってる{コンテンツ種類}なんですが、日本ではまだ誰もやってないんです。今やれば100万再生も狙えます。しかも作り方は超簡単です。今から30秒で解説します。

**収益系:**
これ、知ってますか?{コンテンツ種類}で月{収益額}稼いでる人が続出してるんです。しかもやり方は超簡単です。今から30秒で解説します。

**効率化系:**
これ、やってますか?{コンテンツ種類}を使えば、{削減効果}になるんです。しかもやり方は超簡単です。今から30秒で解説します。

**スキル系:**
これ、できますか?{コンテンツ種類}を使えば、誰でもプロ級の{成果物}が作れるんです。しかもやり方は超簡単です。今から30秒で解説します。

### ステップ紹介（2行目〜N行目）
**プロンプト系ツールの場合:**
ステップ{N}、{ツール名}で、キャプションにあるプロンプトを使って、{生成物}を作ります。

**手順系ツールの場合:**
ステップ{N}、{ツール名}で、{操作内容}。

**最終ステップの場合:**
ステップ{N}、{ツール名}で、{操作内容}すれば完成です。

### 完成（N+1行目）
これだけで{完成物の説明}ができます。

### CTA（最後2行）
今日紹介した{コンテンツ種類}の作り方をまとめました。ほしい人は
{トリガーワード}とコメントしてください。

## プレースホルダー定義

| プレースホルダー | 定義 |
|-----------------|------|
| コンテンツ種類 | 紹介するコンテンツの種類（例: モンスターASMR、鉄球AI動画） |
| ツール名 | ステップで使用するツール（ナレーション表記、例: ナノバナナ、クリング） |
| 生成物 | プロンプト系ツールで生成するもの（例: モンスターの画像、スタートフレーム） |
| 操作内容 | 手順系ツールでの操作（例: ASMRモードをオンにして、動画にします） |
| 完成物の説明 | 最終的にできるもの（例: 本格的なASMR動画、衝撃的なAI動画） |
| トリガーワード | コメント誘導用のワード（例: モンスター、鉄球） |
| 収益額 | 収益系で使用する金額（例: 5万円、10万円）【収益系のみ】 |
| 削減効果 | 効率化系で得られる効果（例: 作業時間が90%削減、手作業が不要）【効率化系のみ】 |
| 成果物 | スキル系で作成できるもの（例: デザイン、動画、イラスト）【スキル系のみ】 |

## ツール種類の判断基準

| 種類 | 判断基準 | 例 |
|------|---------|-----|
| プロンプト系 | テキストプロンプトを入力してAIが生成 | Nano Banana, Gemini, ChatGPT, ImageFX |
| 手順系 | 設定変更やモード切替などの操作 | KLING（ASMRモード）, Vrew（字幕編集） |
| 混合 | 同じツールでも操作によって異なる | KLING（プロンプト入力 + モード設定） |

## ルール

1. **ステップは2〜3つ** - 多すぎると「難しそう」と感じる
2. **「ステップN、ツール名で」形式を厳守** - 自動検出に必要
3. **プロンプト系は「キャプションにあるプロンプトを使って」を必ず入れる**
4. **手順系はそのまま操作内容を説明**
5. **最終ステップは「〜すれば完成です」で終わる**
6. **CTAは「今日紹介した」で始める** - 自動検出トリガー
7. **ですます調で統一**
8. **1行1セグメント** - narration.txt形式に直接対応

## 入力

### テーマ
{ここにテーマを入力}

### 訴求タイプ
{以下から選択}
1. バズ系 - 「海外でバズってる」「100万再生狙える」
2. 収益系 - 「月○万円稼げる」「副業で稼ぐ」
3. 効率化系 - 「作業時間90%削減」「自動化」
4. スキル系 - 「プロ級の〇〇が作れる」「誰でもできる」

### 使用ツール

|---------|------|------|
| {ツール1} | {プロンプト系 or 手順系} | {用途1} |

### フック映像
```

## ナレーション用フォーマット

解説リールのナレーションは **編集点（画像切り替えタイミング）** に対応する。
各行が1つのセグメントとなり、音声生成・タイムスタンプ取得・Premiere Pro自動配置の基準となる。

### 基本ルール

- **1行 = 1セグメント = 1編集点**
- 男性の単一話者（話者指定行は不要）
- セクションごとに1行にまとめる
- 句読点は自然さを保つために適度に残す（完全削除しない）
- ツール名は `ai-tool-name-list.md` のナレーション表記（カタカナ）を使用

### セグメント構造（動的ステップ対応）

| セグメント | セクション | 映像要素 | トリガーセリフ（固定） |
|------------|------------|----------|----------------------|
| 0 | フック | hook.mp4 | （ナレーションなし） |
| 1 | 導入 | completion（プレビュー） | 「これ見たこと〜」「〜100万再生も狙えます」 |
| 2〜N | ステップ1〜N | ツール名 + ui_{N}.png | 「ステップ1」「ステップ2」...（動的検出） |
| N+1 | 完成 | completion.mp4 | 「これだけで〜」 |
| N+2 | CTA前半 | （テロップ背景のみ） | 「今日紹介した〜ほしい人は」 |
| N+3 | CTA後半 | trigger.png | 「〇〇とコメントしてください」 |

**ステップ数は動的に検出**: ナレーション内の「ステップN」パターンを自動検出し、対応するUI画像を配置。

### 固定セリフとトリガーワード

台本は以下の固定セリフをトリガーにして、対応する映像要素が自動配置される：

| トリガーセリフ | 映像要素 | 備考 |
|---------------|----------|------|
| 「これ見たこと〜」「〜100万再生も狙えます」 | 完成動画プレビュー | 導入（完成物を先に見せる） |
| 「ステップN、ツール名で」 | ツール名 + ui_0N.png | ステップN（動的検出） |
| 「キャプションにあるプロンプトを使って」 | - | プロンプト系のみ使用 |
| 「これだけで〜」 | 完成動画（CTA直前まで） | 完成 |
| 「今日紹介した〜ほしい人は」 | テロップ背景 | CTA（固定セリフ） |
| 「〇〇とコメントしてください」 | trigger.png | CTA |

### ステップの種類

| 種類 | 説明 | 判定方法 |
|------|------|----------|
| **プロンプト系** | AIにプロンプトを入力して生成 | 「キャプションにあるプロンプトを使って」が含まれる |
| **手順系** | 設定変更やモード切替など | 上記フレーズが含まれない |

### 例: モンスターASMR（プロンプト系 + 手順系の混合）

```
これ、見たことありますか?海外でバズってるモンスターASMRなんですが、日本ではまだ誰もやってないんです。今やれば100万再生も狙えます。しかも作り方は超簡単です。今から30秒で解説します。
ステップ1、ナノバナナで、キャプションにあるプロンプトを使って、モンスターの画像を作ります。
ステップ2、クリングで、ASMRモードをオンにして、動画にすれば完成です。
これだけで本格的なASMR動画ができます。
今日紹介したモンスターASMRの作り方をまとめました。ほしい人は
モンスターとコメントしてください。
```

↑ステップ1はプロンプト系、ステップ2は手順系

### 例: 鉄球AI動画（全てプロンプト系）

```
これ、見たことありますか?海外でバズってる鉄球衝突AI動画なんですが、日本ではまだ誰もやってないんです。今やれば100万再生も狙えます。しかも作り方は超簡単です。今から30秒で解説します。
ステップ1、ジェミニで、キャプションにあるプロンプトを使って、スタートフレームを作ります。
ステップ2、ジェミニで、キャプションにあるプロンプトを使って、エンドフレームを作ります。
ステップ3、ヒッグスフィールドで、キャプションにあるプロンプトを使って、動画にすれば完成です。
これだけで本格的な衝撃動画ができます。
今日紹介した鉄球AI動画の作り方をまとめました。ほしい人は
鉄球とコメントしてください。
```

### 例: 設定変更のみ（全て手順系）

```
これ、見たことありますか?...今から30秒で解説します。
ステップ1、クリングで、新規プロジェクトを作成します。
ステップ2、クリングで、ASMRモードをオンにします。
ステップ3、クリングで、書き出しボタンを押せば完成です。
これだけで...
```

### ポイント

1. **フックにナレーションは入れない**: AI生成動画を5秒再生して注目を集める
2. **導入は1行に凝縮**: 「これ～30秒で解説します」までを1行に
3. **各ステップは1行**: 「ステップN、ツール名で、キャプションにあるプロンプトを使って...」
4. **完成は1行**: 「これだけで〜ができます」
5. **CTAは2行に分割**: 「ほしい人は」の後で改行し、トリガーワード表示タイミングを作る

### なぜこの形式が重要か

この形式により以下が自動化される：
1. **Fish Audio**: 各行を1つの音声ファイルとして生成
2. **Whisper**: 各音声ファイルから個別にタイムスタンプを取得
3. **Premiere Pro**: タイムスタンプに基づいて画像を自動配置

## テロップ分割ルール

### テロップ分割7つの鉄則

ショート動画のテロップは「読むもの」ではなく、脳に「飛び込んでくる画像」として捉える。

| # | 鉄則 | 説明 |
|---|------|------|
| 1 | **1行最大8文字厳守** | 全角・半角問わず1行は最大8文字以内 |
| 2 | **1行1テロップ** | 改行＝テロップの切り替えとして処理 |
| 3 | **音読完全一致** | ナレーションの語尾や接続詞を一切削らず、一字一句一致させる |
| 4 | **セマンティック・チャンク** | 助詞（が・を・に・ので）で終わるように区切ると次への期待感が出る。単語の途中で切らない |
| 5 | **高速スタッカート演出** | 重要な単語（例：100万再生、完成、無料など）は1単語で1行独立させ、視覚的リズムを作る |
| 6 | **3行禁止・原則1行** | 2行は、8文字で収まらず意味が崩れる場合のみ許容。3行は絶対禁止 |
| 7 | **句読点排除** | 句読点（、。）は排除し、間を置く場合は改行（テロップ切り替え）で表現 |

### 解説リール固有のポイント

- **セグメント区切り**: narration.txtの各行（セグメント）の間に空行を入れて区切る
- **ツール名変換**: `ai-tool-name-list.md` のSRT表記（英語）に変換する（備考欄も確認）
- **フックはテロップなし**: フックはナレーションがないためテロップも不要

### テロップ分割プロンプト（Claude Code用）

```markdown
# Role
あなたはプロのSNSショート動画クリエイター、バズり投稿専門家です。
Premiere Proで効率よく「視聴者の脳をジャックする」テロップ作成を行うためのテキスト整形を行います。

# Task
ナレーション原稿を、ショート動画に最適な「テロップ分割リスト」に変換してください。

# Input
- ナレーション原稿: `{PROJECT_FOLDER}/narration.txt`
- ツール名変換リスト: `docs/archive/ai-tool-name-list.md`

# Output
- テロップテキスト: `{PROJECT_FOLDER}/telop.txt`

# Constraints (鉄則)
1. **1行最大8文字厳守**: 全角・半角問わず1行は最大8文字以内。
2. **1行1テロップ**: 改行＝テロップの切り替えとして処理。
3. **音読完全一致**: ナレーションの語尾や接続詞を一切削らず、一字一句一致させること。
4. **セマンティック・チャンク（意味の塊）**:
   - 助詞（が・を・に・ので）で終わるように区切ると次への期待感が出る。
   - 意味が通じない不自然な場所（単語の途中など）で切らない。
5. **高速スタッカート演出**:
   - 重要な単語（例：100万再生、完成、無料など）は、1単語で1行独立させ、視覚的リズムを作ること。
6. **3行禁止・原則1行**:
   - 2行は、どうしても8文字で収まらず、かつ1行で出すと意味が崩れる場合のみ許容。3行は絶対禁止。
7. **記号の処理**: 句読点（、。）は排除し、間を置く場合は改行（テロップ切り替え）で表現する。
8. **ツール名変換**: `ai-tool-name-list.md`を参照し、カタカナ→SRT表記（英語）に変換する（備考欄も確認）。
9. **セグメント区切り**: narration.txtの各行（セグメント）の間に空行を入れて区切る。

# Output Format
- テロップの内容のみを改行区切りで出力
- セグメント間は空行で区切る
```

## placement.json と Premiere Pro自動配置

### placement.jsonとは

`create_tutorial_srt.py` が生成する素材配置データファイル。
各素材の配置位置・時間・トラックを定義し、JSXスクリプトがこれを読み込んでPremiere Proに自動配置する。

### 自動配置されるもの

| 素材 | トラック | 配置タイミング | スケール/位置 |
|------|----------|----------------|---------------|
| アバター動画 | V1 | シーンごとに切り替え＆ループ | scale=110, y=984 |
| フック動画 | V3 | 0〜5秒 | scale=118 |
| **ツール名画像** | V4 | セグメント2, 4の冒頭1.5秒 | scale=100, x=540, y=1266 |
| UI静止画（ui_00, ui_01） | V4 | セグメント2, 3（ツール名の後） | scale=100, x=540, y=1266 |
| UI静止画（ui_02） | V5 | セグメント4（ツール名の後） | scale=100, x=540, y=1252.5 |
| 完成動画プレビュー | V6 | セグメント1（導入） | scale=40, x=410, y=607 |
| 完成動画 | V6 | セグメント6 | scale=40, x=536, y=640 |
| トリガーワード | V7 | セグメント8（CTA後半） | scale=100, x=540, y=1474.5 |
| UI静止画（ui_03） | V8 | セグメント5 | scale=100, x=540, y=1252.5 |
| 字幕背景 | V14 | 全体 | - |
| ナレーション | A1 | 5秒以降連続配置 | - |
| フック音声 | A2 | 0〜5秒 | - |
| BGM | A3 | 5秒〜終了（-8dB） | - |
| SE | A4 | 各切り替えタイミング | -10dB |

### ツール名自動検出機能

`create_tutorial_srt.py` はナレーション内のツール名を自動検出し、対応する画像を配置する。

**仕組み:**
1. `ai-tool-name-list.md` からカタカナ→英語ファイル名のマッピングを読み込み
2. セグメント2（「まず〇〇で」）とセグメント4（「次に〇〇で」）のナレーションをスキャン
3. ツール名が見つかれば `共有素材\ツール名\{英語名}.png` を配置

**例:**
- ナレーション: 「まずナノバナナで」
- 検出: 「ナノバナナ」→ `nano_banana.png`
- 配置: V4トラックに1.5秒間表示 → その後ui_00.pngに切り替え

**ツール名画像の場所:**
```
C:\Instagramショート\Instagram_Reels_Production\共有素材\ツール名\
├── nano_banana.png
├── kling.png
├── gemini.png
└── ...
```

### JSXスクリプトの使い方

1. **VS Code** で `scripts/premiere/place_ranking_images.jsx` を開く
2. **Premiere Pro** でプロジェクトを開き、シーケンスをアクティブに
3. **F5キー** を押して実行
4. ファイル選択ダイアログが表示される
5. **プロジェクトフォルダの `placement.json` を選択**
6. 自動配置が実行される

### ポイント

- **ランキングリールと解説リールで同じJSXを使用**: placement.jsonのtypeで自動判定
- **素材パスはplacement.json内に記載**: 共有素材は絶対パス、プロジェクト素材もフルパス
- **手動配置不要**: 基本的な素材は全て自動配置される
