# HANDOFF: 特典コンテンツ選定ガイド

**このファイルは特典付き投稿の「ネタ選定」に特化したガイドです。**

---

## 絶対ルール

1. **1ページ完結** - 特典ページはその目的が1ページで完結すること
2. **汎用化必須** - 特定ツール依存（Claude Code等）は汎用的な対話チャットに変換
3. **UIハレーションを避ける** - 講座にない外部ツールの手順は含めない

## 特典の種類

### A. 講座から切り出し（手順付き）

**条件**:
- この講座（content/modules/）に該当コンテンツがある
- 具体的な手順・プロンプトが記載されている
- 1ページで完結できる

**汎用化ルール**:
| 講座の記載 | 特典での記載 |
|-----------|-------------|
| Claude Code | ChatGPT、Gemini、Claude等の対話チャット |
| 特定のIDE | お好みのエディタ |
| Windows固有コマンド | OS共通の説明に変換 |

**メリット**:
- 検証済みの手順なのでハレーションが起きない
- 講座への誘導にもなる

### B. プロンプトのみ

**条件**:
- この講座に該当コンテンツがない
- 外部ツール（UIが変わる可能性がある）

**含めるもの**:
- プロンプト全文
- 期待される出力例
- 使用するツール名（URLは任意）

**含めないもの**:
- 外部ツールの具体的なUI手順
- スクリーンショット（UIが変わると陳腐化）

## リサーチ結果の確認方法

### ファイル構造

```
C:\Instagram_AI\YYYYMMDD_XX\
├── step1_influencer_data.json  ← 特典ネタ選定で参照
├── step2_normalized_tools.json
├── step2_trend_ranking.json
├── instagram_ideas.json
└── quality_check_report.json
```

### step1_influencer_data.json の見方

```json
{
  "posts": [
    {
      "influencer": "インフルエンサー名",
      "date": "投稿日",
      "title": "動画タイトル（最重要）",
      "mentioned_tools": ["ツール名"],
      "related_keywords": ["関連キーワード"],
      "category": "A/B/C/D/E"
    }
  ]
}
```

**見るべきポイント**:
1. `mentioned_tools` で言及が多いツールを抽出
2. `title` でどんな切り口（使い方？比較？）かを確認
3. `category` で投稿タイプを確認（B: 効率化、C: 新機能が特典向き）
