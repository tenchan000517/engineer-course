## プロジェクト概要

### 目的

リール制作における「動画の型」と「台本の型」を明確に分離して定義する。

### 背景

従来のテンプレートガイド（`docs/archive/gift-post-script-template-guide.md`）では、動画の型と台本の型が混在していた。これを整理し、それぞれ独立した定義として再構築する。

### 重要な区別

| 軸 | 意味 | 例 |
|---|---|---|
| **動画の型** | 映像的にどう見せるか | ランキングリール、比較リール、アフレコリール等 |
| **台本の型** | 何を言うか（ストーリー構成） | ランキング構成、比較構成、ステップ構成等 |

**これらは別物であり、組み合わせて使う。**

## 動画の型（5つ）- 定義完了

### 一覧

1. ランキングリール
2. 比較リール
3. アフレコリール
4. トークリール
5. 解説系リール

### 詳細

**ファイル**: `docs/archive/ranking-reel-script-guide.md`（ランキングリール）、`docs/archive/reel-formats.md`（2〜5の型）

#### 1. ランキングリール

- タイトル上部に配置（例：「2026年仕事で使えるAIツール」）
- 左側に順位（1, 2, 3, 4, 論外）
- 「論外」は赤字
- 右側にツールのアイコン/画像枠
- アバターキャラクターが右側に配置

**プロンプト（ranking-reel-script-guide.md に記載）**:
- 事前調査プロンプト
- 台本作成プロンプト
- 特典用プロンプト作成フロー
- 特典用プロンプト生成プロンプト

#### 2. 比較リール

- タイトル上部に配置（例：「2026年バズるリールの作り方」）
- 左右分割（例：2025年 vs 2026年）
- 左側：古いやり方（暗い印象）
- 右側：新しいやり方（明るい印象）
- 下部に説明テロップ
- ツールの画面キャプチャを重ねて表示

#### 3. アフレコリール

1. 冒頭にインパクトのあるバズりフック
2. 一旦普通にしゃべりだす
3. 台本の内容によって作業してる様子 or PC画面 or AIチャット画面
4. 3の3つの様子の繰り返し
5. CTA時にはインパクトのある動画 or 人物がユニークな感じの動画

#### 4. トークリール

映像例：
- 旅行先の映像
- 少し高級感のある暮らしの映像
- おいしそうな料理を作成してる映像
- 神社などを歩いてる映像

**ポイント**: 趣があり憧れる要素のある映像

#### 5. 解説系リール

- ひたすら同じ画角で解説する
- KLINGAIでアバター作成して実現

| 11 | 内容 | 7と同様 | ツールで決まる |

## ディスカッションで確認した事項

### 冒頭フックについて

| フック | 重要度 | 備考 |
|--------|--------|------|
| 視覚フック（0-3秒） | **高** | 派手なエフェクト、どんどん使う |
| 言語フック（3秒〜） | 中 | 必須ではなくなりつつある |

### 型ごとの冒頭パターン

| 動画の型 | 冒頭パターン |
|----------|-------------|
| ランキングリール | 「論外」で始める |
| 比較リール | 左右分割で視覚的に見せる（言語フック不要） |
| アフレコリール | トレンドは「〇〇で億作った」（うちは嘘になる場合使わない） |

### 不要と判断されたもの

- 図解リール（量産性がない）
- vlogリール（量産性がない）
- 高速チュートリアル（量産性がない）

## Whisper実証検証結果（2026-01-23）

### 結論

**faster-whisper + 仮想環境で動作確認成功**

### 役割分担

| 役割 | 担当 |
|------|------|
| タイムスタンプ取得 | Whisper（JSON出力） |
| SRT作成 | Claude Code（台本 + JSON） |

**重要**: Whisperの認識テキストは使わない。タイムスタンプのみを使用する。

### 環境情報

| 項目 | 値 |
|------|-----|
| 使用ツール | faster-whisper（OpenAI Whisperより高速） |
| 仮想環境 | `C:\Users\tench\whisper-env\` |
| スクリプト | `C:\engineer-course\scripts\whisper_timestamps.py` |
| モデル | medium（デフォルト） |
| デバイス | CPU（int8） |

### 実行コマンド

```bash
# Windows CMD/PowerShell から実行
C:\Users\tench\whisper-env\Scripts\python.exe C:\engineer-course\scripts\whisper_timestamps.py "音声ファイル.mp3"
```

### 出力ファイル

| ファイル | 内容 |
|----------|------|
| `*.json` | 単語レベルタイムスタンプ付きJSON |

### SRT作成フロー

1. `script.txt`から台本テキストを取得
2. `combined_all.json`から単語レベルのタイムスタンプを参照
3. 台本のテキストをSRTルール（1行8文字、最大2行）に従って分割
4. JSONの単語タイムスタンプを参照して、各セグメントの開始・終了時間を決定
5. `ai-tool-name-list.md`でツール名をSRT表記（英語）に変換
6. SRTファイルを生成

### 検証で判明したこと

1. **OpenAI Whisper（whisper.exe）は使えない**
   - CUDAエラー: GPUとPyTorchのバージョン不一致
   - largeモデル: ダウンロード時にチェックサム不一致で破損

2. **faster-whisperが正解**
   - 既にセットアップ済みの仮想環境あり
   - CPUでも高速に動作（81秒の音声を処理可能）
   - 単語レベルタイムスタンプ対応

3. **Whisperの認識テキストは使わない**
   - カタカナで出力される（例: キャンバー、ナノバナナプロ）
   - タイムスタンプのみを使用
   - テキストは台本（script.txt）を使用

### テスト結果サンプル

```
入力: combined_all_v7.mp3（81.76秒）
出力: 43セグメント、単語レベルタイムスタンプ付きJSON
```
