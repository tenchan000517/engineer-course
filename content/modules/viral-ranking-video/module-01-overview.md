## セクション1: ランキング形式動画とは

### 概要

Instagram/TikTokでバズっている「ランキング形式動画」は、以下の構造を持ちます。

```
女性の声：キーワードを読み上げる（「ChatGPT」「NISA」など）
男性の声：評価を下す（「論外」「3位」など）+ 理由説明
最後にCTA：「好きな〇〇をコメントで教えてね」→ 特典DM配布
```

### 基本構成

| 要素 | 内容 |
|------|------|
| 尺 | 60〜90秒 |
| 形式 | 男女掛け合い |
| 構造 | 論外 → ランキング → 1位 → CTA |
| 目的 | コメント獲得 → 特典DM配布 → リスト構築 |

### この型の強み

| 強み | 説明 |
|------|------|
| 視聴完了率が高い | 1位を見るまで離脱できない構造 |
| コメント率が高い | 思考コスト0のCTA設計 |
| 再現性が高い | 型に沿えば誰でも作れる |

## セクション2: なぜこの型がバズるのか

### 2.1 認知的不協和（冒頭3秒）

**原理**: 人は「自分の信念」と「新しい情報」が矛盾すると不快感を感じ、その不快感を解消するまで離脱できない。

```
視聴者の信念：「ChatGPTが最強」
        ↓
動画の冒頭：「ChatGPT？論外」
        ↓
認知的不協和（不快感）が発生
        ↓
「なぜ論外なの？」を知りたくて続きを見る
```

**ポイント**: 視聴者が「当たり前」と思っているものを否定する。

### 2.2 ツァイガルニク効果（ランキング構造）

**原理**: 人は「未完了のタスク」を完了させたい本能がある。

ランキング形式 = 「1位を見るまで未完了」
→ 1位を見るまで離脱できない。

### 2.3 順番シャッフル（予測の裏切り）

**原理**: 予測できると脳が省エネモードになり、離脱しやすくなる。

```
❌ 単純な昇順：4位→3位→2位→1位（予測可能）
✅ シャッフル：論外→3位→4位→2位→1位（予測不可能）
```

**ルール**:
- 1位は必ず最後（これだけは絶対）
- 論外の直後は、論外と関連するツールを紹介
- 残りの順番はシャッフル

### 2.4 数字の3つの心理効果

| 役割 | 訴える心理 | 例 |
|------|------------|-----|
| **目標提示** | 欲望（欲しい） | 「月100万」「日給3万」 |
| **証拠提示** | 信頼（本当だ） | 「2.1億再生」「52%が初月収益化」 |
| **障壁除去** | 安心（できそう） | 「30秒で」「1分で」 |

3つ揃うと「欲しい」→「本当だ」→「できそう」の流れが完成。

### 2.5 断定の心理効果

**原理**: 情報過多の時代、人は自分で判断することに疲れている。「これが正解」と断定してくれる人を信頼する。

```
❌ 「ChatGPTはあまりおすすめしません」（弱い）
✅ 「ChatGPT？論外」（断定）
```

### 2.6 CTA設計（思考コスト0）

**原理**: コメントの障壁を極限まで下げる。

```
「好きな〇〇を教えてね」
```

- 正解がない → 何を書いても間違いじゃない
- 1-2語で済む → 「冬」「犬」で完了
- 考える必要がない → 衝動的にコメントできる

## セクション3: ターゲット分析

### 3.1 ペルソナ

#### 基本属性

| 項目 | 内容 |
|------|------|
| **年齢** | 25〜45歳 |
| **職業** | 会社員、主婦、パート、フリーター |
| **SNS利用** | Instagram、TikTokをよく見る |

#### ITリテラシー

| レベル | 説明 |
|--------|------|
| **AIリテラシー** | ChatGPTは知っているが「使いこなせていない」 |
| **技術リテラシー** | プログラミング不可。「〜するだけ」が限界 |
| **情報収集** | SNS中心。公式ドキュメントは読まない |
| **学習意欲** | 低い。「教えてもらいたい」「正解を知りたい」 |

#### 心理特性

| 特性 | 説明 |
|------|------|
| **決断力** | 低い。「正解を教えてほしい」 |
| **行動力** | 低い。「簡単なら始める」 |
| **継続力** | 低い。「すぐ結果が出るもの」を好む |

### 3.2 ターゲットの悩み

投稿内で言及される悩み：

```
「何から始めたらいいかわからない」
「映え写真がないから投稿できない」
「寝起きすっぴんでも理想の自分になりたい」
「今から生活を変えたい」
「難しいのは無理」
```

### 3.3 ターゲットが求めているもの

| 求めているもの | 具体例 |
|----------------|--------|
| **正解** | 「これをやればいい」という明確な答え |
| **簡単さ** | 「〜するだけ」「1分で」「誰でも」 |
| **即効性** | 「初月で収益化」「すぐに結果が出る」 |
| **手取り足取り** | プロンプト集、使い方ガイド、作り方マニュアル |

### 3.4 投稿設計への示唆

#### ツール選定の基準

| 基準 | 説明 |
|------|------|
| **操作難易度** | 「〜するだけ」で説明できるもの |
| **初期コスト** | 無料 or 安価（月1,000円以下） |
| **日本語対応** | 英語UIは避ける |
| **即効性** | 「1分で」「30秒で」結果が出る |

#### 説明の解像度

| NG | OK |
|----|-----|
| 「APIキーを取得して設定」 | 「登録するだけ」 |
| 「プロンプトエンジニアリング」 | 「このプロンプトをコピペ」 |
| 「ワークフローを構築」 | 「10分で設定完了」 |

## よくある質問

**Q: この型は特定のジャンルでしか使えませんか？**
A: いいえ。AIツール、副業、美容、料理など、ランキング形式で表現できるジャンルなら何でも応用可能です。

**Q: 男女掛け合いは必須ですか？**
A: 効果的ですが必須ではありません。ただし、女性の「キーワード読み上げ」と男性の「評価」という役割分担は、視聴者の集中力を維持するのに有効です。

**Q: 論外は必ず入れる必要がありますか？**
A: 冒頭の「論外」は認知的不協和を起こすための重要な要素です。省略すると離脱率が上がる可能性があります。

**Q: 特典なしでも効果はありますか？**
A: コメント率は下がりますが、エンゲージメント向上には効果があります。ただし、リスト構築が目的なら特典配布を推奨します。
