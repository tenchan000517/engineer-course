## セクション1: 新規プロジェクトの作成

### プロジェクト作成の流れ

```
新規プロジェクト作成
    ↓
Social Media Template選択（任意）
    ↓
1080×1920 9:16設定確認
    ↓
フレームレート30fps設定
    ↓
ガイドライン表示ON
    ↓
セーフエリア設定完了
```

### 手順

1. Premiere Proを起動
2. **ファイル** → **新規** → **プロジェクト**を選択
3. プロジェクト名を入力（例：`Instagram_Reel_20250119`）
4. 保存先を指定
5. **OK**をクリック

### プロジェクト命名規則（推奨）

| 形式 | 例 |
|------|-----|
| `[プラットフォーム]_[内容]_[日付]` | `Instagram_Reel_20250119` |
| `[クライアント名]_[案件名]_[バージョン]` | `ABC_Campaign_v1` |

## セクション2: シーケンス設定

### 縦型シーケンスの作成

1. **ファイル** → **新規** → **シーケンス**
2. **設定**タブを選択
3. 以下の設定を入力：

| 項目 | 設定値 |
|------|--------|
| 編集モード | カスタム |
| タイムベース | 30.00 フレーム/秒 |
| フレームサイズ | 1080 × 1920（横×縦） |
| ピクセル縦横比 | 正方形ピクセル (1.0) |
| フィールド | なし（プログレッシブ） |

### カラープロファイル設定

| 項目 | 推奨設定 |
|------|----------|
| 作業カラースペース | Rec. 709 |
| ディスプレイカラーマネジメント | オン |

### ガイドライン表示設定

1. **プログラムモニター**の右下「+」をクリック
2. **セーフマージン**をドラッグしてモニターに追加
3. クリックして有効化

### セーフエリアの重要性

```
┌─────────────────────────────────────┐
│     ← アクションセーフ（90%）→      │
│  ┌─────────────────────────────┐   │
│  │  ← タイトルセーフ（80%）→   │   │
│  │                             │   │
│  │   重要なテキストは          │   │
│  │   この範囲内に配置          │   │
│  │                             │   │
│  └─────────────────────────────┘   │
│                                     │
└─────────────────────────────────────┘
```

## セクション3: ワークスペース配置

### 推奨レイアウト

効率的な編集のため、以下のパネル配置を推奨します：

```
┌───────────────┬──────────────┬──────────────────┐
│  プロジェクト  │ ソースモニター│ プログラムモニター│
│   （素材管理） │  （素材確認）  │   （編集確認）    │
├───────────────┴──────────────┴──────────────────┤
│                タイムライン                       │
│               （編集作業）                        │
├──────────────────┬──────────────────────────────┤
│     ツール       │   エフェクトコントロール      │
│  （編集ツール）   │     （エフェクト調整）        │
├──────────────────┼──────────────────────────────┤
│   エフェクト     │   エッセンシャルグラフィックス │
│（エフェクト選択） │      （テキスト編集）         │
└──────────────────┴──────────────────────────────┘
```

### ワークスペースの保存

1. パネルを好みの配置に調整
2. **ウィンドウ** → **ワークスペース** → **新規ワークスペースとして保存**
3. 名前を入力（例：`縦動画編集`）
4. **OK**をクリック

### チェックポイント

- [ ] パネルを配置した
- [ ] ワークスペースを保存した

## セクション4: テンプレートプロジェクトの作成

### テンプレートに含める要素

**プロフェッショナルな編集者は必ずテンプレートを活用**しています。

| 要素 | 内容 |
|------|------|
| フォルダ構造 | 映像 / BGM / SE / グラフィック |
| BGM | よく使うBGMを事前に配置 |
| SE | よく使う効果音を事前に配置 |
| テキストスタイル | よく使うテロップスタイルを保存 |
| 調整レイヤー | トランジション用を事前に作成 |

### フォルダ構造の作成

1. **プロジェクトパネル**で右クリック
2. **新規ビン**を選択
3. 以下のフォルダを作成：

```
📁 プロジェクト
├── 📁 01_映像
├── 📁 02_BGM
├── 📁 03_SE（効果音）
├── 📁 04_グラフィック
├── 📁 05_書き出し
└── 📁 99_未使用
```

### 音量のプリセット設定

| 要素 | 推奨音量 |
|------|----------|
| BGM | -10dB〜-12dB |
| SE | -15dB |
| ボイス（基準） | -6dB |

### テンプレートとして保存

1. 設定が完了したプロジェクトを保存
2. **ファイル** → **名前を付けて保存**
3. ファイル名を `Template_Instagram_Reel.prproj` などにする
4. 新規プロジェクト作成時に、このファイルをコピーして使用

### チェックポイント

- [ ] フォルダ構造を作成した
- [ ] テンプレートを保存した

## セクション5: ショートカットキー設定

### 必須ショートカット

| 操作 | Windows | Mac |
|------|---------|-----|
| カット（レーザーツール） | C | C |
| 選択ツール | V | V |
| テキストツール | T | T |
| リップル削除 | Shift + Delete | Shift + Delete |
| 再生/停止 | スペース | スペース |
| 1フレーム進む | → | → |
| 1フレーム戻る | ← | ← |
| イン点を設定 | I | I |
| アウト点を設定 | O | O |
| 取り消し | Ctrl + Z | Cmd + Z |

### カスタムショートカットの設定

1. **編集** → **キーボードショートカット**
2. 検索ボックスで目的の機能を検索
3. 好みのキーを割り当て
4. **OK**をクリック

### おすすめカスタムショートカット

| 機能 | 推奨キー |
|------|----------|
| 編集点を追加 | Q |
| 前の編集点を再生ヘッドまでリップルトリミング | A |
| 次の編集点を再生ヘッドまでリップルトリミング | S |

### チェックポイント

- [ ] 基本ショートカットを覚えた
- [ ] カスタムショートカットを設定した（任意）
