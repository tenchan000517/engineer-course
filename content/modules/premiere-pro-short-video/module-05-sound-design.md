## セクション1: 音響設計の基本原則

### 音量バランスの基本

| 要素 | 音量設定 | 周波数帯域 | 効果 |
|------|----------|------------|------|
| ボイス（主音声） | -6dB〜-3dB | 1kHz-4kHz | 明瞭さ確保 |
| BGM | -12dB〜-18dB | 20Hz-200Hz | 雰囲気演出 |
| SE（効果音） | -10dB〜-15dB | 全帯域 | 強調・アクセント |
| 環境音 | -20dB以下 | 広帯域 | リアリティ向上 |

### なぜ音量バランスが重要か

- **ボイスが聞こえにくい** → 離脱率UP
- **BGMがうるさい** → 不快感
- **SEが大きすぎる** → びっくりして離脱

### トラック分離の推奨構成

```
トラック1: ボイス（主音声）
トラック2: BGM
トラック3: SE（効果音）
トラック4: 環境音（オプション）
```

## セクション3: 音量調整とミキシング

### 基本の音量調整

1. タイムラインでクリップを選択
2. **エフェクトコントロール**パネルで**ボリューム**を展開
3. **レベル**の値を調整

### 推奨音量設定

| 要素 | 設定値 |
|------|--------|
| ボイス | -6dB（基準） |
| BGM | -12dB（会話時は-18dB） |
| SE | -10dB（強調時は-6dB） |

### キーフレームで音量を変化させる

会話中はBGMを下げ、間奏で上げる「ダッキング」を設定：

1. BGMクリップを選択
2. **エフェクトコントロール** → **ボリューム** → **レベル**
3. ストップウォッチをクリックしてキーフレームを有効化
4. 再生ヘッドを移動し、値を変更

```
会話開始: -12dB → -18dB（0.5秒で変化）
会話終了: -18dB → -12dB（0.5秒で変化）
```

### EQ調整（中級者向け）

**エフェクト** → **オーディオエフェクト** → **フィルターとEQ** → **パラメトリックイコライザー**

| 調整 | 対象 | 設定 |
|------|------|------|
| ハイパスフィルター | ボイス | 80Hz以下カット |
| ローパスフィルター | BGM | 8kHz以上カット |
| 中域ブースト | ボイス | 1-4kHzを+2dB |

### コンプレッサー（中級者向け）

**エフェクト** → **オーディオエフェクト** → **振幅と圧縮** → **ダイナミクス**

| 項目 | 推奨値 |
|------|--------|
| レシオ | 3:1 |
| しきい値 | -12dB |
| アタック | 10ms |
| リリース | 100ms |

## セクション4: 効果音の配置タイミング

### 効果的なSEの入れどき

| タイミング | 秒数 | SE例 | 効果 |
|------------|------|------|------|
| 開始 | 0秒 | スワイプ音、ビープ音 | 注目を集める |
| フック | 3秒 | ピンポン、クラッシュ | 強調 |
| 展開 | 10秒 | ページめくり、タイピング | テンポ維持 |
| クライマックス | 20秒 | ドン！、バーン！ | 盛り上げ |
| 終了 | 28秒 | ファンファーレ、ピカーン | 満足感 |

### シーン別おすすめSE

| シーン | SE |
|--------|-----|
| テキスト表示 | ポップ音、タイピング音 |
| 画面切り替え | スワイプ音、シュッ |
| 強調 | ドン！、キラーン |
| 成功 | ピンポン、ファンファーレ |
| 失敗・NG | ブブー、ボヨヨン |

### SEの音量調整

| タイプ | 音量 |
|--------|------|
| 軽めのアクセント | -15dB |
| 通常の強調 | -10dB |
| 強い強調 | -6dB |

### 配置のコツ

1. **映像の動きに合わせる**: 画面が切り替わる瞬間に
2. **テキストの出現に合わせる**: テロップ表示と同時に
3. **ボイスのアクセントに合わせる**: 強調したい言葉に
