## セクション1: ジャンプカット

### ジャンプカットとは

同じアングルの映像を不要な部分でカットし、繋げることで**テンポよく情報を伝える**編集手法です。2025年のリールトレンドでは、**1-2秒ごとにカット**することが効果的です。

### 基本手順

1. **カットツール（Cキー）**を選択
2. 不要な部分の開始点でクリック
3. 不要な部分の終了点でクリック
4. **選択ツール（Vキー）**に戻す
5. 不要な部分を選択し、**Delete**で削除
6. **右クリック** → **リップル削除**で隙間を詰める

### 効率的なカット方法

| 方法 | 手順 |
|------|------|
| リップル削除 | 選択 → Shift + Delete |
| 再生しながらカット | スペースで再生 → Cでカット |
| 波形を見てカット | 無音部分を目視で削除 |

### カットのタイミング

| 削除する部分 | 理由 |
|--------------|------|
| 「えー」「あー」 | 無駄な間を削除 |
| 言い直し | テンポを上げる |
| 沈黙・無音 | 離脱を防ぐ |
| 重複説明 | 簡潔にする |

### チェックポイント

## セクション2: ズームトランジション

### ズームトランジションとは

画面が拡大しながら次のシーンに切り替わる効果です。**調整レイヤー**を使うことで、どの素材にも適用できます。

### 調整レイヤーの作成

1. **プロジェクトパネル**で右クリック
2. **新規項目** → **調整レイヤー**
3. タイムラインの映像トラックの上にドラッグ

### ズームイン設定（手順）

1. 調整レイヤーを選択
2. **エフェクト** → **ビデオエフェクト** → **トランスフォーム**をドラッグ
3. **エフェクトコントロール**パネルで以下を設定：

| フレーム | スケール | 位置 |
|----------|----------|------|
| 0フレーム目 | 100% | 中央 |
| 8フレーム目 | 120% | 微調整 |
| 16フレーム目 | 100% | 元に戻す |

### キーフレームの設定

1. **エフェクトコントロール**で「スケール」の横のストップウォッチをクリック
2. 再生ヘッドを移動し、値を変更
3. 自動でキーフレームが追加される

### モーションブラーの追加

自然な動きにするため、モーションブラーを追加：

1. **エフェクト** → **ビデオエフェクト** → **ブラー＆シャープ** → **方向ブラー**
2. 調整レイヤーにドラッグ
3. 設定：

| 項目 | 値 |
|------|-----|
| 方向 | 0° |
| ブラーの長さ | 20（拡大時のみ） |

### チェックポイント

- [ ] 調整レイヤーを作成できた
- [ ] ズームトランジションを作成できた

## セクション3: テロップ作成

### 基本原則

| 原則 | 内容 |
|------|------|
| 読みやすさ重視 | 画面の下部3分の1に配置 |
| 文字サイズ | 画面幅の8-12%が最適（60-80px） |
| 表示時間 | 最小0.5秒、最大2秒まで |
| コントラスト | 背景との明度差を70%以上 |

### Premiere Proでの作成手順

1. **テキストツール（T）**を選択
2. プログラムモニター上でクリック
3. テキストを入力
4. **エッセンシャルグラフィックス**パネルで設定

### 推奨設定

| 項目 | 推奨値 |
|------|--------|
| フォント | Noto Sans JP Bold（無料・商用OK） |
| サイズ | 60-80px（1080×1920基準） |
| 色 | 白（#FFFFFF）または黄（#FFD700） |
| 縁取り | 黒 2-3px |
| 影 | オプション（距離2-4px） |

### テキストの配置

```
┌─────────────────────────────────────┐
│                                     │
│   Instagram UI                      │
│   ←この領域は避ける                  │
│                                     │
├─────────────────────────────────────┤
│                                     │
│                                     │
│   メインコンテンツ                   │
│                                     │
│                                     │
├─────────────────────────────────────┤
│   ┌───────────────────────────┐    │
│   │ テロップはこの範囲に配置    │    │
│   │ （下から1/3の位置）        │    │
│   └───────────────────────────┘    │
│                                     │
│   ← いいね・コメントUIを避ける →    │
└─────────────────────────────────────┘
```

### テキストアニメーション

バズるリールで頻出するアニメーション：

| アニメーション | 設定 |
|----------------|------|
| スライドイン | 位置のキーフレーム：右から左へ0.3秒 |
| フェードイン | 不透明度：0%→100%を0.2秒で |
| ポップアップ | スケール：80%→110%→100%を0.4秒で |
| タイピング | 1文字ずつ表示（0.05秒間隔） |

### テンプレート化

1. 完成したテキストを選択
2. **エッセンシャルグラフィックス** → **モーショングラフィックステンプレートとしてエクスポート**
3. `.mogrt`形式で保存
4. 次回から**グラフィック** → **テンプレート**から呼び出し

### チェックポイント

- [ ] テロップを作成できた
- [ ] 縁取りを設定できた
- [ ] テンプレートとして保存した

## セクション4: AI機能の活用

### サイレンス検出

無音部分を自動で検出・削除する機能：

1. クリップを選択
2. **編集** → **テキストベース編集**（または右クリック → **テキストベース編集**）
3. 文字起こしが完了したら**フィラーワード**を選択
4. **削除**をクリック

### 自動リフレーミング

横動画を縦型に最適化：

1. 横動画をタイムラインに配置
2. 右クリック → **自動リフレーム**
3. アスペクト比を**9:16**に設定
4. **OK**をクリック

### テキストベース編集

音声を文字起こしして、テキストで編集：

1. クリップを右クリック
2. **シーケンスを文字起こし**
3. テキストパネルで不要な言葉を選択
4. **Delete**で映像ごと削除
