## セクション1: 基本設定

### 推奨撮影設定

Instagram Reelsに最適な撮影設定は以下の通りです：

| 項目 | 推奨値 |
|------|--------|
| 解像度 | 1080×1920 (9:16) |
| フレームレート | 30fps または 60fps |
| ビットレート | 8-12 Mbps |
| フォーマット | MP4 (H.264) |
| エンコード | ハードウェアエンコーダー使用 |

### フレームレートの使い分け

| フレームレート | 用途 |
|----------------|------|
| 30fps | 通常のトーク、説明動画 |
| 60fps | 動きのある動画、スローモーション編集用 |

### iPhoneでの設定方法

1. **設定** → **カメラ** → **ビデオ撮影**
2. **1080p HD/30fps** または **1080p HD/60fps** を選択
3. **HDR動画** はオフ推奨（編集時の互換性のため）

### Androidでの設定方法

1. カメラアプリを開く
2. **設定（歯車アイコン）** → **動画サイズ**
3. **FHD 1080p** を選択
4. フレームレートを **30fps** または **60fps** に設定

## セクション2: プロ級撮影テクニック

### 3分の1ルール

**「画面の3分の1ルール」**を意識した撮影が、視聴維持率を向上させます。

```
┌─────────────────────────────────────┐
│         ↑                           │
│         │ 目線の位置                 │
│    ○    │ （上から1/3の位置）        │
│   /│\   ↓                           │
├─────────────────────────────────────┤
│    │                                │
│   / \                               │
│                                     │
└─────────────────────────────────────┘
```

### 必須テクニック

| テクニック | 説明 | 効果 |
|------------|------|------|
| 目線の位置 | 画面上部から3分の1の位置に配置 | 見やすさ向上 |
| 手振り補正 | ジンバルまたは手ブレ補正機能を活用 | プロ感UP |
| 露出ロック | 顔が暗くならないよう露出を固定 | 一定の明るさ |
| 連続撮影 | 同じシーンを3-5秒程度で区切って撮影 | 編集しやすい |

### 露出ロックの方法

**iPhone**:
1. 画面を長押し
2. 「AE/AFロック」が表示されたら成功

**Android**:
1. 被写体をタップしてフォーカス
2. 露出スライダーで調整
3. 長押しでロック（機種により異なる）

## セクション3: シーン別構図パターン

### 構図メモ

| シーンタイプ | 構図 | 効果 |
|--------------|------|------|
| トーク系 | 胸部から上 | 親近感・注目度UP |
| 商品紹介 | 45度斜め上 | 立体感・質感演出 |
| 料理・ハンドメイド | トップダウン | 工程が見やすい |
| スポーツ・ダンス | 全身or半身 | 動きのダイナミズム |

### トーク系の撮影ポイント

```
┌─────────────────────────────────────┐
│                                     │
│    ┌─────────────────────┐         │
│    │                     │         │
│    │   頭上に余白を残す   │         │
│    │        ↓            │         │
│    │       ○             │         │
│    │      /│\            │ ← 胸上  │
│    │                     │   まで  │
│    └─────────────────────┘         │
│                                     │
└─────────────────────────────────────┘
```

- 頭上に適度な余白（画面の10-15%）
- 顔が画面の中央〜上寄りに配置
- 背景はシンプルに（ぼかし効果も有効）

### 商品紹介の撮影ポイント

- 45度斜め上から撮影
- 自然光を活用（窓際がベスト）
- 背景は白または単色

## セクション4: 編集しやすい撮影のコツ

### 連続撮影のルール

編集を楽にするために、以下のルールで撮影します：

| ルール | 内容 |
|--------|------|
| 1カット | 3-5秒程度で区切る |
| 前後余白 | 各カットの前後に1秒の余白を設ける |
| 複数テイク | 同じシーンを2-3回撮影しておく |
| 動きの区切り | 動作の切れ目で撮影を止める |

### 音声の撮り方

| ポイント | 説明 |
|----------|------|
| 外付けマイク | 可能であれば使用（音質が格段に向上） |
| 静かな環境 | エアコンの音なども拾われる |
| 口とマイクの距離 | 20-30cmが理想 |
| テスト録音 | 本番前に必ず確認 |

### 撮影前チェックリスト

- [ ] 1080×1920の縦型設定確認
- [ ] フレームレート30fps or 60fps設定
- [ ] 露出ロック設定
- [ ] 手振り補正ON
- [ ] マイク音質チェック
- [ ] 背景の確認（余計なものがないか）
- [ ] 照明の確認（顔が暗くないか）
