## セクション1: 書き出し設定

### 推奨書き出し設定

| 項目 | 設定値 |
|------|--------|
| 形式 | H.264 |
| プリセット | ソースの一致 - 高ビットレート |
| 解像度 | 1080×1920 |
| フレームレート | 30fps |
| ビットレート | VBR 1パス、ターゲット10Mbps |
| ファイルサイズ | 100MB以下推奨 |

### 書き出し手順

1. **ファイル** → **書き出し** → **メディア**（または Ctrl+M / Cmd+M）
2. **形式**で「H.264」を選択
3. **プリセット**で「ソースの一致 - 高ビットレート」を選択
4. **出力名**をクリックして保存先とファイル名を設定
5. 設定を確認し、**書き出し**をクリック

### ビットレート設定の詳細

**ビットレート設定**タブで調整：

| 項目 | 推奨値 |
|------|--------|
| ビットレートエンコーディング | VBR、1パス |
| ターゲットビットレート | 10 Mbps |
| 最大ビットレート | 15 Mbps |

### ファイルサイズを抑える方法

ファイルサイズが100MBを超える場合：

1. ターゲットビットレートを8Mbpsに下げる
2. 動画の長さを短くする（15-30秒推奨）
3. 書き出し後に再度確認

## セクション2: ループ構造の作成

### ループ構造とは

動画の終わりが自然に始まりに繋がる構造です。完全視聴率を上げ、リピート再生を促進します。

```
┌──────────────────────────────────────┐
│                                      │
│  開始  →  フック  →  展開  →  終了  │
│    ↑                          │     │
│    └──────── ループ ──────────┘     │
│                                      │
└──────────────────────────────────────┘
```

### ループを作る3つの方法

#### 方法1: 同じ画面で始めて終わる

| 開始 | 終了 |
|------|------|
| 同じ背景、同じポーズ | 開始と同じシーンに戻る |

例：「さっき言った〇〇って何？」で終わり → 冒頭の「〇〇知ってる？」に繋がる

#### 方法2: BGMでループ

1. BGMの終わりと始まりが自然に繋がるようにカット
2. フェードアウト/フェードインを使わない
3. ビートの位置で切る

#### 方法3: テキストでループ誘導

終了時に表示するテキスト例：

- 「もう1回見る？」
- 「見逃した人はもう1回」
- 「最初から見てね」

## セクション3: アルゴリズム対策

### 2025年のアルゴリズムが重視する要素

Instagram公式が推奨する要素：

| 要素 | 内容 | 重要度 |
|------|------|--------|
| オリジナルコンテンツ | TikTok等の透かしなし | 必須 |
| 音声付き | ミュートではなく音声ON推奨 | 高 |
| 縦型フルスクリーン | 上下の黒帯なし | 必須 |
| 高解像度 | 1080p以上推奨 | 高 |
| トレンド音源の活用 | 人気の音楽を使用 | 中 |

### NGポイント（避けるべきこと）

| NG | 理由 |
|-----|------|
| 他プラットフォームの透かし | 評価が下がる |
| 低画質 | 優先度が下がる |
| 横動画のまま投稿 | 表示面積が減る |
| 音声なし | エンゲージメントが低下 |

### Instagram Insightsで確認すべき指標

| 指標 | 目標値 | 確認方法 |
|------|--------|----------|
| 視聴維持率 | 75%以上 | インサイト → リーチ |
| 完全視聴率 | 40%以上 | インサイト → エンゲージメント |
| シェア率 | 総到達数の5%以上 | インサイト → シェア |
| 保存率 | 総到達数の3%以上 | インサイト → 保存 |
| コメント率 | 総到達数の2%以上 | インサイト → コメント |

## セクション5: よくある失敗と対策

### 失敗例1: 横動画をそのまま使用

**問題**: 上下に黒帯が入り、表示面積が減る

**対策**: Premiere Proの「自動リフレーミング」機能で縦型に最適化

1. 横動画を右クリック
2. **自動リフレーム**を選択
3. アスペクト比を**9:16**に設定

### 失敗例2: 音量バランスが悪い

**問題**: ボイスが聞こえにくい、BGMがうるさい

**対策**: 以下の基準で調整

| 要素 | 音量 |
|------|------|
| ボイス | -6dB |
| BGM | -12dB |
| SE | -10dB |

### 失敗例3: テキストが読みにくい

**問題**: 背景と同化して見えない

**対策**:
- 縁取り2-3px
- 背景とのコントラスト70%以上
- 下部1/3の範囲に配置

### 失敗例4: 最初の3秒が弱い

**問題**: 冒頭で離脱される

**対策**:
- 結論先行型のフック
- 衝撃的なビジュアル
- 数字や疑問形で始める

### 失敗例5: ファイルサイズが大きすぎる

**問題**: アップロードに失敗する、画質が劣化する

**対策**:
- ビットレートを8-10Mbpsに設定
- 動画の長さを30秒以内に
- 不要なフレームを削除

## よくある質問

**Q: 動画の最適な長さは？**
A: 15-30秒が推奨です。60秒まで投稿可能ですが、短いほど完全視聴率が上がりやすくなります。

**Q: ハッシュタグは何個つけるべき？**
A: 3-5個が推奨です。関連性の高いものを厳選してください。

**Q: 投稿するベストな時間帯は？**
A: フォロワーが最もアクティブな時間帯（Instagram Insightsで確認可能）。一般的には平日12時、19-21時が良いとされています。

**Q: TikTokからの転載は問題ある？**
A: TikTokの透かしが入っている動画はInstagramのアルゴリズムで優先度が下がります。元素材から再編集することを推奨します。
