## セクション1: 2025年アルゴリズムの変更点

### 最大の変更点

Instagramの2025年アルゴリズムは、以下の2点が最大の変更点です：

| 変更点 | 内容 |
|--------|------|
| 視聴数（Views）の統合 | いいね・コメント・シェアを統合した「Views」指標 |
| シェア（送信）の重視 | DMでの送信がリーチ拡大に最も重要 |

### なぜシェアが重要なのか

DMでのシェアは、ユーザーが「この動画を誰かに見せたい」と思った証拠です。Instagramは、この行動を最も価値のあるエンゲージメントとして評価しています。

## セクション2: 視聴維持率を左右する指標

### 3つの重要指標

リールの成功は、以下の3つの要素で決まります：

| 指標 | 目標値 | 説明 |
|------|--------|------|
| 視聴維持率（リテンション） | 75%以上 | 冒頭3秒で視聴者を引きつける |
| シェア率 | 総到達数の5%以上 | DMでの送信がリーチ拡大の最短ルート |
| 完全視聴率 | 40%以上 | ループ構造で自然に再生が繰り返される |

### 補助指標

| 指標 | 目標値 |
|------|--------|
| 保存率 | 総到達数の3%以上 |
| コメント率 | 総到達数の2%以上 |

## セクション3: バズるリールの構成パターン

### 基本構成（30秒リールの場合）

**「最初の3秒」で視聴者の心を掴む**ことが絶対条件です。

```
┌─────────────────────────────────────┐
│ フック（0-3秒）                      │
│ → 強烈なキャッチコピー or           │
│   目を引くビジュアル                 │
├─────────────────────────────────────┤
│ 展開（4-15秒）                       │
│ → テンポよく情報を展開               │
│ → 1-2秒ごとにカット                  │
├─────────────────────────────────────┤
│ クライマックス（16-25秒）            │
│ → 結論 or 衝撃の事実を提示           │
├─────────────────────────────────────┤
│ CTA（26-30秒）                       │
│ → 行動喚起とループ誘導               │
└─────────────────────────────────────┘
```

### 各パートの役割

| パート | 秒数 | 役割 | 具体例 |
|--------|------|------|--------|
| フック | 0-3秒 | 離脱を防ぐ | 「〇〇が実は△△だった件」 |
| 展開 | 4-15秒 | 情報提供 | テンポの良い説明・実演 |
| クライマックス | 16-25秒 | 価値提供 | 結論・ビフォーアフター |
| CTA | 26-30秒 | 行動促進 | 「保存して後で見返してね」 |

## セクション4: 冒頭3秒の設計

### 効果的なフックのパターン

| パターン | 例 |
|----------|-----|
| 疑問形 | 「知ってた？〇〇って実は...」 |
| 数字 | 「3つの方法を紹介します」 |
| 対比 | 「ビフォー→アフターがヤバすぎた」 |
| 衝撃 | 「これ知らないと損します」 |
| 共感 | 「〇〇で悩んでる人、見て」 |

### フック設計のNG例

| NG例 | 理由 |
|------|------|
| 「こんにちは、〇〇です」 | 自己紹介は後回し |
| 長い前置き | 視聴者は待ってくれない |
| 静止画から始まる | 動きがないと離脱される |

## まとめ

### このモジュールで学んだこと

- 2025年のInstagramは「シェア」を最重視
- 冒頭3秒のフックが成功の鍵
- バズるリールは4パート構成（フック→展開→クライマックス→CTA）
- 視聴維持率75%以上、完全視聴率40%以上が目標
