## セクション1: ペルソナ

### 基本属性

| 項目 | 内容 |
|------|------|
| **年齢** | 25〜45歳 |
| **職業** | 会社員、主婦、パート、フリーター |
| **SNS利用** | Instagram、TikTokをよく見る |

### ITリテラシー

| レベル | 説明 |
|--------|------|
| **AIリテラシー** | ChatGPTは知っているが「使いこなせていない」 |
| **技術リテラシー** | プログラミング不可。「〜するだけ」が限界 |
| **情報収集** | SNS中心。公式ドキュメントは読まない |
| **学習意欲** | 低い。「教えてもらいたい」「正解を知りたい」 |

### 心理特性

| 特性 | 説明 |
|------|------|
| **決断力** | 低い。「正解を教えてほしい」 |
| **行動力** | 低い。「簡単なら始める」 |
| **継続力** | 低い。「すぐ結果が出るもの」を好む |

### チェックポイント

- [ ] ペルソナの基本属性を理解した
- [ ] ターゲットのITリテラシーを把握した

## セクション2: ターゲットの悩み

### 投稿内で言及される典型的な悩み

```
「何から始めたらいいかわからない」
「映え写真がないから投稿できない」
「寝起きすっぴんでも理想の自分になりたい」
```

| **時間不足** | 忙しくてできない |
| **自信不足** | 自分には無理だと思っている |

## セクション3: ターゲットが求めているもの

### 4つの欲求

| 求めているもの | 具体例 |
|----------------|--------|
| **正解** | 「これをやればいい」という明確な答え |
| **簡単さ** | 「〜するだけ」「1分で」「誰でも」 |
| **即効性** | 「初月で収益化」「すぐに結果が出る」 |
| **手取り足取り** | プロンプト集、使い方ガイド、作り方マニュアル |

### 心理的ニーズ

- **決めてほしい**: 選択肢が多いと迷う → 「これ一択」と言ってほしい
- **安心したい**: 失敗が怖い → 「誰でもできる」と言ってほしい
- **すぐ結果がほしい**: 待てない → 「30秒で完成」と言ってほしい

### チェックポイント

- [ ] ターゲットが求めているものを把握した
- [ ] 心理的ニーズを理解した

## セクション4: 投稿設計への示唆

### ツール選定の基準

| 基準 | 説明 |
|------|------|
| **操作難易度** | 「〜するだけ」で説明できるもの |
| **初期コスト** | 無料 or 安価（月1,000円以下） |
| **日本語対応** | 英語UIは避ける |
| **即効性** | 「1分で」「30秒で」結果が出る |

### 説明の解像度

| NG | OK |
|----|-----|
| 「APIキーを取得して設定」 | 「登録するだけ」 |
| 「プロンプトエンジニアリング」 | 「このプロンプトをコピペ」 |
| 「ワークフローを構築」 | 「10分で設定完了」 |
| 「パラメータを調整」 | 「ボタンを押すだけ」 |

### 言葉選びのルール

| ルール | 説明 |
|--------|------|
| 専門用語を避ける | ターゲットが知らない言葉は使わない |
| 数字を具体的に | 「すぐ」ではなく「30秒で」 |
| 行動を明確に | 「やってみて」ではなく「このボタンを押して」 |

### チェックポイント

- [ ] ツール選定の基準を理解した
- [ ] 説明の解像度（OK/NG）を理解した

## まとめ

### このモジュールで学んだこと

- ターゲットは「正解を教えてほしい」「簡単なら始める」層
- 専門用語を避け、「〜するだけ」で説明する
- 数字は具体的に（「すぐ」→「30秒で」）
- ツールは無料・日本語対応・簡単操作のものを選ぶ

### ターゲット対応チェックリスト

- [ ] 専門用語を使っていないか
- [ ] 「〜するだけ」で説明できているか
- [ ] 具体的な数字を入れているか
- [ ] 選んだツールはターゲットが使えるものか

## よくある質問

**Q: ターゲットが技術者の場合は？**
A: このペルソナは一般向けSNS運用のものです。技術者向けの場合は、説明の解像度を上げても問題ありません。

**Q: 「〜するだけ」ばかりだと信頼性が下がりませんか？**
A: 嘘をつかない限り問題ありません。本当に「〜するだけ」で結果が出るツールを選ぶことが重要です。

**Q: 英語UIのツールを紹介したい場合は？**
A: 日本語での操作手順を詳しく説明するか、画面キャプチャで視覚的にサポートしてください。
