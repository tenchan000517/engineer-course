## セクション1: 認知的不協和

### 原理

人は「自分の信念」と「新しい情報」が矛盾すると不快感を感じ、その不快感を解消するまで離脱できない。

### 冒頭3秒での活用

```
視聴者の信念：「ChatGPTが最強」
        ↓
動画の冒頭：「ChatGPT？論外」
        ↓
認知的不協和（不快感）が発生
        ↓
「なぜ論外なの？」を知りたくて続きを見る
```

### ポイント

視聴者が「当たり前」と思っているものを否定する。

### 活用例

| ジャンル | 視聴者の信念 | 否定フック |
|----------|--------------|------------|
| AIツール | 「ChatGPTが最強」 | 「ChatGPT？論外」 |
| 投資 | 「NISAが正解」 | 「NISA？時代遅れ」 |
| 副業 | 「ブログで稼げる」 | 「ブログ？オワコン」 |

### チェックポイント

- [ ] 認知的不協和の仕組みを理解した
- [ ] ターゲットの「当たり前の信念」を特定できる

## セクション2: ツァイガルニク効果

### 原理

人は「未完了のタスク」を完了させたい本能がある。

### リール構成での活用

ランキング形式 = 「1位を見るまで未完了」
→ 1位を見るまで離脱できない

ステップ形式 = 「最後のステップを見るまで未完了」
→ 完結を見届けたくて最後まで見る

### ポイント

- **ランキング系**: 1位は必ず最後に配置
- **ステップ系**: 「ステップ3」など番号を見せる
- **比較系**: 結論を最後まで引っ張る

### チェックポイント

- [ ] ツァイガルニク効果を理解した
- [ ] 自分のリール構成で活用できる

## セクション3: 予測の裏切り

### 原理

予測できると脳が省エネモードになり、離脱しやすくなる。

### 順番シャッフルの効果

```
❌ 単純な昇順：4位→3位→2位→1位（予測可能）
✅ シャッフル：論外→3位→4位→2位→1位（予測不可能）
```

### ルール

- 1位は必ず最後（これだけは絶対）
- 論外の直後は、論外と関連するツールを紹介
- 残りの順番はシャッフル

### チェックポイント

- [ ] 予測の裏切りを理解した
- [ ] 順番シャッフルのルールを把握した

## セクション4: 数字の3つの心理効果

### 3つの役割

| 役割 | 訴える心理 | 例 |
|------|------------|-----|
| **目標提示** | 欲望（欲しい） | 「月100万」「日給3万」 |
| **証拠提示** | 信頼（本当だ） | 「2.1億再生」「52%が初月収益化」 |
| **障壁除去** | 安心（できそう） | 「30秒で」「1分で」 |

### 組み合わせの効果

3つ揃うと「欲しい」→「本当だ」→「できそう」の流れが完成。

### 例

```
月100万稼げる副業（目標提示）
実際に9000万再生された（証拠提示）
たった5分で始められる（障壁除去）
```

### チェックポイント

- [ ] 数字の3つの心理効果を把握した
- [ ] 自分のリールで3種類の数字を使える

## セクション5: 断定の心理効果

### 原理

情報過多の時代、人は自分で判断することに疲れている。「これが正解」と断定してくれる人を信頼する。

### NG例とOK例

```
❌ 「ChatGPTはあまりおすすめしません」（弱い）
✅ 「ChatGPT？論外」（断定）

❌ 「〜かもしれない」「〜と思います」
✅ 「〜です」「〜一択」「〜最強」
```

### 使うべき断定ワード

| カテゴリ | ワード |
|----------|--------|
| 否定 | 論外、オワコン、時代遅れ、微妙 |
| 肯定 | 一択、最強、確実に、圧倒的 |
| 限定 | これだけ、唯一、〜しかない |

### 避けるべき言葉

| NG | なぜダメか | 代替 |
|----|------------|------|
| 「〜かもしれない」 | 不確実 | 「〜です」 |
| 「〜と思います」 | 自信がない | 「〜です」 |
| 「個人的には」 | 責任回避 | 削除 |
| 「おすすめかも」 | 曖昧 | 「おすすめです」 |

### チェックポイント

- [ ] 断定の心理効果を理解した
- [ ] 避けるべき言葉を把握した

## よくある質問

**Q: 認知的不協和は毎回使うべきですか？**
A: 冒頭で使うと効果的ですが、必須ではありません。ランキング系では特に有効です。

**Q: 断定しすぎると炎上しませんか？**
A: 事実に基づいた断定であれば問題ありません。嘘や誇張は避けてください。

**Q: 数字は必ず3種類入れるべきですか？**
A: 理想的には3種類ですが、最低でも1つは入れることをおすすめします。
