## セクション1: 特典付き投稿とは

Instagramで「〇〇とコメントしてください」と呼びかけ、コメントした人にDMで特典を自動配布する投稿形式です。

### 通常投稿との違い

| 項目 | 通常投稿 | 特典付き投稿 |
|------|----------|--------------|
| 台本テンプレート | 既存5カテゴリ（A〜E） | **専用テンプレート** |
| CTA | フォロー誘導等 | **「〇〇とコメントしてください」** |
| 特典ページ | なし | **あり（このドメイン上）** |
| エルグラム設定 | なし | **あり（手動）** |
| 頻度 | 多い（日次） | 月数回 |

## セクション3: 特典の設計方針

### 特典の単位

```
❌ 1投稿 = 1特典（毎回作成は大変）
✅ 1ツール（ユースケース）= 1特典（使い回し可能）
```

同じ特典を複数の投稿で使い回すことで、効率的に運用できます。

### 特典ネタの選定方法

**ソース1: 毎月のリサーチ結果**

```
インフルエンサーの投稿タイトル例:
「ChatGPT Canvasで資料作成が10倍速くなる」
「n8nでInstagram投稿を完全自動化する方法」
「Cursorの新機能Composerが便利すぎる」
           ↓
タイトル = 今バズっているユースケース = 特典ネタ
```

**ソース2: 講座コンテンツからの切り出し**

既存モジュールの一部を特典として再利用。

**ソース3: ユーザー自身の調査結果**

独自調査で発見したトピック。

### 特典の中身

```
インフルエンサーの投稿: 「〇〇の使い方」（30-60秒リール）
           ↓
自分の特典: その「詳しい使い方・やり方・情報」をまとめたもの
```

## よくある質問

**Q: 特典付き投稿は通常投稿と別のシートで管理しますか？**
A: はい。`posts_gift`と`canva_gift`という専用シートを使用します。インサイト管理など既存システムとの互換性を保つため、通常投稿と同じ列構成にしています。

**Q: 毎月のリサーチはAntigravity以外でもできますか？**
A: はい。Claude、ChatGPT、Perplexityなど、ブラウザ検索機能を持つAIツールであれば同様のリサーチが可能です。ただし、プロンプトの調整が必要です。

**Q: 特典ページはPDFとWebページどちらがいいですか？**
A: Webページ（/gift/[slug]形式）を推奨します。更新が容易で、アナリティクスも取得できます。PDFはダウンロード配布したい場合に使用します。

**Q: エルグラム設定は自動化できますか？**
A: 現時点ではエルグラムにAPIがないため、手動設定が必要です。月数回の頻度なので、手動で問題ありません。

**Q: 既存の投稿ワークフローを大きく変更する必要がありますか？**
A: いいえ。`canva_gift`シートを対象に追加するだけで、既存ワークフローをそのまま流用できます。
