## セクション1: 特典設計の考え方

### 特典設計の基本原則

特典は「投稿の延長線上」にあるべきです。投稿で興味を持った人が「もっと知りたい」と思う内容を提供します。

### 投稿→特典の設計フロー

```
Step 1: 投稿のテーマを決める
  ↓
Step 2: ターゲットの「次の悩み」を考える
  ↓
Step 3: その悩みを解決する特典を設計
  ↓
Step 4: 特典の形式を選ぶ（PDF/リンク/テキスト）
  ↓
Step 5: 特典を作成
```

### 具体例：投稿テーマ別の特典設計

| 投稿テーマ | ターゲットの次の悩み | 特典内容 |
|------------|----------------------|----------|
| ChatGPT入門 | 「何を聞けばいいかわからない」 | すぐ使えるプロンプト10選 |
| n8n自動化紹介 | 「どこから始めればいい？」 | 初期設定チェックリスト |
| Canvaデザイン術 | 「自分でも作りたい」 | Canvaテンプレートリンク |
| 時間管理術 | 「実践方法がわからない」 | 週間スケジュールテンプレート |
| Instagram運用 | 「投稿ネタがない」 | 投稿アイデア30選 |

### 良い特典の3つの条件

1. **すぐ使える**
   - ダウンロードしてすぐ実践できる
   - 複雑な準備が不要

2. **具体的**
   - 抽象的なアドバイスではなく具体的なツール/リスト
   - 「〇〇するだけ」で使える

3. **投稿の補完**
   - 投稿で伝えきれなかった詳細
   - 投稿を見た人だけが価値を感じる内容

## セクション2: 特典の種類と選び方

### 特典の種類一覧

| 種類 | 具体例 | 作成難易度 | おすすめ場面 |
|------|--------|------------|--------------|
| **PDFガイド** | チェックリスト、ステップガイド | ⭐⭐ | 手順説明、リスト系 |
| **Notionテンプレート** | タスク管理、習慣トラッカー | ⭐⭐ | 管理ツール系 |
| **プロンプト集** | ChatGPT/Claude用プロンプト | ⭐ | AI活用系 |
| **Canvaテンプレート** | SNS投稿用デザイン | ⭐⭐⭐ | デザイン系 |
| **スプレッドシート** | 計算ツール、管理表 | ⭐⭐ | 数値管理系 |
| **限定動画** | 解説動画、チュートリアル | ⭐⭐⭐ | 操作説明系 |
| **テキスト情報** | リスト、コード例 | ⭐ | シンプルな情報 |

### 投稿テーマ別おすすめ特典

#### AI・効率化系

```
投稿: 「ChatGPTで業務効率化」
  → 特典: プロンプト集（テキスト or PDF）

投稿: 「n8nで自動化入門」
  → 特典: ワークフローJSON + 設定チェックリスト（PDF）

投稿: 「Claudeの使い方」
  → 特典: Claude専用プロンプト集（PDF）
```

#### SNS・マーケティング系

```
投稿: 「Instagram投稿の作り方」
  → 特典: Canvaテンプレートリンク

投稿: 「投稿ネタの見つけ方」
  → 特典: 投稿アイデア100選（PDF）

投稿: 「ハッシュタグ戦略」
  → 特典: ジャンル別ハッシュタグリスト（PDF）
```

#### ライフスタイル・自己啓発系

```
投稿: 「朝活のすすめ」
  → 特典: 朝活ルーティンテンプレート（Notion）

投稿: 「習慣化のコツ」
  → 特典: 習慣トラッカー（Notion or PDF）

投稿: 「時間管理術」
  → 特典: 週間スケジュールテンプレート（PDF）
```

### 特典形式の選び方フローチャート

```
Q: 手順やリストを伝えたい？
  → Yes: PDFガイド
  → No: ↓

Q: テンプレートとして使ってほしい？
  → Yes: Notion or スプレッドシート or Canva
  → No: ↓

Q: テキスト情報だけで十分？
  → Yes: プロンプト集（テキスト）
  → No: ↓

Q: 操作を見せたい？
  → Yes: 限定動画
```

## セクション3: AIで特典コンテンツを生成

### AIを使う理由

- **時間短縮**: 0から考えるより圧倒的に速い
- **品質安定**: 構成がしっかりしたコンテンツが作れる
- **アイデア拡張**: 自分では思いつかない視点が得られる

### 特典コンテンツ生成プロンプト

#### プロンプト集を作成する場合

```
あなたはChatGPT/Claudeのプロンプト専門家です。

以下のテーマについて、すぐに使える実用的なプロンプトを10個作成してください。

【テーマ】
{投稿のテーマを入力}

【ターゲット】
{想定する読者を入力}

【出力形式】
各プロンプトについて以下の形式で出力してください：

## プロンプト1: {タイトル}

**用途**: {どんな時に使うか}

**プロンプト**:
```
{実際のプロンプト文}
```

**使い方のコツ**: {1-2文で補足}

---

（以下同様に10個）
```

**使用例**:

```
【テーマ】
Instagram投稿文の作成

【ターゲット】
個人事業主、フリーランスでInstagramを運用している人
```

#### チェックリスト/ステップガイドを作成する場合

```
あなたは{テーマ}の専門家です。

以下のテーマについて、初心者でも実践できるステップバイステップの
チェックリストを作成してください。

【テーマ】
{投稿のテーマを入力}

【ターゲット】
{想定する読者を入力}

【出力形式】
- 全体を5-7つのステップに分ける
- 各ステップに3-5つのチェック項目を入れる
- 各項目は具体的なアクションにする（「〇〇する」形式）
- 初心者が迷わないよう補足説明を入れる

【例】
## Step 1: 準備
- [ ] 〇〇をダウンロードする
- [ ] △△のアカウントを作成する
  → ヒント: 無料プランでOK
```

**使用例**:

```
【テーマ】
n8nの初期設定

【ターゲット】
プログラミング未経験だが自動化に興味がある人
```

#### アイデアリストを作成する場合

```
あなたは{テーマ}のコンテンツクリエイターです。

以下のテーマについて、すぐに使えるアイデアを30個リストアップしてください。

【テーマ】
{投稿のテーマを入力}

【ターゲット】
{想定する読者を入力}

【出力形式】
カテゴリ別に分類して、各アイデアに1-2文の説明を付けてください。

【カテゴリ例】
- 初心者向け（10個）
- 中級者向け（10個）
- 上級者/差別化（10個）
```

### AI出力の編集ポイント

AIの出力をそのまま使うのではなく、以下を調整します：

| 調整項目 | 理由 |
|----------|------|
| 自分の経験を追加 | オリジナリティを出す |
| 不要な項目を削除 | 絞り込んで価値を高める |
| 順序を入れ替え | 優先度順に並べ替える |
| 表現を調整 | ターゲットに合った言葉遣いに |

## セクション4: CanvaでPDF特典を作成

### なぜCanvaを使うのか

- **無料**で使える
- **テンプレート豊富**で初心者でもデザインできる
- **PDF出力**が簡単
- **ブランディング**しやすい（色、フォント統一）

### Canvaでの作成手順

#### Step 1: Canvaにアクセス

1. [Canva](https://www.canva.com/) にアクセス
2. アカウントでログイン（Google連携が簡単）

[スクリーンショット: Canvaトップページ - 実践後に追加]

#### Step 2: テンプレートを選ぶ

1. 検索バーに「checklist」「guide」「ebook」などを入力
2. 好みのテンプレートを選択
3. 「このテンプレートをカスタマイズ」をクリック

**おすすめ検索ワード**:

| 特典タイプ | 検索ワード |
|------------|------------|
| チェックリスト | checklist, to-do list |
| ステップガイド | guide, how-to, tutorial |
| リスト系 | list, tips |
| 電子書籍風 | ebook, workbook |

[スクリーンショット: テンプレート検索結果 - 実践後に追加]

#### Step 3: コンテンツを入力

1. テキストをクリックして編集
2. AIで生成したコンテンツをコピー&ペースト
3. 画像やアイコンを必要に応じて変更

**編集のコツ**:

- タイトルは大きく、目立つように
- チェックボックスは「□」を使用
- 余白を十分に取る（詰め込みすぎない）
- ブランドカラーに合わせて色を調整

[スクリーンショット: コンテンツ編集画面 - 実践後に追加]

#### Step 4: ブランディング要素を追加

1. ロゴを追加（あれば）
2. SNSアカウント名を記載
3. 著作権表記を追加（例: © 2025 @your_account）

[スクリーンショット: ブランディング追加 - 実践後に追加]

#### Step 5: PDFでダウンロード

1. 右上の「共有」をクリック
2. 「ダウンロード」を選択
3. ファイル形式を「PDF（標準）」に設定
4. 「ダウンロード」をクリック

[スクリーンショット: PDF出力設定 - 実践後に追加]

### PDF特典の構成テンプレート

**1ページ目（表紙）**:
```
[タイトル]
〇〇するための
完全チェックリスト

[サブタイトル]
初心者でも迷わない
ステップバイステップガイド

[著者/アカウント名]
@your_instagram_account
```

**2ページ目（目次/概要）**:
```
このガイドの内容

✅ Step 1: 〇〇の準備
✅ Step 2: △△の設定
✅ Step 3: □□の実行
✅ Step 4: 確認と調整
```

**3ページ目以降（本文）**:
```
Step 1: 〇〇の準備

□ チェック項目1
  → 補足説明

□ チェック項目2
  → 補足説明

□ チェック項目3
  → 補足説明
```

**最終ページ（CTA）**:
```
このガイドが役に立ったら...

📱 Instagramをフォロー
   @your_instagram_account

💬 感想をDMで教えてください！

🎁 他の特典も配布中
   プロフィールリンクをチェック
```

## セクション5: 配布リンクの発行

### Google Driveで共有する方法

最も簡単で無料の方法です。

#### Step 1: Google Driveにアップロード

1. [Google Drive](https://drive.google.com/) にアクセス
2. 「＋新規」→「ファイルのアップロード」
3. 作成したPDFを選択

[スクリーンショット: Google Driveアップロード - 実践後に追加]

#### Step 2: 共有設定を変更

1. アップロードしたファイルを右クリック
2. 「共有」→「リンクをコピー」
3. 「リンクを知っている全員」に変更
4. 権限を「閲覧者」に設定
5. 「リンクをコピー」をクリック

[スクリーンショット: 共有設定画面 - 実践後に追加]

#### Step 3: リンクを短縮（任意）

長いリンクを短くしたい場合：

1. [Bitly](https://bitly.com/) にアクセス
2. Google Driveのリンクを貼り付け
3. 短縮URLを取得

**メリット**: クリック数を計測できる

### その他の配布方法

| 方法 | メリット | デメリット |
|------|----------|------------|
| Google Drive | 無料、簡単 | リンクが長い |
| Dropbox | 無料、シンプル | 容量制限あり |
| Notion | テンプレート共有に最適 | 学習コストあり |
| Gumroad（無料設定） | メールアドレス収集可能 | 設定がやや複雑 |
| 自社サイト | ブランディング | サーバー必要 |

## よくある質問

**Q: 特典は毎回新しく作る必要がありますか？**
A: いいえ。同じテーマの投稿であれば、同じ特典を使い回せます。ただし、投稿内容と特典の関連性が薄くならないよう注意してください。

**Q: 特典作成にどれくらい時間がかかりますか？**
A: 慣れると1つの特典（PDF）を30-60分で作成できます。AIでコンテンツを生成し、Canvaのテンプレートを使えば大幅に時短できます。

**Q: 無料のCanvaでも十分ですか？**
A: はい。基本的なPDF特典は無料プランで十分作成できます。ただし、一部のテンプレートや素材はPro限定です。

**Q: 特典のファイルサイズに制限はありますか？**
A: Google Driveは15GBまで無料で使えます。PDF特典は通常数MB程度なので問題ありません。DMでリンクを送る場合、ファイルサイズは関係しません。

**Q: 特典を更新したらリンクは変わりますか？**
A: Google Driveで同じファイルを上書きアップロードすれば、リンクは変わりません。過去に配布した人にも最新版が届きます。

**Q: 複数の投稿で同じ特典リンクを使ってもいいですか？**
A: はい。関連するテーマの投稿であれば、同じ特典リンクを使い回せます。エルグラムで複数の自動応答に同じリンクを設定できます。
