## セクション1: エルグラム設定の流れ

### 設定タイミング

```
投稿公開 → エルグラム設定 → コメント受付開始
```

**重要**: 投稿が公開された後でないと、エルグラムで対象投稿を選択できません。

### 設定の流れ

```
1. エルグラム管理画面にログイン
2. 「自動応答」→「新規作成」
3. 対象の投稿を選択
4. トリガーワードを設定
5. DMメッセージを設定
6. 稼働をON
```

## セクション3: 設定手順

### 参照講座

**必須**: コメント→DM自動配布講座 Module 02

詳細な設定手順は上記講座を参照してください。

### 設定のポイント

#### 対象投稿の選択

投稿を検索して選択します。投稿が公開から時間が経っている場合、検索で見つからないことがあります。その場合は日付で絞り込んでください。

#### トリガーワードの設定

Module 05で決定したtrigger_wordを設定します。

```
例: 「Canvas」
→ 「Canvas」というコメントでDMが送信される
```

**大文字・小文字**: エルグラムは大文字・小文字を区別しません。「canvas」「CANVAS」「Canvas」すべてに反応します。

#### DMメッセージの設定

テキストメッセージで特典URLを送信します。

```
コメントありがとうございます！

ChatGPT Canvasの詳しい使い方はこちら👇
https://your-domain.vercel.app/gift/chatgpt-canvas-guide

このガイドを使って、資料作成を10倍速くしてください！

感想をDMで教えてくれると嬉しいです✨
```

#### 稼働スケジュール

「常に稼働」で問題ありません。投稿の反応が落ち着いたら、稼働をOFFにすることもできます。

## よくある質問

**Q: 投稿が公開されてからエルグラム設定までタイムラグがあっても大丈夫ですか？**
A: はい。エルグラム設定前のコメントには反応しませんが、設定後のコメントには正常に反応します。なるべく早く設定することを推奨します。

**Q: 同じ特典を複数の投稿に設定できますか？**
A: はい。投稿ごとに自動応答を作成し、同じgift_urlを設定すれば、複数の投稿から同じ特典を配布できます。

**Q: トリガーワードを複数設定できますか？**
A: はい。エルグラムでは複数のトリガーワードを設定できます。「Canvas」「欲しい」「ください」など、いくつかのバリエーションを設定しておくと反応率が上がります。

**Q: 投稿を削除したらエルグラムの設定はどうなりますか？**
A: 投稿が削除されると、その投稿に紐づいた自動応答は機能しなくなります。エルグラム側で手動で削除するか、そのままにしておいても問題ありません。

**Q: エルグラムの設定を自動化できますか？**
A: 現時点ではエルグラムにAPIがないため、自動化はできません。月数回の頻度なので、手動で設定することを想定しています。
