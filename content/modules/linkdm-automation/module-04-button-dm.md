## セクション1: 効果的なDMの設計

### ボタンラベルのベストプラクティス

ボタンラベルは、ユーザーの行動を促す重要な要素です。

| 推奨 | 非推奨 |
|------|--------|
| 特典を受け取る | クリック |
| 詳細を見る | ここ |
| 今すぐ申し込む | URL |
| ダウンロードする | リンク |

**ポイント**:
- 行動を促す動詞を使う（受け取る、見る、申し込む）
- ユーザーのメリットを伝える
- 短く明確に（10文字以内推奨）

### Headlineの書き方

Headlineは、DMの本文に表示されるメッセージです。

**効果的な構成**:

```
1. 感謝・挨拶（1行）
   ↓
2. 特典の説明（1-2行）
   ↓
3. 行動を促す（1行）
```

**例1: シンプル版**
```
コメントありがとうございます！
こちらに特典をまとめました。
```

**例2: 詳細版**
```
コメントいただきありがとうございます！
今回の投稿で紹介したプロンプト集と
初心者ガイドをご用意しました。
ぜひお受け取りください！
```

### 複数ボタンの活用

Button Templateでは最大3つのボタンを設置できます。

**活用例**:

| ボタン1 | ボタン2 | ボタン3 |
|---------|---------|---------|
| 特典を受け取る | 他の投稿を見る | お問い合わせ |
| 詳細を見る | 購入ページへ | - |
| 無料版をダウンロード | 有料版を見る | - |

**優先順位**: 最も重要なボタンを1番目に配置します。

### 画像の活用

Image設定で画像をアップロードすると、DMがより目を引くものになります。

**推奨する画像**:
- 特典の表紙画像
- 商品のイメージ画像
- ブランドロゴ

**推奨サイズ**: 1:1（正方形）または16:9

### チェックポイント

- [ ] ボタンラベルは行動を促す内容になっている
- [ ] Headlineは簡潔で分かりやすい
- [ ] 必要に応じて画像を追加した

## セクション2: 活用パターン

### パターン1: 特典配布

最も基本的な活用パターンです。

**設定例**:

| 項目 | 設定 |
|------|------|
| Trigger Type | Keywords |
| Keywords | 欲しい, ほしい, ホシイ |
| Button Name | 特典を受け取る |
| Headline | コメントありがとうございます！特典をご用意しました。 |
| URL | 特典ページのURL |

**投稿のCTA例**:
```
【無料プレゼント】
ChatGPTプロンプト集を配布中！

欲しい方はコメント欄に「欲しい」と
書いてください。DMでお届けします！
```

### パターン2: 全員配布

すべてのコメントに対してDMを送信します。

**設定例**:

| 項目 | 設定 |
|------|------|
| Trigger Type | All comments |
| Send once | チェック |
| Button Name | 詳細を見る |
| Headline | コメントありがとうございます！ |

**注意**: 月1,000DM（無料プラン）の上限に注意してください。

### パターン3: キャンペーン・抽選

期間限定のキャンペーンに活用します。

**設定例**:

| 項目 | 設定 |
|------|------|
| Trigger Type | Keywords |
| Keywords | 参加, エントリー |
| Button Name | キャンペーン詳細 |
| Headline | エントリーありがとうございます！抽選結果は〇月〇日に発表します。 |

### パターン4: 絵文字リアクション

絵文字のみのコメントに反応します。

**設定例**:

| 項目 | 設定 |
|------|------|
| Trigger Type | Emoji's only |
| Button Name | 特典を見る |
| Headline | リアクションありがとうございます！ |

**投稿のCTA例**:
```
気になった方は絵文字でリアクションしてね！
DMで詳細をお送りします。
```

### パターン5: メンション企画

メンションを含むコメントに反応します。

**設定例**:

| 項目 | 設定 |
|------|------|
| Trigger Type | @Mentions only |
| Button Name | お礼の特典 |
| Headline | メンションありがとうございます！ |

### チェックポイント

- [ ] 自分の用途に合ったパターンを選択した
- [ ] 投稿のCTAとトリガーが一致している
- [ ] Send onceを適切に設定した

## セクション3: Configuration設定

### Configurationとは

Configurationでは、LinkDMのデフォルト設定を変更できます。

![Configuration設定](/linkdm-automation/module-03-step05-configuration.png)

### 設定項目

| 項目 | 説明 |
|------|------|
| **Country** | 国（Japan） |
| **Account Type** | アカウントタイプ |
| **Timezone** | タイムゾーン（Pacific Time等） |
| **Default Trigger Type** | デフォルトのトリガータイプ |
| **Default Keyword Triggers** | デフォルトのキーワード |
| **Default Exclude Keywords** | デフォルトの除外キーワード |
| **Default Message** | デフォルトのメッセージ |
| **Default Button Name** | デフォルトのボタン名 |
| **UTM Tag** | UTMパラメータ |
| **Default Image** | デフォルトの画像 |
| **Default URL** | デフォルトのURL |

### デフォルト除外キーワードの活用

**Default Exclude Keywords**に、自動返信したくないキーワードを設定しておくと便利です。

**例**:
```
Bad
Horrible
Disappointed
スパム
```

これらのキーワードを含むコメントには自動返信されません。

### UTM Tagの活用

**UTM Tag**にUTMパラメータを設定すると、Google Analyticsでトラッキングできます。

**例**:
```
?utm_source=instagram&utm_medium=dm&utm_campaign=linkdm
```

### チェックポイント

- [ ] Configurationを確認した
- [ ] 必要に応じてデフォルト値を設定した
- [ ] 除外キーワードを設定した

## セクション4: 統計の読み方と改善

### ダッシュボードの統計

All Postsセクションで、各投稿の統計を確認できます。

| 指標 | 説明 | 目安 |
|------|------|------|
| **SENT** | 送信されたDM数 | - |
| **OPEN** | 開封数 | - |
| **CLICKS** | リンククリック数 | - |
| **CTR** | クリック率（CLICKS / SENT） | 10%以上が良好 |

### 改善のポイント

#### SENTが少ない場合

**原因**: トリガーが厳しすぎる / 投稿のCTAが弱い

**対策**:
- キーワードを増やす（表記ゆれ対策）
- 「All comments」に変更
- 投稿のCTAを明確にする

#### CLICKSが少ない場合

**原因**: ボタンラベルが魅力的でない / 特典の価値が伝わっていない

**対策**:
- ボタンラベルを改善（「詳細」→「特典を受け取る」）
- Headlineで特典の価値を伝える
- 画像を追加してビジュアルを強化

#### CTRが低い場合（10%未満）

**原因**: DMの内容とユーザーの期待がミスマッチ

**対策**:
- 投稿の内容とDMの内容を一致させる
- ターゲットを絞る（Keywordsトリガー）
- 特典の内容を具体的に説明する

### PDCAサイクル

```
Plan: 特典とDMを設計
  ↓
Do: LinkDMで設定、投稿を公開
  ↓
Check: 統計を確認（SENT, CLICKS, CTR）
  ↓
Action: 改善点を見つけて調整
```

### チェックポイント

- [ ] 統計の見方を理解した
- [ ] 改善のポイントを把握した
- [ ] PDCAサイクルを意識できる

## よくある質問

**Q: 無料版の月1,000DM上限はいつリセットされますか？**
A: 毎月1日にリセットされます。ダッシュボードの「MONTHLY DM USAGE」で残りを確認できます。

**Q: 複数の投稿に同じ設定を適用できますか？**
A: Configurationでデフォルト値を設定しておくと、新規設定時に自動で入力されます。Pro以上では「Universal Triggers」機能も利用可能です。

**Q: 統計はリアルタイムで更新されますか？**
A: ほぼリアルタイムで更新されますが、若干の遅延がある場合があります。

**Q: エルグラムと比べてどちらがおすすめですか？**
A: 用途によります。**ボタン付きDMを使いたい場合はLinkDM**、**日本語UIで使いたい、無制限でDMを送りたい場合はエルグラム**がおすすめです。両方を用途に応じて使い分けることも可能です。
