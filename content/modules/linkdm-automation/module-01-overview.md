## セクション1: LinkDMとは

### LinkDMの概要

LinkDMは、Instagram DMの自動化ツールです。Meta公式API（Instagram Messaging API / Private Replies）に準拠しており、安全にコメント→DM自動配布を実現できます。

| 項目 | 内容 |
|------|------|
| 公式サイト | https://www.linkdm.com/ |
| 対応言語 | 英語（UIは英語） |
| 料金 | 無料プランあり / Pro $19/月〜 |
| 特徴 | **ボタン付きDM**が送信可能 |

### LinkDMの最大の特徴：ボタン付きDM

LinkDMでは、DMに**タップ可能なボタン**を設置できます。

**通常のテキストDM**:
```
コメントありがとうございます！
特典はこちら👇
https://example.com/gift
```

**ボタン付きDM（LinkDM）**:
```
コメントありがとうございます！
特典をご用意しました。

[📦 特典を受け取る]  ← タップでリンクに遷移
```

ボタンをタップすると、設定したURLに直接遷移します。URLがテキストで表示されないため、見た目がスッキリし、タップしやすくなります。

### Meta公式APIについて

LinkDMはMeta公式のInstagram Messaging APIを使用しています。

| 項目 | 公式API（LinkDM） | 非公式ツール |
|------|------------------|--------------|
| アカウントBAN | リスクなし | 高リスク |
| 機能の安定性 | 高い | 不安定 |
| Meta推奨 | 推奨 | 非推奨 |

## セクション2: ボタン付きDMの仕組み

### Instagram DMで使えるボタンの種類

Meta公式APIでは、DMに2種類のボタンを設置できます。

#### 1. Button Template（URLボタン）

| 項目 | 内容 |
|------|------|
| ボタン数 | 最大3つ |
| 用途 | **URLへの誘導**（特典ページ、LP等） |
| 表示 | iOS/Android両対応 |

**活用例**:
- 「特典を受け取る」→ 特典ページへ遷移
- 「詳細を見る」→ LPへ遷移
- 「申し込む」→ フォームへ遷移

#### 2. Quick Replies（選択肢ボタン）

| 項目 | 内容 |
|------|------|
| ボタン数 | 最大13個 |
| 用途 | **会話の分岐**（選択肢を提示） |
| 制限 | 各20文字まで / **デスクトップでは表示されない** |

**活用例**:
- 「クーポン」「商品情報」「お問い合わせ」→ 選択に応じて次のメッセージを送信

### ボタン付きDMのメリット

| メリット | 説明 |
|----------|------|
| タップしやすい | ボタンUIで視認性・操作性が向上 |
| URLが目立たない | 長いURLが表示されない |
| 選択肢を提示できる | ユーザーの行動を誘導しやすい |
| CTR向上 | テキストリンクよりクリック率が高い傾向 |

### iOS特有の問題を回避

iOSのInstagramアプリでは、DMに含まれる1つのURLが画像（プレビュー）として表示され、テキストで表示されないことがあります。

**Button Template（ボタン）を使えばこの問題を回避**でき、確実にユーザーをリンク先へ誘導できます。

## セクション3: 料金プランと機能比較

### LinkDM料金プラン

| プラン | 料金 | DM数/月 | アカウント数 |
|--------|------|---------|--------------|
| **Free** | $0 | 1,000 | 1 |
| **Pro** | $19/月 | 25,000 | 3 |
| **Platinum+** | $99/月 | 300,000 | 10 |

### 各プランの機能

#### Free（無料）プラン

| 機能 | 利用可否 |
|------|----------|
| Posts & Reels Auto-Reply（コメント→DM） | ○ |
| **Button Template（ボタン付きDM）** | **○** |
| **All commentsトリガー** | **○** |
| Story DM Auto-Reply | ○ |
| Instagram Automation | ○ |
| Facebook Automation | ○ |
| Next Post Feature | ○ |
| Inbox Starters | ○ |
| **Comment Auto-Reply（コメント欄への公開返信）** | × |
| **Flow Automation** | × |
| **ブランド表記削除** | × |

#### Pro（$19/月）プラン

Free機能に加えて：

| 機能 | 説明 |
|------|------|
| Comment Auto-Reply | コメント欄への公開返信 |
| Universal Triggers | 全投稿に共通のトリガー設定 |
| Flow Automation | 複雑な自動化フロー |
| Inbox Automation | 受信トレイの自動化 |
| Remove LinkDM Branding | LinkDMのブランド表記削除 |

### 無料版でできること・できないこと

**無料版でできる**:
- コメントをトリガーにDM自動送信（Posts & Reels Auto-Reply）
- ストーリーズの自動化
- 月1,000DMまで送信

**無料版ではできない（Pro以上）**:
- コメント欄への公開返信（「DMでお送りしました！」など）
- 複雑な自動化フロー
- LinkDMブランド表記の削除

## セクション4: LinkDMとエルグラムの使い分け

### 比較表

| 項目 | LinkDM | エルグラム |
|------|--------|-----------|
| 言語 | 英語 | 日本語 |
| 無料プラン | 月1,000DM | 2026年3月末まで無制限 |
| **ボタン付きDM** | **対応** | 非対応 |
| コメント欄への返信 | Pro以上 | 無料で可能 |
| 日本語サポート | なし | あり |
| 抽選機能 | あり | あり |
| ステップ配信 | あり（Flow） | あり |

### LinkDMを選ぶべきケース

1. **ボタン付きDMを使いたい**
   - 「特典を受け取る」ボタンでCTRを上げたい
   - iOSのURL表示問題を回避したい

2. **英語UIに抵抗がない**
   - 海外ツールの操作に慣れている

3. **複数の選択肢を提示したい**
   - Quick Repliesで「クーポン」「商品情報」などを分岐させたい

### エルグラムを選ぶべきケース

1. **日本語で操作したい**
   - 英語が苦手、日本語サポートが欲しい

2. **無料で大量配信したい**
   - 月1,000DM以上送る予定がある

3. **コメント欄への公開返信を無料で使いたい**
   - 「DMでお送りしました！」をコメント欄に自動投稿したい

### 両方使い分ける方法

キャンペーンの目的に応じて使い分けることも可能です：

| キャンペーン | 推奨ツール |
|-------------|-----------|
| ボタンで特典配布 | LinkDM |
| 大量のDM配布 | エルグラム |
| コメント欄への返信重視 | エルグラム |
| 選択肢で分岐させたい | LinkDM |

## よくある質問

**Q: LinkDMは日本語で使えますか？**
A: UIは英語のみです。日本語で操作したい場合はエルグラムをおすすめします。

**Q: 無料版でボタン付きDMは送れますか？**
A: **はい、送れます**。無料版でもButton Template（URLボタン）を使ったDM送信が可能です。ただし、「Sent with LinkDM」のブランド表記が表示されます（Pro以上で削除可能）。

**Q: エルグラムとLinkDMを同じアカウントで併用できますか？**
A: 技術的には可能ですが、同じ投稿に対して両方から自動応答を設定すると、ユーザーに2通のDMが届く可能性があります。用途ごとに使い分けることをおすすめします。

**Q: アカウントがBANされるリスクはありますか？**
A: LinkDMはMeta公式APIを使用しているため、適切に利用する限りアカウント停止のリスクは極めて低いです。

**Q: 月1,000DMを超えたらどうなりますか？**
A: 無料プランの上限を超えると、その月はDM送信ができなくなります。Proプラン（$19/月）にアップグレードすると25,000DMまで送信可能になります。
