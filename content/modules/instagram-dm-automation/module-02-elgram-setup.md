このモジュールを終えると、以下のことができるようになります：

- エルグラムにアカウント登録し、Instagramと連携できる
- 投稿へのコメントをトリガーにDMを自動送信できる
- キーワード設定で特定のコメントにのみ反応させられる

## セクション4: 自動応答の設定

### 自動応答設定画面へ

1. 左メニューの「顧客対応」にカーソルを合わせる
2. 「自動応答」をクリック

[スクリーンショット: 自動応答設定メニュー - 実践後に追加]

### 新規自動応答を作成

1. 「＋新規作成」をクリック
2. トリガー（反応条件）を選択：
   - **コメントに反応**: 投稿・リール・ストーリーズ・ライブへのコメント
   - **メンションに反応**: ストーリーズでメンションされた時
   - **DMに反応**: ユーザーからDMを受信した時

3. 「投稿・リールにコメントされた時」の「このトリガーで作成」をクリック
4. 「次へ」をクリック

[スクリーンショット: トリガー選択画面 - 実践後に追加]

### 管理名とフォルダの設定

1. 管理名を入力（例: 「コメントでプロンプト集配布」）
2. 保存先のフォルダを選択（新規作成も可能）
3. 「新規作成」をクリック

[スクリーンショット: 管理名入力画面 - 実践後に追加]

### Step 1: 対象の投稿を選択

1. 対象の投稿を選択：
   - **全ての投稿**: 今後の投稿にも自動応答が反映
   - **指定の投稿のみ**: 既存の投稿を選択（直近200件まで表示）

2. 「保存して次へ」をクリック

[スクリーンショット: 投稿選択画面 - 実践後に追加]

### Step 2: キーワード設定

特定のキーワードを含むコメントにのみ反応させます。

**設定方法1: 全てのコメントに反応**

すべてのコメントに対して自動応答を稼働させます。
除外ワードを設定することで、特定キーワードを除外できます。

**設定方法2: キーワードを指定**

1. 「キーワードを指定」を選択
2. 反応パターンを選択：
   - **どれか1つのキーワードに当てはまる時に反応**（OR条件）
   - **全てのキーワードが含まれている場合のみ反応**（AND条件）

3. キーワードを入力（例: 「欲しい」）
4. 一致条件を選択：
   - **一致**: 「欲しい」のみに反応
   - **含む**: 「欲しいです」など、キーワードを含む文章に反応

5. 「＋キーワードを追加」で複数キーワードを追加（表記ゆれ対策）

| 設定例 | 説明 |
|--------|------|
| 欲しい | 漢字表記 |
| ほしい | ひらがな表記 |
| ホシイ | カタカナ表記 |

6. 「保存して次へ」をクリック

[スクリーンショット: キーワード設定画面 - 実践後に追加]

### Step 3: 絞り込み設定

自動応答を稼働させる対象ユーザーを絞り込めます。

1. 対象を選択：
   - **全員に稼働させる**: すべてのユーザーに稼働
   - **ユーザーを絞り込む**: 条件に合うユーザーのみ稼働

2. 絞り込み条件の例：
   - フォロー状況（フォロワーのみ等）
   - 特定のタグを持つユーザー
   - パーソナル情報

3. 「保存して次へ」をクリック

[スクリーンショット: 絞り込み設定画面 - 実践後に追加]

### Step 4: アクション設定

自動応答が稼働した際のアクション内容を設定します。

#### 稼働回数

同じユーザーにアクションを何回稼働させるかを設定：
- **何度も稼働させる**: トリガーアクションの度に稼働
- **1度のみ稼働**: 初回のトリガーアクションのみ稼働

#### DMに送信するメッセージ

1. メッセージ設定を選択：
   - **1つのメッセージ**: 設定した1件のみ送信
   - **ランダムで設定**: 設定された内容がランダムで送信（最大5パターン）

2. メッセージ作成方法を選択：
   - **メッセージを新しく作成**: 送信内容を新規作成
   - **作成済みテンプレートから追加**: 事前に作成したテンプレートから選択

3. メッセージタイプを選択：
   - テキスト
   - 画像
   - パネルボタン（選択肢付き）

4. メッセージ内容を入力：

```
コメントありがとうございます！

プロンプト集はこちらからダウンロードできます👇
https://example.com/prompt-download

ご質問があればお気軽にDMください！
```

[スクリーンショット: DM内容設定画面 - 実践後に追加]

#### その他のアクション設定

「アクションを登録」から以下も設定可能：
- **タグ**: ユーザーにタグを付ける/外す
- **パーソナル情報**: ユーザー情報を登録
- **ステップ配信**: シナリオ配信を開始

#### アクションタイミング

自動応答を稼働させるタイミングを指定：
- **即時稼働**: トリガー発動時にすぐ送信
- **経過時間で指定**: 1分後、5分後など（手作業感を演出）
- **日時で指定**: 特定の日時に送信

5. 「保存して次へ」をクリック

### Step 5: 投稿内コメント返信

投稿のコメント欄への返信を設定できます（任意）。

1. 返信設定を選択：
   - **返信しない**: コメント欄への返信なし
   - **返信する**: コメント欄に自動返信

2. 返信する場合：
   - コメント内容を入力（例: 「DMでお送りしました！」）
   - 最大5パターンまで設定可能（ランダムで返信）
   - 1コメント最大400文字まで

3. 「保存して次へ」をクリック

[スクリーンショット: コメント返信設定画面 - 実践後に追加]

### Step 6: 稼働スケジュール

自動応答を稼働させる期間を設定します。

1. スケジュールを選択：
   - **利用しない（常に反応）**: 24時間365日稼働
   - **曜日・時間で指定**: 特定の曜日・時間帯のみ稼働
   - **期間で指定する**: 開始日〜終了日を指定

2. 「完了」をクリック

[スクリーンショット: スケジュール設定画面 - 実践後に追加]

### 自動応答を有効化

作成した自動応答が一覧に表示されます。
ステータスが「有効」になっていることを確認してください。

[スクリーンショット: 自動応答一覧画面 - 実践後に追加]

### チェックポイント

- [ ] トリガー（コメント）を設定した
- [ ] 対象の投稿を選択した
- [ ] キーワードを複数設定した（表記ゆれ対策）
- [ ] DM送信内容を設定した
- [ ] 稼働回数を設定した
- [ ] 設定を保存して有効化した

## よくある質問

**Q: エルグラムは本当に無料ですか？**
A: はい。さらに**2025年12月末までに登録したアカウントは、月間のDM/コメント自動返信通数が無制限**になるキャンペーン中です。通常は月間1,000通までが無料プランの制限ですが、キャンペーン期間中は無制限で利用できます。

**Q: アカウントがBANされるリスクはありますか？**
A: エルグラムはMeta公式APIを使用しているため、Instagramの利用規約に沿った安全な自動化です。適切に利用する限り、アカウント停止のリスクは極めて低いです。

**Q: 既存の投稿にも自動応答を設定できますか？**
A: はい。「特定の投稿」を選択して、既存の投稿に対しても自動応答を設定できます。

**Q: 複数の投稿に同じ設定を適用できますか？**
A: はい。「今後の投稿」を選択すると、新規投稿に自動で適用されます。また、複数の特定投稿を選択することも可能です。

**Q: スマホからも設定できますか？**
A: はい。ただし、初期設定はPCを推奨しています。Chromeから操作可能ですが、一部機能はPCのみとなります。

**Q: 1つの投稿に複数のキーワードを設定できますか？**
A: はい。複数のキーワードを設定でき、いずれかに該当すれば自動応答がトリガーされます。表記ゆれ（「欲しい」「ほしい」など）対策に活用してください。
