## 自動応答のトリガー（きっかけ）

ユーザーのアクションに応じて自動でDMやコメント返信を行えます。

| トリガー | 説明 | 活用例 |
|----------|------|--------|
| **投稿・リールにコメント** | フィード投稿やリールへのコメントを検知 | プレゼント配布、キャンペーン |
| **ストーリーズにコメント** | ストーリーへの返信を検知 | 限定情報の配布 |
| **ライブ配信中にコメント** | ライブ中のコメントを検知 | ライブ限定特典配布 |
| **ストーリーズでメンション** | 自分がメンションされたことを検知 | UGCキャンペーン、抽選企画 |
| **DMを受信** | ユーザーからのDMを検知 | FAQ自動返信、カスタマーサポート |

**参考マニュアル**: [自動応答機能の使い方](https://lgram.jp/manual/automatic_response/)

---

## キーワード設定

コメントやDMの内容に応じて反応を制御できます。

| 設定 | 説明 | 使用例 |
|------|------|--------|
| **全てのコメントに反応** | すべてのコメントに自動応答 | 全員にDM送信 |
| **キーワードを指定** | 特定キーワードのみに反応 | 「欲しい」で特典配布 |
| **どれか1つに該当（OR条件）** | 複数キーワードのいずれかで反応 | 「欲しい」「ほしい」両方OK |
| **全てを含む（AND条件）** | 複数キーワード全て含む場合のみ反応 | 「レシピ」+「プレゼント」 |
| **除外ワード設定** | 特定キーワードを除外 | 「質問」は除外 |

**参考マニュアル**: [複数のキーワードにそれぞれ自動返信する方法](https://lgram.jp/manual/auto_keyword_comment/)

## 絞り込み設定

どのユーザーに自動応答を稼働させるか制御できます。

| 条件 | 説明 | 使用例 |
|------|------|--------|
| **フォロー状況** | フォロワーのみ / フォロワー以外 | フォロワー限定特典 |
| **タグ** | 特定タグを持つユーザーのみ | VIP顧客向け案内 |
| **パーソナル情報** | 登録情報で絞り込み | 特定条件のユーザーのみ |
| **DM承認状況** | DM受け取り承認済みユーザー | 確実に届く相手のみ |

**参考マニュアル**: [フォロワーのみに自動応答を稼働させる方法](https://lgram.jp/manual/followers/)

## アクション設定（自動応答で実行できること）

トリガー発動時に実行できるアクションです。

### メッセージ送信

| アクション | 説明 | 使用例 |
|------------|------|--------|
| **テキスト送信** | テキストメッセージをDMで送信 | お礼メッセージ |
| **画像/メディア送信** | 画像・動画をDMで送信 | クーポン画像 |
| **パネルボタン** | 選択肢付きメッセージ | 複数の特典から選択 |
| **テンプレート送信** | 事前作成したテンプレートを送信 | 定型文の再利用 |
| **ランダムメッセージ** | 複数パターンからランダムで送信 | バリエーション演出 |
| **フォーム送信** | 入力フォームを送信 | お問い合わせ受付 |
| **コメント欄に返信** | 投稿のコメント欄に自動返信 | 「DMでお送りしました！」 |

### ユーザー管理アクション

| アクション | 説明 | 使用例 |
|------------|------|--------|
| **タグを付ける** | ユーザーにタグを付与 | 「キャンペーン参加済み」 |
| **タグを外す** | ユーザーからタグを削除 | 対応完了時 |
| **パーソナル情報登録** | ユーザー情報を保存 | 名前、興味関心 |
| **ブロック** | ユーザーをブロック | スパム対策 |

### 高度なアクション

| アクション | 説明 | 使用例 |
|------------|------|--------|
| **抽選メッセージ** | 抽選結果を自動送信 | プレゼントキャンペーン |
| **ステップ配信開始** | シナリオ配信を開始 | 教育コンテンツ配信 |

**参考マニュアル**: [アクション設定の使い方](https://lgram.jp/manual/action-setting/)

## アクションタイミング

いつ自動応答を実行するか制御できます。

| タイミング | 説明 | 使用例 |
|------------|------|--------|
| **即時稼働** | トリガー直後に即座に実行 | すぐに特典配布 |
| **経過時間で指定** | 1分後、5分後など | 手作業感の演出 |
| **日時で指定** | 特定の日時に実行 | キャンペーン開始日 |

---

## 稼働スケジュール

自動応答を稼働させる期間を制御できます。

| スケジュール | 説明 | 使用例 |
|--------------|------|--------|
| **常に稼働** | 24時間365日稼働 | 通常運用 |
| **曜日・時間で指定** | 特定の曜日・時間帯のみ | 営業時間内のみ |
| **期間で指定** | 開始日〜終了日を指定 | 期間限定キャンペーン |

## 高度な機能

### 抽選機能

コメントやDMに対して抽選を実施できます。

| タイプ | 説明 | 使用例 |
|--------|------|--------|
| **くじ引きタイプ** | 即時に抽選結果を送信 | 店頭イベント |
| **宝くじタイプ** | 当選発表日を設定 | 新商品発売キャンペーン |

**参考マニュアル**: [コメントくれた方に抽選メッセージを送信する方法](https://lgram.jp/manual/auto_lottery/)

### ステップ配信（シナリオ配信）

事前に作成したメッセージを順番に自動配信できます。

| 機能 | 説明 |
|------|------|
| タイミング設定 | 開始直後、1時間後、1日後など |
| メッセージ登録 | テキスト、画像、パネルボタン等 |
| アクション連携 | 送信時にタグ付けなども可能 |

**活用例**:
- 診断コンテンツ後のフォローアップ
- 教育・ファン化メッセージ
- セミナーリマインド

**参考マニュアル**: [ステップ配信を稼働させる方法](https://lgram.jp/manual/scenario-operation/)

### 診断コンテンツ

質問の回答に基づいて最適な商品やサービスを提案できます。

| 機能 | 説明 |
|------|------|
| ポイント加算方式 | 回答ごとにポイント付与 |
| 結果分岐 | 合計ポイントで診断結果を変更 |
| ステップ配信連携 | 結果に応じたフォローアップ |

**参考マニュアル**: [診断コンテンツの活用方法](https://lgram.jp/manual/diagnostic-content-creation/)

### カスタマーサポート機能

DMでの問い合わせ対応を効率化できます。

| 機能 | 説明 |
|------|------|
| 新規問い合わせ対応 | 初回DMに自動返信 |
| 対応中ステータス管理 | タグで対応状況を管理 |
| 対応完了処理 | 完了時にタグを外す |

**参考マニュアル**: [インスタで簡易的なカスタマーサポートを行いたい時の設定方法](https://lgram.jp/manual/auto_support/)

### 1:1チャット

エルグラム管理画面からDMの送受信・管理ができます。

| 機能 | 説明 |
|------|------|
| ユーザー検索 | ユーザー名で検索 |
| 絞り込み | タグ、対応ステータスで絞り込み |
| ブックマーク | 重要なユーザーを上部固定 |
| メモ | ユーザーごとにメモを残す |
| 対応ステータス | 対応中、対応終了などを管理 |

**参考マニュアル**: [1:1チャットの使い方](https://lgram.jp/manual/1to1-chat/)

## 便利な活用パターン

### パターン1: コメントで特典配布

```
投稿に「欲しい」とコメント
  ↓
DMで特典リンクを自動送信
  ↓
コメント欄に「DMでお送りしました！」と返信
```

### パターン2: メンション + キーワードでダブル条件

```
ストーリーズでメンション
  ↓
ユーザーに「メンション済み」タグを付与
  ↓
DMで「クーポン」とメッセージ
  ↓
タグを持つユーザーにのみクーポン送信
```

### パターン3: フォロワー限定キャンペーン

```
投稿にコメント
  ↓
フォロワーかどうかチェック
  ↓
フォロワー → 特典送信
フォロワー以外 → 「フォローしてね」案内
```

### パターン4: ライブ限定特典

```
ライブ配信中にコメント
  ↓
コメントしたユーザーにDMで限定特典を送信
```
