## セクション1: 仕組みの全体像

### コメント→DM自動配布とは

Instagramの投稿やリールに対して、ユーザーが特定のキーワード（例：「欲しい」「プレゼント」）をコメントすると、自動でDMが送信される仕組みです。

### 基本的な流れ

```
1. あなたが投稿/リールを公開
   ↓
2. 投稿に「コメントで〇〇と書いてね」とCTAを入れる
   ↓
3. ユーザーがキーワードをコメント
   ↓
4. 自動化ツールがコメントを検知
   ↓
5. DMでプレゼント（リンク、PDF等）を自動送信
```

### なぜ効果的なのか

| メリット | 説明 |
|----------|------|
| エンゲージメント向上 | コメント数が増えることでアルゴリズム評価が上がる |
| リード獲得 | DMでの接触によりリスト化が可能 |
| 24時間対応 | 自動化により深夜でも即座に対応 |
| 手間削減 | 手動でのDM返信作業が不要 |

## セクション2: Meta公式APIについて

### Instagram Graph APIとは

Meta社が提供する公式のAPIで、Instagramのビジネス/クリエイターアカウント向けの機能を提供しています。

2024年中頃に「Instagram API with Instagram Login」がアップデートされ、DM機能が強化されました。

### 公式APIを使うメリット

| 項目 | 公式API | 非公式ツール |
|------|---------|--------------|
| アカウントBAN | リスクなし | 高リスク |
| 機能の安定性 | 高い | 不安定 |
| Meta推奨 | 推奨 | 非推奨 |
| サポート | あり | なし |

### 重要：公式パートナーのみ使用する

アカウントを守るために、必ず**Meta公式パートナー**のツールを使用してください。

公式パートナーの例：
- ManyChat
- iステップ
- エルグラム

## セクション5: 規約と注意点

### Instagramの規約で禁止されていること

以下は規約違反となります：

| 禁止事項 | 具体例 |
|----------|--------|
| 現金の提供 | 「コメントで1万円プレゼント」 |
| 商品券の提供 | 「Amazonギフト券プレゼント」 |
| デジタルインセンティブ | 金銭的価値のあるポイント等 |

### 許可されているもの

以下は問題なく実施可能です：

| 許可されるもの | 具体例 |
|----------------|--------|
| 自社製品 | 自社ブランドのサンプル品 |
| デジタルコンテンツ | PDF、テンプレート、プロンプト集 |
| 限定情報 | 会員限定コンテンツへのアクセス |
| サービス体験 | 無料相談、体験セッション |

### 安全な運用のポイント

1. **Meta公式APIツールのみ使用**
   - 非公式ツールはアカウントBANのリスクあり

2. **スパム的な送信を避ける**
   - 大量の連続送信は避ける
   - メッセージは自然な文面で

3. **ユーザーのアクション起点**
   - 必ずユーザーのコメント等に対する返信として送る
   - 一方的なDM送信は禁止

4. **キーワードは複数設定**
   - 「欲しい」「ほしい」「ホシイ」など表記ゆれに対応

## よくある質問

**Q: 無料で始めるならどのツールがおすすめですか？**
A: エルグラムがおすすめです。日本語対応で基本機能が無料で使えます。ManyChatも無料プランがありますが、英語UIです。

**Q: アカウントがBANされる可能性はありますか？**
A: Meta公式APIを使用したツール（ManyChat、iステップ、エルグラム）を使用すれば、BANのリスクはありません。非公式ツールや手動での大量DM送信は危険です。

**Q: プロアカウントへの切り替えは必須ですか？**
A: はい、必須です。個人アカウントではMeta APIに接続できないため、ビジネスまたはクリエイターアカウントに切り替える必要があります。

**Q: フォロワー数の制限はありますか？**
A: 基本的にはありませんが、一部のツール機能はフォロワー数によって制限される場合があります。詳細は各ツールの公式サイトを確認してください。

**Q: 既存の投稿にも設定できますか？**
A: ツールによって異なります。ManyChatは既存投稿にも設定可能です。詳細は各ツールの設定手順モジュールで解説します。
