## セクション1: ScenebuilderのUI

### タイムラインの構成

動画生成が完了すると、Scenebuilder画面にタイムラインが表示されます。

タイムライン画面：

![タイムライン画面](/google-flow/module-02-timeline-complete.png)

### タイムラインの要素

| 要素 | 説明 |
|------|------|
| プレビュー | 選択中の動画が大きく表示される |
| タイムライン | 画面下部に動画クリップが並ぶ |
| 再生ボタン（▶） | 動画を再生 |
| 時間表示 | 全体の長さ（例: 0:31） |
| +ボタン | 新しいクリップを追加 |
| 完了ボタン | 編集を完了してエクスポートへ |

### 動画クリップの操作

タイムライン上の動画クリップをクリックすると、操作メニューが表示されます。

| 操作 | 説明 |
|------|------|
| **移動...** | クリップの位置を別の場所に移動 |
| **拡張...** | 続きの動画を生成（延長またはジャンプ先） |
| **×** | クリップを削除 |

## セクション2: 続きのシーンを作成する

タイムライン上の「+」ボタンをクリックすると、続きのシーンを追加するモーダルが表示されます。

![続きのシーンを追加](/google-flow/module-02-extend-button.png)

**2つのモード**があります。

### 延長モード（長いショット）

同じシーンを**継続して延長**したい場合に使います。

![延長モード](/google-flow/module-02-extend-mode.png)

- 「延長 ×」ボタンが表示される
- プロンプト欄に「これが起こって次に（長いショット）」と表示
- 同じカメラアングル、同じ構図で続きを生成

**使用例**:
```
The coffee continues to pour. Steam rises steadily.
```

### ジャンプ先モード（シーンがジャンプ）

**別のシーンに切り替えたい**場合に使います。

![ジャンプ先モード](/google-flow/module-02-jump-mode.png)

- 「ジャンプ先 ×」ボタンが表示される
- プロンプト欄に「これが起こって次に（シーンがジャンプ）」と表示
- カメラアングルや構図を変えて新しいシーンを生成

**使用例**:
```
Close-up of the espresso cup. Golden crema on top.
```

### モードの切り替え

プロンプト入力欄の左側にあるボタン（「延長」または「ジャンプ先」）をクリックすると、モードを切り替えられます。

### 「次はどうしますか？」

シーン生成後、タイムライン上に「次はどうしますか？」と表示されます。ここから続けて次のシーンを追加できます。

### プロンプトのコツ

**ポイント**: 続きのプロンプトは**シンプルな方が安定**します。

```
# 推奨（シンプル）
The espresso cup rises from the coffee maker.
Steam trails upward. Studio lighting.

# 非推奨（詳細すぎる）
## Scene: Enjoying the Coffee
**Scene:** A hand reaches in and picks up...
```

### Schedule（タイムライン）

Google FlowにはデフォルトでScheduleというUIがあり、これがいわゆる動画編集ソフトの**タイムライン**に相当します。

![Schedule（タイムライン）](/google-flow/module-02-schedule-timeline.png)

生成した動画クリップはこのSchedule上に並び、最終的に1本の動画として連結されます。

- Scene 1（8秒）を生成 → Scheduleに追加
- 延長でScene 2を生成 → Scheduleに追加
- ジャンプ先でScene 3を生成 → Scheduleに追加

## セクション3: クリップの配置編集

タイムライン上のクリップを編集（削除・並び替え）できます。

### 配置編集モードを開く

タイムライン右下の「配置」ボタンをクリックすると、配置編集モードに入ります。

![配置編集モード](/google-flow/module-02-timeline-done.png)

### クリップの削除

各クリップの右上にある「-」ボタンをクリックすると、そのクリップを削除できます。

### クリップの並び替え

クリップをドラッグ&ドロップすると、順番を変更できます。

- クリップを長押し
- 移動したい位置にドラッグ
- ドロップして確定

### 編集を完了

配置編集が完了したら、「完了」ボタンをクリックして通常モードに戻ります。

## セクション4: エクスポートとダウンロード

編集が完了したら、動画をエクスポートしてダウンロードします。

### Step 1: ダウンロードボタンをクリック

タイムライン右下の「ダウンロード」ボタンをクリックします。

![ダウンロードボタン](/google-flow/module-02-download-start.png)

クリックするとエクスポートが始まります。

### Step 2: エクスポート完了を待つ

エクスポートが完了すると、画面右上に通知が表示されます。

![エクスポート完了](/google-flow/module-02-export-complete.png)

「動画をエクスポートしました」という通知と、以下のボタンが表示されます：
- **ダウンロード**: 動画をダウンロード
- **閉じる**: 通知を閉じる

### Step 3: ダウンロード

「ダウンロード」をクリックすると、Schedule上にある動画が**連結された状態**でMP4形式でダウンロードされます。

### チェックポイント

## セクション5: 実践 - コーヒーメーカーPV

3つのシーンからなるコーヒーメーカーのプロモーション動画を作成しましょう。

### Scene 1: コーヒーメーカー登場

**プロンプト**:
```
A futuristic coffee maker, silver metallic finish, product photography, studio lighting
```

生成結果（8秒）：

![コーヒーメーカー](/google-flow/module-02-coffee-frame.jpg)

### Scene 2: コーヒーが注がれる（延長モード）

Scene 1の動画を選択し、「拡張...」→「延長」モードで続きを作成。

**プロンプト**:
```
The espresso cup with golden crema rises from the futuristic coffee maker.
Steam trails upward. Studio lighting, product photography style.
```

## トラブルシューティング

### 「ポリシー違反」エラー

**原因**: 人物表現（hand, person等）を含むプロンプト

**解決策**: シンプルなプロンプトに変更

```
# NG
A hand reaches in and picks up the coffee cup

# OK
The coffee cup rises smoothly. Steam trails upward.
```

### 連結後の動画がスムーズに繋がらない

**原因**: 前後のシーンで照明や構図が大きく異なる

**解決策**:
- 「延長」モードを使う（同じ構図で続ける）
- プロンプトに「same angle」「consistent lighting」を追加

### エクスポートに時間がかかる

**原因**: 動画が長い、またはサーバー負荷が高い

**解決策**:
- しばらく待つ
- ブラウザを更新せずに待機

## よくある質問

**Q: 「延長」と「ジャンプ先」の違いは何ですか？**
A: 「延長」は同じカメラアングル・構図で続きを生成します。「ジャンプ先」はカメラアングルや構図を変えて新しいシーンを生成します。

**Q: 1回の拡張で何秒追加されますか？**
A: 1回の拡張で最大8秒程度追加されます。複数回の拡張で長尺の動画を作成できます。

**Q: クリップの順序を変更できますか？**
A: 配置編集モードでドラッグ&ドロップで順番を変更できます。

**Q: 生成した動画を削除するには？**
A: 配置編集モードで「-」ボタンをクリックすると削除できます。

**Q: 動画に音声は付きますか？**
A: Veo 3.1（Beta Audio）を選択すると、自動生成された音声が付きます。Veo 2では音声なしです。

**Q: エクスポートした動画の解像度は？**
A: Proプランでは1080pでエクスポートできます。
