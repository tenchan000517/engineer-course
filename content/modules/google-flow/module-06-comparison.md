## セクション3: ユースケース別おすすめ

### Google Flowが向いている場合

- **企業PV・プロモーション動画**
  - 人物の崩れが許されない場面
  - ブランドイメージを重視する場合

- **プロンプト通りの動きを再現したい**
  - 細かい動きの指示を反映させたい
  - 意図通りの演出が必要

- **高品質な仕上がりを求める**
  - クライアントワーク
  - SNS広告素材

- **Scenebuilderで連続動画を作りたい**
  - タイムライン編集で複数シーンを連結
  - 延長・ジャンプ先で続きを生成

### KLINGが向いている場合

- **音声付き動画を作りたい**
  - VIDEO 2.6 Audioで音声同時生成
  - 別途音声編集が不要

- **日本語で操作したい**
  - 英語が苦手な方
  - チームメンバーに共有する場合

- **素早く量産したい**
  - 多少の崩れは許容できる
  - 短納期のプロジェクト

### Sora 2が向いている場合

- **風景・物・抽象的な動画**
  - 人物を含まない動画
  - アート作品・背景動画

- **ChatGPTと連携したワークフロー**
  - 既にChatGPT Plusを契約している
  - プロンプト作成もChatGPTで行いたい

- **Storyboard機能を活用したい**
  - 複数シーンを一括で制作
  - シーケンス動画の制作

### 使い分けフローチャート

```
人物が主役の動画を作りたい？
├─ Yes → 崩れが許されない？
│         ├─ Yes → Google Flow
│         └─ No → 音声も同時に生成したい？
│                   ├─ Yes → KLING
│                   └─ No → Google Flow または KLING
└─ No → Sora 2
```

## まとめ

### 各ツールの位置づけ

| ツール | 一言で言うと |
|--------|-------------|
| Google Flow | 品質最高・有料だが価値あり |
| KLING | 無料あり・バランス型・日本語対応 |
| Sora 2 | 非人物動画・ChatGPT連携 |

### おすすめの使い方

1. **無料で試すならKLING**（166クレジット/月）
2. **品質重視ならGoogle Flow**（$19.99/月〜）
3. **風景・抽象動画はSora 2**
