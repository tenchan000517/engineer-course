# ロック楽曲を生成する

**所要時間**: 15分
**難易度**: ⭐☆☆☆☆

---

## このモジュールで学ぶこと

- Sunoの基本操作
- Customモードでの楽曲生成
- スタイルプロンプトの書き方
- 歌詞へのセクションタグ・歌い方タグの付け方

---

## 学習目標

このモジュールを終えると、以下のことができるようになります：

- Sunoにログインして楽曲を生成できる
- Customモードでプロンプトと歌詞を指定できる
- セクションタグを使って曲の構成を制御できる
- カノンコードなどのコード進行を指定できる

## セクション3: Customモードで作成

ログイン後、左メニューの「Create」をクリックし、上部で「Custom」を選択します。

Customモードの画面：

![Customモード](/images/suno/suno-persona.png)

### 画面構成

| 要素 | 説明 |
|------|------|
| Simple / Custom | Simpleは自動生成、Customは細かく指定 |
| Lyrics | 歌詞を入力 |
| Styles | 音楽スタイル（プロンプト）を入力 |
| + Persona | ボイスペルソナを選択（オプション） |

### チェックポイント

- [ ] Createページに移動した
- [ ] Customモードを選択した

## セクション4: スタイルプロンプトを入力

「Styles」欄に音楽スタイルを入力します。

Styles入力欄：

![Styles入力](/images/suno/suno-styles.png)

### 今回使用するプロンプト

```
Japanese rock anthem, emotional power rock, I-V-vi-iii-IV-I-IV-V progression, soaring male vocals, guitar-driven, cinematic build, explosive chorus, inspirational, dynamic soft-to-loud, epic finale, J-rock, BPM 78
```

### プロンプトの構成要素

| 要素 | 例 | 説明 |
|------|-----|------|
| ジャンル | Japanese rock anthem | 曲の基本ジャンル |
| ムード | emotional, inspirational | 曲の雰囲気 |
| コード進行 | I-V-vi-iii-IV-I-IV-V progression | カノンコード |
| ボーカル | soaring male vocals | 声質・歌い方 |
| 楽器 | guitar-driven | メイン楽器 |
| 構成 | cinematic build, dynamic soft-to-loud | 曲の展開 |
| テンポ | BPM 78 | 速さ |

> **ポイント**: 特定のアーティスト名は著作権の問題があるため使用しません。代わりに「J-rock」「emotional rock anthem」などジャンル名で指定します。

### チェックポイント

- [ ] Stylesにプロンプトを入力した

## セクション5: 歌詞を入力

「Lyrics」欄に歌詞を入力します。セクションタグを使って構成を指定できます。

歌詞入力欄：

![歌詞入力](/images/suno/suno-lyrics.png)

### 使えるセクションタグ

| タグ | 用途 |
|------|------|
| `[Intro]` | イントロ |
| `[Verse]` | Aメロ |
| `[Pre-Chorus]` | Bメロ |
| `[Chorus]` | サビ |
| `[Bridge]` | Cメロ・ブリッジ |
| `[Outro]` | アウトロ |

### 歌い方の指示タグ

| タグ | 効果 |
|------|------|
| `[melodic]` | メロディアスに |
| `[soaring vocals]` | 伸びやかに声を張る |
| `[powerful]` | 力強く |
| `[soft]` | 柔らかく |
| `[building]` | 徐々に盛り上げる |
| `[explosive]` | 爆発的に |

### タイトルを入力

「Song Title」欄に曲のタイトルを入力します。

タイトル入力欄：

![タイトル入力](/images/suno/suno-title.png)

### Advanced Options（オプション）

より細かい設定が必要な場合は「Advanced Options」を開きます。

Advanced Options画面：

![Advanced Options](/images/suno/suno-advanced-options.png)

| 設定 | 説明 | おすすめ |
|------|------|---------|
| Exclude styles | 除外したいスタイル | 不要なジャンルを指定 |
| Vocal Gender | ボーカルの性別 | Male / Female |
| Lyrics Mode | 歌詞モード | Manual（手動）推奨 |
| Weirdness | 独創性 | 50%（デフォルト） |
| Style Influence | スタイル影響度 | 50%（デフォルト） |

## よくある質問

**Q: 無料で何曲まで生成できますか？**
A: 無料プランでは1日10クレジット（5曲分）が付与されます。1回の生成で2クレジットを消費し、2つのバリエーションが生成されます。

**Q: 生成した楽曲の著作権は誰にありますか？**
A: 有料プランでは商用利用が可能です。無料プランでは個人利用に限定されます。詳細はSunoの利用規約を確認してください。

**Q: 特定のアーティストの声で歌わせることはできますか？**
A: 著作権・肖像権の問題があるため、特定のアーティスト名を指定することは推奨されません。代わりにジャンルや歌い方で指定してください。

**Q: 歌詞が長すぎて入力できません**
A: Sunoの歌詞は約3000文字が上限です。長い場合は楽曲を分割して生成し、後から音声編集ソフトで結合することを検討してください。

**Q: 日本語の歌詞でも生成できますか？**
A: はい、日本語の歌詞にも対応しています。ただし、発音が不自然になる場合があるため、ひらがなやカタカナを使用すると改善することがあります。
