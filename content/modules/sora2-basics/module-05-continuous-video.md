## セクション1: 連続動画が必要な理由

### Sora 2の動画長の制限

| プラン | 最大動画長 |
|--------|----------|
| Plus | 25秒 |
| Pro | 25秒 |

25秒を超える動画を作りたい場合、複数のクリップを作成して連結する必要があります。

### 連続動画の課題

単純に別々の動画を作ると：
- キャラクターの見た目が変わる
- シーンの連続性がなくなる
- つなぎ目が不自然になる

### 解決策

**最後のフレームを参照画像として使用**することで、キャラクターと状況の一貫性を保ちながら続きを生成できます。

## セクション2: 最後のフレームを使う方法

### 概要

1. 元の動画の**最後のフレーム**を画像として保存
2. その画像をStoryboardの**参照画像**としてアップロード
3. 続きのシーンを生成

### Step 1: 最後のフレームを抽出

動画の最後のフレームをスクリーンショットで保存します。

**方法:**
- 動画プレーヤーで最後のフレームで一時停止 → スクリーンショット
- 動画編集ソフトでフレームをエクスポート

### Step 2: Storyboardで続きを作成

1. sora.com で「Storyboard」を開く
2. **Scene 1に最後のフレームをアップロード**
3. 続きのシーンをプロンプトで記述
4. 生成

### プロンプト例

元の動画がキャラクターがサムズアップで終わっている場合：

**Scene 1（参照画像をアップロード）:**
```
Chibi anime style, 2D animation.
Same chibi character starts walking forward,
curious expression, looking around.
Background transforms into a colorful digital world.
```

**Scene 2:**
```
Same chibi character discovers a glowing treasure chest,
eyes sparkle with excitement,
reaches out toward the chest.
```

**Scene 3:**
```
Same chibi character opens the chest,
golden light bursts out,
jumps with joy, celebratory atmosphere.
```

## セクション3: Stitch機能

### Stitch機能とは

複数のクリップを**連結**して1本の動画にする機能です。

### 使い方

1. Draftsで連結したい動画を選択

![Drafts画面](/sora2/module-05-drafts.png)

2. 「Stitch」ボタンをクリック

![Stitch UI](/sora2/module-05-stitch-ui.png)

3. プレビュー確認後、連結を実行
4. 完成した動画がDraftsに保存される

### Stitch機能の仕様

| 項目 | 詳細 |
|------|------|
| 動作 | 単純に動画をくっつける |
| 最大長 | 60秒まで |
| クレジット消費 | なし（連結のみ） |
| 利用可能環境 | iOS、sora.com（Androidは未対応） |

### 検証結果

15秒 + 15秒 = **30秒**（単純に足し算）

### Stitch vs 編集ソフト

| 項目 | Stitch | 編集ソフト |
|------|--------|-----------|
| 手軽さ | 簡単 | 手間がかかる |
| トランジション | なし（直接連結） | 追加可能 |
| 細かい調整 | 不可 | 可能 |
| 推奨 | 確認用 | **最終版用** |

**結論**: 最終的な動画は**編集ソフト**で連結する方が品質が高くなります。

## セクション4: 注意点とベストプラクティス

### 重要: 最後のフレームで全身を映す

**最後のフレームでキャラクターの全身が映っていないと、続きの動画で服装などが変わるリスクがあります。**

| 最後のフレーム | 続きの動画 |
|--------------|----------|
| 上半身のみ | 下半身が変わる（半ズボンになる等） |
| 腕が見切れ | 袖の色が変わる |
| 後ろ姿 | 顔のデザインが変わる |

### ベストプラクティス

1. **最後のシーンは全身ショットで終わらせる**
   - キャラクター全体が映るようにプロンプトを記述

2. **プロンプトで特徴を繰り返す**
   - 続きのシーンでもキャラクターの服装・特徴を記述

3. **複数回生成して選ぶ**
   - 一貫性の高いものを選択

4. **シーンの終わりを意識する**
   - 続きを作りやすい終わり方にする

### プロンプトのコツ

```
Same chibi character with messy black hair,
VR goggles on head, black glasses,
black t-shirt, blue jacket tied around waist,
blue jeans, black shoes.
Full body visible in frame.
```

## まとめ

### このモジュールで学んだこと

- **最後のフレームを参照画像として使う**のが連続動画作成の鍵
- Stitch機能は単純に連結するだけ（**編集ソフトの方が良い**）
- **最後のフレームで全身を映す**ことでキャラクター一貫性を保てる

### 連続動画作成の流れ

```
1. 元の動画を作成
      ↓
2. 最後のフレームをスクリーンショット
      ↓
3. そのフレームをStoryboardにアップロード
      ↓
4. 続きのシーンを生成
      ↓
5. 編集ソフトで連結（Stitchは確認用）
      ↓
6. 必要に応じて繰り返し（最大60秒まで）
```

### 重要な注意点

| 項目 | 内容 |
|------|------|
| 最後のフレーム | **全身が映っていること** |
| Stitch | 確認用。最終版は編集ソフトで |
| プロンプト | キャラクター特徴を毎回記述 |

## よくある質問

**Q: Stitch機能でトランジションを追加できますか？**
A: いいえ、Stitchは単純に連結するだけです。トランジションが必要な場合は編集ソフトを使用してください。

**Q: 60秒を超える動画は作れますか？**
A: Sora単体では60秒が上限です。それ以上の長さは編集ソフトで複数の動画を連結してください。

**Q: 続きの動画でキャラクターが変わってしまいました**
A: 最後のフレームで全身が映っていなかった可能性があります。全身ショットで終わるシーンを作り直すか、プロンプトでより詳細にキャラクター特徴を記述してください。

**Q: AndroidでStitch機能は使えますか？**
A: 現時点ではAndroidは未対応です。iOSアプリまたはsora.comを使用してください。
