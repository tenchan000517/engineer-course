## Instagram Graph API インサイトデータ

### 利用可能なメトリクス（メディア単位）

| メトリクス | 説明 | 対象 |
|-----------|------|------|
| `impressions` | 表示回数 | 画像/動画/リール |
| `reach` | リーチしたユニークアカウント数 | 画像/動画/リール |
| `likes` | いいね数 | 画像/動画/リール |
| `comments` | コメント数 | 画像/動画/リール |
| `saved` | 保存数 | 画像/動画/リール |
| `shares` | シェア数 | リールのみ |
| `plays` | 再生回数 | リール/動画 |
| `total_interactions` | 総インタラクション | リール |

### APIエンドポイント

```
GET /{media-id}/insights?metric=impressions,reach,likes,comments,saved,shares,plays
```

### 必要な権限

- `instagram_basic`
- `instagram_manage_insights`（追加で必要かも）

## 想定ワークフロー構成

```
┌─────────────────────────────────────────────────────────────────────┐
│                    インサイトデータ取得ワークフロー                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌──────────────────┐                                               │
│  │  Schedule Trigger │  毎日特定時刻に実行（例: 毎朝9時）              │
│  └────────┬─────────┘                                               │
│           │                                                         │
│           ▼                                                         │
│  ┌──────────────────┐                                               │
│  │  Get PUBLISHED   │  postsシートからPUBLISHED/STORY_POSTEDを取得   │
│  │  Posts           │  → 投稿後24-48時間経過したもの                 │
│  └────────┬─────────┘                                               │
│           │                                                         │
│           ▼                                                         │
│  ┌──────────────────┐                                               │
│  │  Loop            │  各投稿に対して                                │
│  └────────┬─────────┘                                               │
│           │                                                         │
│           ▼                                                         │
│  ┌──────────────────┐                                               │
│  │  Get Insights    │  Instagram Graph APIでインサイト取得           │
│  │  from Instagram  │  GET /{ig_post_id}/insights                   │
│  └────────┬─────────┘                                               │
│           │                                                         │
│           ▼                                                         │
│  ┌──────────────────┐                                               │
│  │  Update Sheet    │  インサイトデータをシートに保存                 │
│  │  with Insights   │  → 新シート or 既存シート追加列                │
│  └────────┬─────────┘                                               │
│           │                                                         │
│           ▼                                                         │
│  ┌──────────────────┐                                               │
│  │  Update Status   │  postsシートのstatusをINSIGHTS_FETCHEDに更新   │
│  └──────────────────┘                                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
