## 絶対ルール

### やってはいけないこと

1. **勝手な判断・解釈をしない** - 不明点は必ずユーザーに確認
2. **暴走しない** - 指示された範囲のみ作業
3. **余計な拡張をしない** - 「ついでに〜も」は禁止
4. **ランキングリールと混同しない** - 別の型であることを意識
5. **「何から始めましょう？」と聞かない** - ロードマップに従う

### やるべきこと

1. **このHANDOFFを最初に読む**
2. **ランキングリール講座を参照して構成を理解する**
3. **現在のフェーズを確認する**
4. **完了したらこのHANDOFFを更新する**

## プロジェクト概要

### 目的

「アフレコリール」の型を講座化し、顔出しなしで量産できるリール制作システムを構築する。

### アフレコリールとは

映像と音声を分けて制作するスタイルのリール。

```
映像：作業風景、AI生成動画、ストック素材、街並みなど
 +
音声：後から録音したナレーション（またはAI音声）
 +
テロップ：無音再生用の補完
```

### ランキングリールとの違い

| 項目 | ランキングリール | アフレコリール |
|------|-----------------|---------------|
| 構造 | 順位づけ（論外→1位） | フック→チラ見せ→CTA |
| 視聴者心理 | 「1位が知りたい」 | 「やり方が知りたい」 |
| 顔出し | 不要 | 不要 |
| 映像素材 | AI生成画像→動画化 | 多様（B-roll、画面録画、AI動画） |
| 音声 | 男女掛け合い | 単独ナレーション |
| 尺 | 60-90秒 | **27-56秒（短め）** |
| リサーチ | Antigravity | Antigravity（**同じ**） |
| 整備 | Claude Code | Claude Code（**同じ**） |

### この型の強み

| 強み | 説明 |
|------|------|
| **顔出し不要** | 映像は作業風景やAI生成で対応可能 |
| **量産しやすい** | 映像素材を使い回せる、リサーチパイプライン共通 |
| **理解度が高い** | 視覚+聴覚の二重チャネルで情報が入る |
| **参入障壁が低い** | 撮影スキル不要、編集も簡単 |
| **飽きにくい** | 映像を楽しみながらノウハウを受け取れる |

## 型の本質（最重要）

### 固定部分と可変部分

```
【固定部分】= 型
フック → AIで何ができるか → プロンプトのチラ見せ → CTA → 特典

【可変部分】= トレンドから選ぶ
「AIで何ができるか」の内容
```

### マスト要素（4つ）

| # | 要素 | 説明 | 例 |
|---|------|------|-----|
| 1 | **AIで何ができるか** | 成果物・効果を見せる | 「こんな映像が作れる」 |
| 2 | **プロンプトのチラ見せ** | 「このプロンプトを使えば」 | 「このプロンプトで〇〇できる」 |
| 3 | **特典への誘導** | チラ見せした内容が特典になる | 「まとめたので〇〇とコメント」 |
| 4 | **思考コスト0のCTA** | 内容と無関係、1-2語で回答可能 | 「旅行したい国」「好きな映画」 |

### 投稿と特典の連動構造

```
動画内：「このプロンプトを使えば〇〇できる」（チラ見せ）
     ↓
視聴者：「そのプロンプト欲しい」（欲求が発生）
     ↓
CTA：「まとめたので、〇〇をコメントで教えてね」
     ↓
特典：チラ見せしたプロンプト/ツールの使い方
```

**ランキングリールと完全に同じ構造。「効果の先出し」→「欲求喚起」→「特典で回収」**

## なぜこの型がバズるのか（心理学的背景）

### 1. 二重符号化理論

**原理**: 視覚と聴覚の両方で情報を受け取ると、記憶定着率が上がる。

```
映像のみ：記憶定着率 10%
音声のみ：記憶定着率 20%
映像＋音声：記憶定着率 50%
```

**ポイント**: アフレコリールは「見て+聞いて」学べるので、視聴者が「わかった」と感じやすい。

### 2. 認知負荷の分散

**原理**: 視覚チャネルと聴覚チャネルは独立して情報を処理できる。

```
❌ テロップだけで説明（視覚に負荷集中）
✅ 映像で状況を見せながら、音声で説明（負荷分散）
```

**ポイント**: 視聴者が「疲れない」ので最後まで見てもらえる。

### 3. 没入感（イマージョン）

**原理**: 魅力的な映像に引き込まれると、情報を受け入れやすくなる。

```
作業風景、旅行映像、街並み、AI生成のクリエイティブ映像
        ↓
「かっこいい」「おしゃれ」と感じる
        ↓
その世界観の中で語られるノウハウを信頼する
```

**ポイント**: 映像の世界観が発信者のブランディングになる。

### 4. ながら視聴への対応

**原理**: SNSユーザーの多くは「ながら視聴」している。

```
通勤中：イヤホンで音声を聴きながら
作業中：BGMとして流しながら
```

**ポイント**: 音声で完結する構成なら、画面を見ていなくても内容が伝わる。

### 5. 保存・シェアの動機

**原理**: 「あとで見返したい」と思わせると保存率が上がる。

```
映像として美しい → 保存して見返したい
ノウハウが詰まっている → 保存してあとで実践したい
```

## 台本の基本構成

### 共通構造（全パターン共通）

```
┌──────────────────────────────────────────────┐
│ ① フック（3-14秒）                            │
│    視覚ショック or 権威提示 or ライフスタイル   │
└──────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────┐
│ ② 解決策の提示（3-7秒）                        │
│    「AIで作れます」「このプロンプトで」         │
└──────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────┐
│ ③ 具体的な方法（10-46秒）                      │
│    ステップ解説 or ツール実演                   │
│    ★「このプロンプトを使えば〇〇できる」を必ず入れる │
└──────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────┐
│ ④ 成果・証拠（3-5秒）                          │
│    「これがこうなった」「〇万再生連発」         │
└──────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────┐
│ ⑤ CTA（5秒）                                   │
│    「〇〇をコメントで教えてね」                 │
└──────────────────────────────────────────────┘
```

### フックの3類型

| 類型 | 手法 | 視聴者心理 | 推奨尺 |
|------|------|-----------|--------|
| **視覚ショック** | すごい映像を冒頭で見せる | 「何これ」→「作り方知りたい」 | 25-30秒 |
| **権威提示** | 実績・肩書きを冒頭で出す | 「この人の言うこと聞こう」 | 50-60秒 |
| **ライフスタイル** | 憧れの生活を見せる | 「こうなりたい」→「方法知りたい」 | 40-45秒 |

### 調査から判明した冒頭フック7カテゴリ

詳細は `content/research/opening-hooks-50-examples.md` を参照。

| # | カテゴリ | 代表例 |
|---|----------|--------|
| 1 | 衝撃・驚き型 | 「まだ○○してないの？」「これ知らないと損」 |
| 2 | 問いかけ・共感型 | 「毎日残業で疲れてませんか？」 |
| 3 | ビフォーアフター・対比型 | 「作業時間：3時間→5分」 |
| 4 | How-to・実演型 | 「たった3ステップで完成」 |
| 5 | ストーリー・体験談型 | 「AIで3ヶ月無駄にした話」 |
| 6 | トレンド・最新情報型 | 「速報！○○に新機能追加」 |
| 7 | 警告・注意喚起型 | 「これやると垢BANされます」 |

### 重要：量産における型の選び方

**7カテゴリから機械的に選ぶのはNG。**

```
❌ 悪い例
「今日は衝撃型、明日は問いかけ型、明後日はストーリー型…」
→ 毎回考える負荷が発生、クオリティが安定しない

✅ 良い例
「自分に合ったフックを1〜2つ決めて、それを使い続ける」
→ 思考コスト最小、クオリティ安定、量産可能
```

**量産の鉄則**: クオリティを落とさずに量産できる「型」を見つけ、それを徹底的に使い回す。

### 構成パターン（サンプル分析から抽出）

#### パターンA: デモ→解決策→CTA型（短尺25-30秒）

```

「こんな〇〇や、こんな〇〇が今バズってるんやけど」
（デモ映像を3連発）

「実はこれ、AIで作れます」

【0:13-0:18】メリット + プロンプトチラ見せ
「〇〇を使えば、一気に〇〇できる」
「このプロンプトを使えば〇〇」

【0:18-0:22】機会強調
「まだ使える人は少ないからチャンス」

【0:22-0:27】CTA

**用途**: AI効果のデモ、新機能紹介、ツール紹介
**特典**: ツールの使い方 + プロンプト

## 音声制作

### 音声の選択肢

| 方法 | メリット | デメリット |

## 制作フロー（詳細）

### Step 1: テーマ選定

```
Antigravityリサーチ結果から選ぶ
        ↓
「AIで何ができるか」が明確なものを選ぶ
        ↓
視覚的に見せられる成果物があるか確認
```

### Step 2: 台本作成

```
構成パターンを選ぶ（A: デモ型 / B: 権威型 / C: vlog型）
        ↓
フック → AIで何ができるか → プロンプトチラ見せ → CTA
        ↓
音声用スクリプトとテロップを分けて記述
```

### Step 3: 特典作成

```
チラ見せしたプロンプトの詳細版を作成
        ↓
使い方の手順をまとめる
        ↓
content/gifts/ に配置
```

### Step 4: 映像素材準備

```
内容に合った映像タイプを選ぶ
        ↓
AI生成 or B-roll or 画面録画
        ↓
尺に合わせて素材を用意（27-56秒分）
```

### Step 5: 音声制作

```
スクリプトを読み上げ or AI音声合成
        ↓
抑揚・スピード・ポーズを調整
        ↓
BGMを選定（著作権フリー）
```

### Step 6: 編集

```
映像と音声を合わせる
        ↓
テロップを追加
        ↓
BGMを追加（音声を邪魔しない音量）
        ↓
