## プロンプトテンプレート集

### 調査で判明した効果的なプロンプト構造

#### Style Block Template

```
[Genre: ジャンル名] [Vibe: ムード] [Instruments: 楽器リスト] [Era: 年代]
```

**例**:
```
[Genre: 1980s Japanese City Pop] [Vibe: Nostalgic, Night Drive] [Instruments: Fender Rhodes, Slap Bass, Brass Section]
```

#### Meta-Tag Template

```
[Intro: 楽器/雰囲気の指定]
[Verse 1]
[Pre-Chorus: Rising tension]
[Chorus: Powerful, anthemic]
[Instrumental Break]
[Verse 2]
[Bridge: Stripped down, emotional]
[Final Chorus: Full power, all instruments]
[Outro: Sustained, fading]
```

#### 歌い方タグ

| タグ | 効果 |
|------|------|
| `[Whispered]` | ささやき声 |
| `[Anthemic]` | 壮大に |
| `[Multi-tracked]` | 多重録音風 |
| `[clear vocals]` | クリアなボーカル |
| `[emotional cracks]` | 感情的な声の震え |

#### コミュニティTips

| 問題 | 解決策 |
|------|--------|
| BPMが無視される | 歌詞内に `[124 BPM]` をメタタグとして記載 |
| 曲が終わらない | `[Stop]` または `[End]` タグを追加 |
| ボーカルが意味不明 | `(clear vocals)` を追加、または歌詞を大文字で記載 |
| AI臭い音 | プロンプトに「AI」という単語を入れない |

## 注意事項

- **Suno v5以降の機能**を前提としている（2025年9月リリース）
- **有料プラン**が必要な機能がある（Stem Export、長尺生成、商用利用）
- **外部DAW**（Logic Pro / Ableton / FL Studio）は別途学習が必要
- コミュニティ情報は変動する可能性があるため、実践検証が重要
