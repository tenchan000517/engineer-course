## ツール別プロンプトのコツ

### Sora 2

| ポイント | 説明 |
|----------|------|
| 構造 | 「主語 + 動作 + 背景 + 雰囲気」の順序 |
| 音声 | 「Enable audio generation」で音声も生成 |
| アスペクト比 | 9:16（縦）、16:9（横）、1:1（正方形） |

### Veo 3 / 3.1

| ポイント | 説明 |
|----------|------|
| 詳細度 | 具体的な形容詞を多用 |
| カメラワーク | 「Camera slowly pushes in」など明記 |
| 雰囲気 | 「Cinematic」「Documentary style」で調整 |

### Runway Gen-4

| ポイント | 説明 |
|----------|------|
| 画像入力 | 参照画像をアップロードすると精度UP |
| スタイル | 「Film noir」「Vogue editorial」などで指定 |
| 動き | Motion Brush機能で部分的な動きを指定可能 |

### Dreamface

| ポイント | 説明 |
|----------|------|
| 人物写真 | 顔がはっきり見える写真を使用 |
| 特殊機能 | Water Float、Mermaid AI、Doll Transformなど |
| 背景 | 自動で水中背景に変換される |

### Haiper AI

| ポイント | 説明 |
|----------|------|
| 画像→動画 | 静止画をアップロードして動画化 |
| 短尺向け | 5〜8秒の短い動画が得意 |
| 抽象表現 | 液体や粒子など抽象的な表現が得意 |
