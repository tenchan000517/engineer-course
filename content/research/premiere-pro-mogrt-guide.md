# モーショングラフィックステンプレート（.mogrt）作成完全ガイド
## Instagram リール用「順位表示アニメーション」

**調査日**: 2026-01-21
**対象**: Instagramリール動画制作（ランキング形式）
**用途**: 詳細手順の生データ保存（編集不可）

---

## 完成イメージ

お客様のランキングリール用に作成するテンプレート：

- **順位表示**：「1位」「2位」「3位」「4位」「論外」
- **アニメーション**：スライドイン、フェードイン
- **編集可能項目**：順位テキスト、色、ツール名

---

## 必要なソフトウェア

- **Adobe After Effects**（テンプレート作成用）
- **Adobe Premiere Pro**（テンプレート使用用）

## Part 1：After Effectsでの順位表示アニメーション作成

### ステップ1：新規プロジェクトとコンポジション作成

#### 1-1. After Effectsを起動

```
ファイル → 新規 → 新規プロジェクト
```

#### 1-2. Instagram リール用コンポジション作成

![コンポジション設定](https://blog.pond5.com/wp-content/uploads/2017/03/screen-shot-2017-03-29-at-3-33-29-pm.png)

```
コンポジション → 新規コンポジション
```

**設定：**
- **コンポジション名**：`Rank_Display_Template`
- **プリセット**：カスタム
- **幅**：`1080` px
- **高さ**：`1920` px（縦型 9:16）
- **フレームレート**：`30` fps
- **デュレーション**：`00:00:03:00`（3秒）
- **背景色**：黒（プレビュー用）

「**OK**」をクリック

---

### ステップ2：順位表示デザインの作成

#### 2-1. 背景シェイプを作成

![シェイプレイヤー作成](https://blog.pond5.com/wp-content/uploads/2017/03/screen-shot-2017-03-29-at-3-36-19-pm.png)

```
レイヤー → 新規 → シェイプレイヤー
```

**手順：**

1. **長方形ツール**を選択
2. コンポジションパネルに長方形を描画
3. レイヤー名を「**背景_シェイプ**」に変更

**プロパティ設定：**
- **塗り**：白 (#FFFFFF)
- **線**：なし
- **サイズ**：幅 400px × 高さ 150px
- **位置**：中央（X: 540, Y: 960）
- **角丸**：20px（オプション）

#### 2-2. 順位テキストを作成

![テキストツール](https://blog.pond5.com/wp-content/uploads/2017/03/screen-shot-2017-03-29-at-3-36-43-pm.png)

```
レイヤー → 新規 → テキスト
```

**手順：**

1. **テキストツール（T）**を選択
2. コンポジションパネルをクリックしてテキスト入力
3. 「**1位**」と入力

**文字パネル設定：**
- **フォント**：Noto Sans JP Bold
- **フォントサイズ**：120px
- **文字色**：黒 (#000000)
- **整列**：中央揃え

**トランスフォーム：**
- **位置**：X: 540, Y: 960（中央）

レイヤー名を「**順位テキスト**」に変更

#### 2-3. ツール名テキストを作成（オプション）

同様の手順で小さいテキストを作成：

```
レイヤー → 新規 → テキスト
```

**設定：**
- **テキスト**：「ツール名」
- **フォントサイズ**：40px
- **位置**：順位テキストの下（Y: 1040）
- レイヤー名：「**ツール名テキスト**」

---

### ステップ3：アニメーションの追加

#### 3-1. スライドインアニメーション

![キーフレーム設定](https://www.schoolofmotion.com/hs-fs/hubfs/Imported%20sitepage%20images/essential-graphics-panel_22.png?width=940&height=389&name=essential-graphics-panel_22.png)

**背景シェイプのアニメーション：**

1. **背景_シェイプ**レイヤーを選択
2. タイムインジケーターを**0フレーム**に移動
3. **位置**プロパティのストップウォッチアイコンをクリック（キーフレーム作成）
4. 位置を **X: -400**, Y: 960（画面外左）に設定
5. タイムインジケーターを**0.5秒**に移動
6. 位置を **X: 540**, Y: 960（中央）に変更

自動的に2つ目のキーフレームが作成される

**イージング適用：**

1. 両方のキーフレームを選択
2. 右クリック → **キーフレーム補助** → **イージーイーズ**

#### 3-2. テキストのフェードインアニメーション

**順位テキストのアニメーション：**

1. **順位テキスト**レイヤーを選択
2. タイムインジケーターを**0.3秒**に移動
3. **T**（トランスフォーム）→ **不透明度**のストップウォッチアイコンをクリック
4. 不透明度を**0%**に設定
5. タイムインジケーターを**0.8秒**に移動
6. 不透明度を**100%**に変更

同様に「**ツール名テキスト**」にもフェードインを適用

### ステップ4：エッセンシャルグラフィックスパネルで編集可能に設定

#### 4-1. エッセンシャルグラフィックスパネルを開く

![エッセンシャルグラフィックスパネル](https://blog.frame.io/wp-content/uploads/2024/08/EG-Template-MOGRT-Adobe-After-Effects-2024-09.jpg)

```
ウィンドウ → エッセンシャルグラフィックス
```

または

```
コンポジション → Rank_Display_Template を右クリック
→ 「エッセンシャルグラフィックスで開く」
```

#### 4-2. テンプレート名を設定

![テンプレート名](https://www.premiumbeat.com/blog/wp-content/uploads/2019/05/Motion-Graphics-Template-3.jpg)

エッセンシャルグラフィックスパネル上部の「**マスター**」フィールドに名前を入力：

```
順位表示_ランキングアニメーション
```

#### 4-3. 編集可能なプロパティを追加

![プロパティの追加](https://blog.frame.io/wp-content/uploads/2024/08/EG-Template-MOGRT-Adobe-After-Effects-2024-17.jpg)

**サポートされるプロパティのみ表示：**

エッセンシャルグラフィックスパネル下部の「**ソロサポートされるプロパティ**」ボタンをクリック
→ タイムラインに編集可能なプロパティのみが表示される

**順位テキストを編集可能にする：**

1. タイムラインで「**順位テキスト**」レイヤーを展開
2. **テキスト** → **ソーステキスト**を探す
3. **ソーステキスト**を**エッセンシャルグラフィックスパネルにドラッグ**

パネルに「ソーステキスト」が追加される

**プロパティ名を変更：**

エッセンシャルグラフィックスパネルで「ソーステキスト」をダブルクリック
→ 「**順位**」に変更

**ツール名テキストを編集可能にする：**

同様の手順で「**ツール名テキスト**」の**ソーステキスト**を追加
→ 名前を「**ツール名**」に変更

**背景色を編集可能にする：**

1. 「**背景_シェイプ**」レイヤーを展開
2. **コンテンツ** → **長方形 1** → **塗り 1** → **カラー**
3. **カラー**プロパティを**エッセンシャルグラフィックスパネルにドラッグ**
4. 名前を「**背景色**」に変更

### ステップ5：論外用の赤色バージョンを作成（オプション）

#### 5-1. コンポジションを複製

```
プロジェクトパネル → Rank_Display_Template を右クリック
→ 複製（Ctrl+D / Cmd+D）
```

#### 5-2. 複製したコンポジションの設定変更

**名前変更：**
```
Rank_Display_Template_RED（論外用）
```

**テキスト色を赤に変更：**

1. 複製したコンポジションを開く
2. 「順位テキスト」レイヤーを選択
3. 文字パネルで**文字色を赤**（#FF0000）に変更

**エッセンシャルグラフィックスで同様に設定**

---

### ステップ6：ポスターフレームを設定

![ポスターフレーム](https://www.premiumbeat.com/blog/wp-content/uploads/2019/05/Motion-Graphics-Template-3.jpg)

**手順：**

1. タイムインジケーターを**1秒**に移動（アニメーション完成時）
2. エッセンシャルグラフィックスパネルの「**ポスター時間を設定**」ボタンをクリック

このフレームがPremiere Proのサムネールになる

### ステップ7：.mogrt ファイルとして書き出し

#### 7-1. 書き出し設定

![書き出し設定](https://helpx.adobe.com/content/dam/help/en/after-effects/using/creating-motion-graphics-templates/jcr_content/main-pars/image_1532082706/export-video-preview.png.img.png)

**手順：**

1. エッセンシャルグラフィックスパネル下部の「**モーショングラフィックステンプレートを書き出し**」ボタンをクリック

![書き出しダイアログ](https://www.simonsaysai.com/hs-fs/hubfs/image17-11.png?width=472&height=475&name=image17-11.png)

**設定項目：**

**宛先：**
- 「**ローカルテンプレートフォルダー**」を選択
  - 自動的にPremiere Proで使えるフォルダに保存される

**パス（参考）：**
- **Windows**: `C:\Users\[ユーザー名]\Documents\Adobe\Premiere Pro\25.0\Templates`
- **Mac**: `/Users/[ユーザー名]/Documents/Adobe/Premiere Pro/25.0/Templates`

**オプション：**
- ビデオプレビューを含める（推奨）
  - Premiere Proでホバー時にプレビュー表示
- このモーショングラフィックステンプレートが Adobe Fonts にないフォントを使用している場合は警告

「**OK**」をクリック

`.mogrt`ファイルが書き出される

## Part 2：Premiere Proでのテンプレート使用

### ステップ1：エッセンシャルグラフィックスパネルを開く

![Premiere Proエッセンシャルグラフィックス](https://skillhub.jp/wp-content/uploads/2021/08/PR-MOGRT-03-1024x574.jpg)

```
ウィンドウ → エッセンシャルグラフィックス
```

### ステップ2：テンプレートの読み込み

#### 自動的に表示される場合

「**参照**」タブ → 「**ローカルテンプレートフォルダー**」
→ 「**順位表示_ランキングアニメーション**」が表示される

#### 手動で読み込む場合

![インストール](https://skillhub.jp/wp-content/uploads/2021/08/PR-MOGRT-04-1024x573.jpg)

1. パネル右下の「**モーショングラフィックステンプレートをインストール**」フォルダアイコンをクリック
2. 書き出した`.mogrt`ファイルを選択
3. 「**開く**」をクリック

### ステップ3：タイムラインに配置

![タイムラインに配置](https://skillhub.jp/wp-content/uploads/2021/08/PR-MOGRT-05-1024x575.jpg)

**手順：**

1. エッセンシャルグラフィックスパネルのテンプレートを選択
2. タイムラインの**V5トラック**（順位表示用）にドラッグ

グラフィッククリップが配置される

### ステップ4：内容をカスタマイズ

![編集](https://skillhub.jp/wp-content/uploads/2021/08/PR-MOGRT-07-1024x576.jpg)

**手順：**

1. タイムライン上のグラフィッククリップを選択
2. エッセンシャルグラフィックスパネルの「**編集**」タブを開く
3. 以下を編集：
   - **順位**：「1位」→「2位」などに変更
   - **ツール名**：「Genspark」など
   - **背景色**：必要に応じて変更

リアルタイムでプレビューに反映される

## バリエーション作成のコツ

### 複数の順位用テンプレートを作成

After Effectsで以下のバリエーションを作成すると便利：

1. **通常版**：1位〜4位用（黒文字）
2. **論外版**：赤文字、警告マーク付き
3. **強調版**：金色、大きめサイズ（1位専用）

### フォルダで整理

Premiere Proのエッセンシャルグラフィックスパネルでフォルダ作成：

```
順位表示/
├── 通常_1〜4位
├── 論外_赤字
└── 強調_1位専用
```

## トラブルシューティング

### 問題1：Premiere Proでテンプレートが表示されない

**原因：**
- 保存場所が正しくない

**解決方法：**

```
Premiere Pro → 編集 → 環境設定 → メディア
→ 「ローカルテンプレートフォルダーの場所」を確認
```

### 問題2：フォントが見つからない

**原因：**
- Adobe Fontsにないフォントを使用

**解決方法：**

1. After Effectsで**Adobe Fonts**のフォントに変更
2. または使用するPCに同じフォントをインストール

### 問題3：アニメーションが動かない

**原因：**
- エフェクトコントロールで再生ヘッドが0フレームで止まっている

**解決方法：**

Premiere Proのプログラムモニターで再生すると正しくアニメーションする
