# SRT字幕ファイルをPremiere Proに読み込んで自動適用する完全ガイド

**調査日**: 2026-01-21
**対象**: Instagramリール動画制作（ランキング形式）

1. **SRTファイルの準備・確認**

## ステップ1：SRTファイルの準備と確認

### 1-1. SRTファイルの形式を確認

![SRTファイル例](https://www.dsp.co.jp/tocreator/all/tips-all/wp-content/uploads/2021/06/caption_06-1024x576.jpg)

**正しいSRTファイルの形式：**

```srt
1
00:00:00,000 --> 00:00:01,500
実はこれ

2
00:00:01,500 --> 00:00:03,000
AIで作った

3
00:00:03,000 --> 00:00:05,000
ASMR動画なんです
```

**重要なポイント：**
- 番号は連番
- タイムコードは `時:分:秒,ミリ秒` 形式
- `-->` の前後にスペース必須
- 字幕ブロック間は空行が必要

### 1-2. SRTファイルの保存場所を確認

プロジェクトフォルダ内の「`03_字幕_Subtitles`」フォルダに配置することを推奨。

---

## ステップ2：SRTファイルをPremiere Proにインポート

### 方法1：ファイルメニューから読み込み（推奨）

![ファイルから読み込み](https://digitalanarchy.com/blog/wp-content/uploads/2021/05/Premiere_Pro_Import_SRT_1-562x302.jpg)

**手順：**

```
メニューバー → ファイル → 読み込み
```

または **`Ctrl + I`**（Windows）/ **`Cmd + I`**（Mac）

![SRTファイルを選択](https://www.simonsaysai.com/hs-fs/hubfs/image28-9.png?width=544&height=647&name=image28-9.png)

1. 読み込みダイアログで**SRTファイル**を選択
2. 「**読み込み**」をクリック

### 方法2：ドラッグ&ドロップ（簡単）

![ドラッグ&ドロップ](https://www.dsp.co.jp/tocreator/all/tips-all/wp-content/uploads/2021/06/caption_06-1024x576.jpg)

**手順：**

エクスプローラー（Windows）/ Finder（Mac）から、**SRTファイルをプロジェクトパネルにドラッグ**

これだけで読み込み完了

### 方法3：タイムラインに直接ドロップ

![タイムラインに直接](https://www.dsp.co.jp/tocreator/all/tips-all/wp-content/uploads/2021/06/caption_07-1024x576.jpg)

SRTファイルを**タイムラインパネルの空いている箇所**に直接ドラッグ

→ 自動的に「**新しいキャプショントラック**」が作成される

---

## ステップ3：タイムラインへの配置

### 3-1. プロジェクトパネルからタイムラインへドラッグ

![キャプショントラック作成](https://www.dsp.co.jp/tocreator/all/tips-all/wp-content/uploads/2021/06/caption_07-1024x576.jpg)

**手順：**

1. プロジェクトパネルの**SRTファイル**をクリック
2. タイムラインの**空いているビデオトラック上部**にドラッグ
3. 「**新しいキャプショントラック**」ダイアログが表示される

![新しいキャプショントラック設定](https://www.simonsaysai.com/hs-fs/hubfs/image17-11.png?width=472&height=475&name=image17-11.png)

**設定項目：**
- **形式**：Subtitle（デフォルト）
- **ストリーム名**：わかりやすい名前に変更（例：メインナレーション）
- **OK**をクリック

### 3-2. キャプショントラックが作成される

![キャプショントラック](https://www.dsp.co.jp/tocreator/all/tips-all/wp-content/uploads/2021/06/caption_08-1024x576.jpg)

- 紫色の**キャプションクリップ**がタイムラインに配置される
- SRTファイルのタイミング通りに字幕が表示される

---

## ステップ4：字幕スタイルの適用

### 4-1. テキストパネルを開く

![テキストパネル](https://helpx.adobe.com/content/dam/help/en/premiere/desktop/add-text-images/insert-captions/create-styles-for-captions/jcr_content/main-pars/image_1915058813/caption-style.png.img.png)

```
ウィンドウ → テキスト
```

### 4-2. キャプションを選択してスタイルを確認

![キャプション選択](https://www.dsp.co.jp/tocreator/all/tips-all/wp-content/uploads/2021/06/caption_10-1024x576.jpg)

**手順：**

1. タイムライン上の**キャプションクリップを選択**
2. プログラムモニターで字幕が表示される
3. **テキストパネル**でスタイルを編集

### 4-3. プロパティパネルでスタイルを編集

![プロパティパネル](https://douga-jin.com/wp-content/uploads/2023/12/caption-change-4.webp)

**Premiere Pro 2025の場合：**

```
ウィンドウ → プロパティ
```

**編集できる項目：**
- **フォント**：Noto Sans JP Bold
- **フォントサイズ**：80
- **文字色**：白 (#FFFFFF)
- **アウトライン**：黒、5px
- **背景の塗り**：オン/オフ
- **位置**：画面下から20%

## ステップ5：スタイルの一括変更

### 5-1. リンクスタイルの作成

![リンクスタイル作成](https://yuchannelblog.com/wp-content/uploads/2025/03/premier-pro-text-style01.png)

**手順：**

1. デザインを確定したキャプションを選択
2. **プロパティパネル**を開く
3. 「**リンクスタイル**」セクションの「**+**」ボタンをクリック
4. 「**スタイルを作成**」を選択

![スタイル名入力](https://douga-jin.com/wp-content/uploads/2023/12/caption-change-7.webp)

**設定：**
- **スタイル名**：`リール_通常字幕`
- **保存先**：「ローカルスタイルに保存」を選択
- 「**OK**」をクリック

### 5-2. 複数のキャプションにスタイルを一括適用

![一括適用](https://douga-jin.com/wp-content/uploads/2023/12/caption-change-10.webp)

**方法1：全てのキャプションを選択して適用**

**手順：**

1. タイムラインでキャプショントラックをクリック
2. **`Ctrl + A`**（Windows）/ **`Cmd + A`**（Mac）で全選択
3. プロパティパネルの「**スタイルブラウザー**」を開く
4. 保存した「**リール_通常字幕**」をクリック

全ての字幕に一括でスタイルが適用される

**方法2：個別に選択して適用**

![個別適用](https://community.adobe.com/t5/image/serverpage/image-id/635127iF851E8EBE3EE7A98/image-size/large?v=v2&px=999)

**手順：**

1. **Shift**を押しながら複数のキャプションクリップを選択
2. スタイルブラウザーから「**リール_通常字幕**」をクリック

## ステップ6：「論外」部分を赤字に変更

### 6-1. 論外用の赤字スタイルを作成

![論外スタイル](https://douga-jin.com/wp-content/uploads/2023/12/caption-change-7.webp)

**手順：**

1. 「論外」が含まれるキャプションを選択
2. プロパティパネルで**文字色を赤**に変更（#FF0000）
3. 「**リンクスタイル**」の「**+**」→「**スタイルを作成**」
4. スタイル名：`リール_論外_赤字`
5. 「**ローカルスタイルに保存**」→「**OK**」

### 6-2. 論外キャプションに赤字スタイルを適用

![論外適用](https://douga-jin.com/wp-content/uploads/2023/12/caption-change-10.webp)

**手順：**

1. 「論外」の順位が表示されるキャプションを選択
2. スタイルブラウザーから「**リール_論外_赤字**」をクリック

該当する字幕だけが赤字に変更される

## よくある問題と解決方法

### 問題1：SRTファイルが読み込めない

**原因：**
- SRTファイルの形式が正しくない
- 文字コードが対応していない

**解決方法：**

1. SRTファイルを**メモ帳**（Windows）/ **テキストエディット**（Mac）で開く
2. 「**名前を付けて保存**」
3. **文字コード**：`UTF-8`を選択
4. 再度読み込み

### 問題2：タイミングがずれている

**原因：**
- SRTファイルのタイムコードが動画と合っていない

**解決方法：**

![キャプションの編集](https://www.diyvideostudio.com/wp-content/uploads/2021/10/Export-and-Import-Subtitles-in-Premiere-Pro-4.jpg)

**手順：**

1. プロジェクトパネルのSRTファイルを**ダブルクリック**
2. 「**キャプションエディター**」が開く
3. タイミングを直接編集
4. 「**OK**」で保存

### 問題3：スタイルが適用されない

**原因：**
- キャプションがリンクスタイルに紐付いていない

**解決方法：**

1. キャプションを選択
2. プロパティパネルで「**リンクスタイル**」の「**なし**」をクリック
3. 保存済みスタイルを選択

## 実際の作業フロー（効率的な手順）

### ステップバイステップ

```
1. SRTファイルをプロジェクトパネルにドラッグ（5秒）
   ↓
2. SRTファイルをタイムラインにドラッグ（5秒）
   ↓
3. キャプションを全選択（Ctrl+A）（2秒）
   ↓
4. 保存済み「リール_通常字幕」スタイルを適用（3秒）
   ↓
5. 「論外」部分のみ選択して赤字スタイル適用（10秒）
   ↓
完成！（合計25秒）
```

## さらなる効率化テクニック

### テクニック1：スタイルをテンプレートプロジェクトに保存

保存したスタイルは**プロジェクトテンプレート**に含まれるため、次回以降は自動で使用可能になります。

### テクニック2：キーボードショートカットを活用

| 操作 | Windows | Mac |
|------|---------|-----|
| 読み込み | `Ctrl + I` | `Cmd + I` |
| 全選択 | `Ctrl + A` | `Cmd + A` |
| 再生/停止 | `Space` | `Space` |

### テクニック3：位置の微調整

![位置調整](https://helpx.adobe.com/content/dam/help/en/premiere/desktop/add-text-images/insert-captions/create-styles-for-captions/jcr_content/main-pars/image_718234041/Caption-style.png.img.png)

プロパティパネルの「**位置**」で、字幕の縦位置を微調整できます。

**推奨設定：**
- **X軸**：0（中央）
- **Y軸**：-150（画面下から150px上）
