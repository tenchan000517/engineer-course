## 共通パターン（本質の抽出）

### フックの3類型

| 類型 | 手法 | 視聴者心理 | サンプル |
|------|------|-----------|---------|
| **視覚ショック** | すごい映像を冒頭で見せる | 「何これ」→「作り方知りたい」 | 1 |
| **権威提示** | 実績・肩書きを冒頭で出す | 「この人の言うこと聞こう」 | 2 |
| **ライフスタイル** | 憧れの生活を見せる | 「こうなりたい」→「方法知りたい」 | 3 |

### 共通構造（全サンプル）

```
① フック（3-14秒）
   └─ 視覚 or 権威 or ライフスタイル

② 解決策の提示（3-7秒）
   └─ 「AIで作れます」「このプロンプトで」

③ 具体的な方法（10-46秒）
   └─ ステップ解説 or ツール実演

④ 成果・証拠（3-5秒）
   └─ 「これがこうなった」「〇万再生連発」

⑤ CTA（5秒）
   └─ 「〇〇をコメントで教えてね」
```

## ランキングリールとの比較

| 項目 | ランキングリール | アフレコリール |
|------|-----------------|---------------|
| **構造** | 固定（論外→ランキング→1位→CTA） | 柔軟（複数パターン） |
| **フック** | 認知的不協和（「論外」で否定） | 視覚/権威/ライフスタイル |
| **視聴継続の仕組み** | 「1位が知りたい」 | 「やり方が知りたい」 |
| **ナレーター** | 男女掛け合い | 単独（主に女性） |
| **映像** | AI生成画像→動画化 | B-roll + 画面録画の組み合わせ |
| **尺** | 60-90秒 | **27-56秒（短め）** |
| **CTA設計** | 思考コスト0 | 思考コスト0（同じ） |

## 心理学的メカニズム

### ランキングリールで使用 → アフレコでは使わない

| メカニズム | ランキング | アフレコ |
|-----------|-----------|---------|
| 認知的不協和 | ✅ 冒頭の「論外」 | ❌ 使わない |
| ツァイガルニク効果 | ✅ 1位を見るまで離脱不可 | △ ステップ完了への欲求 |

### アフレコリール特有のメカニズム

#### 1. 即時的な価値提供（サンプル1）

```
視覚ショック（すごい映像）
        ↓
「これ作りたい」という欲求が発生
        ↓
方法を教えてもらえる期待で視聴継続
```

#### 2. 権威性による信頼（サンプル2）

```
「億作った私が」（権威提示）
        ↓
「この人の言うことは正しい」という信頼
        ↓
ステップ解説を素直に受け入れる
```

#### 3. 憧れ喚起→方法への誘導（サンプル3）

```
海外旅行、自由なライフスタイル（憧れ）
        ↓
「どうやってるの？」という疑問
        ↓
「AIでインスタ伸ばしたから」（解決策）
        ↓
「私もやりたい」→方法を聞く姿勢に
```

#### 4. ステップ構造の安心感

```
「Step1, Step2, Step3...」と順番に提示
        ↓
「順番にやれば自分にもできそう」
        ↓
特典（プロンプト集）で再現性を担保
```

## CTA設計の分析

### 完全一致点（ランキングリールと同じ）

```
❌ 内容に関連したCTA
   「AIについてどう思う？」→ 考える必要がある

✅ 思考コスト0のCTA
   「旅行したい国」「好きな映画」「今日食べたもの」
   → 1-2語で答えられる、正解がない
```

### CTAの実例

| サンプル | CTA | 特徴 |
|----------|-----|------|
| 1 | 旅行したい国 | 国名1語でOK |
| 2 | 好きな映画 | タイトル1語でOK |
| 3 | 今日食べたもの | 料理名1語でOK |

## 映像構成の分析

### 映像素材の種類

| パート | サンプル1 | サンプル2 | サンプル3 |
|--------|----------|----------|----------|
| フック | AI生成動画（効果デモ） | ライフスタイルB-roll | 旅行vlog |
| 解説 | AI生成+ツール画面 | ツール画面録画 | GPTs画面録画 |
| 成果 | 再生数カウンター | 再生数グラフ | インサイト画面 |
| CTA | 国旗絵文字演出 | 資料プレビュー | ライフスタイルに戻る |

### 映像の法則

```
【フック】 目を引く映像（AI生成 or B-roll or vlog）
     ↓
【解説】 画面録画（ツール操作、ChatGPT画面）
     ↓
【成果】 数字の可視化（グラフ、カウンター、インサイト）
     ↓
【CTA】 ライフスタイルに戻る or 特別演出
```

## 制作上の発見

### 尺について

| パターン | 推奨尺 | 理由 |
|----------|--------|------|
| デモ型 | 25-30秒 | 視覚インパクト重視、説明は最小限 |
| ステップ型 | 50-60秒 | 3-5ステップを丁寧に解説 |
| vlog型 | 40-45秒 | vlog+ノウハウのバランス |

**ランキングリール（60-90秒）より全体的に短い。**

### B-roll素材について

サンプル2, 3で使用されているライフスタイル映像:
- 海辺のテラス
- ホテルの窓からの景色
- ハンモックでPC操作
- 夕暮れ時のPC作業
- 旅行先での食事

**AI生成ではなく実写（または実写風ストック素材）が多い。**

## 型の本質（最重要）

### 固定部分と可変部分

```
【固定部分】= 型
フック → AIで何ができるか → プロンプトのチラ見せ → CTA → 特典

【可変部分】= トレンドから選ぶ
「AIで何ができるか」の内容
```

### マスト要素（4つ）

| # | 要素 | 説明 | 例 |
|---|------|------|-----|
| 1 | **AIで何ができるか** | 成果物・効果を見せる | 「こんな映像が作れる」 |
| 2 | **プロンプトのチラ見せ** | 「このプロンプトを使えば」 | 「このプロンプトで〇〇できる」 |
| 3 | **特典への誘導** | チラ見せした内容が特典になる | 「まとめたので〇〇とコメント」 |
| 4 | **思考コスト0のCTA** | 内容と無関係、1-2語で回答可能 | 「旅行したい国」「好きな映画」 |

### 投稿と特典の連動構造

```
動画内：「このプロンプトを使えば〇〇できる」（チラ見せ）
     ↓
視聴者：「そのプロンプト欲しい」（欲求が発生）
     ↓
CTA：「まとめたので、〇〇をコメントで教えてね」
     ↓
特典：チラ見せしたプロンプト/ツールの使い方
```

**ランキングリールと完全に同じ構造。「効果の先出し」→「欲求喚起」→「特典で回収」**
