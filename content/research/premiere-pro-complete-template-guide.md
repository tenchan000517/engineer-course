## Phase 2：ビン（フォルダ）構造の作成

### ステップ2-1：プロジェクトパネルでビンを作成

![ビン作成](https://blog.pond5.com/wp-content/uploads/2016/02/Screen-Shot-2016-02-16-at-10.35.10-AM.png)

**方法1：アイコンから作成**

プロジェクトパネル右下の「**新規ビン**」アイコンをクリック

**方法2：ショートカット**

```
Ctrl + B (Windows) / Cmd + B (Mac)
```

**方法3：右クリック**

プロジェクトパネルの空白部分で右クリック → 「**新規ビン**」

---

### ステップ2-2：完全なビン構造を作成

以下の順番で**8つのビン**を作成します：

```
プロジェクトパネル/
├── 01_素材_Raw_Footage
├── 02_音声_Audio
├── 03_字幕_Subtitles
├── 04_BGM_Music
├── 05_グラフィックス_Graphics
├── 06_完成シーケンス_Final_Sequences
├── 07_書き出し_Exports
└── 08_参考資料_Reference
```

**詳細な作成手順：**

#### 1つ目のビン：素材フォルダ

1. 「**新規ビン**」をクリック
2. 作成されたビン（デフォルト名「ビン」）を選択
3. **Enter**キーを押して名前を編集
4. `01_素材_Raw_Footage` と入力
5. **Enter**で確定

#### サブビンを作成（素材フォルダ内）

「01_素材_Raw_Footage」をダブルクリックして開く

以下の**サブビン**を作成：

```
01_素材_Raw_Footage/
├── メイン動画
├── アバター素材
└── ツールアイコン
```

**戻る方法：**
プロジェクトパネル左上の「**上矢印**」（1つ上のレベル）をクリック

#### 2つ目のビン：音声フォルダ

同様に作成：

```
02_音声_Audio/
├── 男性ナレーション
├── 女性ナレーション
└── 効果音_SE
```

#### 3つ目のビン：字幕フォルダ

```
03_字幕_Subtitles/
└── SRTファイル
```

#### 4つ目のビン：BGMフォルダ

```
04_BGM_Music/
```

#### 5つ目のビン：グラフィックスフォルダ

```
05_グラフィックス_Graphics/
├── タイトル
├── 順位表示
└── トランジション
```

#### 6つ目のビン：完成シーケンスフォルダ

```
06_完成シーケンス_Final_Sequences/
```

#### 7つ目のビン：書き出しフォルダ

```
07_書き出し_Exports/
```

#### 8つ目のビン：参考資料フォルダ

```
08_参考資料_Reference/
```

### ステップ2-3：説明用テキストファイルの追加（オプション）

各ビンに「**使い方.txt**」を追加すると便利です。

### ステップ4-2：ビデオトラック名の設定

![トラック名設定](https://blog.pond5.com/wp-content/uploads/2016/02/Screen-Shot-2016-02-16-at-10.35.43-AM.png)

**手順：**

タイムラインパネル左側のトラックヘッダーで、各トラック名をダブルクリックして編集

**V6（最上部）から順に：**

| トラック | 名前 | 用途 |
|---------|------|------|
| V6 | `タイトル・テキスト` | 動画タイトル表示 |
| V5 | `順位表示` | 1位、2位、論外など |
| V4 | `ツールアイコン` | 各ツールのロゴ・画像 |
| V3 | `アバター` | キャラクター表示 |
| V2 | `メイン動画` | ランキング説明動画 |
| V1 | `背景・調整レイヤー` | 背景色、カラーグレーディング |

**ビデオトラック名変更の詳細手順：**

1. 「V6」の名前部分をダブルクリック
2. テキスト編集可能になる
3. `タイトル・テキスト` と入力
4. **Enter**で確定
5. V5〜V1も同様に変更

---

### ステップ4-3：オーディオトラック名の設定

**A1（最上部）から順に：**

| トラック | 名前 | 用途 |
|---------|------|------|
| A1 | `男性ナレーション` | メインナレーション |
| A2 | `女性ナレーション` | 質問・相づち |
| A3 | `BGM` | 背景音楽 |
| A4 | `効果音・SE` | 効果音 |

**設定方法：**

タイムラインパネルでオーディオトラック部分を表示
（スクロールまたはタイムラインを縮小表示）

各トラック名をダブルクリックして変更

---

### ステップ4-4：トラックの高さ調整（オプション）

作業しやすいようにトラックの高さを調整：

**メイン動画トラック（V2）を大きく：**

1. V2トラックの境界線にカーソルを合わせる
2. 上下矢印カーソルになったらドラッグして高さ調整
3. 推奨：通常の2〜3倍の高さ

**字幕トラックを見やすく（後で追加）**

## 実際の使用フロー

### プロジェクト開始からの流れ

```
【Day 1】準備
1. テンプレートから新規プロジェクト作成（5秒）
2. プロジェクト名を変更（例：AIツールランキング_20260121）

【Day 2】素材配置
3. 素材を各ビンにドラッグ＆ドロップ（2分）
   - 01_素材_Raw_Footage → メイン動画
   - 02_音声_Audio → ナレーション
   - 03_字幕_Subtitles → SRTファイル

【Day 3】編集
4. タイムラインに素材配置（5分）
   - V2: メイン動画
   - A1/A2: ナレーション
   - 字幕トラック: SRT読み込み

5. スタイル適用（30秒）
   - 全字幕選択 → 通常スタイル適用
   - 論外部分 → 赤字スタイル適用

【Day 4】書き出し
6. 書き出し（2分）
   - Ctrl+M → Instagram_Reels プリセット選択
   - 書き出し
```

**合計作業時間：約10分** ← テンプレートなしだと30〜40分
