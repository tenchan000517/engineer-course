# Sora 2クイックスタートガイド

OpenAIのSora 2を使って、テキストからAI動画を生成する方法を解説します。

---

## 準備するもの

- ChatGPT Plusアカウント（$20/月）
- ブラウザ

---

## ステップ1: Soraにアクセス

1. ブラウザで `sora.com` を開く
2. ChatGPTアカウントでログイン

---

## ステップ2: 動画を生成

1. 画面左上の「Create」をクリック
2. プロンプト入力欄に動画の説明を入力
3. 設定を確認:
   - Duration: 5秒 / 10秒 / 15秒 / 20秒
   - Resolution: 480p / 720p / 1080p
   - Aspect Ratio: 16:9 / 9:16 / 1:1
4. 「Generate」をクリック
5. 1-2分待つと動画が生成

## Storyboard機能

複数シーンを繋げて台本どおりの動画を作る機能。

### 使い方
1. 画面下部の「Storyboard」をクリック
2. Scene 1にプロンプトを入力
3. 「+」でシーンを追加
4. 各シーンにプロンプトを入力
5. 「Create」で生成

### 設定
- Duration: 最大25秒
- シーン数: 自由（25秒以内で分割）

---

## カメラワーク用語

| 用語 | 効果 |
|------|------|
| `camera slowly pans left` | ゆっくり左にパン |
| `camera tilts up` | 上にチルト |
| `camera tracks forward` | 前に進む |
| `low-angle shot` | 見上げる構図 |
| `aerial shot` | 空撮 |
| `close-up` | クローズアップ |

---

## 人物の一貫性を保つコツ

Storyboardで同じ人物を使う場合:

```
Scene 1: A Japanese man, late 20s, short black hair, navy blazer...
Scene 2: Same man, late 20s, short black hair, navy blazer...
Scene 3: Same man...
```

- **全シーンで同じ特徴を繰り返す**
- **「Same」を使って参照**

## よくある質問

A: ChatGPT Plusサブスクリプションが必要です。
