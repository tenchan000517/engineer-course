# ChatGPTの回答精度を上げる3つの言葉

**この特典を受け取っていただきありがとうございます！**

ChatGPTは便利ですが、実は「大嘘つき」になることがあります。でも、たった3つの言葉を付け足すだけで、正直に答えてくれるようになります。

この特典では、ChatGPTの回答精度を劇的に上げる3つの魔法の言葉と、すぐに使えるプロンプトをお届けします。

## なぜChatGPTは嘘をつくのか

ChatGPTは「わからない」と言うのが苦手です。

| 問題 | 原因 |
|------|------|
| 存在しない本を紹介する | 「何か答えなきゃ」と思って作り話をする |
| 間違った数字を出す | 自信がなくても推測で答えてしまう |
| 古い情報を最新と言う | 学習データの限界を伝えない |

**結論**: ChatGPTに「正直に答えていいよ」と許可を出す必要があります。

---

## 精度を上げる3つの言葉

### 1. 「自信がないときは『わかりません』と答えてください」

```
自信がないときはわかりませんと答えて、嘘や推測で答えないでください。
```

**効果**:
- 知らないことを「知らない」と言ってくれる
- 推測と事実を区別してくれる
- 誤った情報を鵜呑みにするリスクが減る

---

### 2. 「ステップバイステップで教えてください」

```
結論を急がないで、考えた手順をステップバイステップで教えてください。
```

**効果**:
- 思考過程が見えるので、間違いに気づきやすい
- 複雑な問題でも整理して回答してくれる
- 「なんとなく」で答えることが減る

---

### 3. 「引用元やリンクを必ず出してください」

```
その答えの根拠となる引用元やリンクを必ず出してください。
```

**効果**:
- 出典を求めると嘘をつきにくくなる
- 自分で裏付けを確認できる
- 信頼性の高い情報だけを採用できる

**注意**: ChatGPTは架空のURLを作ることもあるので、実際にリンクを開いて確認しましょう。

## コピペで使えるプロンプト

以下のプロンプトをChatGPTに最初に送ってから質問すると、精度が大幅に上がります。

### 基本プロンプト

```
これからいくつか質問をします。回答時は以下のルールに従ってください。

1. 自信がないときは「わかりません」と答えて、嘘や推測で答えないでください
2. 結論を急がず、考えた手順をステップバイステップで教えてください
3. 答えの根拠となる引用元やリンクを必ず出してください

では、質問です。
[ここに質問を入力]
```

---

### リサーチ用プロンプト

```
以下のトピックについて調べてください。

【トピック】
[調べたい内容]

【ルール】
1. 自信がない情報は「確認が必要」と明記してください
2. 各情報の出典（サイト名やURL）を必ず記載してください
3. 推測や憶測は含めないでください
4. 情報が見つからない場合は「情報が見つかりませんでした」と正直に答えてください

【出力形式】
- 箇条書きまたは表形式で整理
- 各項目に出典を明記
```

---

### 比較・分析用プロンプト

```
以下の2つを比較分析してください。

【比較対象】
A: [対象1]
B: [対象2]

【ルール】
1. 確実な情報のみ記載し、不確かな点は「要確認」と明記
2. 比較の根拠となる情報源を示してください
3. ステップバイステップで分析過程を説明してください

【出力形式】
1. それぞれの特徴（表形式）
2. 比較ポイント
3. 結論と根拠
```

---

### 文章作成用プロンプト

```
以下の条件で文章を作成してください。

【作成内容】
[作成したい文章の内容]

【ルール】
1. 事実と意見を明確に区別してください
2. 数字やデータを使う場合は出典を明記してください
3. 作成手順をステップバイステップで説明してから文章を出力してください
4. 不確かな情報は含めないでください

【出力形式】
1. 文章作成の手順説明
2. 作成した文章
3. 参考にした情報源（あれば）
```

## 実践例

### Before（3つの言葉なし）

**質問**: 「日本で一番売れている車は何ですか？」

**ChatGPTの回答**:
> 日本で一番売れている車はトヨタ・ヤリスです。2023年の販売台数は約20万台でした。

（※この情報が正しいかどうか確認できない）

---

### After（3つの言葉あり）

**質問**:
```
日本で一番売れている車は何ですか？

回答時のルール：
1. 自信がない情報は「わかりません」と答えてください
2. ステップバイステップで説明してください
3. 情報の出典を必ず記載してください
```

**ChatGPTの回答**:
> **調査手順**:
> 1. 日本自動車販売協会連合会の統計を確認
> 2. 2023年の車名別販売台数ランキングを参照
>
> **結果**:
> 2023年の新車販売台数1位はトヨタ・ヤリスで、約212,927台でした。
>
> **出典**: 日本自動車販売協会連合会「車名別販売台数」
> https://www.jada.or.jp/
>
> **注意**: 私の学習データは2024年4月までなので、最新の2024年データは確認できません。最新情報は上記サイトでご確認ください。

（※出典があるので自分で確認できる）
