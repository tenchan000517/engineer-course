## Gensparkとは

Gensparkは、複数のAIを統合した「スーパーエージェント」です。

| 特徴 | 説明 |
|------|------|
| **リサーチ力** | 複数サイトから情報収集、出典も明記 |
| **資料作成** | テーマを入れるだけでスライド完成 |
| **動画生成** | テキストや画像から動画を作成 |
| **無料で使える** | 基本機能は無料、スライドも無料 |

### アクセス方法

1. [genspark.ai](https://www.genspark.ai/) にアクセス
2. Googleアカウントでログイン
3. 使いたい機能を選択

---

## 機能1: リサーチ

Gensparkのリサーチは「出典付き」で信頼性が高いのが特徴です。

### 基本的な使い方

1. Gensparkにアクセス
2. 調べたいことを入力
3. AIが複数サイトから情報収集
4. 出典付きのレポートが完成

### ChatGPTとの違い

| 項目 | ChatGPT | Genspark |
|------|---------|----------|
| 情報源 | 学習データのみ | リアルタイムWeb検索 |
| 出典 | なし | あり（URL付き） |
| 信頼性 | 嘘が混じることも | 出典で確認可能 |

### リサーチのコツ

- **具体的に指示する**: 「AI」ではなく「2024年以降の画像生成AI」
- **出力形式を指定**: 「表形式でまとめて」「箇条書きで」
- **出典を求める**: 「参照元URLを必ず記載して」

---

## 機能2: 資料作成（AIスライド）

テーマを入力するだけで、プロ級のスライドが完成します。

### 基本的な使い方

1. Gensparkにアクセス
2. 「AIスライド」を選択
3. 作りたい資料の内容を入力
4. 数分でスライド完成
5. PDF or PowerPointでダウンロード

### AIスライド2.0の特徴

| 特徴 | 説明 |
|------|------|
| **ハルシネーション90%削減** | 嘘の情報が大幅に減少 |
| **数百種類のテンプレート** | 全て無料で使用可能 |
| **リサーチ統合** | 必要なデータを自動で調べてくれる |

### 資料作成のコツ

- **事前リサーチを指示**: データがない部分は「Webで調べて」と指示
- **構成を指定**: どんなスライドが欲しいか明確に
- **会社情報を入れる**: 連絡先など固有情報は必ず入力

---

## 機能3: 動画生成

テキストや画像から動画を生成できます。

### 基本的な使い方

1. Gensparkにアクセス
2. 「AI動画」を選択
3. 作りたい動画の説明を入力（または画像をアップロード）
4. AIが動画を生成
5. ダウンロード

### 動画生成のコツ

- **具体的なシーンを指定**: 「海辺を歩く女性」など
- **カメラワークを指定**: 「ゆっくりズームイン」など
- **BGMも生成可能**: 「明るいBGMを付けて」

### 1. Claudeでバズるリール台本を作成

**使用ツール**: Claude（claude.ai）

**プロンプト**:

```
# 命令
あなたはInstagramマーケティングのトップエキスパートであり、ショート動画のプロ脚本家です。
以下の条件に基づき、爆発的な再生数（バズ）と高い保存率を狙えるリール動画の企画・台本を【5本】作成してください。

# 前提条件（あなたの情報）★ここを書き換えてください
- ジャンル: [発信ジャンルを入力。例：時短レシピ、英語学習、フリーランスの働き方]
- ターゲット: [誰に向けた発信か。例：忙しい30代主婦、TOEIC600点を目指す会社員]
- アカウントのゴール: [どうなって欲しいか。例：フォロワー増、LINE登録、アフィリエイト成約]
- 投稿の雰囲気: [例：親しみやすい、辛口・本音、おしゃれで憧れ重視]

# バズるための構成要件（必須）
1. **フック（開始0-2秒）**:
   - 視聴者の指を止めさせる強力なインパクト（意外性、共感、否定、煽り）。
   - テロップは視認性が高く、興味をそそる文言にする。
2. **展開（テンポ）**:
   - 冗長な説明は省き、結論ファーストまたは意外な展開を入れる。
   - 視聴者が「自分に関係がある」と思わせる「自分ごと化」を促す。
3. **CTA（行動喚起）**:
   - 自然な流れで「保存」や「コメント」を促す（例：「後で見返すために保存」「○○な人はコメントして」）。

# 出力フォーマット
各アイデアを以下の項目で整理し、表形式または見やすいリスト形式で出力してください。

1. **タイトル（管理用）**: 企画のキャッチーなタイトル
2. **フック（画面上の文字）**: 最初の2秒で表示する強力なテキスト
3. **映像イメージ**: 何が映っているか、どんな動きか（具体的かつ撮影しやすく）
4. **台本/テロップ構成**:
   - 冒頭：
   - 中盤：
   - 結末：
5. **バズるポイント**: なぜこれが伸びるのかの心理学的解説
6. **推奨BGMの雰囲気**: （例：アップテンポ、ASMR、感動系など）

# 制約事項
- 抽象的な表現は避け、具体的でそのまま撮影に使えるレベルにする。
- ターゲットの悩みや欲望を深く突く内容にする。
- 5本とも切り口（構成パターン）を変えること（例：ランキング形式、NG集、Vlog風、Before/Afterなど）。
```

**使い方**:
1. claude.aiにアクセス
2. 上記プロンプトをコピペ
3. ★の部分を自分の情報に書き換え
4. 送信

### 2. NanoBananaで理想の自分を作成

**使用ツール**: NanoBanana Pro（Google AI Studio経由）

NanoBananaは、Googleの画像生成AI「Gemini」を使って高品質な画像を生成できるツールです。

#### 環境構築（初回のみ）

1. [Google AI Studio](https://aistudio.google.com/)にアクセス
2. APIキーを取得
3. Python環境でgoogle-genai SDKをインストール

```powershell
pip install google-genai python-dotenv
```

#### プロンプト例: 透明感のある寝起き美女

```
masterpiece, best quality, ultra detailed, highres, 8k, (1girl), solo, (beautiful face:1.2), (waking up:1.2), sitting on bed, (messy hair:1.3), bedhead, (no makeup:1.4), natural skin, bare face, sleepy eyes, slightly open mouth, stretching, (white oversized t-shirt:1.1), falling off shoulder, bedroom, messy bed sheet, pillow, (morning light:1.3), sun rays, volumetric lighting, soft focus, depth of field, cinematic lighting, lens flare, floating dust, dreamy atmosphere
```

**ネガティブプロンプト**:
```
(worst quality, low quality:1.4), (heavy makeup:1.3), lipstick, eyeshadow, blush, jewelry, earrings, bad anatomy, bad hands, text, error, missing fingers, extra digit, fewer digits, cropped, jpeg artifacts, signature, watermark, username, blurry, artist name, gloom, dark
```

#### プロンプトのポイント

| 要素 | 効果 |
|------|------|
| `(no makeup:1.4)` | すっぴん感を強調 |
| `messy hair, bedhead` | 寝癖でリアリティUP |
| `morning light, sun rays` | 逆光で肌を綺麗に |
| `(1.2)` などの数字 | 重み付け（大きいほど強調） |

### 3. Gensparkでプロ級リサーチ

**使用ツール**: Genspark

**プロンプト**:

```
# リサーチ依頼

## 調査対象 ★ここを書き換えてください
[調べたい内容を具体的に記入]
例：Instagramで直近1ヶ月以内にバズっているAI関連の投稿

## 調査要件
1. 該当する情報を5〜10件ピックアップ
2. 各項目について以下を記載：
   - 情報源（サイト名・アカウント名など）
   - 日付
   - 具体的な内容の要約
   - 参照URL

## 出力形式
- 表形式でまとめる
- 各情報の出典URLを必ず明記
- 最後に「共通点・トレンド傾向」のまとめを追加

## 注意事項
- 推測ではなく、実際に確認できた情報のみ記載
- 情報が見つからない項目は「情報なし」と記載
- データを勝手に作成しない
```

**使い方**:
1. genspark.aiにアクセス
2. 上記プロンプトをコピペ
3. ★の部分を調べたい内容に書き換え
4. 送信

### 4. Gensparkで営業資料を作成

**使用ツール**: Genspark（AIスライド）

**プロンプト**:

```
# スライド作成依頼

## あなたの情報（★必須：書き換えてください）
- 資料の種類: [営業資料 / 企画書 / 報告書 / 提案書]
- 商品・サービス名:
- ターゲット: [誰に見せる資料か]
- 目的: [この資料で何を達成したいか]

## あなたの会社情報（★必須）
- 会社名:
- 電話番号:
- メールアドレス:
- Webサイト:
- 担当者名:

## 料金プラン（★ある場合は記入）
- プラン1: [プラン名] / [価格] / [内容]
- プラン2: [プラン名] / [価格] / [内容]
- プラン3: [プラン名] / [価格] / [内容]
※料金がない場合は「要問い合わせ」と記載

## 実績・事例（★ある場合は記入）
- 導入企業数:
- 具体的な事例:
- お客様の声:
※ない場合は「実績スライドは省略」と記載

## 事前リサーチ指示
スライド作成前に、以下をWebでリサーチしてください：
- ターゲットが抱える課題・悩みのデータ
- 業界の市場規模・トレンド
- 競合他社の価格帯・サービス内容

リサーチ結果は出典URLを明記してスライド内で使用してください。

## スライド構成
1. 表紙（会社名・サービス名）
2. 課題提起（リサーチしたデータで裏付け）
3. 解決策（あなたの商品・サービス）
4. 特徴・強み（3〜5つ）
5. 導入事例・実績（入力があれば）
6. 料金プラン（入力した内容を使用）
7. 導入の流れ
8. よくある質問
9. お問い合わせ先（入力した会社情報を使用）

## デザイン要件
- 信頼感のある配色
- 表やグラフで視覚的に
- 1スライド1メッセージ

## 重要な注意事項
- 私が入力していない情報は絶対に推測・補完しないでください
- 不足している情報がある場合は、その項目をスライドから省略してください
- 架空のデータや数字を作成しないでください
```

**使い方**:

| 手順 | やること |
|------|----------|
| 1 | ★マークの欄を全て埋める |
| 2 | ない情報は「省略」「要問い合わせ」と記載 |
| 3 | Gensparkの「AIスライド」に貼り付け |
| 4 | 生成されたスライドを確認 |
| 5 | PDF or PowerPointでダウンロード |
