# 広告クリエイティブ生成プロンプト集

デザイナーに頼まなくても、ABテスト用の広告画像を量産できます。

---

## 使い方

1. Google AI Studio（aistudio.google.com）を開く
2. 以下のプロンプトをコピペ
3. `[ここに〇〇を入れる]` の部分を変える
4. 生成！

---

## テンプレート1: SNS広告（Instagram/Facebook）

フィード用の正方形広告。

```
Create a social media ad for [サービス/商品カテゴリ].

Dimensions: 1:1 square for Instagram/Facebook feed.

Text Content:
- Headline: "[日本語ヘッドライン]"
  Bold, motivational font
  White with subtle shadow

- CTA: "[CTAテキスト]" in button style
  [色] background, white text

Visual Elements:
- [ビジュアル要素]
- Dynamic, energetic composition
- Subtle motion blur for energy

Color Scheme:
- Energetic gradients ([色1] to [色2])
- High contrast for visibility
- App UI mockup visible in corner (optional)

Style:
- Aspirational, motivating
- Clean, modern aesthetic
- Professional quality
```

**使用例**：
```
サービス/商品カテゴリ: a fitness app
日本語ヘッドライン: 変わる、30日で
CTAテキスト: 無料で始める
色: Green
ビジュアル要素: Before/After split showing transformation, person in athletic pose
色1: purple
色2: pink
```

## 色の組み合わせガイド（業種別）

| 業種 | 主色 | グラデーション | 効果 |
|------|------|---------------|------|
| フィットネス | 紫 | 紫→ピンク | エネルギッシュ |
| 美容 | ピンク | ピンク→オレンジ | 華やか |
| 金融 | 青 | 紺→青 | 信頼感 |
| 食品 | オレンジ | 赤→オレンジ | 食欲増進 |
| 旅行 | 青 | 青→緑 | 開放感 |
| テック | 紫 | 紫→青 | 革新性 |

## CTAボタンのパターン

### 行動喚起系
- `今すぐ始める`
- `無料で試す`
- `詳しく見る`
- `今すぐ購入`

### 緊急性系
- `期間限定`
- `残りわずか`
- `本日限り`

### 価値訴求系
- `無料ダウンロード`
- `0円で体験`
- `リスクなし`

## ABテスト用のバリエーション

同じ内容で異なる要素を変えて複数生成：

### 色違い
```
Color Scheme: Gradient from purple to pink
→
Color Scheme: Gradient from blue to teal
```

### CTAテキスト違い
```
CTA: "今すぐ始める"
→
CTA: "無料で試す"
```

### ビジュアル違い
```
Visual: Before/After split
→
Visual: Person celebrating achievement
```

---

## 注意点

- テキストは大きく、読みやすく
- CTAボタンは目立つ色で
- 情報は詰め込みすぎない（3要素以内）
- モバイルで見ても読める大きさに
