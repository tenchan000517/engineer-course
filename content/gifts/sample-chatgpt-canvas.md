## セクション1: ChatGPT Canvasとは

ChatGPT Canvasは、2024年10月にリリースされた新機能です。

通常のチャットとは別に、**編集可能なドキュメント画面**が開き、文章やコードを直接編集しながらAIと協力して作業できます。

### 従来のChatGPTとの違い

| 項目 | 従来のChatGPT | Canvas |
|------|--------------|--------|
| 出力形式 | チャット形式 | ドキュメント形式 |
| 編集 | 再生成が必要 | その場で編集可能 |
| 部分修正 | 難しい | 選択して修正依頼可能 |

## セクション2: 基本的な使い方

### ステップ1: Canvasを開く

ChatGPTで以下のように入力します：

```
資料を作成したいので、Canvasで開いてください
```

または、長文の作成・編集を依頼すると自動的にCanvasが開きます。

### ステップ2: 部分選択して修正

Canvasでは、**テキストの一部を選択して修正依頼**ができます。

1. 修正したい部分をドラッグして選択
2. 右クリックまたはツールバーから「AIに依頼」
3. 「もっと簡潔に」「詳しく」などを選択

### ステップ3: ツールバーを活用

右側のツールバーには以下の機能があります：

- **長さを調整**: 短く/長く
- **読みやすさ**: 難易度調整
- **絵文字を追加**: 見やすく装飾
- **校正**: 誤字脱字チェック

## セクション3: 資料作成を効率化する3つのテクニック

### テクニック1: 構成から作る

いきなり本文を書かず、**まず構成（目次）を作成**します。

```
以下のテーマで資料の構成を作ってください：
- テーマ: [あなたのテーマ]
- 対象者: [誰向けか]
- ページ数: [目安]
```

構成ができたら、各セクションを個別に展開していきます。

### テクニック2: セクション単位で依頼

全体を一度に生成するのではなく、**セクションごとに依頼**します。

```
セクション1「はじめに」を300文字で書いてください
```

これにより、各セクションの品質を確認しながら進められます。

### テクニック3: 参考情報を与える

より質の高い出力を得るため、**参考情報やデータを提供**します。

```
以下のデータを元に、グラフの説明文を作成してください：
- 売上: 前年比120%
- 顧客数: 5,000人増加
- 満足度: 4.5/5.0
```

## よくある質問

**Q: Canvasは無料で使えますか？**
A: いいえ、ChatGPT Plus（月額$20）またはTeamプラン以上が必要です。

**Q: スマホでも使えますか？**
A: 現在はPC版のみ対応しています。モバイルアプリでは通常のチャット形式になります。

**Q: 作成した内容はエクスポートできますか？**
A: はい、テキストとしてコピーまたはダウンロードできます。Word形式でのエクスポートも可能です。
