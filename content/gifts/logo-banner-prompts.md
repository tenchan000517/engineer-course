# ロゴ・バナー生成プロンプト集

ロゴやバナー、外注すると高いですよね。
AIなら10分で何パターンも作れます。

---

## 使い方

1. Google AI Studio（aistudio.google.com）を開く
2. 以下のプロンプトをコピペ
3. `[ここに〇〇を入れる]` の部分を変える
4. 生成！

---

## ロゴテンプレート1: 日本語ロゴ

飲食店や和風ビジネス向け。

```
Create a logo design for [業種] called "[店名/社名]".

Text Requirements:
- Main text: "[日本語名]" in bold Japanese brush calligraphy style (Shodo)
  All kanji must be accurately rendered
  Thick, confident brush strokes
  Black color

- Subtext: "[ローマ字]" in small, clean sans-serif
  Position: Below the kanji
  Gray color

Design Elements:
- Circular badge/stamp design (hanko inspired)
- Red circular border/seal element
- [関連モチーフ] subtly incorporated

Color Palette:
- Primary: Deep red (#C41E3A)
- Secondary: Black
- Accent: Cream/off-white

Style:
- Vintage Japanese aesthetic
- Modern clarity and simplicity
- Works at any size (scalable design)

Background: White for visibility.
```

**使用例**：
```
業種: Japanese ramen shop
店名/社名: 麺道場
日本語名: 麺道場
ローマ字: MENDOJO
関連モチーフ: Steam rising, noodle bowl silhouette
```

## バナーテンプレート1: セールバナー

ECサイトやキャンペーン向け。

```
Generate a promotional web banner for [キャンペーン名].

Dimensions: 16:9 wide format for website homepage hero section.

Text Specifications:
- Main headline: "[メインコピー]" in bold, white, sans-serif font
  Position: Centered in the upper third, largest element
  Style: Clean, modern, with slight outer glow for visibility

- Subtext: "[サブコピー]" in lighter weight font
  Position: Directly below headline
  Size: 50% of headline size

- CTA button: "[ボタンテキスト]" text on [色] rectangle
  Position: Bottom right corner
  Colors: White text on [色コード] background

Visual Elements:
- Background: Smooth gradient from [色1] to [色2]
- [装飾要素] on left and right edges
- Clean, modern aesthetic with ample white space

Priority: Text clarity and professional appearance.
```

**使用例**：
```
キャンペーン名: online summer sale
メインコピー: SUMMER SALE
サブコピー: Up to 50% Off
ボタンテキスト: Shop Now
色: orange
色コード: #FF6B35
色1: coral pink
色2: warm orange
装飾要素: Subtle tropical leaf silhouettes
```
