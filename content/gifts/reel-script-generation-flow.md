# リール台本生成フロー（3ステッププロンプト）

リール台本、まだ自分で考えてますか？
このフローを使えば、毎月30本以上の台本を効率的に作れます。

---

## 全体フロー

```
ステップ1: リサーチ（Perplexity）
     ↓
ステップ2: 構造化（ChatGPT）
     ↓
ステップ3: 台本生成（ChatGPT）
```

---

## ステップ1: リサーチプロンプト

**使うツール**: Perplexity（perplexity.ai）

**プロンプト**:
```
[あなたのジャンル]で影響力のあるインフルエンサー5人の
直近1ヶ月の投稿を調査してください。

以下の形式でまとめてください：
- インフルエンサー名
- 投稿タイトル/テーマ
- バズった理由（推測）
- 使用されているツール/サービス名

特に以下に注目してください：
- 複数人が言及しているトピック（本当のトレンド）
- 視聴者の反応が大きかったもの
- 「知らなかった」系の驚き要素があるもの
```

**カスタマイズ例**:
- `[あなたのジャンル]` → AI活用、副業、美容、料理など

**なぜPerplexityか**:
- 最新情報を出典付きで出力
- 「これって最新情報？」の心配なし
- SNSやニュースからも検索

---

## ステップ2: 構造化プロンプト

**使うツール**: ChatGPT

**プロンプト**:
```
以下のリサーチ結果から、リール投稿のネタを抽出してください。

【リサーチ結果】
（ステップ1の結果を貼り付け）

【出力形式】
以下の形式で10個のネタを提案してください：

# ネタ1: [タイトル]
- カテゴリ: [A: 比較 / B: 効率化 / C: 新機能 / D: 警告 / E: ランキング]
- ターゲット: [誰向けか]
- フック: [冒頭3秒で言うこと]
- 核心: [視聴者が得られる価値]
- CTA: [最後の行動喚起]

【条件】
- 嘘や誇張は含めない
- 実際に自分が実践できる内容のみ
- 視聴者がすぐ試せる具体性
```

---

## ステップ3: 台本生成プロンプト

**使うツール**: ChatGPT

**プロンプト**:
```
以下のネタからリール台本を作成してください。

【ネタ】
（ステップ2から選んだネタを貼り付け）

【台本構成】
6枚構成（各15-20秒読み）で作成：

## 1枚目（導入・フック）
- 視聴者を止める一言
- 問題提起または驚きの事実

## 2枚目（解説1）
- 1つ目のポイント
- 具体例を含める

## 3枚目（解説2）
- 2つ目のポイント
- 具体例を含める

## 4枚目（解説3）
- 3つ目のポイント
- 具体例を含める

## 5枚目（解説4）
- 4つ目のポイント
- 具体例を含める

## 6枚目（CTA）
- まとめ
- 行動喚起（保存/フォロー/コメント）

【条件】
- 口語調で読みやすく
- 1枚あたり30-50文字程度
- 専門用語は避けるか説明を入れる
```

## 実践例

### ステップ1の結果例
```
インフルエンサー: チャエン
投稿: 「ChatGPTでリール台本を作る方法」
バズった理由: 具体的な手順が分かりやすい
使用ツール: ChatGPT

インフルエンサー: mikimiki
投稿: 「Perplexityでネタ探しが10倍速くなる」
バズった理由: 無料ツールで即実践可能
使用ツール: Perplexity
```

### ステップ3の出力例
```
## 1枚目（フック）
リール台本、まだ自分で考えてる？

私は毎月30本以上の台本を、
この3ステップで作ってます。

## 2枚目（解説1）
ステップ1、リサーチ。

Perplexityにこのプロンプトを送ると、
今バズってるネタを出典付きで出してくれます。

## 3枚目（解説2）
ステップ2、構造化。

ChatGPTにこのプロンプトを送って、
さっきのネタを6枚構成に整理。

## 4枚目（解説3）
ステップ3、台本生成。

最後にこのプロンプトで、
各スライドのナレーション文を生成。

## 5枚目（解説4）
ポイントは「インフルエンサー起点」。

自分で考えるより、
すでにバズった人を参考にした方が早い。

## 6枚目（CTA）
今日紹介した3つのプロンプトをまとめました。

欲しい人は好きな寿司ネタを
コメントで教えてね。
```

## カテゴリ分類ガイド

| カテゴリ | 特徴 | 例 |
|---------|------|-----|
| **A: 比較** | 「〇〇 vs △△」 | ChatGPT vs Gemini |

## 月間運用フロー

```
毎月1日: リサーチ実行（ステップ1）
       ↓
毎月2-3日: 構造化・ネタ出し（ステップ2）
       ↓
毎週: 台本生成（ステップ3）×8本
       ↓
合計: 約32本/月
```

---

## 注意点

- **嘘をつかない**: バズるために誇張しない
- **実践可能な内容**: 視聴者がすぐ試せる
- **自分の言葉に変換**: AIの出力をそのまま使わない
