# 音声文字起こし自動化ワークフロー

会議の文字起こし、まだ手作業でやってますか？
音声ファイルを入れるだけで記事になるシステムを作りましょう。

---

## システム構成図

```
┌─────────────────┐
│  Google Drive   │ 音声ファイルをアップロード
│   (トリガー)     │
└────────┬────────┘
         │ ファイル検知
         ↓
┌─────────────────┐
│      n8n       │ ワークフロー実行
│                │
└────────┬────────┘
         │
    ┌────┴────┐
    ↓         ↓
┌─────────┐ ┌─────────┐
│ Whisper │ │ Gemini  │
│ (文字起こし) │ (整形)    │
└────┬────┘ └────┬────┘
     └─────┬─────┘
           ↓
┌─────────────────┐
│ Google Sheets   │ 結果を出力
│  (記事保存)      │
└─────────────────┘
```

---

## 処理フロー

```
1. Google Driveに音声ファイルをアップロード
       ↓
2. n8nがファイルを検知
       ↓
3. Whisperで文字起こし（音声→テキスト）
       ↓
4. Geminiで整形（「えーと」削除、段落分け）
       ↓
5. Google Sheetsに記事として出力
```

## ステップ1: Whisperセットアップ

### インストール（Whisper.cpp版）
```bash
# リポジトリをクローン
git clone https://github.com/ggerganov/whisper.cpp

# ビルド
cd whisper.cpp
make

# モデルをダウンロード（medium推奨）
bash ./models/download-ggml-model.sh medium
```

### 文字起こし実行
```bash
./main -m models/ggml-medium.bin -l ja -f audio.wav
```

| オプション | 説明 |
|-----------|------|
| `-m` | モデルファイル |
| `-l ja` | 日本語指定 |
| `-f` | 入力ファイル |

---

## ステップ2: Gemini整形プロンプト

**プロンプト**:
```
以下の文字起こしテキストを、読みやすい記事形式に整形してください。

【処理内容】
1. 「えーと」「あのー」「うーん」などのフィラーを削除
2. 話し言葉を書き言葉に変換
3. 適切な段落に分割
4. 句読点を適切に配置
5. 明らかな言い間違いを修正

【出力形式】
- 見出し（##）で大きなトピックを分割
- 箇条書きを適切に使用
- 1段落は3-4文程度

【元テキスト】
{transcription}
```

## ステップ3: n8nワークフロー

### ノード構成
```
1. Google Drive Trigger
   - 特定フォルダを監視
   - 新規ファイル検知

2. HTTP Request (Whisper API)
   - 音声ファイルを送信
   - 文字起こし結果を取得

3. HTTP Request (Gemini API)
   - 整形プロンプトを送信
   - 整形済みテキストを取得

4. Google Sheets
   - 結果を書き込み
```
