## Genspark用：バズるリール企画10選を一括生成

リールのネタ切れに悩んでいませんか？このプロンプトをGensparkに投げるだけで、最新トレンドを反映したリール企画が10本まとめて出てきます。

### 使い方

1. 下記のプロンプトをコピー
2. Gensparkの検索窓に貼り付け
3. 「★ここを書き換えてください」の部分だけ自分の情報に変更
4. 実行するだけで10本分の企画が完成

### プロンプト

```
あなたはInstagramリールの企画専門家です。
以下の情報をもとに、今すぐ撮影できる具体的なリール企画を10本作成してください。

【入力情報】
【ターゲット】★ここを書き換えてください（例：20代会社員）
【ジャンル】★ここを書き換えてください（例：ビジネス系/副業・キャリア）
【トレンドキーワード】★ここを書き換えてください（例：AI活用・時短術）

【出力形式】各企画ごとに以下を出力してください：

1. タイトル（15文字以内、数字を入れる）
2. 冒頭5秒のフック（視聴者を引き込む一言）
3. 構成（3〜5ステップで展開）
4. 撮影のポイント（カット数・必要な素材）
5. 投稿文の方向性（保存orシェアを促す要素）
6. 関連ハッシュタグ5つ

【条件】
- 最新のトレンド情報を調査してから企画を作成
- すべての企画が異なる切り口であること
- 専門知識不要で誰でも撮影可能な内容にすること
- 視聴維持率80%以上を狙える構成にすること
```

### 活用のコツ

- 月初めに実行して1ヶ月分のネタをストック
- 出力結果に「もっと具体的に」と追加質問すると詳細が出る
- ハッシュタグは最新のトレンドが反映されるので毎月更新推奨

## Nanobanana用：売れるクリエイティブ5パターン

目的に応じて5つのパターンを使い分けることで、あらゆる用途の「売れるクリエイティブ」を作成できます。各プロンプトは独立しているので、必要なものだけ使ってください。

---

### パターン1：問題提起型

ターゲットの悩みに共感し、解決策を提示するデザインです。認知段階のユーザーに効果的。

#### 使い方

1. 下記プロンプトの「★ここを書き換えてください」部分を編集
2. Nanobananaに貼り付けて実行
3. 生成後「メインコピーの色を変更」など日本語で微調整可能

#### プロンプト

```
【商品・サービス】★ここを書き換えてください（例：オンライン英会話）
【ターゲット】★ここを書き換えてください（例：英語が話せず海外出張で困っている30代会社員）
【訴求ポイント】★ここを書き換えてください（例：月額2,980円で毎日25分レッスン）

上記の情報をもとに、問題提起型のクリエイティブを作成してください。

【デザイン要件】
- メインコピー：ターゲットの悩みを問いかける形式（例：「英語が話せず、会議で黙ってしまう自分にサヨナラ」）
- サブコピー：解決策とベネフィット（例：「1日25分で、3ヶ月後には英語で商談できる」）
- CTAボタン：「無料体験はこちら」を右下に配置
- 配色：信頼感を出すネイビー(#1E3A8A)をメインに、アクセントでオレンジ(#F97316)
- レイアウト：左側にビジネスマンが悩む表情の画像、右側にテキストを配置
- サイズ：Instagram正方形投稿(1080x1080px)
- フォント：メインコピーは太めのゴシック体、サブコピーは読みやすい明朝体
```

### パターン2：数字訴求型

実績や数字で信頼性を訴求するデザインです。比較検討段階のユーザーに効果的。

#### プロンプト

```
【商品・サービス】★ここを書き換えてください（例：ダイエットサプリ）
【実績数字】★ここを書き換えてください（例：累計販売100万個突破／満足度96.8％／平均-8.5kg）
【ターゲット】★ここを書き換えてください（例：産後太りに悩む20代〜30代ママ）

上記の情報をもとに、数字で信頼性を訴求するクリエイティブを作成してください。

【デザイン要件】
- メインコピー：実績数字を大きく強調（例：「累計100万個突破！96.8%が効果を実感」）
- サブコピー：具体的な変化（例：「飲むだけで平均-8.5kg」）
- ビジュアル要素：Before→Afterの矢印表現、星5つの評価アイコン
- 配色：清潔感のある白(#FFFFFF)ベースに、ピンク(#EC4899)をアクセント
- レイアウト：上部に大きく数字、中央にBefore/After、下部にCTAボタン
- CTAボタン：「今すぐ試す」を中央下に配置
- サイズ：Instagramストーリーズ(1080x1920px)
- フォント：数字は極太ゴシック体で視認性重視
```

### パターン3：限定性訴求型

緊急性と限定性で今すぐ行動させるデザインです。キャンペーンやセール時に効果的。

#### プロンプト

```
【商品・サービス】★ここを書き換えてください（例：Webデザイン講座）
【限定情報】★ここを書き換えてください（例：先着50名限定／48時間限定セール／通常価格98,000円→今だけ49,800円）
【特典】★ここを書き換えてください（例：無料相談30分付き／教材プレゼント）

上記の情報をもとに、緊急性と限定性を訴求するクリエイティブを作成してください。

【デザイン要件】
- メインコピー：緊急性を強調（例：「残り48時間！先着50名様限定」）
- サブコピー：価格訴求（例：「通常98,000円→今だけ49,800円（50%OFF）」）
- 特典表示：「さらに！無料相談30分付き」を目立たせる
- 配色：緊急性を出す赤(#DC2626)をメインに、黄色(#FBBF24)で注意喚起
- レイアウト：上部に「限定」「緊急」のラベル、中央に価格比較、下部に特典
- CTAボタン：「今すぐ申し込む」を赤色の大きなボタンで
- 視覚効果：カウントダウンタイマー風のデザイン、点滅するような視覚的アクセント
- サイズ：バナー広告(1200x628px)
- フォント：緊急性を出す斜体＋太字ゴシック
```

### パターン4：ストーリー型

感情に訴え、共感と希望を与えるデザインです。ブランディングや高額商品に効果的。

#### プロンプト

```
【商品・サービス】★ここを書き換えてください（例：転職支援サービス）
【ターゲットのストーリー】★ここを書き換えてください（Before→After形式。例：「毎日終電、やりがいもない。このままでいいのか？」→「天職に出会い、年収150万円UP、定時退社の毎日」）
【訴求ポイント】★ここを書き換えてください（例：無料キャリア相談／転職成功率95％）

上記のストーリーをもとに、共感と希望を与えるクリエイティブを作成してください。

【デザイン要件】
- メインコピー：ターゲットの悩みに共感（例：「『このままでいいのか？』と不安な毎日」）
- サブコピー：変化後の未来（例：「→天職に出会い、年収150万UP、定時退社の毎日へ」）
- ビジュアル：左側に暗いトーン（悩む表情）、右側に明るいトーン（笑顔）のコントラスト
- 配色：左半分はグレー(#6B7280)で沈んだ印象、右半分は明るいブルー(#3B82F6)で希望を表現
- レイアウト：左右分割デザイン、中央に矢印「→」
- CTAボタン：「無料相談してみる」を右下に配置
- サイズ：Instagram正方形投稿(1080x1080px)
- フォント：感情に訴える柔らかい丸ゴシック体
```

### パターン5：シンプル訴求型

洗練されたミニマルデザインで、ブランドの品格を表現します。高級志向の商品に効果的。

#### プロンプト

```
【商品・サービス】★ここを書き換えてください（例：高級スキンケアブランド）
【コアメッセージ】★ここを書き換えてください（短く印象的な一言。例：「本物の美しさは、シンプルから。」）
【ターゲット】★ここを書き換えてください（例：質を重視する30代〜40代女性）

上記の情報をもとに、洗練されたミニマルデザインのクリエイティブを作成してください。

【デザイン要件】
- メインコピー：短く印象的な一言（例：「本物の美しさは、シンプルから。」）
- サブコピー：ブランドの哲学を一文で（例：「99%天然由来。無添加処方。」）
- ビジュアル：商品ボトル1つを中央に配置、周囲に大きな余白
- 配色：高級感のあるモノトーン（白#FFFFFF + ゴールド#D4AF37のアクセント）
- レイアウト：中央に商品、上部にメインコピー、下部にブランドロゴ
- CTAボタン：控えめに「詳しく見る」を小さく下部に
- デザイン哲学：余白を贅沢に使い、引き算の美学
- サイズ：Instagram正方形投稿(1080x1080px)
- フォント：細身の明朝体で上品に
```

### サイズ展開も簡単

生成した画像を他のサイズに展開したい場合は、以下のように指示するだけです：

- 「このデザインを9:16のストーリーズサイズで作り直して」
- 「バナー広告サイズ(1200x628px)に変更して」
- 「16:9の横長バナーにして」

### 5パターンの使い分け

- 悩みを訴求したい → パターン1（問題提起型）
- 実績で信頼を得たい → パターン2（数字訴求型）
- 今すぐ行動させたい → パターン3（限定性訴求型）
- 感情に訴えたい → パターン4（ストーリー型）
- ブランドイメージを高めたい → パターン5（シンプル訴求型）

全てのプロンプトをコピーして保存し、必要なときにすぐ使えるようにしておくことをおすすめします。
