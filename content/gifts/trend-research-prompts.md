# トレンドリサーチプロンプト集

ネタ切れ、もうしなくなります。
毎月100個以上のネタを見つける方法を解説します。

---

## リサーチの全体像

```
インフルエンサー5人を選ぶ
       ↓
Perplexityで直近1ヶ月を調査
       ↓
複数人が言及 = 本当のトレンド
       ↓
ChatGPTで投稿企画に変換
```

---

## プロンプト1: インフルエンサー調査

**使うツール**: Perplexity

```
以下の5人のインフルエンサーが直近1ヶ月で話題にしたトピックを調査してください。

【インフルエンサー】
1. [名前1]
2. [名前2]
3. [名前3]
4. [名前4]
5. [名前5]

【調査対象】
- YouTube動画のタイトル・内容
- X（Twitter）の投稿
- Instagram投稿

【出力形式】
各インフルエンサーごとに：
- 言及したツール/サービス名
- 投稿タイトル
- 投稿日
- 推定再生回数/いいね数

最後に「複数人が言及したトピックTOP10」をまとめてください。
```

## プロンプト2: トレンドランキング抽出

**使うツール**: ChatGPT

```
以下のリサーチ結果から、トレンドTOP20を抽出してください。

【リサーチ結果】
（Perplexityの結果を貼り付け）

【抽出基準】
- 複数のインフルエンサーが言及している
- 直近1ヶ月以内の話題
- 具体的なツール/サービス/テクニックである

【出力形式】
| 順位 | トピック | 言及数 | 該当インフルエンサー |
|------|---------|-------|-------------------|
| 1 | ... | ... | ... |
```

## プロンプト4: 特定ジャンルの深掘り

**使うツール**: Perplexity

```
「[トピック名]」について、以下を調査してください。

1. 基本情報
   - 何ができるか
   - 料金体系
   - 競合との違い

2. SNSでの話題性
   - Xでの言及数（直近1ヶ月）

```

## なぜインフルエンサー起点なのか

### メリット
- **検証済み**: すでにバズっている
- **タイミング**: 今話題になっている
- **信頼性**: 複数人が言及 = 本当のトレンド

### 自分で考える場合のリスク
- トレンドを外す可能性
- 興味を持たれない可能性
- 時間がかかる

---

## 注意点

### やっていいこと
- トレンドを参考にオリジナルコンテンツを作る
- 同じテーマを自分の視点で解説
- インフルエンサーの切り口を応用

### やってはいけないこと
- 丸パクリ
- 嘘の情報を流す
- 自分で試していないことを「おすすめ」と紹介
