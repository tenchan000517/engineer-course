# YouTubeサムネイル生成プロンプト集

サムネで損してるかも…そんな悩みを解決するプロンプト集です。

---

## 使い方

1. Google AI Studio（aistudio.google.com）を開く
2. 以下のプロンプトをコピペ
3. `[ここに〇〇を入れる]` の部分を変える
4. アスペクト比を「16:9」に設定
5. 生成！

---

## テンプレート1: ハウツー系

インパクトのある「3分で完成！」系サムネイル。

```
Create a YouTube thumbnail for a coding tutorial video.

Dimensions: 16:9 (standard YouTube thumbnail).

Text Overlay:
- Main text: "[ここに日本語タイトル]" in massive, pop-style Japanese font
  Color: Bright yellow with thick white outline and drop shadow
  Position: Center, slightly upper
  Style: Bold, attention-grabbing

Visual Elements:
- Split composition: [左側の状態] on left, [右側の状態] on right
- Red arrow pointing from left to right
- Surprised/excited person expression on the right side
- Bright, saturated colors for maximum visibility
- Slight blur/vignette on edges to focus attention

Background:
- [背景の説明]
- Dramatic lighting with blue accent

Style: High energy, clickable, YouTube algorithm optimized.
```

**使用例**：
```
Main text: "3分で完成!"
左側の状態: messy code
右側の状態: clean code
背景の説明: Code editor interface visible
```

## サムネイル作成の鉄則

| 要素 | 推奨 | NG |
|------|------|-----|
| テキスト | 大きく、3-5語以内 | 小さい文字、長文 |
| 顔 | 表情豊かなクローズアップ | 遠景、無表情 |
| 色 | 高コントラスト、彩度高め | 淡い色、モノトーン |
| 構図 | シンプル、焦点明確 | 雑然、要素過多 |
| 縁取り | テキストに白/黒縁取り | 縁取りなし |

---

## 文字スペースを空けるコツ

プロンプトに以下を追加すると、文字を入れるスペースを空けてくれます：

```
Leave empty space on the [right/left/top/bottom] side
for text overlay. This area should have simple,
uncluttered background for legibility.
```

例：
```
Leave empty space on the right side for text overlay.
This area should have a solid or gradient background
for easy text placement in post-production.
```

## 注意点

- 生成した画像は **Canvaで文字を追加** すると精度が上がります
- 複雑な日本語は AI が間違えることがあるので、後から追加推奨
- 解像度は 1280x720 以上を確保
