# SNS投稿用画像プロンプト集

フリー素材感がすごい…そんな悩みを解決するプロンプト集です。

---

## 使い方

1. Google AI Studio（aistudio.google.com）を開く
2. 以下のプロンプトをコピペ
3. あなたの投稿内容に合わせて1行だけ変える
4. 生成！

---

## Instagram投稿用（1:1）

### フード写真

```
Create an Instagram post image for a food blogger.
Content: [ここに料理名を入れる]

Composition:
- Overhead shot (flat lay)
- Dish centered in frame
- Colorful ingredients arranged artfully
- Props around (spoon, napkin, flowers)

Setting:
- Light wooden table or marble surface
- Natural morning light
- Soft shadows
- Clean, minimal styling

Style: Food photography, Instagram aesthetic, drool-worthy.
```

**カスタマイズ例**：
- `Content: Beautiful acai bowl` → アサイーボウル
- `Content: Japanese ramen with soft-boiled egg` → ラーメン
- `Content: Avocado toast with poached egg` → アボカドトースト

---

### ライフスタイル写真

```
Create an Instagram lifestyle photo.
Scene: [ここにシーンを入れる]

Visual Elements:
- Natural lighting, golden hour preferred
- Minimalist, aesthetic composition
- Soft, warm color palette
- Intentional negative space

Style:
- Aspirational, cozy atmosphere
- Instagram-worthy aesthetic
- Professional quality

Dimensions: 1:1 square for Instagram feed.
```

**カスタマイズ例**：
- `Scene: Morning coffee routine at home` → 朝のコーヒータイム
- `Scene: Workspace with laptop and plants` → おしゃれなデスク
- `Scene: Reading corner with cozy blanket` → 読書コーナー

## YouTubeサムネイル用（16:9）

### ハウツー系

```
Create a YouTube thumbnail for a tutorial video.
Topic: [ここにトピックを入れる]

Text Overlay:
- Main text: "[日本語タイトル]" in massive, pop-style font
  Color: Bright yellow with thick white outline and drop shadow
  Position: Center, slightly upper

Visual Elements:
- Split composition showing before/after
- Surprised/excited person expression
- Red arrow pointing transformation
- Bright, saturated colors

Style: High energy, clickable, YouTube algorithm optimized.
```

**カスタマイズ例**：
- `Topic: Excel automation` + `Main text: "3分で完成!"`
- `Topic: Photo editing` + `Main text: "神ツール発見!"`
- `Topic: AI tools` + `Main text: "知らないと損!"`

## ポイント：ナラティブ記述

キーワードを羅列するのではなく、**1つの文章として書く**のがコツです。

**悪い例**：
```
food, table, aesthetic, natural light
```

**良い例**：
```
A beautifully plated dish on a rustic wooden table,
bathed in soft natural morning light streaming through
a nearby window, creating an aspirational lifestyle aesthetic.
```

これだけで、AIの理解度が全然違います。
