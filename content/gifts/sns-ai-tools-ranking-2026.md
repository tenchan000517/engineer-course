## Nano Banana Pro: 広告ビジュアル作成

商品写真とイメージ参考画像をアップロードするだけで、プロ級の広告ビジュアルが完成します。

### プロンプト

```
あなたは世界的な広告代理店のクリエイティブディレクターです。商品の魅力を最大限に引き出し、ターゲットの心を掴むビジュアルを制作します。

【背景・目的】
素人が撮った商品写真も、プロが撮ったようなイメージ画像と組み合わせることで、雑誌やSNS広告レベルのビジュアルに生まれ変わります。2K/4K高解像度で出力するため、印刷物にも使用可能です。

【入力情報】
1. 商品写真: ★商品の画像をアップロード
2. イメージ参考画像: ★目指したい雰囲気の画像を1-3枚アップロード
3. 使用目的: ★例:Instagram広告、LP用メインビジュアル、雑誌広告

【生成指示】
アップロードした商品を主役に、参考画像の世界観・ライティング・構図を完璧に再現した広告ビジュアルを制作してください。

- 商品の特徴(質感・色・形)を忠実に保つ
- 背景・小道具で高級感/親しみやすさ/先進性などを演出
- プロカメラマンが撮影したような自然な光と影
- 4K解像度で出力し、印刷にも耐えるクオリティ

商品が自然に溶け込みながらも、視線が最初に向かうよう配置を工夫してください。
```

### 使い方

| 手順 | やること |
|------|----------|
| 1 | [Google AI Studio](https://aistudio.google.com/) にアクセス |
| 2 | Googleアカウントでログイン |
| 3 | 右上の「Model」から `Gemini 2.0 Flash` を選択 |
| 4 | 商品写真と参考画像をアップロード |
| 5 | 上記プロンプトを貼り付けて実行 |

### ポイント

- 参考画像は「こういう雰囲気にしたい」という画像を選ぶ
- 使用目的を具体的に書くほど、適切な構図になる
- 気に入らなければ「もう少し明るく」「背景をシンプルに」と追加指示

## Genspark AI: SNS運用一気通貫

1回のプロンプトで、企画から投稿文まで全て完成します。

### プロンプト

```
あなたは総フォロワー100万人超のSNSプロデューサーです。コンテンツ企画から投稿までの全工程を、戦略的かつ効率的に設計し、即実行可能な形で納品します。

【背景・目的】
SNSコンテンツ制作では、企画段階から投稿文まで一貫した戦略が必要です。このプロンプトは、思いつきから完成まで最短30分で到達できるよう、全工程を自動化します。

【入力情報】
1. コンテンツのジャンル: ★例:美容、ビジネス、料理、ライフハック
2. 目的: ★例:認知拡大、商品紹介、教育コンテンツ、エンゲージメント向上
3. 尺(動画の場合): ★例:30秒、60秒、90秒

---

【制作プロセス】以下を順番に、見出しを付けて出力してください

## 1. 企画案(3案)
- ターゲット層が「見たい」と思う切り口
- トレンドや季節感を反映
- 各案に想定エンゲージメント率を記載

## 2. 選定企画の構成案
- オープニング(最初の3秒で引き込むフック)
- 本編の展開(起承転結)
- クロージング(行動喚起)
- 想定尺と各パートの秒数配分

## 3. 台本(セリフ・ナレーション)
- 話し言葉で自然な言い回し
- 感情の抑揚指示を【】で記載
- テロップ候補を[テロップ:]で併記

## 4. 撮影指示書
- 必要なカット数とアングル
- 照明・背景の指定
- 小道具リスト
- 撮影時の注意点

## 5. 編集ポイント
- BGMの雰囲気(テンポ、ジャンル)
- トランジション(場面転換)のタイミング
- テロップのデザイン方向性
- サムネイル案(3パターン)

## 6. 投稿文(3パターン)
- パターンA:ストレート型(要点を端的に)
- パターンB:ストーリー型(共感を呼ぶ)
- パターンC:質問型(エンゲージメント狙い)
- ハッシュタグ10個(トレンド+ニッチの組み合わせ)
- 投稿最適時間帯の推奨

## 7. 成果測定の指標
- 追跡すべきKPI(再生数、保存数、シェア数など)
- 改善ポイントの仮説

---

【出力ルール】
- すべて日本語で出力
- コピペしてすぐ使えるよう、装飾は最小限に
- 専門用語は避け、初心者でも理解できる表現で
- 各セクションは独立して使えるよう完結させる

このプロンプトを実行することで、企画会議からポスト完成まで、通常3日かかる作業が30分で完了します。
```

### 使い方

| 手順 | やること |
|------|----------|
| 1 | [Genspark](https://www.genspark.ai/) にアクセス |
| 2 | Googleアカウントでログイン |
| 3 | 上記プロンプトの★部分を自分の情報に書き換え |
| 4 | 貼り付けて実行 |

### ポイント

- ジャンルは具体的に書く（「美容」より「30代向けスキンケア」）
- 目的を明確にすると、CTAまで一貫した内容になる
- 出力が長いので、必要な部分だけコピペして使ってもOK
