# Instagram自動投稿フロー全体図

毎日投稿するの大変じゃないですか？
1ヶ月分を1日で仕込んで、あとは自動投稿する方法を解説します。

## 各ステップの詳細

### ① リサーチ（月1回）

**使うツール**: Perplexity

```
[あなたのジャンル]で直近1ヶ月バズった投稿を調査し、
以下の形式でまとめてください：
- 投稿タイトル
- バズった理由
- 使われている構成
```

### ② 台本作成（月1回）

**使うツール**: ChatGPT

リサーチ結果を元に、30本分の台本を一括生成。

### ③ 画像作成（月1回）

**使うツール**: Canva or AI画像生成

テンプレートを用意して、テキストを流し込むだけ。

### ④ 音声合成（自動）

**使うツール**: Fish Audio

自分の声を複製して、台本を読ませる。
n8nで自動化可能。

### ⑤ 動画合成（自動）

**使うツール**: n8n + Canva API

画像 + 音声 = 動画を自動生成。

### ⑥ 自動投稿（自動）

**使うツール**: Instagram Graph API

指定した日時に自動投稿。

## 月間スケジュール例

```
【月初（1-2日）】
- リサーチ実行
- 30本分のネタ出し
- 台本一括生成

【月初（3-5日）】
- 画像テンプレート作成
- スプレッドシートに登録

【毎日（自動）】
- 音声合成（当日分）
- 動画合成（当日分）
- 18:00に自動投稿
```

## n8nワークフロー構成

### ワークフロー1: 音声合成
```
Cron (毎日7:00)
     ↓
Google Sheets (今日の投稿を取得)
     ↓
Fish Audio API (音声生成)
     ↓
Google Drive (音声保存)
     ↓
Google Sheets (URLを更新)
```

### ワークフロー2: 自動投稿
```
Cron (毎日18:00)
     ↓
Google Sheets (投稿準備完了のものを取得)
     ↓
Instagram API (投稿実行)
     ↓
Google Sheets (ステータス更新)
```

## Instagram Graph API設定

### 必要なもの
1. Facebookビジネスページ
2. Instagramプロアカウント
3. Meta Developer App
4. アクセストークン

### 投稿エンドポイント
```
POST /me/media
{
  "image_url": "https://...",
  "caption": "投稿テキスト #ハッシュタグ"
}

POST /me/media_publish
{
  "creation_id": "先ほどのID"
}
```

## 運用のコツ

### 投稿タイミング
| 曜日 | 推奨時間 |
|------|---------|
| 平日 | 7:00, 12:00, 18:00, 21:00 |
| 土日 | 10:00, 14:00, 20:00 |

### ハッシュタグ戦略
- 大（100万+）: 1-2個
- 中（1万-100万）: 3-5個
- 小（1000-1万）: 5-10個
- ニッチ: 2-3個

## トラブルシューティング

| 問題 | 原因 | 対策 |
|------|------|------|
| 投稿失敗 | トークン期限切れ | 60日ごとに更新 |
| 画像エラー | URLアクセス不可 | 公開URLを使用 |
| レート制限 | 投稿頻度過多 | 間隔を広げる |
