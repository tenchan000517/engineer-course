## 1. プロジェクト概要

### 1.1 目的

ゆめマガ制作の素材収集状況を可視化し、制作可否を自動判定するシステム。

### 1.2 アーキテクチャ

```
Google Drive（素材保存）
    ↓
GAS「Driveフォルダ作成」→ 素材ごとにフォルダ作成 + URL行に記載
    ↓
インタビュワーがURL行からフォルダを開いてファイルをアップロード
    ↓
GAS「素材チェック」→ フォルダ内にファイルがあれば✅
    ↓
素材OK + バリデーションOK = 「制作可能」表示
```

| 4  | D.表紙   | -      | -          | -          | ... |

## 4. GASメニュー機能一覧

```
ゆめマガ管理
├── 新しい号を作成          → showCreateIssueDialog()
├── テンプレート再生成       → regenerateTemplate()
├── ─────────────────
├── 素材チェック（Drive確認） → checkMaterialsFromDrive()
├── Driveフォルダ作成        → createMonthlyFolders()
├── ─────────────────
├── バリデーション実行       → runValidation()
├── バリデーション結果詳細   → showValidationDetails()
├── ─────────────────
└── フォルダ構造確認（デバッグ）→ debugFolderStructure()
```

### 4.1 Driveフォルダ作成（createMonthlyFolders）の動作

1. 各カテゴリの必要素材ごとにフォルダを作成
2. フォルダのURLをシートのURL行に記載
3. フォルダタイプに応じて構造が異なる：
   - **monthly**: `{カテゴリ}/{月号}/{素材名}/`
   - **company**: `{カテゴリ}/{企業名}/{素材名}/`
   - **flat**: `{カテゴリ}/{素材名}/`

### 4.2 素材チェック（checkMaterialsFromDrive）の動作

1. 各カテゴリの素材フォルダをスキャン
2. フォルダ内にファイルがあればチェックボックスを✅
3. ファイル名をノートに記録
4. 結果をダイアログで表示

## 6. Driveフォルダ構造（新構造）

### 6.1 月号管理カテゴリ（A, D, H, I, K, L, E, P）

```
{カテゴリフォルダ}/
└── 2026_01/              ← 月号フォルダが上位
    ├── 録音データ/       ← 素材ごとに1フォルダ
    ├── 文字起こし/
    ├── 原稿/
    ├── 縦長メイン写真/
    ├── プロフィール写真/
    ├── 横長写真1/
    └── 横長写真2/
```

### 6.2 企業管理カテゴリ（C）

```
C_新規企業/
└── {企業名}/
    ├── 情報シート/
    ├── ロゴ/
    ├── アイキャッチ/
    ├── 事業内容画像/
    └── 代表写真/
```

### 6.3 フラットカテゴリ（G）

```
G_企業SNS紹介/
└── ロゴ/
    └── ファイル
```

### 6.4 旧構造との違い

| 項目 | 旧構造 | 新構造 |
|------|--------|--------|
| 月号フォルダの位置 | サブフォルダの下 | カテゴリの直下 |
| 素材フォルダ | 「録音データ」「写真データ」に混在 | 素材名ごとに分離 |
| URL | なし | 各素材フォルダのURLをシートに記載 |
