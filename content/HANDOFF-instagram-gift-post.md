## プロジェクト概要

### 目的

Instagramで特典付き投稿を行い、エルグラムで自動DM配布するシステムを構築する。

### 通常投稿との違い

| 項目 | 通常投稿 | 特典付き投稿 |
|------|----------|--------------|
| 台本テンプレート | 既存5カテゴリ（A〜E） | **専用テンプレート** |
| CTA | フォロー誘導等 | **「〇〇とコメントしてください」** |
| 特典ページ | なし | **あり（このドメイン上）** |
| エルグラム設定 | なし | **あり（手動）** |
| 頻度 | 多い（日次） | 月数回 |

## 特典の設計方針

### 特典の単位

```
❌ 1投稿 = 1特典（毎回作成は大変）
✅ 1ツール（ユースケース）= 1特典（使い回し可能）
```

### 特典ネタの選定方法

**ソース1: 毎月のリサーチ結果**

```
インフルエンサーの投稿タイトル例:
「ChatGPT Canvasで資料作成が10倍速くなる」
「n8nでInstagram投稿を完全自動化する方法」
「Cursorの新機能Composerが便利すぎる」
           ↓
タイトル = 今バズっているユースケース = 特典ネタ
```

**ソース2: 講座コンテンツからの切り出し**

- 既存モジュールの一部を特典として再利用

**ソース3: ユーザー自身の調査結果**

- 独自調査で発見したトピック

### 特典の中身

```
インフルエンサーの投稿: 「〇〇の使い方」（30-60秒リール）
           ↓
自分の特典: その「詳しい使い方・やり方・情報」をまとめたもの
```
