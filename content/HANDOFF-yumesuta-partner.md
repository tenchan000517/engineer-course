# HANDOFF: ゆめスタパートナー業務フロー改善

## 概要

ゆめスタパートナー（カテゴリP）の業務フローを改善するタスク。
新規業務フローの設計、GASスクリプトの改善、ドキュメント化を行う。

---

## 業務フロー（確定版）

### 全体像

```
【パートナー管理シート】              【進捗管理シート】
┌──────────────────────────┐         ┌──────────────────────┐
│ ☑ 全社確認OK             │         │ カテゴリP            │
│ ─────────────────────── │   →     │ ・掲載企業リスト     │
│ 企業名 | 役職 | 掲載名 ...│   GAS   │ ・ロゴ✅             │
│ 掲載有無 | HP掲載有無 ...│   連携   │ ・QRコード✅         │
│ ロゴURL | QRコードURL    │         │ ・必要情報✅         │
└──────────────────────────┘         └──────────────────────┘
```

### 月次運用フロー

```
1. 新規月号シート作成（GAS）
   ├── 前月シートをコピー
   ├── E列（掲載有無）を全てFALSEに
   ├── G列（HP掲載有無）を全てFALSEに
   └── 前月でFALSEだった行はグレーアウト（削除しない）

2. 掲載企業の選定（手動）
   └── 掲載有無(E列)をTRUEに変更

3. 全社確認OK✅ をTRUEに変更（手動）
   │
   └──【自動チェック実行】
       ├── 掲載TRUE企業を取得
       ├── 各企業の必須項目チェック
       │   ├── 企業名
       │   ├── 役職
       │   ├── 掲載名
       │   ├── URL
       │   ├── ロゴ（Driveに存在するか）
       │   └── QRコード（Driveに存在するか）
       │
       ├──【不足あり】
       │   ├── アラート表示（不足項目一覧）
       │   └── 全社確認OKをFALSEに戻す
       │
       └──【不足なし】
           └── メッセージ表示
               ├── 「✅ 不足はありませんでした」
               ├── 「指定のフォーマットに沿って担当者に報告してください」
               └── 報告フォーマットを表示

4. 素材チェック（進捗管理シートGAS）
   └── 制作開始OK
```

## パートナー管理シート構成

### シート上部（固定表示エリア）

```
┌─────────────────────────────────────────────────────┐
│  【2026年01月号】                                    │
│                                                     │
│  ロゴフォルダ: [URL]    QRフォルダ: [URL]           │
│                                                     │
│  ☑ 全社確認OK  ← 大きく表示、チェック対象           │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### データ列構成

| 列 | 内容 | 必須 | 備考 |
|----|------|:----:|------|
| A | 企業名 | ✅ | ファイル名のキーとして使用 |
| B | 役職 | ✅ | |
| C | 掲載名 | ✅ | |
| D | URL | ✅ | QRコード生成元 |
| E | 掲載有無（雑誌） | | TRUE/FALSE |
| F | 掲載終了時期（雑誌） | | 日付 |
| G | HP掲載有無 | | TRUE/FALSE |
| H | HP掲載終了時期 | | 日付 |
| I | ロゴURL | | 自動記載 |
| J | QRコードURL | | 自動記載 |

### 行の状態

| 状態 | 表示 |
|------|------|
| 掲載有無=TRUE | 通常表示 |
| 掲載有無=FALSE（当月） | 通常表示 |
| 掲載有無=FALSE（前月からの引き継ぎ） | グレーアウト |

| 機能 | トリガー | 説明 |
|------|---------|------|

## 素材チェック時のアラート

| 条件 | アラート内容 |
|------|-------------|
| シートなし | 「該当月のシートが存在しません」 |
| 全社確認OK=FALSE | 「全社確認OKにチェックしてください」 |
| 掲載TRUE 0社 | 「掲載パートナーが0社です。掲載有無を確認してください」 |
| 掲載TRUE 1〜10社 | 「各パートナー掲載有無を確認し更新してください」 |
| 掲載TRUE 11〜30社 | 「全社掲載有無を確認しましたか？」 |
| 30社超 | 通常処理 |

## 全社確認OK時の自動チェック

### チェック項目

| 項目 | チェック内容 |
|------|-------------|
| 企業名 | 空欄でないか |
| 役職 | 空欄でないか |
| 掲載名 | 空欄でないか |
| URL | 空欄でないか、URL形式か |
| ロゴ | `ロゴ/{企業名}.*` がDriveに存在するか |
| QRコード | `QRコード/{企業名}.*` がDriveに存在するか |

### 不足ありの場合

```
⚠️ 以下の項目が不足しています：

・株式会社マルトモ: ロゴ未登録
・名古屋経済大学: URL未入力
・有限会社一誠: QRコード未生成

全社確認OKをFALSEに戻しました。
不足項目を修正してから再度チェックしてください。
```

### 不足なしの場合

```
✅ 不足はありませんでした

指定のフォーマットに沿って担当者に報告してください

━━━ 報告フォーマット ━━━
【2026年01月号 パートナー確認完了】
掲載企業数: 25社
確認日: 2025/12/18
確認者: ○○

制作開始OKです。
━━━━━━━━━━━━━━━━
```
