# HANDOFF: バズるリールの型6選

**このファイルを最初に読んでください。**

---

## 絶対ルール

### やってはいけないこと

1. **勝手な判断・解釈をしない** - 不明点は必ずユーザーに確認
2. **暴走しない** - 指示された範囲のみ作業
3. **余計な拡張をしない** - 「ついでに〜も」は禁止
4. **古い情報から憶測しない** - 必ず最新情報を確認
5. **「何から始めましょう？」と聞かない** - ロードマップに従う

### やるべきこと

1. **このHANDOFFを最初に読む**
2. **現在のフェーズを確認する**
3. **既存のランキングリール講座を参照する**
4. **完了したらこのHANDOFFを更新する**

## プロジェクト概要

### 目的

Instagram/TikTokでバズるリールを量産するための「6つの型」を講座化し、再現性の高いコンテンツ制作システムを構築する。

### 6つの型の概要

| # | 型 | 概要 | 視聴者心理 |
|---|------|------|-----------|
| 1 | **ランキングリール** | 順位づけで紹介 | 「1位が知りたい」で最後まで見る |
| 2 | **比較リール** | 失敗vs成功、AvsB | 「自分はどっち？」で自己投影 |
| 3 | **アフレコリール** | 映像+後からナレーション | 視覚+聴覚で理解度アップ |
| 4 | **図解リール** | 図や文字で整理 | 「パッと見て理解」で保存率UP |
| 5 | **トークリール** | 直接カメラに語りかけ | 感情伝達でファン化 |
| 6 | **vlogリール** | 日常+ノウハウ | 親近感で距離を縮める |

## 各型の詳細

### 1. ランキングリール ✅ 実装完了

**状態**: 講座完成、台本12本作成済み

**構造**:
```
冒頭フック: 「これ知らないと損!〇〇ランキング」
カウントダウン: 下位から順に紹介(5位→1位) ※シャッフル推奨
詳細: 各項目に短い特徴+実績例
まとめ: CTA(コメントやフォロー誘導)
```

**伸びる理由**:
- 「1位が知りたい」心理で視聴完了率UP
- 保存してあとで見返したくなる
- どれか一つは自分に刺さる

**心理学的テクニック**:
- 認知的不協和（冒頭3秒の「論外」）
- ツァイガルニク効果（1位を見るまで未完了）
- 順番シャッフル（予測の裏切り）

| `content/guides/viral-ranking-video-guide.md` | 台本作成ガイド【完全版】 |

### 2. 比較リール ❌ 未実装

**状態**: 未着手

**構造**:
```
冒頭: 比較テーマを宣言（例：「2025年の運用 vs 2026年の運用」）
Aパターン: 悪い例・古いやり方・失敗例
Bパターン: 良い例・最新のやり方・成功例
CTA: 「あなたはどちら派?」「最新の方法を真似しよう」と誘導
```

**伸びる理由**:
- 「自分はどっち？」で自己投影
- Before→Afterでストーリー性
- テンポよく切り替わり飽きない

**比較の切り口例**:
| 切り口 | 例 |
|--------|-----|
| 時代 | 2025年 vs 2026年 |
| スキル | 素人 vs プロ |
| 結果 | 失敗例 vs 成功例 |
| 方法 | 旧式 vs 最新 |

**注意点**:
- 対比が曖昧だと伝わらない
- 数字や具体的な行動の違いを見せる

---

### 3. アフレコリール ❌ 未実装 ★次に実装

**状態**: HANDOFF作成中 → `HANDOFF-afreco-reel.md`

**構造**:
```
冒頭フック: テロップ+アフレコの一言で惹きつける
本編: 背景映像に合わせて、ノウハウやストーリーを説明
CTA: ナレーション+文字でアクションを促す
```

**伸びる理由**:
- 視覚+聴覚で理解度アップ
- 顔出しなしでOK → 参入障壁低い
- 映像を楽しみながらノウハウを受け取れる

**特徴**:
- 作業風景、旅行映像、街並みなどのビジュアル
- 後からナレーションを重ねる
- 量産しやすい

**注意点**:
- 音声が単調だと離脱される
- 抑揚やテンションを意識
- 無音再生用のテロップ必須

---

### 4. 図解リール ❌ 未実装

**状態**: 未着手

**構造**:
```
フック: 全体像を提示して興味を惹く
展開: 段階的に図解を見せる（ステップ・層・比較など）
結論: 注意点+CTA
```

**伸びる理由**:
- 「パッと見て理解できる」で保存・シェア
- 情報量が多いテーマとの相性◎
- 「専門家感」「信頼感」を演出
- 保存率が高く拡散されやすい

**図解の種類**:
| 種類 | 用途 |
|------|------|
| ステップ図 | 手順説明 |
| 比較表 | AvsB |
| ピラミッド | 階層構造 |
| フローチャート | 処理の流れ |

**注意点**:
- 1枚に詰め込みすぎない
- 「1スライド1メッセージ」

---

### 5. トークリール ❌ 未実装

**状態**: 未着手

**構造**:
```
冒頭: 感情をのせた一言（悲しい/怒り/驚き）
理由: なぜそれが大事かを熱弁
解決: 具体的なノウハウや事例を提示
結論: 視聴者への問いかけ+CTA
```

**伸びる理由**:
- 感情がストレートに伝わる
- 冒頭3秒で強い感情→スクロール停止
- 問いかけでコメント率UP
- ファン化に直結

**冒頭の感情パターン**:
| 感情 | 例 |
|------|-----|
| 怒り | 「これ許せない」 |
| 悲しみ | 「知らなかった自分が恥ずかしい」 |
| 驚き | 「マジで衝撃だった」 |
| 共感 | 「みんな同じこと思ってるよね？」 |

**注意点**:
- 背景・服装・ライティングも重要
- 話が長いと離脱される
- 要点を短くまとめる

---

### 6. vlogリール ❌ 未実装

**状態**: 未着手

**構造**:
```
フック: 日常のワンシーン
展開: 生活シーンを見せながら、合間にノウハウや価値観を加える
結論: 視聴者への問いかけ+CTA
```

**伸びる理由**:
- 属人性の高いコンテンツでファン化
- 「リアルな日常」で親近感
- どんなジャンルとも掛け合わせ可能

**掛け合わせ例**:
| ジャンル | vlog要素 |
|----------|----------|
| AI活用 | 作業風景+ツール紹介 |
| 副業 | 1日の流れ+収益報告 |
| 学習 | 勉強風景+学びの共有 |

**注意点**:
- ただの日常映像は伸びない
- プチノウハウや体験談、価値観を加える

## 実装優先順位

### 優先度の考え方

| 要素 | 説明 |
|------|------|
| 再現性 | 型に沿えば誰でも作れるか |
| 量産性 | 短時間で大量に作れるか |
| 既存資産 | 既存コンテンツを活用できるか |
| 顔出し不要 | 顔出しなしで制作できるか |

### 実装順序

1. **ランキングリール** ✅ 完了
2. **アフレコリール** ★次 - 顔出し不要、量産しやすい
3. **図解リール** - 既存講座から切り出しやすい
4. **比較リール** - ランキングと類似構造
5. **vlogリール** - 日常素材が必要
6. **トークリール** - 顔出し必要、属人性高い

## 共通の制作フロー

### 全型共通のステップ

```
Step 1: テーマ選定
        - リサーチ結果から選ぶ
        - ターゲットのニーズに合わせる

Step 2: 台本作成
        - 型に沿った構成で作成
        - CTA設計

Step 3: 素材準備
        - 映像素材（AI生成 or 撮影）
        - テロップ・図解

Step 4: 編集
        - Canva / CapCut
        - 音声合成（必要な場合）

Step 5: 投稿+自動化
        - エルグラム設定
        - 特典DM配布
```

### 重要：量産における型の選び方

**7カテゴリから機械的に選ぶのはNG。**

```
❌ 悪い例
「今日は衝撃型、明日は問いかけ型、明後日はストーリー型…」
→ 毎回考える負荷が発生、クオリティが安定しない

✅ 良い例
「自分に合ったフックを1〜2つ決めて、それを使い続ける」
→ 思考コスト最小、クオリティ安定、量産可能
```

**量産の鉄則**: クオリティを落とさずに量産できる「型」を見つけ、それを徹底的に使い回す。
