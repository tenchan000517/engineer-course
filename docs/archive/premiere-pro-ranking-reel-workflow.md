# Instagram Reels テンプレートプロジェクト：新規動画作成から書き出しまでの完全ガイド

このガイドでは、テンプレート化したプロジェクトを使って、**新しいランキングリール動画を最初から最後まで作成する全手順**を解説します。

---

## 📋 事前準備（作業前に用意するもの）

### 必要な素材リスト
- **台本ファイル** (.txt または .docx) - ランキング台本作成プロンプトで生成したもの
- **SRT字幕ファイル** (.srt) - 台本をベースに作成した字幕
- **メイン動画素材** (.mp4など) - 背景動画やB-roll映像
- **ツールアイコン画像** (.png) - 紹介するツールのロゴ（透過PNG推奨）
- **アバター素材** (オプション) - キャラクター画像
- **ナレーション音声** (.mp3/.wav) - 男性/女性ナレーション
- **BGM** (.mp3) - 背景音楽
- **効果音** (オプション) - トランジション用SE

---

## 🎬 完全ワークフロー（所要時間：約30〜45分）

---

### **Phase 1: テンプレートからプロジェクト作成（5分）**

#### ステップ1-1: 新規プロジェクトを開始
1. Premiere Proを起動
2. ホーム画面で「**新規プロジェクト**」をクリック
3. プロジェクト名を入力
   - 例：`ランキングリール_[テーマ名]_2026-01-21`
4. 保存場所を選択
   - 推奨：専用フォルダ（例：`D:\リール動画\2026-01\`）
5. 「**プロファイルテンプレート**」ドロップダウンから
   - `Instagram_Reels_Complete_Template`を選択
6. 「**作成**」をクリック

#### ステップ1-2: テンプレート構造の確認
プロジェクトが開くと、以下の構造が自動で展開されます：

**プロジェクトパネル（ビン構造）:**
```
📁 01_素材_Raw_Footage
   📁 メイン動画
   📁 アバター素材
   📁 ツールアイコン
📁 02_音声_Audio
   📁 男性ナレーション
   📁 女性ナレーション
   📁 効果音
📁 03_字幕_Subtitles
📁 04_BGM_Music
📁 05_グラフィックス_Graphics
   📁 順位表示
   📁 タイトル
   📁 トランジション
📁 06_完成シーケンス_Final_Sequences
📁 07_書き出し_Exports
📁 08_参考資料_Reference
```

**タイムラインパネル（シーケンス）:**
- シーケンス名：`Instagram_Reels_Main`
- トラック構造：
  - **V6**: タイトル・テキスト
  - **V5**: 順位表示
  - **V4**: ツールアイコン
  - **V3**: アバター
  - **V2**: メイン動画
  - **V1**: 背景・調整レイヤー
  - **A1**: 男性ナレーション
  - **A2**: 女性ナレーション
  - **A3**: BGM
  - **A4**: 効果音

---

### **Phase 2: 素材インポートと整理（5〜7分）**

#### ステップ2-1: 素材をインポート
1. **ファイル → 読み込み**（または `Ctrl+I` / `Cmd+I`）
2. 用意した素材を**一括選択**してインポート
3. または**エクスプローラー/Finderから直接ドラッグ＆ドロップ**

#### ステップ2-2: 素材を適切なビンに整理
各素材を対応するビンに移動：

| 素材の種類 | 移動先ビン |
|-----------|-----------|
| メイン動画（背景映像） | `01_素材_Raw_Footage/メイン動画` |
| ツールアイコン（PNG） | `01_素材_Raw_Footage/ツールアイコン` |
| アバター画像 | `01_素材_Raw_Footage/アバター素材` |
| 男性ナレーション | `02_音声_Audio/男性ナレーション` |
| 女性ナレーション | `02_音声_Audio/女性ナレーション` |
| SRT字幕ファイル | `03_字幕_Subtitles` |
| BGM | `04_BGM_Music` |
| 効果音 | `02_音声_Audio/効果音` |
| 台本テキスト（参考用） | `08_参考資料_Reference` |

**💡 効率化のヒント:**
- 素材名を事前にリネームしておく
  - 例：`メイン動画_AIツール比較.mp4`、`ツールアイコン_ChatGPT.png`
- 色ラベルを活用（右クリック → ラベル）
  - 赤：未配置、緑：配置済み、青：要確認

---

### **Phase 3: タイムラインへ素材配置（10〜15分）**

#### ステップ3-1: 背景・メイン動画を配置
1. `Instagram_Reels_Main`シーケンスをダブルクリックして開く
2. **V2トラック**に**メイン動画**をドラッグ
   - タイムライン開始位置（00:00:00:00）に配置
3. 動画の長さを調整
   - 目標：15〜30秒（Instagram Reels推奨）
   - 不要部分をカット（`C`キー → Razorツール）

#### ステップ3-2: V1背景・調整レイヤー（オプション）
**背景色を追加する場合:**
1. **ファイル → 新規 → カラーマット**
2. サイズ：1080×1920、色：お好み（例：グラデーション背景）
3. **V1トラック**に配置
4. メイン動画より長めにストレッチ

**調整レイヤーを追加する場合:**
1. **ファイル → 新規 → 調整レイヤー**
2. V1に配置し、エフェクト（色補正など）を適用

#### ステップ3-3: アバター素材配置（V3トラック）
1. アバター画像を**V3トラック**にドラッグ
2. 位置調整
   - エフェクトコントロール → 位置：
     - 左下配置：`X=200, Y=1700`
     - 右下配置：`X=880, Y=1700`
3. スケール調整（推奨：50〜70%）
4. 必要に応じてキーフレームでアニメーション追加

#### ステップ3-4: ツールアイコン配置（V4トラック）
1. ツールアイコン（PNG）を**V4トラック**に配置
2. 各ツール紹介のタイミングに合わせて配置
   - 例：4位紹介時 → 4位ツールのアイコンを表示
3. 位置調整
   - 推奨位置：`X=540, Y=600`（画面中央上部）
   - スケール：30〜40%
4. トランジション追加（オプション）
   - クロスディゾルブ（`Ctrl+D` / `Cmd+D`）

---

### **Phase 4: 順位表示MOGRTの配置（5分）**

#### ステップ4-1: Essential Graphicsパネルを開く
1. **Window → Essential Graphics**（`Ctrl+9` / `Cmd+9`）
2. 「**ローカルテンプレート**」タブを選択

#### ステップ4-2: 順位表示テンプレートを配置
1. `順位表示_ランキングアニメーション`を探す
2. **V5トラック**の該当位置にドラッグ
   - 4位紹介 → 00:00:03:00 あたり
   - 3位紹介 → 00:00:10:00 あたり
   - 2位紹介 → 00:00:17:00 あたり
   - 1位紹介 → 00:00:24:00 あたり

#### ステップ4-3: 順位とツール名を編集
1. タイムライン上のMOGRTクリップを選択
2. Essential Graphicsパネルの「**編集**」タブで：
   - **順位**：「4位」→「3位」→「2位」→「1位」
   - **ツール名**：各ツールの正式名称を入力
   - **背景色**：必要に応じて変更（1位は金色など）

#### ステップ4-4: 論外版MOGRTを配置（該当する場合）
1. `順位表示_論外_赤字`テンプレートを選択
2. V5トラックの最後に配置
3. 「論外」と表示されるツール名を入力

---

### **Phase 5: SRT字幕の読み込みと適用（5分）**

#### ステップ5-1: SRTファイルをインポート
1. `03_字幕_Subtitles`ビンを選択
2. SRTファイルをドラッグ＆ドロップでインポート

#### ステップ5-2: タイムラインに配置
**方法A: ドラッグ&ドロップ**
1. SRTファイルをタイムライン上にドラッグ
2. 「**新規キャプショントラックを作成**」を選択
3. 配置先：開始位置（00:00:00:00）

**方法B: シーケンス経由**
1. シーケンスを右クリック → **キャプション → 字幕を追加**
2. **ファイルから読み込み** → SRTファイルを選択

#### ステップ5-3: 字幕スタイルを適用
1. **テキストパネル**を開く（Window → テキスト）
2. 字幕トラックのクリップを選択
3. 「**スタイル**」ドロップダウンから：
   - **通常部分**：`リール_通常字幕`を適用
   - **論外部分**：該当セグメントのみ`リール_論外_赤字`を適用

#### ステップ5-4: 位置と表示タイミング調整
1. 字幕パネルで各セグメントの位置を確認
   - 推奨位置：画面中央やや下（Y=1200）
2. タイミングがずれている場合は微調整
   - 再生ヘッドを該当位置に移動 → 字幕セグメントをドラッグ

---

### **Phase 6: 音声とBGMの配置（5分）**

#### ステップ6-1: ナレーション配置
1. **男性ナレーション**を**A1トラック**に配置
2. **女性ナレーション**を**A2トラック**に配置
   - 2声の掛け合いスタイルの場合、交互に配置
   - 1声のみの場合はA1またはA2のみ使用
3. 音量調整
   - エフェクトコントロール → ボリューム：`0dB`（標準）
   - 必要に応じて`-3dB`〜`+3dB`で微調整

#### ステップ6-2: BGM配置
1. BGMファイルを**A3トラック**に配置
2. 動画の長さに合わせてトリミング
3. 音量調整
   - ナレーションが聞こえるよう、BGMは**-15dB〜-20dB**に下げる
4. フェードイン/アウト適用
   - 開始部分：**0〜1秒**でフェードイン
   - 終了部分：**最後1秒**でフェードアウト
   - エフェクト → オーディオトランジション → クロスフェード(定パワー)

#### ステップ6-3: 効果音配置（オプション）
1. 効果音を**A4トラック**に配置
   - 順位発表時の「シュイン」音
   - 論外発表時の「ブー」音など
2. タイミング調整：順位表示MOGRTと同期

---

### **Phase 7: タイトル・テキスト追加（V6トラック）（5分）**

#### ステップ7-1: オープニングタイトル作成
1. **ファイル → 新規 → レガシータイトル**
   - または**グラフィック → 新規レイヤー → テキスト**
2. テキスト入力
   - 例：「2026年版 最強AIツール ランキングTOP4」
3. フォント設定
   - Noto Sans JP Bold、100px、白色、黒アウトライン
4. **V6トラック**の開始位置（00:00:00:00）に配置
5. デュレーション：3秒
6. トランジション追加：クロスディゾルブ

#### ステップ7-2: エンディングCTA追加
1. 同様に新規テキストを作成
2. 内容例：
   ```
   詳しくは概要欄から！
   特典プロンプトもチェック👇
   ```
3. V6トラックの最後に配置
4. デュレーション：3秒

---

### **Phase 8: 最終調整とプレビュー（5分）**

#### ステップ8-1: 全体の長さを確認
- タイムライン全体の長さ：**15〜30秒**（Instagram Reels推奨）
- 30秒を超える場合はカット編集

#### ステップ8-2: レンダリングとプレビュー
1. タイムライン範囲を選択（In点/Out点設定）
2. **シーケンス → イン/アウト間をレンダリング**（`Enter`キー）
3. 全画面プレビュー（`\`キー）で確認

#### ステップ8-3: チェック項目
- [ ] 字幕が読みやすく表示されているか
- [ ] 順位表示のタイミングが適切か
- [ ] ナレーションとBGMの音量バランスが適切か
- [ ] ツールアイコンが正しく表示されているか
- [ ] 全体の流れがスムーズか
- [ ] 論外部分の赤字表示が正しいか

#### ステップ8-4: 修正が必要な場合
- 字幕タイミング調整：字幕パネルで該当セグメントを選択 → ドラッグ
- 音量調整：オーディオクリップミキサーで各トラック調整
- 色補正：Lumetriカラーで明るさ/コントラスト調整

---

### **Phase 9: 書き出し（5分）**

#### ステップ9-1: 書き出し設定を開く
1. 完成したシーケンスを選択
2. **ファイル → 書き出し → メディア**（`Ctrl+M` / `Cmd+M`）

#### ステップ9-2: プリセット選択
1. 「**プリセット**」ドロップダウンから
   - `Instagram_Reels_1080x1920_30fps`を選択
   - （テンプレート作成時に保存したプリセット）

**プリセットが見つからない場合は手動設定:**
- **形式**: H.264
- **プリセット**: YouTube 1080p HD（ベース）
- **幅**: 1080
- **高さ**: 1920
- **フレームレート**: 30fps
- **ビットレート設定**: VBR、2パス
- **ターゲットビットレート**: 15 Mbps
- **最大ビットレート**: 20 Mbps
- **オーディオ形式**: AAC
- **サンプルレート**: 48000 Hz
- **オーディオビットレート**: 320 kbps

#### ステップ9-3: 出力ファイル名と保存先
1. **出力名**をクリック
2. ファイル名を設定
   - 例：`ランキングリール_AIツール_2026-01-21_完成版.mp4`
3. 保存先を選択
   - 推奨：`07_書き出し_Exports`フォルダ内

#### ステップ9-4: 書き出し実行
1. **書き出し**ボタンをクリック
2. 進行状況を確認（約2〜5分）
3. 完了後、**書き出し先フォルダを開く**で確認

---

### **Phase 10: 最終確認とアップロード準備（3分）**

#### ステップ10-1: 書き出し動画を確認
1. 書き出したMP4ファイルをダブルクリックで再生
2. 確認項目:
   - [ ] 動画が正しく再生されるか
   - [ ] 字幕が埋め込まれているか（SRTを焼き込んだ場合）
   - [ ] 音声が正常に出力されているか
   - [ ] 解像度が1080x1920であるか
   - [ ] 全体の品質が良好か

#### ステップ10-2: キャプション作成
台本に基づいて**Instagramキャプション**を作成（別ツールで）:
```
【2026年版】最強AIツールランキングTOP4🔥

1位は意外なあのツール...！
詳しくは動画で👀

📝概要欄から特典プロンプトもGET✨

#AIツール #生成AI #ChatGPT #業務効率化 #副業 #最新情報
```

#### ステップ10-3: アップロード
1. Instagram アプリ/Creator Studio を開く
2. 書き出した動画をアップロード
3. キャプション・ハッシュタグを貼り付け
4. カバー画像を選択（1位ツールの画面がおすすめ)
5. 投稿！

## 🎯 効率化のための追加Tips

### 1. **ショートカットキーの活用**
- `C`: Razorツール（カット）
- `V`: 選択ツール
- `Ctrl+K` / `Cmd+K`: 再生ヘッド位置でカット
- `Ctrl+D` / `Cmd+D`: デフォルトトランジション適用
- `\`: 全画面プレビュー
- `Space`: 再生/停止
- `Shift+Delete`: リップル削除（ギャップを詰める）

### 2. **ネスト化でタイムラインを整理**
複数のクリップをまとめる:
1. V4〜V6のグラフィックス系クリップを選択
2. 右クリック → **ネスト**
3. ネスト名：「グラフィックスまとめ」

### 3. **プロジェクトの保存ルール**
- 定期保存：`Ctrl+S` / `Cmd+S`（10分ごと）
- 自動保存設定：**編集 → 環境設定 → 自動保存**
  - 間隔：5分
  - 最大数：20

### 4. **複数動画の同時作業**
同じテーマで複数のバリエーション作成時:
1. `Instagram_Reels_Main`シーケンスを複製
2. シーケンス名を変更
   - 例：`Instagram_Reels_Main_バージョン2`
3. 別の台本・素材で作業

### 5. **トラブルシューティング**
| 問題 | 解決方法 |
|------|---------|
| 字幕が表示されない | テキストパネル → キャプションを選択 → スタイル再適用 |
| MOGRTが見つからない | Essential Graphics → ローカルテンプレートを更新 |
| 音声が途切れる | オーディオ設定 → サンプルレートを統一（48000 Hz） |
| 書き出しが遅い | プレビューファイルを削除（シーケンス → レンダリングファイルを削除） |
| プロジェクトが重い | メディアキャッシュを削除（編集 → 環境設定 → メディアキャッシュ） |
