# 特典付き投稿 台本テンプレートガイド

**このドキュメントについて**

Claude Codeが特典付き投稿の台本を作成する際に必ず参照するガイドラインです。
10本の実際の台本サンプルを**本質的に分析**し、うちのコンテンツで使える型を定義しています。

---

## 絶対ルール

### やってはいけないこと

| NG | 理由 |
|---|---|
| **嘘をつく** | 信頼を失う、長期的にマイナス |
| 「通常3000円→無料URL」を使う | うちにはそういうURLがない |
| 「高単価案件まとめ」を特典にする | うちにはアフィリエイト案件情報がない |
| 収益額を誇張する（月100万など） | 嘘になる |
| 緊急性を嘘で演出する（最後のチャンス） | 嘘になる |
| 投稿と連動しない特典を作る | 視聴者が欲しいものではない |

### やるべきこと

1. **投稿と特典を連動させる**
2. **嘘のない内容だけを使う**
3. **詳細は特典に取っておく**

---

## 本質の理解（最重要）

### 投稿と特典の関係

```
投稿の役割: 「これがすごい」「これが答え」を見せる（詳細は教えない）
     ↓
視聴者: 「それ欲しい」「詳しく知りたい」
     ↓
特典の役割: 投稿で見せた内容の「詳細」を教える
```

**具体例**:
- 投稿で「このプロンプトを送ると」と言う → 特典でそのプロンプト全文を渡す
- 投稿で「このツールを使って」と言う → 特典でツールの設定手順を渡す
- 投稿で「1位は○○」と言う → 特典で1位の詳しい使い方を渡す

### NG例（過去の失敗）

| 作ったもの | 問題 |
|---|---|
| 「SNS投稿画像プロンプト集」 | 対応する投稿がない。投稿で「このプロンプトでこんな画像が！」と見せていない |
| 「トレンドリサーチプロンプト」 | 投稿との連動がない。単独で存在している |

→ **特典は投稿とセットで設計する**

## ランキング形式・対話形式の本質

### よくある誤解

> 「ランキング形式は、順位付けに価値がある」

### 本質

**ランキング形式も対話形式も、「1位（伝えたいもの）に注目させる」ための誘導装置**

```
「論外」で除外 → 「これじゃない」で選択肢を絞る
順位をバラバラに出す → 「1位は何？」と最後まで見させる
最後に1位で締める → 「これが答え」を印象付ける
```

### ChatGPTを「論外」にする意味

- みんなが使ってる（常識）を覆す → 「え、そうなの？」と引く
- **ただし嘘はダメ**
- 本当に論外な理由がある場合のみ使える（例：無料版は画像3枚/日制限）

### 対話形式の本質

対話形式は**「型」ではなく「演出手法」**。

```
声A（男性）: ChatGPT？
声B（女性）: うーん、論外。
```

これは「質問→回答」の繰り返しで、結論（1位）に誘導している。
ランキング形式やステップ形式と**組み合わせて**使う。

## 使える型一覧

| 型 | 概要 | 特典 |
|---|---|---|
| **型A: 成果物見せ + ステップ誘導** | 成果物を見せ、簡潔なステップで「このプロンプト」へ誘導 | 手順・プロンプトの詳細 |
| **型B: 複数プロンプト積み上げ** | 複数ステップで「このプロンプト」を繰り返し、期待値を積み上げる | 全プロンプトまとめ |
| **型C: ランキング形式** | 除外と順位で1位に注目させる | 1位の詳しい使い方 |
| **型D: 対話形式（演出）** | 2声構成で型A〜Cを演出 | 型による |
| **型E: 高速チュートリアル** | 高速で操作を見せ、真似できない状態を作る | ゆっくり版の詳細手順 |

## 型A: 成果物見せ + ステップ誘導

**参照サンプル**: 2, 6, 8

### 構造

```
【導入】
成果物を見せる
「これ、○○で作りました」
   ↓
問題提起 or 興味づけ
「でも普通にやると○○」「○○な人が増えてる」
   ↓
【解説】
ステップ1: 準備段階（誰でもできる）
ステップ2: 核心の一歩手前
ステップ3: 核心（「このプロンプト」「このツール」）
   ↓
【CTA】
「詳しい手順をまとめました」
「○○をコメントで教えてね」
```

### なぜこの構造か

1. **成果物で掴む**: 「こんなの作れるんだ」と興味
2. **ステップで簡単に見せる**: 「自分でもできそう」と思わせる
3. **詳細は言わない**: 「このプロンプト」で止める
4. **特典で詳細を渡す**: 「それが知りたかった」を満たす

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「このプロンプトを送ると」 | プロンプト全文 |
| 「このツールを使って」 | ツールの設定手順 |
| 「こんな感じで完成」 | 再現するための詳細手順 |

### 具体例

```
【導入】
これ、AIで5分で作りました。

冒頭3秒が大事なのは当然ですが、
今はただ綺麗な映像や強い言葉だけでは止まってもらえません。
そこで使ってほしいのがAIフック。

【解説】
1. この拡張機能をダウンロード
2. 自分の写真をアップロードして、作りたいイメージを入力
3. 生成ボタンを押すだけ

これで目を引くAIフックが作れます。

【CTA】
さすがにこの動画だけでは解説しきれないので、記事にまとめました。
作りたい人は、○○をコメントで教えてください。
```

### 注意点

- 成果物は本当に作ったものを見せる（嘘ダメ）
- ステップは3-5個程度（多すぎると見切られる）
- 各ステップの詳細は言わない（特典への布石）

## 型B: 複数プロンプト積み上げ

**参照サンプル**: 3, 4

### 構造

```
【導入】
権威 or 実績
「○○した私が」「○○を達成した方法」
   ↓
【解説】
ステップ1: 「このプロンプト」を使って○○
ステップ2: 「このサイト」で○○
ステップ3: 「このプロンプト」で○○
ステップ4: 「このツール」を使って○○
ステップ5: 「このプロンプト」で仕上げ
   ↓
【CTA】
「今日紹介した全部をまとめました」
```

### なぜこの構造か

1. **「このプロンプト」を繰り返す**: 毎回「何それ？」が発生
2. **期待値が積み上がる**: 5回言えば5つ分の「欲しい」
3. **特典で全部渡す**: 「全部まとめました」で一気に回収

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「このプロンプト」×5回 | 5つのプロンプト全文 |
| 「このサイト」「このツール」 | URL・ツール名・設定手順 |
| 流れ全体 | 全体をまとめた資料 |

### 具体例

```
【導入】
インスタで○○した私が、今ゼロからやるならこうします。

【解説】
1. AIで別人に変身
   このプロンプトを送って理想の自分を作ります

2. ジャンル選定
   このプロンプトを送れば穴場ジャンルを見つけてくれます

3. プロフィール作成
   このプロンプトにあなたの情報を入れると
   プロ級のプロフィールを提案してくれます

4. ネタ探し
   このサイトを開いて参考アカウントを入力
   全リールを再生回数順にまとめてくれます

5. リール作成
   このプロンプトを送れば
   バズる台本に書き換えてくれます

【CTA】
今日紹介した手順を全部まとめました。
欲しい人は○○をコメントで教えてね。
```

### 注意点

- 本当に使えるプロンプト・ツールを紹介する（嘘ダメ）
- 各ステップで「これ何？」を発生させる
- 特典は「全部まとめ」が基本

## 型C: ランキング形式

**参照サンプル**: 5, 7

### 構造

```
【導入】なし（いきなり始まる）
   ↓
【解説】
○○？ → 論外（理由を簡潔に）
○○？ → 3位 or 4位（良い点を説明）
○○？ → 2位（良い点を説明）
○○？ → 1位（詳しく説明、ここが核心）
   ↓
【CTA】
「1位の使い方をまとめました」
```

### なぜこの構造か

1. **論外で常識を覆す**: 「みんな使ってるけど実は微妙」で引く
2. **順位で期待を煽る**: 「じゃあ1位は何？」と最後まで見させる
3. **1位で締める**: 最も伝えたいものを印象付ける
4. **特典は1位の詳細**: 1位に注目させたから、1位だけ渡せばいい

### 順位の出し方

```
悪い例: 5位 → 4位 → 3位 → 2位 → 1位（予想通りで飽きる）

良い例: 論外 → 2位 → 4位 → 3位 → 1位（順番がバラバラで「1位は？」と引く）
```

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「1位は○○」 | 1位の詳しい使い方 |
| 1位の良さを説明 | 具体的な設定・プロンプト |

### 具体例

```
【解説】
ChatGPT？
→ うーん、論外。無料版だと画像は1日3枚まで。正直微妙。

Perplexity？
→ 2位。ネタ探しはこれ一択。最新情報を出典付きで出してくれる。

Vrew？
→ 4位。テロップ編集が10秒でできる。精度も高い。

Fish Audio？
→ 3位。自分の声で自然なアフレコを作ってくれる。

Google AI Studio？
→ これは圧倒的1位。GeminiもNanoBananaも無料で使える。
  台本も画像もこれ一つで完結。

【CTA】
今日紹介したツールの使い方をまとめました。
欲しい人は○○をコメントで教えてね。
```

### 注意点

- **論外にする理由は本当のこと**（嘘ダメ）
- **1位が本当に良い理由が必要**
- 順位を付けるなら、本当にその順位である根拠を持つ

## 型D: 対話形式（演出手法）

**参照サンプル**: 4, 5, 7

### 本質

対話形式は**「型」ではなく「演出手法」**。
型A, B, Cと組み合わせて使う。

```
声A（提示役）: ○○？ / ○日目
     ↓
声B（評価役）: 評価・解説
     ↓
（繰り返し）
     ↓
最後に声Bが核心を詳しく説明
```

### なぜ対話形式を使うか

1. **2声で飽きさせない**: 1人だと単調
2. **声Aは視聴者の代わり**: 質問する役
3. **声Bは回答を与える役**: 結論に誘導

### 組み合わせパターン

| 組み合わせ | 声Aの役割 | 声Bの役割 |
|---|---|---|
| 対話 × ランキング | ツール名を提示 | 順位・評価を回答 |
| 対話 × 日数ステップ | 「○日目」とコール | その日のやることを解説 |
| 対話 × 通常ステップ | 「ステップ○」とコール | 具体的な内容を解説 |

### 具体例（ランキング × 対話）

```
声A（男性）: ChatGPT？

声B（女性）: うーん、論外。
無料版だと画像は1日3枚まで。正直微妙かな。

---

声A: Perplexity？

声B: 2位。
ネタ探しはこれ一択。最新情報を出典付きで出してくれる。

---

声A: Google AI Studio？

声B: これは圧倒的1位。
GeminiもNanoBananaも無料で使える。
台本も画像もこれ一つで完結します。

---

【CTA】
声B: 今日紹介したツールの使い方をまとめました。
○○をコメントで教えてね。
```

### 具体例（日数ステップ × 対話）

```
声A（男性）: 1日目。

声B（女性）: GenSparkにこのプロンプトを送ると、
今アツいジャンルをまとめてくれる。その中から選ぶ。

---

声A: 2日目。

声B: プロフィール作成。このプロンプトを使って
フォロー率の高いプロフィールを作る。

---

声A: 3日目から6日目。

声B: リール投稿。この3つの文字起こしをこのプロンプトと一緒に
ChatGPTに送ると、バズる台本を作ってくれる。

---

声A: 7日目以降。

声B: リールの強化。投稿したリールのインサイトを
ChatGPTに送ると改善点を出してくれる。

---

【CTA】
声B: この手順で進めれば最短で目標達成できます。
全手順とプロンプトをまとめました。
欲しい人は○○をコメントで教えてね。
```

### 注意点

- 対話形式は「演出」であって「型」ではない
- 型A, B, Cと組み合わせて使う
- 2声が難しければ1声でも成立する（本質は同じ）

## 型E: 高速チュートリアル

**参照サンプル**: 8

### 構造

```
【導入】
成果物を見せる
「この○○の作り方、教えます」
   ↓
【解説】
画面録画で操作を高速で見せる（30秒程度）
   ↓
「保存して真似してみてね」
   ↓
【CTA】
「詳しい手順をDMで送ります」
```

### なぜこの構造か

1. **高速で見せる**: 「こんな簡単に？」と思わせる
2. **速すぎて真似できない**: 「もっと詳しく知りたい」
3. **特典で詳細を渡す**: ゆっくり版の手順書

### 投稿と特典の連動

| 投稿で見せること | 特典で渡すもの |
|---|---|
| 操作の流れ（高速） | 各操作の詳細手順（ゆっくり） |
| 完成物 | 再現するためのステップバイステップ |

### 具体例

```
【導入】
この空撮風動画の作り方、こっそり教えちゃいます。
めっちゃ簡単だよ。

【解説】（画面録画、テロップ付き）
0:06 まずは「Google Earth Studio」と検索
0:08 ログインして「試す」をクリック
0:10 プルダウンから「クイックスタート」
0:12 「スパイラル」を選択
0:16 好きな場所を検索
0:19 スライダーで調整
0:22 「レンダリング」で書き出し
0:26 完成！

【CTA】
「作りたい場所」をコメントで教えて！
詳しい手順をDMで送ります。
```

### 注意点

- 本当に動く手順を見せる（嘘ダメ）
- 高速で見せるからこそ「詳細欲しい」が発生する
- 特典は「ゆっくり版」「テキスト版」として価値がある

## 特典の棚卸しフロー

### なぜ棚卸しが必要か

特典は「うちが持っている実体」から選ぶ。
実体がないのに特典を作ると、嘘になるか、価値のないものになる。

### 棚卸しの評価軸

特典の価値は以下の4軸で評価する：

| 軸 | 説明 | 高評価の例 |
|---|---|---|
| **日常使い** | 普段の作業で使えるか | 毎日の投稿に使える |
| **効率化** | いつもの作業が楽になるか | 1時間→10分になる |
| **稼げる可能性** | 収益につながるか | 副業・集客に直結 |
| **SNS関連** | 投稿に直結するか | Instagram/X/YouTube |

### 高評価になりやすいもの

```
SNS投稿 × 稼げる可能性 = 最も需要が高い
```

- SNS投稿に使える画像プロンプト
- リール/ショート動画の台本テンプレート
- サムネイル・アイキャッチのプロンプト
- バズる投稿の構造

### 低評価になりやすいもの

- 技術者向けすぎるもの（n8nワークフロー、GASコード）
- 汎用的すぎて「いつ使うか」が不明確なもの
- SNS投稿に直結しないもの

### 棚卸しのフロー

```
1. 講座コンテンツを確認
   └ 実際に使っているプロンプト、手順、ツール情報を洗い出す

2. 4軸で評価
   └ 日常使い / 効率化 / 稼げる / SNS関連

3. 高評価のものを特典候補に
   └ 特に「SNS × 稼げる」が重なるもの

4. 投稿とセットで設計
   └ この特典を「すごい」と思わせる投稿は何か？
```

## 「すごい」と思わせる = 権威性

### 本質

投稿の役割は「特典がすごい」と思わせること。

```
視聴者: 「この人が使ってるプロンプトすごい」
     ↓
視聴者: 「それ欲しい」
     ↓
特典: 実際にそのプロンプトを渡す
```

### 権威性の作り方

| 方法 | 例 |
|---|---|
| **成果を見せる** | 「これ、5分で作りました」「この方法で○○できました」 |
| **問題を解決する** | 「まだ○○で困ってる？」「これで解決」 |
| **効率化を見せる** | 「1時間かかってた作業が10分に」 |
| **常識を覆す** | 「みんな○○使ってるけど、実は△△の方がいい」 |

### 権威性 ≠ 嘘

- 本当に成果が出たものを見せる
- 本当に効率化できるものを紹介する
- 本当に良いと思うものを推す

**嘘の権威性はダメ**（「月100万稼いだ」等の誇張）

## 制作フロー

### 推奨フロー

```
1. 特典を決める
   └ 棚卸し結果から、高評価のものを選ぶ
   └ 「SNS × 稼げる」が重なるものが理想

2. 「すごい」と思わせるポイントを決める
   └ この特典の何がすごいのか？
   └ 成果？効率化？問題解決？

3. 型を選ぶ
   └ 型A〜Eのどれが適しているか

4. 投稿を設計する
   └ 特典の「すごさ」を見せる構成
   └ 「このプロンプト」「このツール」で詳細は特典へ

5. トリガーワードを決める
   └ 答えやすいものを選ぶ

6. 台本を作成する
   └ 投稿と特典が連動しているか確認
```

### チェックリスト

#### 投稿
- [ ] 嘘がないか
- [ ] 「このプロンプト」「このツール」等で特典への期待を作れているか
- [ ] 詳細を言いすぎていないか（特典の価値を残しているか）

#### 特典
- [ ] 投稿で言った内容の「詳細」になっているか
- [ ] 視聴者が「それが欲しかった」と思える内容か
- [ ] うちが実際に持っている情報か

#### 連動
- [ ] 投稿を見た人が特典を欲しくなる流れになっているか
- [ ] 投稿と特典が1セットとして成立しているか
