# 特典付き投稿 台本テンプレートガイド

**このドキュメントについて**

Claude Codeが特典付き投稿の台本を作成する際に必ず参照するガイドラインです。
10本の実際の台本サンプルを**本質的に分析**し、うちのコンテンツで使える型を定義しています。

---

## 絶対ルール

### やってはいけないこと

| NG | 理由 |
|---|---|
| **嘘をつく** | 信頼を失う、長期的にマイナス |
| 「通常3000円→無料URL」を使う | うちにはそういうURLがない |
| 「高単価案件まとめ」を特典にする | うちにはアフィリエイト案件情報がない |
| 収益額を誇張する（月100万など） | 嘘になる |
| 緊急性を嘘で演出する（最後のチャンス） | 嘘になる |
| 投稿と連動しない特典を作る | 視聴者が欲しいものではない |

### やるべきこと

1. **投稿と特典を連動させる**
2. **嘘のない内容だけを使う**
3. **詳細は特典に取っておく**

---

## 本質の理解（最重要）

### 投稿と特典の関係

```
投稿の役割: 「これがすごい」「これが答え」を見せる（詳細は教えない）
     ↓
視聴者: 「それ欲しい」「詳しく知りたい」
     ↓
特典の役割: 投稿で見せた内容の「詳細」を教える
```

**具体例**:
- 投稿で「このプロンプトを送ると」と言う → 特典でそのプロンプト全文を渡す
- 投稿で「このツールを使って」と言う → 特典でツールの設定手順を渡す
- 投稿で「1位は○○」と言う → 特典で1位の詳しい使い方を渡す

### NG例（過去の失敗）

| 作ったもの | 問題 |
|---|---|
| 「SNS投稿画像プロンプト集」 | 対応する投稿がない。投稿で「このプロンプトでこんな画像が！」と見せていない |
| 「トレンドリサーチプロンプト」 | 投稿との連動がない。単独で存在している |

→ **特典は投稿とセットで設計する**

## ランキング形式・対話形式の本質

### よくある誤解

> 「ランキング形式は、順位付けに価値がある」

### 本質

**ランキング形式も対話形式も、「1位（伝えたいもの）に注目させる」ための誘導装置**

```
「論外」で除外 → 「これじゃない」で選択肢を絞る
順位をバラバラに出す → 「1位は何？」と最後まで見させる
最後に1位で締める → 「これが答え」を印象付ける
```

### ChatGPTを「論外」にする意味

- みんなが使ってる（常識）を覆す → 「え、そうなの？」と引く
- **ただし嘘はダメ**
- 本当に論外な理由がある場合のみ使える（例：無料版は画像3枚/日制限）

### 対話形式の本質

対話形式は**「型」ではなく「演出手法」**。

```
声A（男性）: ChatGPT？
声B（女性）: うーん、論外。
```

これは「質問→回答」の繰り返しで、結論（1位）に誘導している。
ランキング形式やステップ形式と**組み合わせて**使う。

## リール制作の4つの軸

リール制作は以下の4つの軸で構成される。これらは**独立した軸**であり、組み合わせて使う。

| 軸 | 意味 | 選択肢 |
|---|---|---|
| **型（構成）** | 台本のストーリー構造 | 型A〜D |
| **演出手法** | 型をどう演出するか | 対話形式 / 単独ナレーション |
| **制作手法** | どう撮影・制作するか | アフレコ / トーク / vlog |
| **視覚情報** | 背景で何を流すか | AI映像 / 画面収録 / 図解 等 |

**例**: 「型C（ランキング）× 対話形式 × アフレコ × AI映像」

---

## 型（構成）一覧

**台本のストーリー構造**。どんな論理で視聴者を誘導するか。

| 型 | 概要 | 特典 |
|---|---|---|
| **型A: 成果物見せ + ステップ誘導** | 成果物を見せ、簡潔なステップで「このプロンプト」へ誘導 | 手順・プロンプトの詳細 |
| **型B: 複数プロンプト積み上げ** | 複数ステップで「このプロンプト」を繰り返し、期待値を積み上げる | 全プロンプトまとめ |
| **型C: ランキング形式** | 除外と順位で1位に注目させる | 1位の詳しい使い方 |
| **型D: 比較リール** | 「失敗例 vs 成功例」で対比を見せる | 成功例の詳しいやり方 |
| **型E: 逆説フック×3点ノウハウ** | 常識を否定して引き込み、3つのノウハウで解決 | ノウハウまとめ |

## 演出手法一覧

**型をどう演出するか**。型A〜Dと組み合わせて使う。

| 演出手法 | 概要 | 効果 |
|---|---|---|
| **対話形式** | 2声構成（質問役+回答役） | 飽きさせない、テンポが出る |
| **単独ナレーション** | 1声で進行 | シンプル、量産しやすい |

## 制作手法一覧

**どう撮影・制作するか**。型・演出とは独立した軸。

| 制作手法 | 映像 | うちでの実現 |
|---|---|---|
| **アフレコリール** | AI映像、画面収録等 + ナレーション | **標準手法** |
| **トークリール** | 関係のない旅行・暮らし映像 + ストーリー | 作業風景等で代用 |
| **解説系リール** | カメラ目線 + PC画面 | **KLINGAIでアバター作成** |

**トークリールとの違い**:
- トークリール: 映像は関係ない（旅行、暮らし）、「昔→今」のストーリー
- 解説系リール: カメラ目線で教える + PC画面等でデモ

## 視覚情報一覧

**背景で何を流すか**。型・演出・制作手法とは独立した軸。

| 視覚情報 | 概要 | 適した場面 |
|---|---|---|
| **AI生成映像** | Flow、Sora2等で生成した映像 | 抽象的な話、雰囲気重視 |
| **画面収録** | ツール操作を録画 | 具体的な手順説明 |
| **図解・スライド** | Canva等で作った図 | 全体像の説明、ステップ説明 |
| **作業風景** | デスク、PC、手元など | vlog的なアプローチ |
| **成果物映像** | 完成した画像・動画を見せる | 型Aの導入部分 |

**注意**: 「図解リール」「高速チュートリアル」は視覚情報の選択肢であり、型（構成）ではない

## 冒頭フックの2層構造

リールの冒頭は2層で構成される。

### 視覚フック（0-3秒）

**目的**: 指を止めさせる（内容と無関係でもOK）

| 手法 | 例 |
|---|---|
| 派手なエフェクト | ガラス割れ、雷、爆発 |
| 大きな動き | ジャンプ、転倒、変身 |
| インパクト映像 | 衝撃的なビジュアル |

**ツール**: CapCutのテンプレート機能、グリーンバック素材

### 言語フック（3秒〜）

**目的**: 内容に引き込む（型によって異なる）

| 型 | 冒頭パターン |
|---|---|
| **型C（ランキング）** | 「論外」で始める |
| **型D（比較）** | 左右分割で視覚的に見せる（言語フック不要） |
| **型E（逆説フック）** | 「実は〇〇は××です」 |
| **アフレコ系トレンド** | 「〇〇で億作った」「〇〇で7桁作った」 |

**注意**: 言語フックは必須ではなくなりつつある。視覚フックの重要度が上がっている

## 型A: 成果物見せ + ステップ誘導

**参照サンプル**: 2, 6, 8

### 構造

```
【導入】
成果物を見せる
「これ、○○で作りました」
   ↓
問題提起 or 興味づけ
「でも普通にやると○○」「○○な人が増えてる」
   ↓
【解説】
ステップ1: 準備段階（誰でもできる）
ステップ2: 核心の一歩手前
ステップ3: 核心（「このプロンプト」「このツール」）
   ↓
【CTA】
「詳しい手順をまとめました」
「○○をコメントで教えてね」
```

### なぜこの構造か

1. **成果物で掴む**: 「こんなの作れるんだ」と興味
2. **ステップで簡単に見せる**: 「自分でもできそう」と思わせる
3. **詳細は言わない**: 「このプロンプト」で止める
4. **特典で詳細を渡す**: 「それが知りたかった」を満たす

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「このプロンプトを送ると」 | プロンプト全文 |
| 「このツールを使って」 | ツールの設定手順 |
| 「こんな感じで完成」 | 再現するための詳細手順 |

### 具体例

```
【導入】
これ、AIで5分で作りました。

冒頭3秒が大事なのは当然ですが、
今はただ綺麗な映像や強い言葉だけでは止まってもらえません。
そこで使ってほしいのがAIフック。

【解説】
1. この拡張機能をダウンロード
2. 自分の写真をアップロードして、作りたいイメージを入力
3. 生成ボタンを押すだけ

これで目を引くAIフックが作れます。

【CTA】
さすがにこの動画だけでは解説しきれないので、記事にまとめました。
作りたい人は、○○をコメントで教えてください。
```

### 注意点

- 成果物は本当に作ったものを見せる（嘘ダメ）
- ステップは3-5個程度（多すぎると見切られる）
- 各ステップの詳細は言わない（特典への布石）

## 型B: 複数プロンプト積み上げ

**参照サンプル**: 3, 4

### 構造

```
【導入】
権威 or 実績
「○○した私が」「○○を達成した方法」
   ↓
【解説】
ステップ1: 「このプロンプト」を使って○○
ステップ2: 「このサイト」で○○
ステップ3: 「このプロンプト」で○○
ステップ4: 「このツール」を使って○○
ステップ5: 「このプロンプト」で仕上げ
   ↓
【CTA】
「今日紹介した全部をまとめました」
```

### なぜこの構造か

1. **「このプロンプト」を繰り返す**: 毎回「何それ？」が発生
2. **期待値が積み上がる**: 5回言えば5つ分の「欲しい」
3. **特典で全部渡す**: 「全部まとめました」で一気に回収

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「このプロンプト」×5回 | 5つのプロンプト全文 |
| 「このサイト」「このツール」 | URL・ツール名・設定手順 |
| 流れ全体 | 全体をまとめた資料 |

### 具体例

```
【導入】
インスタで○○した私が、今ゼロからやるならこうします。

【解説】
1. AIで別人に変身
   このプロンプトを送って理想の自分を作ります

2. ジャンル選定
   このプロンプトを送れば穴場ジャンルを見つけてくれます

3. プロフィール作成
   このプロンプトにあなたの情報を入れると
   プロ級のプロフィールを提案してくれます

4. ネタ探し
   このサイトを開いて参考アカウントを入力
   全リールを再生回数順にまとめてくれます

5. リール作成
   このプロンプトを送れば
   バズる台本に書き換えてくれます

【CTA】
今日紹介した手順を全部まとめました。
欲しい人は○○をコメントで教えてね。
```

### 注意点

- 本当に使えるプロンプト・ツールを紹介する（嘘ダメ）
- 各ステップで「これ何？」を発生させる
- 特典は「全部まとめ」が基本

## 型C: ランキング形式

**参照サンプル**: 5, 7

### 伸びる理由（心理効果）

1. **「次はなんだろう？」「1位が知りたい」** → 視聴完了率UP
2. **まとめ感が強い** → 「保存してあとで見返したい」と思わせやすい
3. **項目が複数ある** → 「どれか一つは自分に刺さる」と感じやすい

### 構造

```
【導入】なし（いきなり始まる）
   ↓
【解説】
○○？ → 論外（理由を簡潔に）
○○？ → 3位 or 4位（良い点を説明）
○○？ → 2位（良い点を説明）
○○？ → 1位（詳しく説明、ここが核心）
   ↓
【CTA】
「1位の使い方をまとめました」
```

### なぜこの構造か

1. **論外で常識を覆す**: 「みんな使ってるけど実は微妙」で引く
2. **順位で期待を煽る**: 「じゃあ1位は何？」と最後まで見させる
3. **1位で締める**: 最も伝えたいものを印象付ける
4. **特典は1位の詳細**: 1位に注目させたから、1位だけ渡せばいい

### 順位の出し方（最新トレンド）

```
古い手法: 5位 → 4位 → 3位 → 2位 → 1位（予想通りで飽きる）

最新トレンド: 論外 → 2位 → 4位 → 3位 → 1位（順番がバラバラで「1位は？」と引く）
```

**ポイント**: 「論外」で常識を覆し、順番をバラバラにすることで最後まで見させる

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「1位は○○」 | 1位の詳しい使い方 |
| 1位の良さを説明 | 具体的な設定・プロンプト |

### 具体例

```
【解説】
ChatGPT？
→ うーん、論外。無料版だと画像は1日3枚まで。正直微妙。

Perplexity？
→ 2位。ネタ探しはこれ一択。最新情報を出典付きで出してくれる。

Vrew？
→ 4位。テロップ編集が10秒でできる。精度も高い。

Fish Audio？
→ 3位。自分の声で自然なアフレコを作ってくれる。

Google AI Studio？
→ これは圧倒的1位。GeminiもNanoBananaも無料で使える。
  台本も画像もこれ一つで完結。

【CTA】
今日紹介したツールの使い方をまとめました。
欲しい人は○○をコメントで教えてね。
```

### 注意点

- **論外にする理由は本当のこと**（嘘ダメ）
- **1位が本当に良い理由が必要**
- 順位を付けるなら、本当にその順位である根拠を持つ
- **ランキングの根拠が曖昧だと信頼を失う**
- **ダラダラ紹介せず、テンポよく切り替える**

## 型D: 比較リール

### 伸びる理由（心理効果）

1. **「自分はどっちだろう？」と自己投影** → 関心度UP
2. **Before→Afterでストーリー性** → 不安を煽りつつ解決策を提示できる
3. **テンポよく切り替わる** → 「飽きさせない流れ」を自然に作れる

### 構造

```
【導入】
比較テーマを宣言
「○○ vs △△」「失敗例 vs 成功例」
   ↓
【解説】
Aパターン: 悪い例・古いやり方・失敗例
   ↓
Bパターン: 良い例・最新のやり方・成功例
   ↓
【CTA】
「あなたはどちら派?」
「最新の方法をまとめました」
```

### 比較パターン例

| パターン | 例 |
|---|---|
| 時代比較 | 「2025年の運用 vs 2026年の運用」 |
| スキル比較 | 「素人 vs プロ」「初心者 vs 上級者」 |
| 結果比較 | 「失敗例 vs 成功例」「Before vs After」 |
| 手法比較 | 「古いやり方 vs 最新のやり方」 |

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「Bパターン（成功例）はこうやる」 | 成功例の詳しいやり方・手順 |
| 「最新の方法はこれ」 | 最新手法のテンプレート・プロンプト |

### 具体例

```
【導入】
2025年の運用 vs 2026年の運用

【解説】
2025年:
毎日投稿が正義だと思ってた
→ 量産しても伸びない、疲弊するだけ

2026年:
週3投稿でも伸びる人が続出
→ 1本の質を上げる方が効率的

【CTA】
2026年版の投稿テンプレートをまとめました
欲しい人は○○をコメントで教えてね
```

### 注意点

- **対比が曖昧だと伝わらない**
- **数字や具体的な行動の違い**を見せることが重要
- 「なんとなく違う」ではなく「ここがこう違う」を明確に

## 型E: 逆説フック×3点ノウハウ

### 概要

常識を否定して注意を引き、3つのノウハウで解決策を提示する構成。
主に**解説系リール**（カメラ目線+PC画面）で使用。

### 基本スペック

| 項目 | 内容 |
|---|---|
| 動画の長さ | 30〜40秒（推奨35秒） |
| ターゲット感情 | 「損をしたくない」「裏技を知りたい」「簡単に解決したい」 |
| 編集テンポ | 1カット2〜3秒 |
| ナレーション速度 | 1秒あたり7〜8文字（やや早口） |

### タイムライン構成

```
【0-3秒】視覚フック
派手なエフェクト（内容と無関係でもOK）
→ 指を止めさせる

【3-8秒】言語フック
「実は[常識]は[否定]です」
「[ターゲット]だけ見てください」
→ 常識の否定で引き込む

【9-13秒】解決策提示
「ある[数字]つのことをするだけで、[理想の結果]になります」
→ ハードルを下げる

【14-28秒】3つのノウハウ
1つ目：[具体的な行動A]
2つ目：[具体的な行動B]
3つ目：[具体的な行動C]
→ リスト形式で提示

【29-33秒】まとめ
「これだけで[ベネフィット]です。今回紹介したコツをまとめました。」
→ 効果の保証とプレゼント提示

【34-36秒】CTA
「欲しい人はコメントで[簡単な質問]を教えてください」
→ 無関係な質問でコメント誘導（アルゴリズムハック）
```

### 穴埋め式スクリプト

```
（0:00〜）
実は、[業界の常識/ツール名]は[ネガティブな言葉]です。
[損をしたくない/失敗したくない]人だけ見てください。
ある[数字]つの[行動/設定]をするだけで、
[ツール/対象]が[劇的な変化]になります。

（0:14〜）
1つ目、[状況A]の時は「[解決策ワードA]」と言って、[NG行動]しないでください。
2つ目、[状況B]ときは、[具体的な手順/魔法の言葉]と伝えてください。
3つ目、その答えの根拠となる[証拠/ソース]を必ず出してください。

（0:29〜）
これだけで[成果/精度]がぐんと上がります。
今回紹介した[ノウハウ名]をまとめました。

（0:34〜）
欲しい人はコメントで、[簡単な質問]を教えてください。
```

### マーケティングロジック

| 手法 | 理由 |
|---|---|
| **逆説フック（プロスペクト理論）** | 人は「得する」より「損を回避する」に強く反応 |
| **3つのポイント** | 情報は3つが最も覚えやすい。「3つ目は？」で視聴維持 |
| **無関係なコメント誘導** | 1秒で書けるコメント → アルゴリズムが「良い動画」と判断 |

### 投稿と特典の連動

| 投稿で言うこと | 特典で渡すもの |
|---|---|
| 「3つのコツをまとめました」 | 3つのノウハウの詳細版 |
| 「これだけで○○になります」 | 具体的な手順・プロンプト |

### 注意点

- 「〇〇で億作った」等の実績は嘘になる場合は使わない
- 逆説フックの否定は本当のことに限る
- 3つのノウハウは具体的で再現可能なものにする

## 演出手法: 対話形式

**参照サンプル**: 4, 5, 7

### 本質

対話形式は**「型」ではなく「演出手法」**。
型A〜Dと組み合わせて使う。

```
声A（提示役）: ○○？ / ○日目
     ↓
声B（評価役）: 評価・解説
     ↓
（繰り返し）
     ↓
最後に声Bが核心を詳しく説明
```

### なぜ対話形式を使うか

1. **2声で飽きさせない**: 1人だと単調
2. **声Aは視聴者の代わり**: 質問する役
3. **声Bは回答を与える役**: 結論に誘導

### 組み合わせパターン

| 組み合わせ | 声Aの役割 | 声Bの役割 |
|---|---|---|
| 対話 × ランキング | ツール名を提示 | 順位・評価を回答 |
| 対話 × 日数ステップ | 「○日目」とコール | その日のやることを解説 |
| 対話 × 通常ステップ | 「ステップ○」とコール | 具体的な内容を解説 |

### 具体例（型C ランキング × 対話形式）

```
声A（男性）: ChatGPT？

声B（女性）: うーん、論外。
無料版だと画像は1日3枚まで。正直微妙かな。

---

声A: Perplexity？

声B: 2位。
ネタ探しはこれ一択。最新情報を出典付きで出してくれる。

---

声A: Google AI Studio？

声B: これは圧倒的1位。
GeminiもNanoBananaも無料で使える。
台本も画像もこれ一つで完結します。

---

【CTA】
声B: 今日紹介したツールの使い方をまとめました。
○○をコメントで教えてね。
```

### 具体例（型B 複数プロンプト × 対話形式）

```
声A（男性）: 1日目。

声B（女性）: GenSparkにこのプロンプトを送ると、
今アツいジャンルをまとめてくれる。その中から選ぶ。

---

声A: 2日目。

声B: プロフィール作成。このプロンプトを使って
フォロー率の高いプロフィールを作る。

---

声A: 3日目から6日目。

声B: リール投稿。この3つの文字起こしをこのプロンプトと一緒に
ChatGPTに送ると、バズる台本を作ってくれる。

---

【CTA】
声B: 全手順とプロンプトをまとめました。
欲しい人は○○をコメントで教えてね。
```

### 注意点

- 対話形式は「演出」であって「型」ではない
- 型A〜Dと組み合わせて使う
- 2声が難しければ1声でも成立する（本質は同じ）

## 視覚情報: 図解・スライド

### 概要

Canva等で作った図解やスライドを背景に流す。

### 効果

1. **「パッと見て理解できる」** → 保存・シェアしたくなる
2. **図解を出すだけで「専門家感」「信頼感」を演出**
3. **「あとで見返そう」** → 保存率が高い

### 図解パターン例

| パターン | 例 |
|---|---|
| ステップ図 | 「①→②→③」の流れ |
| 層構造 | 「初級→中級→上級」のピラミッド |
| 比較図 | 「AとBの違い」を並べる |
| フロー図 | 「こうなったらこっち」の分岐 |

### 注意点

- **1枚のスライドに情報を詰め込みすぎると逆効果**
- **「1スライド1メッセージ」**を心がける
- 図解は視覚情報の選択肢であり、型（構成）ではない

## 制作手法: アフレコリール

**うちの標準制作手法**

### 概要

映像と音声を分けて制作。作業風景、AI生成映像、画面収録などのビジュアルに、後からナレーションを重ねる。

### 伸びる理由

1. **視覚+聴覚の両方に訴える** → 理解度UP
2. **顔出しなしでOK** → 参入障壁が低い、量産しやすい
3. **映像を楽しみながらノウハウを受け取れる** → 飽きにくい、最後まで見てもらいやすい

### 構成テンプレート

```
冒頭フック: テロップ+アフレコの一言で惹きつける
本編: 背景映像に合わせて、ノウハウやストーリーを説明
CTA: ナレーション+文字でアクションを促す
```

### 注意点

- **音声が単調だとすぐに離脱される**
- **抑揚やテンション**を意識する
- **無音再生の人のためにテロップ補完**は必須

---

## 制作手法: トークリール

### 概要

演者が直接カメラを見て語りかける形式。顔、声、表情がダイレクトに伝わる。

### うちでの使い方

顔出しなし方針だが、**アバター動画**（Hedra、Dreamina等）で同じ効果を狙える。

### 伸びる理由

1. **感情がストレートに伝わる** →「この人を信頼したい」と思わせやすい
2. **冒頭3秒で強い感情（怒り・悲しみ・驚き）** → スクロールを止めやすい
3. **「あなたもそう思いませんか？」と問いかけ** → 視聴者を参加させ、コメント率UP
4. **人柄・ストーリーを前面に出せる** → ファン化に直結

### 構成テンプレート

```
冒頭: 感情をのせた一言（悲しい/怒り/驚き）
理由: なぜそれが大事かを熱弁
解決: 具体的なノウハウや事例を提示
結論: 視聴者への問いかけ+CTA
```

### 冒頭フック例

| 感情 | 例 |
|---|---|
| 怒り | 「これマジでやめてほしい」 |
| 悲しみ | 「正直、もう無理だと思ってた」 |
| 驚き | 「これ知った時、衝撃だった」 |

### 注意点

- 背景・服装・ライティングなどの「画面の雰囲気」も影響
- **話が長いと離脱される**ので、要点を短くまとめる

## 制作手法: vlogリール

### 概要

モーニングルーティンや作業風景など、生活感のある映像の中で、合間にノウハウ・自分の考えを語るスタイル。

### うちでの使い方

顔出しなしでも「**作業風景**」「**画面収録**」で疑似vlog的なアプローチが可能。

### 伸びる理由

1. **属人性が高い** → ファン化しやすい
2. **リアルな日常** → 視聴者との距離を縮め、親近感が生まれる
3. **いろんなジャンルと掛け合わせ可能** → どんな発信者でも取り入れやすい

### 構成テンプレート

```
フック: 日常のワンシーン（作業風景、ツール起動など）
展開: 生活シーンを見せながら、合間にノウハウや価値観を加える
結論: 視聴者への問いかけ+CTA
```

### 注意点

- **ただの日常映像を流すだけでは伸びない**
- **プチノウハウ・体験談・自分の価値観**を加えることが重要
- 「見せる」だけでなく「伝える」要素が必要

| 実績の誇張 | 「10億達成した○○が」 | 嘘になる |

## 特典の棚卸しフロー

### なぜ棚卸しが必要か

特典は「うちが持っている実体」から選ぶ。
実体がないのに特典を作ると、嘘になるか、価値のないものになる。

### 棚卸しの評価軸

特典の価値は以下の4軸で評価する：

| 軸 | 説明 | 高評価の例 |
|---|---|---|
| **日常使い** | 普段の作業で使えるか | 毎日の投稿に使える |
| **効率化** | いつもの作業が楽になるか | 1時間→10分になる |
| **稼げる可能性** | 収益につながるか | 副業・集客に直結 |
| **SNS関連** | 投稿に直結するか | Instagram/X/YouTube |

### 高評価になりやすいもの

```
SNS投稿 × 稼げる可能性 = 最も需要が高い
```

- SNS投稿に使える画像プロンプト
- リール/ショート動画の台本テンプレート
- サムネイル・アイキャッチのプロンプト
- バズる投稿の構造

### 低評価になりやすいもの

- 技術者向けすぎるもの（n8nワークフロー、GASコード）
- 汎用的すぎて「いつ使うか」が不明確なもの
- SNS投稿に直結しないもの

### 棚卸しのフロー

```
1. 講座コンテンツを確認
   └ 実際に使っているプロンプト、手順、ツール情報を洗い出す

2. 4軸で評価
   └ 日常使い / 効率化 / 稼げる / SNS関連

3. 高評価のものを特典候補に
   └ 特に「SNS × 稼げる」が重なるもの

4. 投稿とセットで設計
   └ この特典を「すごい」と思わせる投稿は何か？
```

---

## 「すごい」と思わせる = 権威性

### 本質

投稿の役割は「特典がすごい」と思わせること。

```
視聴者: 「この人が使ってるプロンプトすごい」
     ↓
視聴者: 「それ欲しい」
     ↓
特典: 実際にそのプロンプトを渡す
```

### 権威性の作り方

| 方法 | 例 |
|---|---|
| **成果を見せる** | 「これ、5分で作りました」「この方法で○○できました」 |
| **問題を解決する** | 「まだ○○で困ってる？」「これで解決」 |
| **効率化を見せる** | 「1時間かかってた作業が10分に」 |
| **常識を覆す** | 「みんな○○使ってるけど、実は△△の方がいい」 |

### 権威性 ≠ 嘘

- 本当に成果が出たものを見せる
- 本当に効率化できるものを紹介する
- 本当に良いと思うものを推す

**嘘の権威性はダメ**（「月100万稼いだ」等の誇張）

---

## 制作フロー

### 推奨フロー

```
1. 特典を決める
   └ 棚卸し結果から、高評価のものを選ぶ
   └ 「SNS × 稼げる」が重なるものが理想

2. 「すごい」と思わせるポイントを決める
   └ この特典の何がすごいのか？
   └ 成果？効率化？問題解決？

3. 型を選ぶ
   └ 型A〜Eのどれが適しているか

4. 演出手法を選ぶ
   └ 対話形式 or 単独ナレーション

5. 視覚情報を選ぶ
   └ AI映像 / 画面収録 / 図解 / 成果物映像

6. 投稿を設計する
   └ 特典の「すごさ」を見せる構成
   └ 「このプロンプト」「このツール」で詳細は特典へ

7. トリガーワードを決める
   └ 答えやすいものを選ぶ

8. 台本を作成する
   └ 投稿と特典が連動しているか確認
```

### チェックリスト

#### 投稿
- [ ] 嘘がないか
- [ ] 「このプロンプト」「このツール」等で特典への期待を作れているか
- [ ] 詳細を言いすぎていないか（特典の価値を残しているか）

#### 特典
- [ ] 投稿で言った内容の「詳細」になっているか
- [ ] 視聴者が「それが欲しかった」と思える内容か
- [ ] うちが実際に持っている情報か

#### 連動
- [ ] 投稿を見た人が特典を欲しくなる流れになっているか
- [ ] 投稿と特典が1セットとして成立しているか
