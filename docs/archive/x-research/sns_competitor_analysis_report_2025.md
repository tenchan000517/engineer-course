# 2025年版 SNS競合調査 完全無料マニュアル

本レポートでは、2025年12月時点で有効な、**完全無料**で行えるSNS競合調査のツールと具体的な調査手順をまとめました。

## 概要: 無料リサーチの考え方

無料ツールは「期間制限」や「回数制限」がある場合がほとんどです。そのため、**「無料ツールで全体像をざっと把握し、手動リサーチで深掘りする」**というハイブリッドなアプローチが最も効率的かつ高精度です。

---

## 1. YouTube 競合調査（無料編）

動画コンテンツは情報量が多いため、ツールでの効率化が鍵となります。

### 推奨無料ツール

| ツール名 | お勧め機能・使い方 | URL |
| :--- | :--- | :--- |
| **vidIQ** (Chrome拡張) | **必須導入**。インストールするだけで、他人の動画の「タグ」「SEOスコア」「1時間あたりの再生数(VPH)」がブラウザ上に表示されます。競合が狙っているキーワードが丸裸になります。 | [Chrome Store](https://chrome.google.com/webstore/detail/vidiq-vision-for-youtube/pachckjkecffpdphbpmfolblodfkgbhb) |
| **Social Blade** | チャンネルの「成長推移」を確認します。急激に伸びた時期（スパイク）を見つけ、その時期に投稿された動画を特定するのに使います。 | [Social Blade](https://socialblade.com/) |
| **NoxInfluencer** | **日本国内のトレンド**把握に強いです。簡易的な検索ならログインなしでも使用可能。「登録者推移」や「平均再生数」で競合の体力を測ります。 | [NoxInfluencer](https://jp.noxinfluencer.com/) |

### 手動リサーチ手順（泥臭い深掘り）

1.  **「フィルター」機能の活用**:
    *   競合チャンネルの動画一覧を開き、「**人気順 (Most Popular)**」に並べ替えます。→ **そのチャンネルの最大ヒット（ホームラン）**がわかります。
    *   次に「**古い順 (Oldest)**」を見て、初期のコンセプトを確認します。
2.  **「最近のヒット」を探す**:
    *   「動画」タブで直近1ヶ月〜3ヶ月の動画を見ます。**「チャンネル登録者数に対して、再生数が異常に多い動画」**（アベレージを超えている動画）を探します。これが「今、需要があるネタ」です。
3.  **コメント欄分析**:
    *   「新しい順」に並べ替え、視聴者の「生の声（不満や要望）」を拾います。「もっと〇〇について知りたい」「ここが分かりにくかった」というコメントは、**あなたの動画で解決すべき差別化ポイント**です。

## 2. X (旧Twitter) 競合調査（無料編）

Xはフロー型情報のため、ツールでの過去ログ検索には限界があります。「高度な検索」コマンドが最強の武器になります。

### 推奨無料ツール

| ツール名 | お勧め機能・使い方 | URL |
| :--- | :--- | :--- |
| **whotwi** | ログイン不要で、特定IDの「仲良しの人（よく絡む人）」「投稿時間の傾向」「よく使う言葉」が分かります。競合のペルソナ分析に最適です。 | [whotwi](https://ja.whotwi.com/) |
| **SocialDog** (無料版) | 機能制限はありますが、「キーワードモニター」などの一部機能は優秀。自身の運用補助ついでに競合のインサイトも一部見れます。 | [SocialDog](https://social-dog.net/) |
| **Twittrend** | 「今」日本で何が流行っているか、地域別のトレンドを把握します。 | [Twittrend](https://twittrend.jp/) |

### 手動リサーチ手順（高度な検索コマンド）

Xの検索窓に以下のコマンドを入力することで、有料ツール顔負けの情報を引き出せます。

1.  **競合の「バズったツイート」だけ抽出する**:
    *   コマンド: `from:ユーザーID min_faves:100`
    *   意味: そのユーザーの投稿の中で、100いいね以上のものだけを表示。数字は規模に合わせて調整してください。これで**「何がウケたか」**が一発で分かります。
2.  **競合への「批判」や「要望」を探す**:
    *   コマンド: `to:ユーザーID -from:ユーザーID`
    *   意味: そのユーザーへのリプライ（返信）のみを表示（本人の返信は除く）。カスタマーサポート的なやり取りが見えるため、**競合の弱点やユーザーの不満**が見つかります。
3.  **特定期間の投稿を見る**:
    *   コマンド: `from:ユーザーID since:2024-01-01 until:2024-12-31`
    *   過去のキャンペーン時の動きなどを追うのに便利です。

## 3. WEBサイト・Instagram・その他

### Instagram (無料)
*   **スマホアプリを活用**: 現在、InstagramのAPI制限により、サードパーティの完全無料・高機能ツールは生存競争が激しいです。PCブラウザではなく、スマホアプリで「発見タブ」のリールを観察するのが最も鮮度が高いです。
*   **SaveIGなどの保存ツール**: 競合のストーリーズやリールを透かしなしで保存し、手元で構成を分析します（※再アップロードは厳禁）。
*   **HINOME (無料プラン)**: 分析ツールとして優秀です。まずは無料枠で自社分析しつつ、競合のアカウントの動きと比較します。

### 全体・WEB検索
*   **Google Trends**: [trends.google.co.jp](https://trends.google.co.jp/)
    *   キーワードの人気推移を比較。「今、この話題は右肩上がりか？」を確認します。
*   **SimilarWeb** (無料版): [similarweb.com](https://www.similarweb.com/)
    *   競合の「Webサイト」がある場合、どこからSNS流入があるかを確認できます。

## 4. 分析まとめフォーマット（スプレッドシート用）

調査結果はただ見るだけでなく、以下のような項目でスプレッドシートにまとめると、後の施策に活かしやすくなります。

| 分析項目 | 記入例・チェックポイント |
| :--- | :--- |
| **基本情報** | アカウント名、URL、フォロワー数、開始日 |
| **定量的指標** | 平均いいね数、平均再生数、投稿頻度（週何回？） |
| **勝者のコンテンツ** | 最も伸びた投稿のURL、タイトル、サムネイルの特徴 |
| **ターゲット層** | コメント欄から推測される年齢層・性別・悩み |
| **強み (Good)** | 編集のテンポが良い、返信がマメ、キャラが立っている |
| **弱み (Bad)** | 更新が不定期、音声が聞き取りにくい、情報の鮮度が低い |
| **差別化アイデア** | **「彼らがやっていないことで、自分ならできること」**を書く |
