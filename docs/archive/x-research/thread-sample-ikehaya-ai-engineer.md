## 【1ツイート目】本文（長文ポスト）

```
【宣言：プログラミング知識ゼロですが、AIエンジニアを目指します！】

イケハヤです。

ゴールデンウィークも終盤ですが、皆さんいかがお過ごしですか？

いやー、ぼくは昨日からちょっと「興奮」してしまって、あまり眠れてないんですよ。

というのも、昨日、友人の経営者（が遊びに来てくれて、すごいものを見せてもらったんです。

それは何かというと、「AIを使って、プログラミング知識がなくても開発ができてしまう」という現実です。

彼自身、自社の業務に特化した「AIエージェント」を作って、業務効率化をバリバリ進めていると。

正直、衝撃でした。

「え、今こんなことできるの！？」って。

ぼく自身は、エンジニア的な知識はほぼゼロです。

中学生の頃にJavaScriptを少しかじったくらいで、Pythonってどうやって実行するの？ というレベルです。

でも、AIツールを使えば、ぼくみたいな人間でも開発っぽいことができちゃうんですね……。

====

昨日から早速「WindSurf」というツールを教えてもらって触ってるんですが、たとえば「仮想通貨ニュースを拾ってきて、イケハヤ風にまとめる」みたいなデモなら、30分くらいで作れちゃいました。

AIに「こんな感じにしたいんだけど」って自然言語で指示するだけで、コードを書いてくれるんですよ……。

分からなければ、AI（チャッピー）に聞けばいい。AIが先生になってくれる時代です。すごい。

なので、ぼく、今月ひとつ目標ができました。

「AIでプログラミングができるようになる」

そして、「自分の業務に特化したAIエージェントを作る」

幸い、AIのおかげで書籍の執筆が思ったより早く終わって、今月は少し時間ができそうです。

この時間を使って、がっつりAI開発を学びます。

====

これ、たぶん今、多くの人にとっては「自分には関係ない話」と思えるかもしれません。

でも、ぼくみたいな「ノンエンジニア」でも、もうツール開発とかアプリ開発ができちゃうんですよ。

これは、「開発の民主化」が始まっているということです。

たとえば、ぼくらの「クリプトニンジャ」事業や「Ninja DAO」でも、このスキルは革命を起こす可能性があります。

今、Ninja DAOのメンバーはAIを使ったコンテンツ制作（イラスト、アニメ、漫画着色など）はかなり先進的にできるようになってきていますが、開発の部分はまだこれからです。

もしメンバーのみんなが、日々の定型業務を自動化するような「専用ツール」を自分で作れるようになったら？

たとえば日々の業務の分析や改善、顧客レスポンス、コンテンツ制作なんかも、かなりのレベルで自動化できるでしょう。

これは生産性が爆上がりしますよね。

今までは「こういうツールがあったら便利だけど、開発はお金がかかるし……」と思っていたものが、自分たちで作れてしまう。

しかも、外部のSaaSを使うより、自分たちの業務に完全に「カスタマイズ」されたものが作れる可能性だってあるわけです。

これは、システムの「内製化」がめちゃくちゃ進むということですよね。

====

煽るようですが、この「AI開発」の波は、想像を絶するインパクトになるでしょう。

正直、今プログラミング言語を一から勉強している人は、ちょっと考え直した方がいいですね……。

このタイミングで「AI開発」を理解しておくと、1年後、さらにすごいことができるようになっているはず。

ぼく自身、まずは体を張ってしっかりAI開発を学習します。

実際に何か作って、「ほら、こんなのできましたよ！」と皆さんにお見せできるように、今月頑張ります。

皆さんも、もし関心があれば、ぜひ「WindSurf」あたりから触ってみるのがいいかもしれません。月額15ドルとか、めちゃくちゃ安くて驚きました。

====

本当に、今は面白い時代です。

NFTやWeb3が盛り上がった時も楽しかったけど、それとはまた質の違う楽しさがAIにはあります。

このタイミングでAIを楽しめるかどうかで、次の時代で生き残れるかが変わってくる、と本気で思っています。

ぼくもがっつり勉強しますので、皆さんもぜひ注目してみてください。新しいことを学ぶのは楽しいですね！
```
