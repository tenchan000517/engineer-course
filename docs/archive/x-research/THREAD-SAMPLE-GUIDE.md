# 参考スレッドの保存ガイド

## 保存場所

```
content/modules/x-research/thread-sample-{トピック}.md
```

## ファイル命名規則

```
thread-sample-{トピック}.md
```

例：
- `thread-sample-gem-notebooklm.md`
- `thread-sample-cursor-agent.md`
- `thread-sample-n8n-automation.md`

---

## フォーマット

```markdown
# スレッドサンプル: {タイトル}

## 【1ツイート目】フック

` ` `
{フック全文}
` ` `

---

## 【2ツイート目】{見出し}（1/N）

` ` `
{本文全文}
` ` `

---

## 【3ツイート目】{見出し}（2/N）

` ` `
{本文全文}
` ` `

---

（以下、ツイート数分繰り返し）

---

## 【最終ツイート】まとめ

` ` `
{まとめ全文}
` ` `
```

---

## ルール

1. **一言一句そのまま保存** - 改変・省略しない
2. **コードブロックで囲む** - 各ツイートは ` ` ` で囲む
3. **区切り線を入れる** - 各ツイート間に `---` を入れる
4. **見出しを付ける** - `## 【Nツイート目】{内容}` 形式
