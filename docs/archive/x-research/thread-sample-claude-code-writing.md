# スレッドサンプル: Claude Code ライター活用

## 【1ツイート目】本文

```
Claude Codeは、開発以外にも活用できる。

例えば、100以上のファイルを読み込んでレポートを作るケース。

今回は「2025年AIニュースまとめ100選」のブログ作成にClaude Codeを使用し、2万文字超の記事を作れた。

ChatGPTは通常チャットだと10ファイルが上限で、他のAIツールでも高精度な長文記事は難しい。

一方、Claude Codeは長時間の実行力が高く、細部まで確認しながら質の高い記事を作れる。

手順はこちら。

① noteから1年分の記事をダウンロード
② Claude Codeでローカルファイルを選別
③ 内容をもとにファクトチェックしつつ記事作成
④ チャットしながら随時修正して完成

API経由でClaudeを叩いているため、Web版と比べてコンテキスト制限に引っかかりにくい。

ライター業務でも、かなり使える。
```
