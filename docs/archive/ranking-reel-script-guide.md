# ランキングリール台本作成ガイド

## 台本作成フロー

1. ユーザーが「ランキング形式の台本を作ってください」と依頼
2. Claude Codeが以下のテーマ選択肢を提示：
   1. 2026年SNSに使えるAIツールランキング
   2. 2026年動画編集に使えるAIツールランキング
   3. 2026年アプリ開発に使えるAIツールランキング
   4. 2026年「作業効率が爆上がりする」AIツールランキング
   5. 2026年「売れるクリエイティブ」を作るAIツールランキング
   6. 2026年「顔出し無しで伸ばす」AIツールランキング
   7. 2026年「情報発信×調査」で勝つAIツールランキング
3. ユーザーがテーマを選択
4. Claude Codeが台本作成プロンプトの「ランキングテーマ: {ここにテーマを入力}」をユーザーが選択したテーマに置き換えて出力
5. ユーザーがAIで生成した台本をClaude Codeに貼る
6. Claude Codeが台本から以下を抽出し、特典用プロンプト生成プロンプトのプレースホルダーを埋めて出力
   - {2位ツール名}
   - {1位ツール名}
   - {種類}：プロンプト系 or 非プロンプト系
   - {できること}：「このプロンプトを投げれば〇〇ができます」または「〇〇ができます」の〇〇
7. ユーザーがプロンプト生成プロンプトを実行
8. 結果をClaude Codeに貼る
9. Claude Codeがテスト用プロンプトを作成
   - プロンプト系：プレースホルダーを実際の値で埋めた状態で出力
   - 非プロンプト系：手順はそのまま出力
10. ユーザーが検証（実際に動くか確認）
    - プロンプト系：出力されたプロンプトをツールに投げて、期待通りの結果が出るか確認
    - 非プロンプト系：手順通りにやってみて、できるか確認
    - NGならClaude Codeに報告 → 修正 → 再度テスト用出力 → 再検証
11. 特典ページ作成（`content/guides/gift-page-creation-guide.md` 参照）
12. キャプション作成（本ファイルの「キャプション作成ルール」参照）
13. ナレーション整形（本ファイルの「ナレーション用フォーマット」参照）

## プレースホルダー定義

| プレースホルダー | 定義 |
|---|---|
| 論外の理由 | そのツールが論外である具体的な理由。制限や微妙な点を挙げる（例：無料版だと画像は1日3枚まで） |
| ツール名２の用途 | 2位ツールが最も得意とする用途（例：リールのネタ探し） |
| ツール名２のメリット１ | 2位ツールの1つ目のメリット（例：最新情報を出典付きで出力してくれる） |
| よくある不安 | ユーザーが抱えがちな不安（例：根拠が曖昧じゃない？これって最新情報？） |
| ツール名２のメリット２ | 2位ツールの2つ目のメリット（例：SNSやニュースからも情報を検索してくれる） |
| 得られる結果 | そのメリットで得られる具体的な成果（例：バズる旬のネタが効率よく見つかります） |
| ２位の特典説明 | プロンプト系：「このプロンプトを投げれば、〇〇ができます」 / 非プロンプト系：「〇〇ができます」（例：このプロンプトを投げれば、リール10本分の企画が一気に出ます / 字幕→カット編集まで"テキスト編集感覚"で一気に終わります） |
| ツール名３のメリット | 4位ツールのメリット（例：面倒なテロップ編集が10秒でできる） |
| 比較対象 | 比較するツールや基準（例：有料のCapCut） |
| 優れている点 | 比較対象より優れている点（例：精度も高い） |
| 用途 | 4位ツールの用途（例：動画を編集） |
| ツール名４の機能説明 | 3位ツールの機能（例：自分の声を登録して台本を読ませると、自然なアフレコを作ってくれる音声生成AI） |
| 自己言及や実演 | 実際に使っている証拠や問いかけ（例：この声もFish Audioって気づきましたか？） |
| ツール名４のメリット | 3位ツールのメリット（例：読み間違いもないし場所も選ばない） |
| 解決できる問題 | そのツールで解決できる問題（例：アフレコのハードルを下げてくれます） |
| ツール名５の概要説明 | 1位ツールの概要（例：SNS運用のワークフローをまとめて自動化できるAI） |
| ツール名５のメリット | 1位ツールのメリット（例：企画から投稿文まで一気通貫で作れる） |
| １位で解決できる問題 | 1位ツールで解決できる問題（例：毎回ゼロから作る手間がなくなります） |
| １位の特典説明 | プロンプト系：「このプロンプトを投げれば、〇〇ができます」 / 非プロンプト系：「〇〇ができます」（例：このプロンプトを投げれば、企画→構成→台本→撮影指示→投稿文まで一気通貫で完成します / 自然なアフレコが作れます） |
| ２位の特典内容 | CTAで使う2位の特典内容。プロンプト系：「〇〇に使えるプロンプト」 / 非プロンプト系：「〇〇の使い方」（例：リール企画に使えるプロンプト / 字幕編集の使い方） |
| １位の特典内容 | CTAで使う1位の特典内容。プロンプト系：「〇〇に使えるプロンプト」 / 非プロンプト系：「〇〇の使い方」（例：編集を自動化するプロンプト / アフレコ作成の使い方） |
| トリガーワード | コメントで答えやすい質問（例：今日何食べたか、好きな寿司ネタ、好きな季節） |

## ルール

1. **嘘をつかない** - ツールの機能やメリットは事実に基づくこと
2. **論外の理由は本当のこと** - 誇張や嘘はNG
3. **具体的な数字を入れる** - 「10秒で」「1日3枚まで」など
4. **口調はですます調** - ただし「論外」「2位」など順位部分は「です」不要
5. **1位は最も詳しく説明する** - メリット→解決できる問題→「このプロンプトを投げれば」の順
6. **順位はバラバラに出す** - 論外→2位→4位→3位→1位の順
7. **異なる用途のツールを横断的に選ぶ** - 同じジャンルのツール比較ではない
8. **論外は意外性を出す** - 知名度が高くてみんな使ってるけど実は微妙なツールを選ぶ（例：ChatGPT、CapCut、Canva）
9. **ニッチで価値のあるツールを選ぶ** - 一般的なツールより、知る人ぞ知るツール（Nano Banana Pro、Genspark、Fish Audio、Vrew等）を優先

ランキングテーマ: {ここにテーマを入力}

- 2026年「売れるクリエイティブ」を作るAIツールランキング
- 2026年「顔出し無しで伸ばす」AIツールランキング
- 2026年「情報発信×調査」で勝つAIツールランキング

入力例：

| 論外候補 | 2位候補 | 1位候補 |
|---|---|---|
| ChatGPT | Vrew | Genspark |
| CapCut | Fish Audio | Vrew |
| ChatGPT | Genspark | Google AI Studio |
| Notion AI | Comet | Genspark |

| CapCut | Fish Audio | Vrew |
| ChatGPT | Comet | Genspark |

## 出力形式

1. リサーチ結果（5ツールの概要と用途）
2. ランキング決定理由
3. 完成した台本

## 事前調査プロンプト

台本作成の前に、このプロンプトでテーマとツール候補を調査する。

```markdown
# 調査依頼：ランキングリール台本の入力例

## 背景

Instagramリールで「AIツールランキング」形式の台本を作成するプロンプトを作っています。
このプロンプトに入力する「ランキングテーマ」の例を調査してください。

## 要件

### テーマの粒度

以下のレベルの粒度で設定します：
- 2026年SNSに使えるAIツールランキング
- 2026年最も稼げる副業ランキング
- 2026年仕事で使えるAIツールランキング
- 2026年動画編集に使えるAIツールランキング
- 2026年アプリ開発に使えるAIツールランキング

### ツール選定の条件

1. **論外枠**：知名度が高くてみんな使ってるけど実は微妙なツール（例：ChatGPT）
2. **1位・2位枠**：ニッチで価値のあるツール（例：Nano Banana Pro、Genspark、Fish Audio、Google AI Studio、Vrew等）
3. **異なる用途のツールを横断的に選ぶ**：同じジャンルのツール比較ではない

### 台本の特徴

- 2位と1位で「このプロンプトを投げれば〇〇ができます」と紹介
- CTAで「2位の用途に使えるプロンプトと1位でできることのプロンプトをまとめました」と特典誘導

## 調査してほしいこと

1. 上記の粒度に合うランキングテーマを5〜10個提案
2. 各テーマに対して、論外・1位・2位の候補ツールを挙げる
3. 各ツールで「このプロンプトを投げれば〇〇ができます」の〇〇部分を提案
```
