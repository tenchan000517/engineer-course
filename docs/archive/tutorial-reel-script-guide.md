## SRTファイル作成ルール

ナレーション台本をPremiere Pro用のSRTファイル（字幕ファイル）に変換するルール。

### 基本ルール

- 1行8文字前後
- 最大2行
- 不自然な改行をするくらいなら少ない文字でOK
- 2行で収まらない場合は次の字幕に分割

### 話スピード（表示時間）

- 短いフレーズ（1行）: 0.5〜1秒
- 通常フレーズ（2行）: 1〜2秒
- 強調・間を取る箇所: 2〜4秒

### 表記ルール

- ツール名はアルファベット: `Nanobanana`、`KLING AI`、`Google AI`
- 数字は半角: `5,000万回`、`2つ`、`5分`

### 改行位置

意味の区切りで改行または分割する:

**2行でまとめる例**:
```
これあるAIを
使えば

たった5分で
できちゃいます
```

**別の字幕に分割する例**:
```
12
00:00:28,416 --> 00:00:29,083
このプロンプト

13
00:00:29,083 --> 00:00:29,958
を使って

14
00:00:29,958 --> 00:00:30,625
開始フレームの

15
00:00:30,625 --> 00:00:31,500
画像を作ります
```

### 間隔

- 通常: 字幕が連続
- セクション切り替え: 数秒の空白あり

### SRTファイルの形式

```
1
00:00:00,000 --> 00:00:01,000
実はこれ

2
00:00:01,000 --> 00:00:02,000
AIで作った

3
00:00:02,000 --> 00:00:04,000
ASMRベッド
動画なんです
```

### Premiere Proで読み込む

1. ファイル → 読み込み
2. SRTファイルを選択
3. タイムラインにドラッグ
4. 音声に合わせてタイミングを調整
