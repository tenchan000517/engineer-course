# AIツール名表記リスト

SRT作成時・ナレーション作成時に使用する正式表記リスト。

## 使い方

- **ナレーション作成時**: カタカナ表記を使用（Fish Audioで自然な日本語発音になる）
- **SRT作成時**: 英語表記を使用
- **バージョン番号**: リストにバージョンが入っている場合は、そのバージョンを必ず入れる（例: Veo 3.1とVeo 3は別物）
- **リストにないツール名**: 変換せずにユーザーに報告する。正しい表記が確定したらリストに追記する
