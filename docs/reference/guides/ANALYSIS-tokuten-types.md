# Instagram特典サンプル 型分析

28サンプルを分析した結果、以下の型を特定。

---

## B. 動画（リール）の型（7型）

### 1. ランキングリール
順位づけで紹介（5位→1位）。

| 特徴 | 効果 |
|------|------|
| カウントダウン形式 | 「1位が知りたい」で視聴完了率UP |
| 複数項目 | どれか1つは刺さる |
| 保存されやすい | まとめ感 |

**例**: miyu_ai「AI副業ランキング」、saki_aideai「魔法のフレーズ3選」

### 2. 比較リール
2つのパターンを対比。

| パターン | 例 |
|----------|-----|
| 失敗例 vs 成功例 | - |
| 初心者 vs プロ | reelda_「必須AIツール」 |
| 現実 vs AI | nextpiece「すっぴん vs AI美女」 |

### 3. アフレコリール
映像と音声を分離、ナレーション重ね。

| 特徴 | 効果 |
|------|------|
| 顔出し不要 | 参入障壁低い |
| 映像+声 | 理解度UP |

### 4. 解説系リール（チュートリアル）
ツールの使い方をステップで解説。

| 特徴 | 効果 |
|------|------|
| 操作画面キャプチャ | 再現性高い |
| 30秒〜1分で完結 | 「自分にもできそう」 |

**例**: sakura_kossori「鉄球AI動画」、waigo_ai「Kling Motion」

### 5. トークリール
顔出しで直接語りかけ。

| 特徴 | 効果 |
|------|------|
| 感情が伝わる | 信頼感・ファン化 |
| 問いかけ | コメント率UP |

**例**: ayane_insta「アカウント添削」

### 6. 変身デモリール
AIでの変身を視覚的にデモ。

| 特徴 | 効果 |
|------|------|
| ワイプで比較 | 技術の凄さが直感的 |
| 衣装・顔の変化 | 驚き |

**例**: nextpiece「現実 vs AI分身」、waigo_ai「白い紙→iPhone」

### 7. 衝撃映像フックリール
冒頭でインパクトのある映像。

| 特徴 | 効果 |
|------|------|
| 鉄球衝突、壁崩壊など | スクロール停止 |
| 「何が起こる？」 | 視聴完了率UP |

**例**: sakura_kossori「鉄球衝突」、SakiSNS「壁壊れフック」

## C. フック（冒頭）の型（8型）

### 1. 否定型
「〜しない限り稼げない」で危機感。

```
これら「3つのこと」をマスターしない限り、お金を稼ぐことはできない。
```

### 2. 問題提起型
「〜で悩んでいませんか？」で共感。

```
リールが全然伸びない…って悩んでいませんか?
```

### 3. 驚き型
「クレイジー」「衝撃」で興味喚起。

```
これ、本当にクレイジーです。
```

### 4. 比較型
現状と理想のギャップを提示。

```
現実の私は、ほら、すっぴんにパジャマ姿。でも、この「AIの私」はお出かけコーデでバッチリ決めてるでしょ？
```

### 5. 数字型
具体的な数字でインパクト。

```
今やれば100万再生も狙えるんです！
```

### 6. 疑問残し型
「なんで？」「誰のせい？」を誘発。

```
子供が片付けないのって、すごく良いこと
→「なんで！？」
```

### 7. 権威付け型
実績や有名人の名前を出す。

```
ChatGPTを作ったOpenAI社の社長が提唱しているフレーズで
```

### 8. 対比・断定型
「〇〇なら△△」の構造。

```
聞き方が雑なら、答えも雑。それがAI。
```

## D. CTA（コール・トゥ・アクション）の型（5型）

### 1. トリガーワード型
特定のキーワードをコメント。

| ワード | 効果 |
|--------|------|
| 「AI」 | シンプル、覚えやすい |
| 「ガイド」 | 何がもらえるか明確 |
| 「MASTER」 | 英語圏向け |
| 「教学」 | 中国語圏 |

### 2. 自由入力型
視聴者に自由に入力させる。

| 例 | 効果 |
|-----|------|
| 「好きな数字」 | 参加感UP |
| 「好きな果物」 | エンゲージメント向上 |
| 「今行きたい場所」 | コメント多様化 |

### 3. フォロー誘導型
フォローを直接促す。

```
今後も見逃さへんように、さきをフォローして待ってて！
```

### 4. LINE誘導型
公式LINEへ誘導。

```
公式LINEを登録してお待ちください
```

### 5. コンサル/有料サービス誘導型
有料へ直接つなげる。

```
下記リンクからコンサルティングを予約してください。
```

## E. 映像演出の型（6型）

### 1. ワイプ比較
画面を分割して元と変換後を同時表示。

**例**: nextpiece「現実の私 vs AIの私」

### 2. 操作画面キャプチャ
ツールの操作画面を録画。

**例**: 全チュートリアル系

### 3. プロンプトスクロール
プロンプトテキストをスクロール表示。

**例**: timkoda_「プロンプトの権威付け」

### 4. 変身トランジション
煙・モーフィングで変身。

**例**: SakiSNS「煙になって瞬間移動」、sakura_kossori「鉄球で消える」

### 5. 衝撃エフェクト
壁崩壊、物体衝突など。

**例**: SakiSNS「壁壊れフック」

### 6. AIアバター + リップシンク
AIキャラクターが口パクで喋る。

**例**: timkoda_、nextpiece

## F. 型の組み合わせパターン

### パターン1: チュートリアル基本形
```
解説系リール + ツールSOP + トリガーワードCTA
```

### パターン2: ランキング＋深掘り
```
ランキングリール + 1位のみツールSOP + 自由入力CTA
```

### パターン3: 衝撃フック＋解説
```
衝撃映像フック + 解説系リール + トリガーワードCTA
```

### パターン4: 比較＋ツール紹介
```
比較リール + 複数ツール紹介 + フォロー誘導CTA
```

### パターン5: フレームワーク提示
```
トークリール + フレームワーク型 + LINE誘導CTA
```
