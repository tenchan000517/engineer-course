# Instagram特典サンプル分析・プロンプト生成メタプロンプト

このプロンプトを別のAIに渡すことで、サンプルの分析と再現性のある投稿作成プロンプトを生成させることができます。

---

## 使い方

1. 以下のプロンプト全体をコピー
2. ChatGPT / Claude / Gemini 等に貼り付け
3. サンプルデータを添付または貼り付け
4. 実行

---

## メタプロンプト（ここからコピー）

```
あなたはInstagramマーケティングの分析専門家であり、
コンテンツ戦略のプロンプトエンジニアです。

これから提供するInstagram特典サンプル（リール台本、特典コンテンツ）を分析し、
再現性の高い投稿を作成するためのプロンプトを生成してください。

# PHASE 1: サンプル分析

## 1-1. 分析対象
以下のサンプルを分析してください：

{ここにサンプルを貼り付け、または「添付ファイルを参照」と記載}

## 1-2. 抽出すべき型（カテゴリ）

以下の5つの観点で型を抽出してください：

### A. 特典コンテンツの型
サンプルの特典がどのような形式で提供されているかを分類。
例：
- ツール使い方SOP型
- プロンプト集型
- フレームワーク型
- GPTs提供型
- 比較形式型
- 添削・レビュー型
- 完全マニュアル型

### B. 動画（リール）の型
サンプルの動画がどのような構成で作られているかを分類。
例：
- ランキングリール
- 比較リール
- アフレコリール
- 解説系リール
- トークリール
- 変身デモリール
- 衝撃映像フックリール

### C. フック（冒頭）の型
冒頭3秒でどのように視聴者の注意を引いているかを分類。
例：
- 否定型（「〜しない限り稼げない」）
- 問題提起型（「〜で悩んでいませんか？」）
- 驚き型（「これ、マジでクレイジー」）
- 比較型（「現実の私 vs AIの私」）
- 数字型（「100万再生」「月〇〇万」）
- 疑問残し型（「〜って実は良いこと」→「なんで!?」）
- 権威付け型（「〇〇社の社長が提唱」）

### D. CTA（行動喚起）の型
視聴者にどのようなアクションを促しているかを分類。
例：
- トリガーワード型（「AI」「ガイド」等をコメント）
- 自由入力型（「好きな果物」「好きな数字」）
- フォロー誘導型
- LINE誘導型
- コンサル誘導型

### E. 映像演出の型
どのような映像表現が使われているかを分類。
例：
- ワイプ比較
- 操作画面キャプチャ
- プロンプトスクロール表示
- 変身トランジション
- 衝撃エフェクト
- AIアバター＋リップシンク

## 1-3. 出力フォーマット（分析結果）

以下の形式で分析結果を出力してください：

```markdown
# 分析結果

## A. 特典コンテンツの型（〇型）

| # | 型名 | 説明 | 該当サンプル |
|---|------|------|--------------|

## B. 動画（リール）の型（〇型）

| # | 型名 | 特徴 | 効果 |
|---|------|------|------|

## C. フック（冒頭）の型（〇型）

| # | 型名 | パターン | 例文 |
|---|------|----------|------|

## D. CTA（行動喚起）の型（〇型）

| # | 型名 | 特徴 | 例文 |
|---|------|------|------|

## E. 映像演出の型（〇型）

| # | 型名 | 説明 | 使用シーン |
|---|------|------|------------|

## 合計: 〇型
```

# PHASE 2: プロンプト生成

分析結果をもとに、以下のプロンプトを生成してください。

## 2-1. 生成すべきプロンプト一覧

1. **リール台本作成プロンプト（マスター版）**
   - 動画の型を選択式で指定できる
   - フックの型を選択式で指定できる
   - CTAの型を選択式で指定できる
   - 出力は時間・映像・テロップ・セリフの表形式

2. **特典コンテンツ作成プロンプト（マスター版）**
   - 特典の型を選択式で指定できる
   - ステップバイステップの構成
   - コピペ用プロンプトを含める指示

3. **フック作成プロンプト**
   - 1つのテーマから複数パターンのフックを同時生成
   - 各フックに「なぜ効くか」の解説付き

4. **CTA作成プロンプト**
   - 1つの特典から複数パターンのCTAを同時生成
   - 押し売り感を消す言い回しを含む

5. **競合分析→超える台本生成プロンプト**
   - 競合の台本を入力として受け取る
   - 構成を分解し、改善点を抽出
   - 改善版の台本を出力

6. **AIフック映像プロンプト生成プロンプト**
   - フックの型を選択
   - 画像生成プロンプト（英語）を出力
   - 動画生成プロンプト（英語）を出力
   - 日本語訳も添える

## 2-2. 各プロンプトの構成要件

各プロンプトには以下を含めてください：

```
## 入力情報
- ユーザーが入力すべき項目を【】で明示
- 選択式の場合は選択肢を列挙

## 出力フォーマット
- 具体的な出力形式を指定
- 表形式、箇条書き等を明示

## 制約条件
- 品質を担保するためのルール
- やってはいけないこと
```

## 2-3. 出力フォーマット（プロンプト）

以下の形式で各プロンプトを出力してください：

```markdown
# プロンプト〇: {プロンプト名}

## 概要
{このプロンプトで何ができるか、1-2文}

## プロンプト本文
```
{ここにプロンプト全文}
```

## 使い方
1. {ステップ1}
2. {ステップ2}
3. {ステップ3}

## 出力例
{このプロンプトを使った場合の出力イメージ}
```

# PHASE 3: 組み合わせガイド

最後に、プロンプトの組み合わせパターンを提案してください。

## 3-1. 出力フォーマット

```markdown
# 組み合わせ推奨パターン

| 目的 | 使うプロンプト | 順序 |
|------|----------------|------|
| {目的1} | {プロンプト番号} | {使う順序} |
| {目的2} | {プロンプト番号} | {使う順序} |
```

---

# 制約条件（全体）

1. **アレンジを加えない**: サンプルに含まれる要素のみを抽出し、独自の解釈を加えない
2. **具体例を引用**: 型を説明する際は、必ずサンプルから具体例を引用する
3. **再現性重視**: 他の人が同じ品質で再現できるよう、詳細に記述する
4. **日本語で出力**: 分析結果・プロンプトともに日本語で出力（AIプロンプトは英語+日本語訳）
5. **数を明示**: 各カテゴリで何型あるかを数字で明示

---

# 出力の流れ

1. まず PHASE 1 の分析結果を出力
2. 次に PHASE 2 の各プロンプトを出力
3. 最後に PHASE 3 の組み合わせガイドを出力

準備ができたら、サンプルデータの分析を開始してください。
```

## 補足: サンプルデータの準備方法

### 方法1: 既存の分析結果を渡す
`ANALYSIS-tokuten-types.md` をそのまま渡し、「この分析をもとにプロンプトを生成して」と依頼。

### 方法2: 生サンプルを渡す
各特典の内容をそのまま貼り付け、1から分析させる。

### 方法3: 要約して渡す
各サンプルの「台本のポイント」「特典の特徴」セクションのみを抽出して渡す。

---

## このメタプロンプトの特徴

1. **2フェーズ構成**: 分析→生成の順序を明確化
2. **型の定義を事前提示**: 抽出すべき観点を5つに限定
3. **出力フォーマット固定**: 表形式で統一し、比較しやすく
4. **制約条件明示**: アレンジを禁止し、再現性を担保
5. **組み合わせガイド**: 実用的な使い方まで出力させる
