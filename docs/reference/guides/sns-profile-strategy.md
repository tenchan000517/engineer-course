## Step 1: プロフィール設計(第一印象で勝つ)

### X (Twitter) プロフィール

#### アイコン戦略
- **NG例:** 顔写真、風景、アニメキャラ
- **正解:**
  - パターンA: 作業中の横顔(ディスプレイの光で顔が照らされてる感じ)
  - パターンB: 「元和菓子屋→月収○○万」の文字入り画像
  - **重要:** 背景は暗め、コントラスト強め = タイムラインで目立つ

#### ヘッダー画像
```
【推奨デザイン】
左側: 和菓子屋時代の写真(モノクロ、暗い)
右側: 現在のPC作業環境(カラー、明るい)
中央: 大きく矢印「→」

テキストオーバーレイ:
「3年前:時給950円 → 今:時給2万円」
「変えたのはAIツールだけ」
```

#### プロフィール文(160文字の魔法)

```
元和菓子屋(クビ) → 月収○○万エンジニア

ChatGPT使ってる人、損してます
Cursor × Claude Codeで人生変わった

文系/未経験/40代からでも
AIで誰でも稼げる時代を証明中

3年で500人がフリーランス化
プロンプト集を固定ツイートで無料配布

#AI副業 #フリーランスエンジニア
```

**プロフィール設計の原則:**
- 数字を3つ入れる(信頼性)
- 対立構造を入れる(ChatGPT vs Cursor)
- 実績を入れる(500人指導)
- プレゼントを入れる(無料配布→フォロー誘導)
- ハッシュタグ2つ(検索流入)
