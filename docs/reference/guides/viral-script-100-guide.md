# InstagramリールとYouTubeショート動画でバズった投稿台本100選

3つの専門家視点（SNSバズるプロ・映像クリエイター・AIツール専門家）から、2026年最新のバズり投稿を分析し、すぐに使える台本を100個厳選しました。

---

## 基本構成の黄金ルール

### バズる動画の共通点
- **冒頭1-3秒**：視聴者の手を止める強力なフック
- **文字数**：300-400文字（15-60秒動画）
- **構成**：問題提起 → 解決策 → ベネフィット
- **テンポ**：2-3秒ごとにカットチェンジ
