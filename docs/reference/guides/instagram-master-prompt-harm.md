## 📌 HARMの法則とは

人間の行動を促す4つの根源的欲求:
- **H (Health)**: 健康・美容・体型・若さへの欲求
- **A (Ambition)**: 成功・キャリア・富・地位への欲求
- **R (Relationship)**: 人間関係・愛情・承認への欲求
- **M (Money)**: 金銭・資産・経済的自由への欲求

この法則を各投稿のフックとベネフィット設計に組み込みます。

## 💡 HARM法則の深掘り解説

### **各HARMの具体的訴求例**

#### **H (Health) - 健康・美容・体型**
```
✅ 良い例:
- 「1日10分で理想の体型に」
- 「睡眠時間を削らずに副業する方法」
- 「ストレスなく稼げるAI活用術」

❌ 悪い例:
- 「健康的に稼げます」（抽象的）
- 「病気になりません」（薬機法違反）
```

#### **A (Ambition) - 成功・キャリア・地位**
```
✅ 良い例:
- 「会社員から独立できた方法」
- 「フォロワー1万人達成のロードマップ」
- 「AIで差をつけるキャリア戦略」

❌ 悪い例:
- 「成功者になれます」（抽象的）
- 「絶対に独立できます」（誇大）
```

#### **R (Relationship) - 人間関係・承認**
```
✅ 良い例:
- 「家族に誇れる副業の始め方」
- 「SNSで影響力を持つ方法」
- 「周囲から尊敬される専門性の磨き方」

❌ 悪い例:
- 「友達が増えます」（曖昧）
- 「絶対にモテます」（関連性なし）
```

#### **M (Money) - 金銭・経済的自由**
```
✅ 良い例:
- 「初月から5万円稼いだ方法」
- 「月10万の副業収入ロードマップ」
- 「スキマ時間で収益化する仕組み」

❌ 悪い例:
- 「絶対に稼げます」（誇大）
- 「月100万円確実」（景表法違反）
```
