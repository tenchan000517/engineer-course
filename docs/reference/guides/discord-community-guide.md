### 決済連携の完全自動化【最重要】

#### 仕組み: Stripe → Zapier/Make.com → Discord

```
【フロー図】

顧客が29.8万円決済（Stripe）
    ↓
Webhookトリガー発火
    ↓
Zapier/Make.comが検知
    ↓
顧客のメールアドレスを取得
    ↓
Discordアカウントを検索
    ↓
「有料メンバー」ロールを自動付与
    ↓
ウェルカムメッセージ自動送信
    ↓
キックオフ面談予約リンク送信
```

#### 設定手順（Make.com使用）

**Step 1: Stripe Webhook設定**

```
1. Stripe Dashboard → 開発者 → Webhook
2. 新しいWebhookを追加
3. イベント選択: checkout.session.completed
4. Webhook URLを控える
```

**Step 2: Make.comシナリオ作成**

```
モジュール1: Stripe Webhook
→ イベント: checkout.session.completed

モジュール2: データ抽出
→ 顧客メールアドレス
→ 商品名
→ 決済額

モジュール3: Discordユーザー検索
→ メールアドレスでDiscord IDを検索

モジュール4: Discordロール付与
→ 「有料メンバー」ロールを付与

モジュール5: Discord DM送信
→ ウェルカムメッセージ
→ キックオフ面談予約リンク
→ 事前アンケートリンク

モジュール6: Notion/Airtableに記録
→ 購入者リストに自動追加
→ ステータス: 「購入完了」
```

**Step 3: テスト決済**

```
1. Stripe テストモードで決済実行
2. Make.comのログを確認
3. Discordでロール付与を確認
4. DMが届くか確認
```
